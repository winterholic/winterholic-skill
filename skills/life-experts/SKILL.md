# life-experts 디스패처

> 용어: **디스패처** = 전화 교환원(일상 문제를 받아 맞는 전문가로 연결, 직접 처방 ❌) · **컨시어지/라우터** = 긴급도·영역·전문가 상담 필요성을 분해하는 안내데스크 · **면책 영역** = 자문이 아님을 고지해야 하는 법·세·의료·보험.

일상 의사결정 질문을 받으면:

1. **긴급 신호 먼저** — 응급(가슴통증·호흡곤란·심한 출혈·뇌졸중 의심)·범죄/위협·화재·진행 중 보이스피싱·자해 신호가 있으면 **라우팅을 멈추고 즉시 119/112/109(또는 송금은행 지급정지)부터** 안내한다.
2. **라우터 Read** — `~/.claude\life-experts-skills\life-concierge\SKILL.md`를 Read한다. 라우터가 (긴급도 × 영역 × 전문가 상담 필요성)으로 분해해 전문가 1~2명을 정한다.
3. 영역이 이미 명확하면(예: "연말정산 공제", "전세 계약 확인") 라우터를 건너뛰고 해당 전문가 `~/.claude\life-experts-skills\life-<이름>\SKILL.md`를 직접 Read한다. 제작 상태(✅/⬜)는 `~/.claude\life-experts-skills\README.md` 카탈로그 참조.
4. **미제작(⬜) 전문가는 Read 시도하지 않는다** — 폴백으로 진행하고 한 줄 알린다:
   `⬜ life-<이름> 미제작 — 일반 지식 + <공식 출처(예: 국세청·정부24)>로 진행. 확인 필요: <스킬이 있었다면 점검했을 항목>`
5. 읽은 매뉴얼의 긴급 게이트·워크플로우·안티패턴을 그대로 따른다. **면책 영역(법·세·의료·보험)이면 안내 말미에 "정보 제공이며 자문이 아님 + 전문가 상담 권고"**, **제도 수치엔 "(YYYY 기준, 확인 필요)" + 공식 출처**를 빠뜨리지 않는다(안전 규율: README §제1원칙).
