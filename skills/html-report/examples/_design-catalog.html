4. Callout

Note

이건 .callout.note 입니다. 의미 없는 일반 참고 사항용. 아이콘은 펜·메모 모양.

16. Q&A Toggle

왜 GHCR 가 아니라 GCP Artifact Registry 인가?

GitHub App Installation Token이 GHCR pull을 지원하지 않아 PAT 의존 발생 → 최소권한 원칙 위배. GCP AR + SA JSON 키 조합은 repo 단위 IAM 격리 가능.

Watchtower polling 주기는?

기본 5분. WATCHTOWER_POLL_INTERVAL=300. 즉시 배포가 필요한 경우 SIGUSR1 시그널로 강제 트리거.

17. Formula · Worked Example

Methodology·Explainer 타입용. mono 선형 표기 + <sub>/<sup>, 외부 수식 렌더러 없음.

지수(오늘) = 지수(직전 리밸런싱일) × Σ [ wi × Pi(오늘) ÷ Pi(리밸런싱일) ] — 체인 방식
wi
종목 i 의 비중 (합 = 1)
Pi(t)
종목 i 의 t 시점 수정주가
숫자 예시

종목 3개(비중 0.5 / 0.3 / 0.2), 리밸런싱일 대비 각각 +2%, −1%, +5% 움직였다면:

지수 = 100 × (0.5×1.02 + 0.3×0.99 + 0.2×1.05) = 100 × 1.017 = 101.7

비중이 큰 종목의 등락이 지수에 더 크게 반영된다.
