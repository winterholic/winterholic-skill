# 채널 플레이북 — 구조·입찰·소재·측정 (채널별 실무)

> 부패 매우 빠름 — 플랫폼 UI·명칭·정책은 늘 공식 문서 최신 확인. 벤치마크는 **벤더·시점 라벨** 필수이며 산업·객단가·지역별 편차 큼(자기 계정 기준으로 재조정).

## 공통 원칙 (모든 채널)
- **소재가 1번 레버** — 타깃팅은 알고리즘이 대신함. 콘셉트 단위 다수 동시 테스트.
- **학습 보존** — 잦은 변경(예산·타깃·소재) = 학습 리셋. 변경은 점진(통설 ±20~30%).
- **측정은 다층** — 플랫폼 리포트 ROAS는 부풀려짐(evidence.md §4). MER/aMER + 증분성(지오리프트)로 교차검증.
- **전환 신호 정확성이 토대** — 값(value)·서버사이드(CAPI/Enhanced Conversions) 검증 후 최적화.

---

## 1. Google Search (검색 광고)

**성격**: 수요 **수확(harvesting)** — 이미 의도가 있는 검색자를 잡음. 증분성이 채널마다 다름(브랜드검색 iROAS 낮음, 비브랜드 신규 키워드 높음).

- **구조**: 브랜드 / 비브랜드 / 경쟁사 캠페인 분리(예산·의도·증분성이 다름). 테마별 애드그룹, 광고문안 반응형(RSA).
- **매칭·입찰**: 광범위 매칭은 **Smart Bidding + 깨끗한 전환 데이터와 함께**라야(단독 사용 금물). 입찰은 데이터 없으면 Max Conversions → 안정 후 tCPA/tROAS(evidence.md §5).
- **소재/자산**: RSA 헤드라인·설명 다양성, 사이트링크·콜아웃·구조화 스니펫 등 확장, Enhanced Conversions로 신호 보강.
- **측정 주의**: **브랜드검색은 고 ROAS·저 증분**(어차피 올 사람 — Blake·Nosko·Tadelis 2015 eBay 실험). 방어 목적과 증분 효율을 구분.

**벤치마크(WordStream 2024 Google Ads, 전체 평균, 검색 중심):** CTR **6.42%**, CPC **~$4.66**, CVR **6.96%**. 산업 편차 큼(법률 CPC ~$8.94 최고 / 예술·엔터 ~$1.72 최저; 자동차수리 CVR ~12.96% 최고). 17,000+ 캠페인, 2023-04~2024-03. https://www.wordstream.com/blog/2024-google-ads-benchmarks (⚠️ 미국·영어권 중심, 자기 산업·지역으로 재조정)

## 2. Performance Max (PMax)

**성격**: 구글 전 인벤토리(검색·디스플레이·유튜브·Gmail·디스커버·맵)를 **하나의 캠페인으로 자동 배분**. 자산 그룹 + 목표(전환/가치) 기반. 공식: https://support.google.com/google-ads/answer/10724817

- **구조**: 자산 그룹을 **오디언스 시그널/테마별**로 분리(잡탕 금지). 검색 캠페인과 카니발라이즈 주의 — 브랜드 트래픽을 PMax가 삼키지 않게 브랜드 제외 설정 검토.
- **입찰**: Max Conversion Value / tROAS(이커머스), tCPA(리드젠). **가치 데이터 정확성**이 tROAS 품질을 좌우.
- **소재/자산**: 이미지·로고·비디오·헤드라인 폭넓게 공급(빠지면 저품질 자동생성 인벤토리로 감). 오디언스 시그널은 힌트(하드 타깃 아님).
- **측정 주의**: **블랙박스·리포팅 투명성 낮음**(채널별 세부 안 보임) — 검색 대비 증분성 논쟁. 브랜드/기존고객 수확분이 섞여 ROAS 부풀 수 있음 → 지오리프트로 증분 확인 권장.

## 3. Meta (Facebook / Instagram)

**성격**: 수요 **창출** + 관심 기반. Advantage+ 로 예산·소재 자동 최적화(2022-08, evidence.md §1).

- **구조**: 넓은 캠페인 + **소수 애드셋**(잘게 쪼개면 신호 분산 → 학습 지연). Advantage+ Shopping(ASC) 또는 수동 중 목표에 맞게. 중복 오디언스 회피.
- **입찰/예산**: CBO(캠페인 예산 최적화)로 애드셋 간 자동 배분. 학습기(learning phase) 벗어날 전환량 확보 — "애드셋당 주 ~50 전환" 임계는 **업계 통설**(공식 확정 아님, 확인 필요).
- **소재**: **1번 레버.** 훅(첫 3초)·앵글·UGC·포맷(릴스/스토리/피드) 변주. 콘셉트 단위 테스트, 소량 노출 조기판단 금물.
- **측정 주의**: ATT 이후 **모델링 전환 비중↑**(실측 아님), 뷰스루/기여 윈도우로 클레임 과다. CAPI(서버사이드)로 신호 복구. MER/aMER로 전사 교차검증.

**벤치마크(2025, 미디어 믹스별 편차):** 전 산업 중앙값 CPM **~$13.48**, CTR **~2.19%**, CVR **~1.57%**(미국 CPM 최고 ~$20.48). 출처 Triple Whale 2025 Facebook Ads 벤치마크(이커머스 브랜드 중심). https://www.triplewhale.com/blog/facebook-ads-benchmarks (⚠️ 이커머스 편향, 자기 카테고리로 재조정)

## 4. TikTok

**성격**: 수요 창출·발견. 네이티브 UGC 스타일이 성패를 가름(광고 티 나면 스킵). 숏폼·트렌드 사이클 빠름.

- **구조**: 넓게 시작, 소재 다양성으로 알고리즘이 오디언스 탐색. Smart Performance Campaign(자동) 또는 수동.
- **입찰**: 전환/가치 최적화. 학습량 확보 전 조급한 변경 금물(타 채널과 동일 원리).
- **소재**: **네이티브 UGC가 핵심** — FYP에 녹아드는 톤. 훅 강도·트렌드 활용·크리에이터 협업. 소재 피로(fatigue) 빠름 → 리프레시 주기 짧게.
- **측정 주의**: 뷰스루 기여 크고 크로스채널 영향(TikTok 봤다가 구글 검색) — 라스트클릭이 특히 과소평가. MER·증분성 중요.

**벤치마크(2025, 이커머스):** CPM **~$13.26**(+16% YoY), CTR 산업별 **~0.4~0.6%대 다수**(일부 ~0.84%까지), CVR **~2.01%**(−6.2% YoY), CPA **~$32.74**, ROAS **~2.21**. 출처 Triple Whale 2025 TikTok 벤치마크(이커머스). https://www.triplewhale.com/blog/tiktok-benchmarks (⚠️ 지표·출처마다 CTR/CPM 편차 큼 — 자기 계정 기준으로)

## 5. 앱 캠페인(iOS) 측정 — SKAN 4
- ATT로 유저 단위 IDFA 측정 붕괴 → **SKAdNetwork 4**(집계·지연·프라이버시 임계). fine(0~63)/coarse(none~high) conversion value, postback 최대 3개·35일, lockWindow로 조기 확정(evidence.md §8, Apple 공식).
- **함의**: coarse 전환·랜덤 지연·crowd anonymity로 리포팅 지연·저해상 → 앱 캠페인도 MMM·지오리프트 상보 측정 필요.

## 6. 채널 선택 요약
| 채널 | 성격 | 최적 용도 | 측정 주의 |
|---|---|---|---|
| Google Search | 수확 | 명확한 의도·전환 | 브랜드검색 저증분 |
| PMax | 자동 혼합 | 이커머스 규모·자동화 | 블랙박스·수확 혼입 |
| Meta | 창출+관심 | 신규수요·리타게팅 | 모델링 전환·기여 과다 |
| TikTok | 발견·창출 | 젊은층·UGC·신규수요 | 뷰스루·크로스채널 |

> 벤치마크는 전부 **진입 기준선**일 뿐 — 자기 계정 데이터 축적 후 그것을 진실원으로 삼아라. 증분성(evidence.md §4)과 단위경제(unit-economics.md)가 최종 게이트.
