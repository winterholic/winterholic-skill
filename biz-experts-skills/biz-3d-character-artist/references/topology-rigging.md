# 캐릭터 토폴로지 · 폴리 예산 · 리깅 실무 사양 (실전)

> 근거: Polycount Wiki · topologyguides.com · Autodesk 리깅 가이드 · Mori 언캐니 밸리(1970/2012). 툴 무관 원리.

## 1. 토폴로지 원칙

### 쿼드 우선
- **쿼드(4각) = 좋은 토폴로지의 기본**. 서브디비전·디포메이션에서 예측 가능하게 접힘.
- **삼각형·n-gon**: 변형부(관절·얼굴)에서 핀칭·아티팩트. **안 보이고 안 접히는 평면부에만** 허용(실시간 로폴은 최종 삼각화되지만 작업은 쿼드로).

### 엣지 루프 = 근육 방향
- **얼굴**: 눈 주위 **안와 동심 루프(2~3겹)**, 입 주위 **구륜 동심 루프**, 콧방울·눈꺼풀·이마 루프. 표정 근육이 접히는 방향으로 흘러야 자연스러운 표정.
- **관절**: 팔꿈치·무릎·손가락은 굽힘 축을 **가로지르는 루프 3겹+**(굽힐 때 부피 유지). 어깨·엉덩이는 다축이라 루프 복잡.
- **폴(pole, 3·5각 만나는 점)**: 변형부·시선 집중부 회피, 평평한 뒤통수·겨드랑이 등에 숨김.

### 밀도 배분 (폴리 절약의 핵심)
- 변형·시선 집중부(얼굴·손·관절)에 폴리 집중, 평평한 큰 면(가슴·허벅지 중간)은 성기게. → 같은 폴리 예산으로 더 좋은 실루엣·변형.

## 2. 폴리 예산 (2026 통념 — 프로젝트가 최종)

| 타깃 | 삼각형 수(바디) | 비고 |
|------|----------------|------|
| 모바일/VR | ~5k~20k | 배터리·발열 제약, VR은 양안 2배 부담 |
| PC 게임 | ~15k~25k(의상 포함 ~50k~60k) | 캐릭터 중심 게임은 더 |
| AAA 주인공 | ~50k~100k+ | LOD로 원거리 저감 |
| 영화/시네마틱 | 수백만+ | 하이폴 직접 렌더 |

- **LOD(Level of Detail)**: 카메라 거리별 다중 해상도(LOD0 풀→LOD3 저폴리). 실시간 성능 필수.
- "poly count"는 관행상 **삼각형 수**로 소통(정점 수가 GPU 부하 지표로 더 정확).

## 3. 파이프라인 순서
1. **블록아웃/스컬프**(ZBrush 등 하이폴) — 형태·디테일.
2. **리토폴**(로폴 재구성) — 깨끗한 쿼드 엣지플로우. 오토리토폴 후 **얼굴·손·관절 수동 보정 필수**.
3. **UV** — 심 배치, 텍셀 밀도 일관, 얼굴에 UV 공간 더 할당.
4. **베이크** — 하이폴 디테일을 노멀·AO·curvature 맵으로(케이지 사용).
5. **텍스처** — PBR(→ biz-3d-designer pbr-pipeline).
6. **리깅** — 스켈레톤 배치.
7. **스키닝(weight painting)** — 정점-본 가중치.

## 4. 리깅 · 스키닝

### 스켈레톤
- 본은 관절 회전축에 정확히 배치. 계층(hierarchy): root→hips→spine→…, 팔·다리 대칭.
- **IK/FK**: 발·손은 IK(목표 위치 지정), 세밀한 팔 호선은 FK. 보통 스위칭 지원.

### 스키닝(weight painting)
- **정점당 본 가중치 합 = 1.0**(정규화).
- 실시간: **정점당 영향 본 ≤ 4개**(GPU 스키닝 상한 관행).
- **관절 집중**: 팔꿈치·무릎·손가락·어깨·목 = 변형 최대 → 가중치 세심히. 어깨가 가장 어려움(다축 회전, 겨드랑이 함몰 방지).
- 자동 웨이트(heat map 등) 후 **수동 보정 필수** — 자동은 관절에서 찌그러짐·부피 손실.
- 검증: 극단 포즈(팔 완전 굽힘·다리 벌림)에서 메시 관통·함몰 확인.

## 5. 언캐니 밸리 실무 대응 (Mori 1970 가설)
- **모션이 외형보다 언캐니를 증폭** — 정교한 사실적 얼굴일수록 미묘한 애니 오류(눈 안 깜빡임·경직된 립싱크)가 강한 거부감. 스타일라이즈(양식화)가 오히려 안전할 때 많음.
- 눈·입 주위 토폴로지가 표정 자연스러움을 좌우 → 언캐니 회피의 기술적 지점.
- ⚠️ 언캐니 밸리는 **가설·휴리스틱**(법칙 아님, 실증 혼재). 디자인 방향 참고용.

## 6. 흔한 실수 (교정)
- ❌ 고폴리면 좋다 → 아님. 토폴로지·엣지플로우 > 밀도.
- ❌ 관절에 삼각형/n-gon → 굽힘 시 아티팩트. 쿼드 루프로.
- ❌ 오토리토폴/오토스키닝 후 방치 → 얼굴·관절 붕괴. 수동 보정.
- ❌ 노멀맵으로 실루엣 개선 시도 → 착시만, 실루엣은 지오메트리.
- ❌ 사실적 얼굴 + 어설픈 모션 → 언캐니. 모션 품질 or 양식화 검토.
