# 성과관리 & PIP 실무 (공정·문서화)

> evidence.md 보강. 저성과 대응·PIP·성장대화의 실무 절차. **성과관리·해고는 법규 직결 — 이 문서는 관리 프레임이지 법률 자문이 아니다. 실제 인사 조치 전 인사/법무 협의 필수(→ biz-people-hr / life-legal).**

## 1. 저성과 진단 — 원인부터 분리 (조치 전)

성급히 PIP·해고로 가지 말 것. 먼저 원인을 4갈래로 분리:

| 원인 | 신호 | 매니저 대응 |
|---|---|---|
| **역량**(할 줄 모름) | 노력하나 결과 미달, 같은 실수 반복 | 교육·페어링·과업 축소(S1 구조 제공) |
| **동기**(하기 싫음) | 능력 있으나 몰입 없음, 최소만 | 1:1로 근본 원인(의미·인정·번아웃·팀 갈등) 탐색 |
| **우선순위**(할 게 너무 많음) | 바쁜데 중요한 게 안 됨 | 매니저가 정렬·삭감(레버리지 문제, 개인 탓 아님) |
| **개인사**(일시적) | 갑작스런 저하, 평소와 다름 | 배려·유연성, 필요시 휴가/EAP 안내 |

- **가장 흔한 오진**: 우선순위·환경 문제(매니저 책임)를 개인 역량 문제로 착각.

## 2. PIP(Performance Improvement Plan) — 언제·구조·유의

### 언제 쓰나
- 1:1 피드백·지원(위 4갈래 대응)을 충분히 했는데도 **명확한 성과 격차가 지속**될 때.
- ❌ PIP를 "해고 알리바이"로 형식만 밟는 것 — 신뢰·사기를 크게 해치고, 관할에 따라 법적 리스크(확인 필요: 한국은 PIP 자체가 해고 정당성을 담보하지 않음).
- ✅ PIP는 원칙적으로 **개선을 목표로 한 진짜 기회** — 성공 사례를 상정하고 설계.

### 구조 (5요소)
```
PIP — {이름} / 시작 {날짜} / 검토 {30·60·90일}
1. 기대 수준    구체·측정 가능 (예: "스프린트 커밋의 90%를 마감 내 완료")
2. 현재 격차    사실·사례만 (날짜·건). 감정·인격 평가 금지
3. 지원         조직이 제공할 것 (교육·페어링·체크포인트·리소스)
4. 마일스톤     주간 점검일 + 각 시점 기준
5. 결과 분기    달성→정상화 / 미달→공정한 다음 절차(인사 협의)
```

### 법적 유의 (확인 필요 — 관할별 상이, 반드시 법무 확인)
- **문서화**: 모든 대화·피드백·마일스톤 결과를 날짜와 함께 사실 기반 기록. 사적 폴더 보관.
- **일관성**: 유사 상황의 다른 직원과 다르게 다루면 차별 주장 소지.
- **보복 금지**: 병가·육아휴직·내부고발·차별 문제제기 직후의 성과 조치는 보복으로 해석될 위험(확인 필요: 한국 근로기준법·남녀고용평등법 관련 — 법무 확인).
- **한국 특유**(확인 필요): 한국은 해고 요건이 엄격("정당한 이유", 근로기준법 §23). PIP 미달만으로 해고 정당성이 인정되지 않는 경우가 많고, 저성과 해고는 개선 기회·교육·배치전환 노력 등이 종합 판단됨. **정식 자문 필수.**
- 미국(at-will)이라도 차별·보복 예외가 있어 문서화·일관성은 동일하게 중요.

## 3. 윤리 게이트 (거부권급 — evidence.md·SKILL.md와 동일)
차별·괴롭힘·보복, 공개 망신주기, 법규 위반 해고는 **협조 불가**. 병가·휴직 사용자 불이익, 문서화·기회 없는 즉시 해고 요청 → HR·법무 강권 + 정식 절차 대안만 제시.

## 4. 성장대화 (성과관리의 반대 축 — 잘하는 사람 키우기)

저성과 대응만이 성과관리가 아니다. 고성과자·중간층 성장이 팀 산출의 레버리지(Grove).

### 성장대화 질문 (분기 1회 권장)
- "3년 뒤 어떤 일을 하고 있고 싶어요? 거기서 역산하면 지금 뭘 키워야 할까요?"
- "지금 일의 몇 %가 성장으로 느껴져요? 몇 %가 반복이에요?"
- "당신이 과소평가받고 있다고 느끼는 강점이 있나요?"

### 커리어 사다리 명확화 (Fournier)
- 다음 레벨의 기대치를 **구체 행동으로** 언어화(모호한 "더 리더십을" 금지).
- 스트레치 과제 배정 → S3/S4로 위임 수준 상향(evidence.md §8) → 성장 = 위임 가능 범위 확대.
