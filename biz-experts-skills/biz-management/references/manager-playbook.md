# 매니저 실무 판정표 (Radical Candor 2×2 · TRM 위임 매트릭스)

> SKILL.md 보강. 피드백·위임 상황에서 즉시 참조하는 판정표. evidence.md와 함께.

## 1. Radical Candor 2×2 — 피드백 자가진단
축: **Care Personally**(배려, Y) × **Challenge Directly**(직설, X). (evidence.md §3)

| | 직설 낮음 | 직설 높음 |
|---|---|---|
| **배려 높음** | Ruinous Empathy(좋은 게 좋다 — 성장 없음) | **Radical Candor(목표)** |
| **배려 낮음** | Manipulative Insincerity(뒷담·정치) | Obnoxious Aggression(막말 — 신뢰 파괴) |

- 내 피드백이 어느 사분면인지 먼저 찍는다. **Care Personally 없이 직설만 = Obnoxious Aggression**이지 Radical Candor가 아니다(가혹함 면허 오용 주의).
- 교정 방향: Ruinous Empathy → 도전 추가 / Obnoxious Aggression → 배려 추가.

## 2. TRM(Task-Relevant Maturity) 위임 매트릭스
과업별 기술(교육·경험)+의지 수준으로 관리 스타일을 바꾼다(Grove, evidence.md §1).

| TRM | 관리 스타일 | 위임 수준 | 체크 주기 |
|---|---|---|---|
| 낮음 | 구조·지시(무엇을·어떻게) | 최소 | 잦게(격일~주) |
| 중간 | 지원·상호추론(왜·함께) | 부분 | 주~격주 |
| 높음 | 목표 위임+모니터(무엇만) | 최대 | 성과 시점 |

- **같은 사람도 과업마다 TRM이 다르다** — 사람이 아니라 과업 단위로 판정.
- 안티패턴: 신입에게 목표만 던짐(방치) / 베테랑을 사사건건 간섭(마이크로매니지).

## 3. 저성과 대응 단계 (공정·문서화)
1. 1:1에서 사실·영향 기반 피드백(감정·인격 평가 금지).
2. 원인 분리: 역량 / 동기 / 우선순위 / 개인사.
3. TRM 낮으면 구조·체크포인트 지원(교정 기회).
4. 개선 안 되면 PIP(기대·격차·지원·마일스톤·재평가 시점) — **시작 전 인사/법무 협의**.
> 차별·보복·부당해고는 협조 불가(윤리 게이트). 관할 근로법 준수 — 사람·법무 판단.
