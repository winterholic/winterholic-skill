# 그리드·타이포그래피·색 실무 사양 (실전)

> 근거: Müller-Brockmann *Grid Systems*(1981) · Bringhurst *Elements of Typographic Style*(1992) · A List Apart "More Meaningful Typography" · WCAG 2.1. 2026-07 검증.

## 1. 그리드 사양

### 그리드 4유형 (선택)
| 유형 | 용도 | 핵심 |
|------|------|------|
| Manuscript(단일) | 책·장문 | 하나의 큰 텍스트 블록 + 여백 |
| Column(다단) | 잡지·웹 | N개 세로 단, 웹은 **12컬럼** 표준 |
| Modular(격자) | 대시보드·카드·갤러리 | 행×열 모듈 |
| Baseline | 수직 리듬 | 텍스트 행을 기준선 배수에 정렬 |

### 그리드 구성요소
- **Margin**: 콘텐츠 외곽 여백. 인쇄는 좌우 비대칭(제본 여유), 웹은 대칭.
- **Column**: 콘텐츠가 앉는 세로 단.
- **Gutter**: 단 사이 간격. 웹 관행 **16~24px**. 좁으면 단이 붙어 보이고 넓으면 분리됨.
- **Module**: 행+열이 만드는 격자 칸(모듈러 그리드).

### 8-Point Grid (UI 사실상 표준)
- 모든 간격·크기를 **8의 배수**(8·16·24·32·40…)로. 세밀함이 필요하면 4px 하프스텝(Airbnb 등).
- 이유: 다양한 화면 배율(1×/2×/3×)에서 소수점 없이 나눠떨어짐 → 렌더링 선명.

## 2. 타이포그래피 사양

### 모듈러 스케일 (조화로운 크기 세트)
base × 비율의 거듭제곱으로 크기를 생성. 임의 숫자(15·18·23…) 대신 비율 기반.

| 비율 | 이름 | 느낌 |
|------|------|------|
| 1.067 | Minor Second | 아주 촘촘(정보 밀도 높은 UI) |
| 1.125 | Major Second | 촘촘 |
| 1.2 | Minor Third | 부드러움 |
| **1.25** | **Major Third** | **가장 흔한 기본값** |
| 1.333 | Perfect Fourth | 대비 뚜렷(에디토리얼) |
| 1.5 | Perfect Fifth | 강한 대비 |
| 1.618 | Golden | 극적(히어로·포스터) |

예(base 16px, 비율 1.25): 16 → 20 → 25 → 31.25 → 39 → 48.8 …(반올림해 사용).

### 측정·행간 (가독성 핵심)
- **줄 길이(measure)**: 45~75자(이상 66자). 다단은 40~50자.
- **행간(line-height)**: 본문 **1.4~1.6**(웹 관행 1.5). 헤드라인은 좁게(1.1~1.3), 캡션도 좁게.
- **줄 길이와 행간은 함께 조정**: 줄이 길수록 행간을 넓혀 다음 줄 찾기 쉽게.
- **자간(tracking)**: 대문자·작은 글씨는 살짝 넓게(+), 큰 헤드라인은 살짝 좁게(−).

### 위계 (Type Scale를 역할에 매핑)
Display > H1 > H2 > H3 > Body-lg > Body > Caption > Overline. 각 단계는 **크기+굵기+색+간격**의 조합으로 구별(크기만으로 구별하지 말 것).

## 3. 색 사양

### 색공간 (매체 결정)
- **화면 = RGB / 인쇄 = CMYK.** RGB 색역이 넓어 네온·형광은 인쇄 시 칙칙 → 인쇄물은 CMYK 소프트프루프로 작업.
- **별색(Pantone/Spot)**: 브랜드 색 정확도·금은·형광이 필요할 때. CMYK로 못 내는 색.
- HEX/RGB/CMYK/Pantone 4표기 병행(브랜드 일관성).

### 접근성 대비 (WCAG 2.1 — 반올림 금지)
- **본문 텍스트 : 배경 ≥ 4.5:1** (SC 1.4.3, AA).
- **큰 텍스트(24px+ 또는 18.66px+ bold) ≥ 3:1**.
- **UI 컴포넌트·그래픽 경계 ≥ 3:1** (SC 1.4.11).
- **색만으로 정보 전달 금지** (SC 1.4.1, Level A) — 링크는 밑줄, 에러는 아이콘+텍스트 병행.

### 팔레트 구성 (실무)
- Primary / Secondary / Accent / Neutral(회색 계열 5~9단계) / Semantic(성공·경고·에러·정보).
- **60-30-10 규칙**(관행): 지배색 60%·보조색 30%·강조색 10%.

## 4. 인쇄 프리플라이트 (넘기기 전 체크)
- 재단여백(**bleed) 3mm** + 안전여백 3~5mm(중요 요소는 재단선에서 안쪽).
- 해상도 **300ppi**(원본 이미지 기준), 라인아트/텍스트는 벡터.
- CMYK 변환 완료(RGB 잔존 금지), 검정은 리치블랙 or 100K 용도 구분.
- 폰트 아웃라인화 또는 임베드, 오버프린트 확인.

## 5. 흔한 실수 (교정)
- ❌ 임의 폰트 크기(15·17·22px) → 모듈러 스케일로 통일.
- ❌ 본문 줄이 화면 가득(100+자) → 45~75자로 max-width 제한.
- ❌ 회색 텍스트 대비 부족(#999 on white ≈ 2.85:1) → 4.5:1 확보(#767676 이상).
- ❌ 화면용 RGB 그대로 인쇄 입고 → 색 틀어짐. CMYK 변환+bleed.
