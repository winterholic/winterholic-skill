# GTM 모션 선택 의사결정 매트릭스

> SKILL.md 보강. 모션(PLG/SLG/하이브리드) 선택을 5개 축으로 정형화. evidence.md와 함께 참조.

## 1. 5축 판정표

| 축 | PLG 신호 | SLG 신호 |
|---|---|---|
| 가격(ACV) | 낮음(월 $10~수백) | 높음(연 수천만~) |
| 제품 복잡도 | 셀프 온보딩 가능 | 도입에 컨설팅·통합 필요 |
| 구매자 | 실사용자=구매 결정 | 별도 의사결정자(경영·구매부서) |
| 계약 규모·주기 | 소액·즉시·자동갱신 | 대형·장기·협상 |
| 가치 실현 시간 | 분~시간(즉시 "aha") | 주~월(도입 프로젝트) |

- **3축 이상 PLG 쪽** → PLG 주도. **3축 이상 SLG 쪽** → SLG 주도.
- **섞임** → 하이브리드(PLG로 유입 → 임계치 도달 계정만 세일즈 확장). 엔터프라이즈 확장기의 컨센서스(evidence.md §2).

## 2. 단위경제 게이트 (모션 확정 전 필수)
- **CAC < LTV**가 성립하지 않는 모션은 채택 금지. 저가 제품에 외부 영업(SLG) = CAC가 LTV 초과 = 팔수록 손실(안티패턴 1).
- 빠른 가늠: **객단가(ARPU) × 예상 유지기간 > 1회 획득비용(CAC)** 이면 성립. 정밀 계산은 → biz-finance-fpa.

## 3. 모션별 지표(정렬 대상)
- **PLG**: 가입→활성화율·PQL(product-qualified lead)·셀프 전환율·제품 내 바이럴 계수.
- **SLG**: 파이프라인·승률·평균 딜사이즈·세일즈 사이클·MQL→SQL 전환.
- 모션과 지표·조직이 어긋나면 잘못된 걸 최적화한다(안티패턴 4).

## 4. 진화 트리거
- PLG 단독 → 하이브리드 전환 신호: 엔터프라이즈 문의 증가, 보안/SSO 요구, 팀 좌석 수 급증.
- 한 모션 고집은 큰 딜을 놓친다(안티패턴 5) — 단계별로 모션을 추가한다.

## 5. 출처
- PLG/SLG·하이브리드·MQL/SQL은 evidence.md 참조(OpenView 역사적·업계 컨센서스). 미검증 수치(하이브리드 NRR·SiriusDecisions 승률)는 인용 금지.
