# 로고 시스템 & 브랜드 가이드라인 실무 사양 (실전)

> 근거: David Airey, *Logo Design Love* · Romaniuk, *Building Distinctive Brand Assets*(2018) · 실무 브랜드 가이드라인 관행(2026-07 검증).

## 1. 로고 타입 7분류 (선택 기준)

| 타입 | 예 | 언제 |
|------|-----|------|
| **워드마크(logotype)** | Google, Coca-Cola | 이름 자체가 짧고 독특할 때 |
| **레터마크/모노그램** | IBM, HBO, CNN | 이름이 길어 축약이 필요할 때 |
| **픽토리얼 마크(브랜드마크)** | Apple, Twitter | 인지도가 이미 높거나 상징이 강할 때 |
| **추상 마크** | Nike swoosh, Pepsi | 특정 사물에 안 묶이고 개념을 표현 |
| **마스코트** | KFC, Michelin | 친근함·캐릭터 자산 필요 |
| **엠블럼** | Starbucks, Harley | 전통·권위 느낌, 배지형 |
| **콤비네이션 마크** | Adidas, Burger King | 심볼+워드마크. **가장 안전한 기본값**(심볼 단독/워드 단독 분리 사용 가능) |

실무 권장: 신생 브랜드는 **콤비네이션 마크**로 시작 — 심볼 인지도가 쌓이면 심볼 단독으로 축소.

## 2. 반응형 로고 시스템 (Responsive Logo)
크기·맥락별로 여러 버전을 준비 — 현대 필수(파비콘~빌보드).

| 버전 | 용도 | 구성 |
|------|------|------|
| Full (primary) | 명함·헤더·인쇄 | 심볼 + 풀 워드마크 + 태그라인 |
| Standard | 웹 헤더 | 심볼 + 워드마크 |
| Compact | 좁은 공간 | 심볼 + 축약 워드마크 |
| Icon/Mark | 파비콘·앱 아이콘·소셜 프로필 | 심볼만 |

## 3. 로고 구성 사양 (가이드라인에 반드시 명시)

### 여백 (Clear Space / Exclusion Zone)
- **비율로 정의, 고정 px 금지.** 로고의 반복 요소를 1단위(X)로 삼아 상하좌우 최소 X 여백.
- 관행: 워드마크는 대문자 높이(cap-height) 또는 x-height, 심볼마크는 심볼의 특정 폭/획을 X로.
- 이 영역에 텍스트·그래픽·다른 로고 침범 금지.

### 최소 크기 (Minimum Size)
- 화면: px 단위. 주 로고 하한 ~**80px 폭**, 아이콘 마크 ~**24px**(흔한 관행값, 실제 로고 복잡도에 따라 조정).
- 인쇄: mm 단위(예: 워드마크 폭 최소 20mm).

### 색 변형 (Color Variants) — 최소 준비 세트
1. 풀컬러(primary) 2. 단색 흑 3. 단색 백(reverse, 어두운 배경용) 4. 1색 별색(Pantone) — 인쇄 단가 절감용.
- 배경 대비 규칙: 밝은 배경=풀컬러/흑, 어두운 배경=백. **저대비 조합 금지.**

## 4. 오용 금지(Logo Misuse) — ❌ 예시 필수 수록
- 늘리기/찌그러뜨리기(비율 왜곡) · 회전/뒤집기 · 임의 색 교체 · 그림자·베벨·글로우 효과 추가 · 요소 위치/크기 개별 변경 · 서체 교체 · 여백 무시(꽉 찬 박스 안 배치) · 저대비/복잡 사진 위 배치 · 투명도 임의 조정.
- 가이드라인에는 "✅ 올바른 사용" 옆에 "❌ 이렇게 쓰지 마세요"를 **시각적으로 나란히** 제시.

## 5. 구별 자산(DBA) 시스템 — 로고 너머
Romaniuk(2018): 로고는 구별 자산의 **일부**일 뿐. 강한 브랜드는 **여러** 자산을 소유.

| 자산 유형 | 예 | 비고 |
|-----------|-----|------|
| 색 | Tiffany 블루, Coca-Cola 레드 | 형태 기반 자산이 가장 강함(연구) |
| 로고/심볼 | Nike swoosh | |
| 캐릭터 | 미쉐린맨, M&M's | 스토리텔링 강점 |
| 서체/레터링 | Disney, Coca-Cola 스펜서체 | |
| 오디오 로고 | Intel 5음, Netflix "타둠" | |
| 슬로건 | "Just Do It" | |
| 패키지 형태 | Coca-Cola 병, Toblerone | |

- **DBA 강도 = Fame × Uniqueness.** Fame 높지만 Uniqueness 낮으면(예: 흔한 파랑) 자산으로 약함. 둘 다 높은 자산에 투자·일관 반복.
- 실무: DBA는 **한번 정하면 오래 반복**해야 축적됨. 잦은 리브랜딩은 정신적 가용성을 리셋시키는 비용.

## 6. 브랜드 가이드라인 문서 목차 (표준 구조)
1. 브랜드 전략(미션·비전·가치·아키타입·보이스톤) 2. 로고(타입·반응형·여백·최소크기·색변형·오용) 3. 색 팔레트(primary/secondary, HEX/RGB/CMYK/Pantone, 접근성 대비) 4. 타이포그래피(서체·위계·웹폰트) 5. 이미지·일러스트·아이콘 스타일 6. 구별 자산 목록 7. 적용 예시(명함·웹·소셜·패키지). 상세는 `brand-guidelines-structure.md`.
