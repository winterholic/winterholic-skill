## 3. 보이스 & 톤 / 빈 상태
보이스 일관·톤 상황별(에러=차분). 빈 상태 = 설명+첫 행동 CTA. 스타일 가이드 참고: Mailchimp Content Style Guide, GOV.UK. Plain Writing Act(2010, 미 연방).
- 상세 패턴·비교는 분리: **`microcopy-patterns.md`**(상태별 ❌/✅ + 리뷰 체크리스트), **`voice-tone.md`**(톤 매핑·접근성·i18n·스타일가이드 비교표).
- 검증된 1차 인용: Mailchimp "same voice all the time, but tone changes"(감정 상태 기반 톤). Material = sentence case·ALL CAPS 금지·에러 긍정형("Try again")·2인칭. GOV.UK = plain English 강제·에러에 "field" 금지. Polaris = 동사로 시작·"you can" 제거·소리내어 읽기·7학년 읽기 수준. (출처 URL은 각 파일 하단.)

## 4. 다크패턴 — 관할권 구분 (중요)
- 명명: Harry Brignull(2010); 현재 "deceptive patterns"로 개명. https://www.deceptive.design/
- **EU DSA Art.25(1)**(EU 전역 직접적용 2024-02-17, "다크패턴"을 명시한 최초의 EU법) — 단 **"온라인 플랫폼" 대상 한정**이고, **이미 UCPD(불공정상관행지침)·GDPR이 규율하는 행위에는 적용 제외**(중복 회피 조항). 전면 금지가 아님(EUR-Lex 1차).
- 미 FTC법 + ROSCA, FTC 다크패턴 보고서(2022). 캘리포니아 CPRA.
- 집행 사례: **Epic Games $5.2억**($245M 다크패턴 환불+$275M COPPA 벌금, 2022, FTC), **Amazon $25억**(2025-09-25 판결, FTC) = **$10억 민사벌금 + $15억 환불, 약 3,500만명 대상**(1인당 최대 $51, 2025.11~12 자동 환불; FTC 1차 확정). Prime 무단가입·취소 방해 다크패턴.
- ⚠️ "다크패턴은 (어디서나) 불법" 식 뭉뚱그림 금지 — 관할(EU DSA / 美 FTC·ROSCA / 캘리포니아) 구분.
