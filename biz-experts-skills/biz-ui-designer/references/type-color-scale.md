# 타이포·색·대비 실무표 (검증판)

> biz-ui-designer 실무 레퍼런스. 모든 수치에 1차/권위 출처. 검증일 2026-07-01.
> **핵심 원칙(불변)**: 황금비는 UI 비례 정당화 근거 아님(Markowsky 1992). 8pt는 표준 아닌 관례. 60-30-10은 1차 출처 없는 인테리어 관례. 특정 숫자보다 **일관성·제한**이 본질.

## 1. 타입 스케일 (모듈러 스케일)

**모듈러 스케일** = 기준 크기(보통 본문 16px)에 고정 비율을 반복 곱해 크기 단계를 만드는 방식. 각 단계가 수학적 관계를 공유해 시각적 조화가 생긴다(음악의 음정과 유사). 출처: https://www.modularscale.com/ , https://type-scale.com/

### 자주 쓰는 비율 (base 16px 기준, 반올림)

| 비율명 | 배수 | 성격 | 예시 스텝(px) |
|---|---|---|---|
| Minor Third | 1.2 | 잔잔·촘촘, 콘텐츠 위주 | 16 · 19 · 23 · 28 · 33 · 40 |
| **Major Third** | **1.25** | 균형·중간 대비 (가장 무난) | 16 · 20 · 25 · 31 · 39 · 49 |
| **Perfect Fourth** | **1.333** | 고전적·또렷한 위계 (웹 기본) | 16 · 21 · 28 · 38 · 50 · 67 |
| Augmented Fourth | 1.414 | 극적 대비, 랜딩/히어로 | 16 · 23 · 32 · 45 · 64 · 90 |
| Golden(참고만) | 1.618 | 대비 매우 큼 — **황금비의 "미적 우월"은 근거 없음**, 큰 대비가 필요할 때 도구로만 | 16 · 26 · 42 · 68 |

- **실무 선택**: 콘텐츠·문서·블로그 → 1.2~1.25 / 랜딩·히어로 → 1.333~1.414. 반응형에서 모바일은 비율을 낮춰(작게) 두는 게 안전.
- **왜 모듈러인가**: 임의 크기 난립을 막고 단계를 제한 → 위계가 또렷. 계산기 없이도 스텝 표 하나 정해 쓰면 충분.
- 출처: 비율·용도 정리 https://cieden.com/book/sub-atomic/typography/different-type-scale-types , https://baseline.is/tools/type-scale-generator/

### 실무 스텝 예 (Perfect Fourth, 역할 매핑)

```
12  캡션·메타·라벨(3차)
14  보조 본문·설명(2차)
16  본문 기준(base) — 웹 본문은 16px 이상 권장(모바일 가독·줌 방지)
21  소제목 H4~H3
28  섹션 제목 H2
38  페이지 제목 H1
50+ 히어로·디스플레이
```
굵기는 2~3개로 제한(regular 400 / semibold 600 / bold 700). 크기+굵기+색을 조합해 위계.

## 2. 라인하이트(줄간) · 측정(measure, 줄길이)

### 줄길이 (measure)
- **본문 한 줄 45~75자(공백 포함), 66자가 이상적.** 출처: Robert Bringhurst, *The Elements of Typographic Style* — 웹 정리 http://webtypography.net/2.1.2
- 너무 길면(>75자) 다음 줄 시작을 놓치고, 너무 짧으면(<45자) 시선이 자주 튄다.
- 실무: 본문 컨테이너 `max-width` 약 60~70ch로 제한(초광폭 화면에서 줄이 늘어지지 않게).

### 라인하이트(줄간)
- **WCAG 1.4.12 텍스트 간격(레벨 AA)**: 사용자가 다음 값으로 재정의해도 콘텐츠 손실이 없어야 함 — **줄높이 ≥ 폰트크기의 1.5배**, 문단 뒤 간격 ≥ 2배, 자간 ≥ 0.12배, 어간 ≥ 0.16배. 출처: https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html
  - 주의: 이건 "저자가 1.5로 만들라"가 아니라 "사용자가 1.5로 바꿔도 안 깨지게 하라"는 기준. 다만 **본문 기본값을 1.5 안팎(1.4~1.6)** 으로 두면 재정의 여유·가독 둘 다 잡힘 — 실무 관례.
- **크기와 반비례**: 본문(작을수록)은 줄간 넉넉히(1.4~1.6), 제목·디스플레이(클수록)는 줄간 타이트하게(1.0~1.25). 큰 글자에 1.5를 그대로 쓰면 줄이 붕 뜬다.
- 줄길이가 길수록 줄간도 약간 넉넉하게(시선 복귀 도움).

## 3. 색 대비 실무표 (WCAG — W3C 1차)

### 텍스트 대비 (SC 1.4.3, 레벨 AA)
| 항목 | 최소 대비 | 정의(1차) |
|---|---|---|
| 일반 텍스트 | **≥ 4.5:1** | 큰 텍스트 미만 전부 |
| **큰 텍스트** | **≥ 3:1** | **18pt(≈24px) 이상, 또는 14pt(≈18.66px) 볼드 이상** |
- 출처: https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html
- **AAA(강화, SC 1.4.6)**: 일반 ≥ 7:1, 큰 텍스트 ≥ 4.5:1. https://www.w3.org/WAI/WCAG21/Understanding/contrast-enhanced.html
- 반올림 금지: 2.999는 3:1 미달. 실측은 대비 계산기/`web-design-guidelines`에 위임.

### 비텍스트 대비 (SC 1.4.11, 레벨 AA)
- UI 컴포넌트 경계·상태, 의미 전달 그래픽·아이콘 ≥ **3:1**. 출처: https://www.w3.org/WAI/WCAG21/Understanding/non-text-contrast.html
- 즉 아웃라인 버튼 테두리, 입력창 경계, 포커스 링, 토글 상태는 배경 대비 3:1 이상이어야 "보인다"고 할 수 있음.

## 4. 색 시스템 구축법 (역할·상태색)

Refactoring UI 원칙: **흑백 먼저 설계하고 색은 마지막에.** 위계는 간격·크기·대비가 만들고 색은 보조. 출처: https://www.refactoringui.com/ , 요약 https://www.sglavoie.com/posts/book-summary-refactoring-ui/

### 최소 팔레트 구성 (실무)
```
중립(회색)  : 8~10단계 필요 (텍스트 계열 + 배경/경계 계열).
             텍스트는 순수 검정(#000)이 아닌 아주 어두운 회색부터.
             예 900/700/500/400 = 본문/보조/placeholder·비활성/경계.
브랜드(주색): 명도 5~9단계(50~900). 강조·주요 액션에만 희소하게.
시맨틱     : 아래 상태색. 각각 명도 단계(연한 배경 / 진한 텍스트·아이콘)로 쌍 구성.
```
- **회색을 여러 단계로**: "텍스트=검정, 보조=회색" 2단계로는 위계가 부족. Refactoring UI는 명암 여러 단계를 권장.
- **컬러/이미지 위 텍스트**: 흰 배경용 연회색을 컬러 배경에 그대로 쓰면 대비 붕괴. 배경 색조를 머금은 밝은/어두운 색으로 교체.

### 시맨틱 컬러 역할 (관례 — 문화권 의존, 색 단독 금지)
| 역할 | 통상 색 | 용도 |
|---|---|---|
| success | green | 성공·완료·긍정 |
| warning | amber/yellow | 주의·되돌릴 수 있는 경고 |
| danger/error | red | 오류·파괴적 액션·삭제 |
| info | blue | 중립 안내 |
- 상태는 **색 + 아이콘 + 텍스트** 함께(색맹·흑백 환경). 색만으로 의미 전달 금지(WCAG 1.4.1 색 사용).
- 색-의미 매핑은 문화권 의존(예: 빨강=위험이 보편은 아님) → "확인 필요", 제품 맥락에 맞춰 결정.

## 5. 8pt 간격 시스템 (관례 — 표준 아님)

- **8dp는 Material의 관례**, Shopify Polaris는 4px 단위. "표준"이 아니라 **일관된 배수 시스템을 쓰는 것**이 본질. 4px 서브스텝을 섞기도 함(작은 요소 미세 조정).
- 실무 스텝: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 (8의 배수 + 4 서브스텝). 이 안에서만 골라 쓰면 간격 난립이 사라짐.
- **근접성(게슈탈트)**: 관련 요소는 간격 작게(묶음), 무관 묶음 사이는 크게. 간격이 그룹·위계를 만든다.
- 출처: 8dp Material https://m2.material.io/design/layout/spacing-methods.html (관례임을 명시), 근접성 학술 https://pmc.ncbi.nlm.nih.gov/articles/PMC3482144/
