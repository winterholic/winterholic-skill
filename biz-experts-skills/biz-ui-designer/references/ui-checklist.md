> 수치는 `type-color-scale.md` 참조. 대비 실측·접근성 코드 감사는 `web-design-guidelines`에 위임.

## A. 시각 위계 — 강조의 5가지 수단

강조는 색 하나가 아니라 **5수단의 조합**으로 만든다. "안 예뻐 보임"의 1순위 원인은 위계 부재.

| 수단 | 강조 방향 | 비고 |
|---|---|---|
| **크기(size)** | 클수록 강조 | 제한된 타입 스케일 안에서 |
| **무게(weight)** | 굵을수록 강조 | 굵기 2~3개로 제한 |
| **색/명도(color)** | 진할수록·채도 높을수록 강조 | 색은 보조 — 단독 의존 금지 |
| **간격(space)** | 여백이 넓을수록 주목·분리 | 여백이 그룹을 만든다 |
| **대비(contrast)** | 배경과 차이 클수록 강조 | 약화(회색)로 위계를 만드는 게 핵심 |

- [ ] 이 화면의 1차/2차/3차가 명확한가? (다 강조 = 강조 없음)
- [ ] **주요 액션이 화면당 1개**로 좁혀졌나? 나머지는 보조(아웃라인·텍스트 버튼)로 약화했나?
- [ ] 강조를 **색에만** 의존하지 않았나? → **흑백 테스트**: 화면을 그레이스케일로 바꿔도 1차→2차→3차 순으로 읽히면 통과.
- [ ] 덜 중요한 요소를 **회색·작게 "약화"** 시켜 위계를 만들었나? (강조는 약화로 만든다 — Refactoring UI)

## B. 타이포그래피

- [ ] 크기 단계가 **제한된 스케일(모듈러) 5단계 이내**인가? 제멋대로 크기 난립 아님?
- [ ] 굵기가 **2~3개**로 제한됐나?
- [ ] 본문 줄길이 **45~75자(66 이상적)** 범위인가? 초광폭에서 `max-width`(약 60~70ch)로 가뒀나?
- [ ] 라인하이트: 본문 넉넉(1.4~1.6), 제목·디스플레이 타이트(1.0~1.25)? 큰 글자에 큰 줄간을 그대로 쓰지 않았나?
- [ ] 본문 크기가 모바일에서 16px 이상인가?(가독·자동 줌 방지)

---

## C. 색 · 대비

- [ ] 회색(중립)이 **여러 단계**인가? (텍스트=검정/보조=회색 2단계로 끝내지 않음)
- [ ] 브랜드/강조색을 **희소하게** 썼나?(주요 액션·핵심 강조에만)
- [ ] 텍스트가 순수 검정(#000)이 아니라 아주 어두운 회색인가?(과한 대비 완화)
- [ ] 컬러/이미지 배경 위 텍스트를 **흰 배경용 연회색 그대로** 쓰지 않았나? → 배경 색조 머금은 색으로.
- [ ] 대비: 본문 **≥ 4.5:1**, 큰 텍스트(18pt/24px↑ 또는 14pt볼드↑) **≥ 3:1** (WCAG 1.4.3 AA)?
- [ ] UI 경계·아이콘·포커스 링 등 비텍스트 대비 **≥ 3:1** (WCAG 1.4.11 AA)?
- [ ] 상태·의미를 **색 단독**으로만 전달하지 않았나?(색 + 아이콘 + 텍스트 — WCAG 1.4.1)

## D. 간격 · 레이아웃 · 그리드

- [ ] 간격이 **일관된 배수 시스템**(예: 4/8/12/16/24/32/48) 안에서만 나오나? 임의 값 난립 아님?
- [ ] **근접성(게슈탈트)**: 관련 요소는 가깝게 묶고, 무관 묶음 사이는 여백을 크게 했나?
- [ ] 정렬선이 통일됐나?(좌측 정렬선 1개로 흐름 정리, 들쭉날쭉한 정렬 없음)
- [ ] 여백이 인색하지 않은가?(밀집 = 인지부하↑·싸 보임 / 단 대시보드는 밀도 우선)
- [ ] 구분을 **테두리 남발**로 하지 않았나? → 간격·배경 음영·그림자로, 테두리는 최소.

### 그리드 · 브레이크포인트 (관례 — 프로젝트 의존)
- 12컬럼 그리드가 웹 관례(2·3·4·6 분할 유연). 컬럼 폭 + **거터(gutter)** 로 구성.
- 브레이크포인트는 **콘텐츠가 깨지는 지점**에서 잡는 것이 원칙 — 특정 기기 픽셀에 맞추지 말 것. 흔한 참고값(모바일/태블릿/데스크톱 ~360/768/1024/1280)은 **관례이며 표준 아님, "확인 필요"**. 프레임워크/디자인시스템마다 다름.
- 모바일 우선: 데스크톱 레이아웃을 축소하지 말고 **콘텐츠 우선순위로 재배열**.

## E. 컴포넌트 상태 매트릭스

인터랙티브 컴포넌트(버튼·입력·링크·토글 등)는 **모든 상태**를 정의해야 완성. 상태 누락이 "미완성 느낌"의 흔한 원인.

| 상태 | 정의 | 시각 신호(예) |
|---|---|---|
| **default** | 평상 | 기본 스타일 |
| **hover** | 포인터 올림(데스크톱) | 명도·그림자 약간 변화 |
| **focus** | 키보드/탭 포커스 | **가시적 포커스 링(대비 ≥ 3:1)** — 제거 금지 |
| **active/pressed** | 눌림 | 명도 더 진하게·살짝 눌린 느낌 |
| **disabled** | 비활성 | 명도 낮춤(회색)·커서 not-allowed. 단 대비 기준은 완화 대상이나 "읽히긴" 해야 |
| **loading** | 처리 중 | 스피너/스켈레톤, 중복 클릭 방지 |
| **error/invalid** | 검증 실패 | 색+아이콘+메시지(색 단독 금지) |
| (선택) selected/checked | 선택됨 | 상태 대비 ≥ 3:1 |

- [ ] 위 상태가 필요한 만큼 **전부** 정의됐나?(특히 focus·disabled·error·loading 누락 잦음)
- [ ] **포커스 표시를 제거(outline:none만)** 하지 않았나? 키보드 접근성 필수.
- [ ] hover 전용 정보가 터치 기기에서 대체 경로가 있나?

## F. 터치 타깃 · 인터랙션 (근거 명확 — 헷갈림 주의)

- **WCAG 2.5.8 Target Size (Minimum), 레벨 AA = 24×24 CSS px** (최소). 예외: 충분한 간격, 등가 컨트롤, 인라인 텍스트, 브라우저 기본, 필수. 출처: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- **WCAG 2.5.5 Target Size (Enhanced), 레벨 AAA = 44×44 CSS px.** 출처: https://www.w3.org/WAI/WCAG21/Understanding/target-size.html
- **Apple HIG: 최소 44×44 pt** (visionOS는 60×60 pt hit region). 출처: https://developer.apple.com/design/tips/
- **Material Design: 최소 48×48 dp** (물리 약 9mm), 타깃 간 간격 8dp 이상 권장. 출처: https://m3.material.io/foundations/designing/structure
- 정리: **AA 하한은 24px지만, 모바일/터치 실무 권장은 44~48px.** "44px가 WCAG AA"는 오류 — 그건 AAA(2.5.5). 제품 타깃 사용자·기기에 맞춰 44~48을 실무 기본값으로.
- [ ] 주요 터치 타깃이 44~48px 안팎인가? 인접 타깃 간 간격 충분한가?

## G. 깊이 · 폴리시 (Refactoring UI)

- [ ] 그림자를 **남발**하지 않았나?(다 뜨면 아무것도 안 뜬다) → 고정된 **엘리베이션 단계 세트**로 일관되게.
- [ ] 그림자 색이 불투명 회색이 아니라 **투명한 어두운색**인가?(현실 광원 모사)
- [ ] 광원은 **위에서** 오는 것으로 일관?(위로 뜬 요소 = 큰 그림자 → 주목)
- [ ] (선택) 2겹 그림자(넓고 옅음 + 좁고 진함)로 현실감?
- 출처: https://www.sglavoie.com/posts/book-summary-refactoring-ui/ , https://www.refactoringui.com/

## H. 종합 진단 순서 ("안 예뻐 보임" → 원인 규명)

1. **흑백 테스트** — 위계가 색에만 의존하는지(A).
2. **간격 일관성 + 근접 그룹** — 배수 시스템·그룹핑(D).
3. **타입 크기/굵기 난립** — 스케일·굵기 제한(B).
4. **대비** — 본문 4.5:1·큰텍스트 3:1·비텍스트 3:1(C).
5. **상태 누락** — focus/disabled/error/loading(E).
6. **막히면** — 레퍼런스 UI 1개와 나란히 두고 차이 나는 항목부터.

> 모든 수치의 1차 출처와 미신 교정(황금비·8pt·60-30-10)은 `evidence.md`·`type-color-scale.md` 참조.
