# biz-content-marketing — 실전 운용집 (Playbook)

> 일류 콘텐츠 마케터가 실제로 굴리는 절차·템플릿·판정 기준. evidence.md의 이론을 현장 실행으로 옮긴다. 근거·출처는 `evidence.md` 참조. 수치는 출발점(rule of thumb)이지 절대 규칙 아님.

---

## A. Big 5 기반 콘텐츠 기획 워크숍

목표: "우리가 쓰고 싶은 것"이 아니라 "고객이 영업 대화 전에 실제로 검색·질문하는 것"에서 콘텐츠를 뽑는다.

### A-1. 질문 수집 (raw questions)
아래 5개 원천에서 실제 질문 문장을 **그대로** 수집(가공 금지, 고객 언어 보존):
- **영업팀**: "상담 전화·데모에서 반복해서 나오는 질문 20개" — 특히 가격·경쟁사 질문.
- **CS/지원 티켓**: 반복 문의 top 20.
- **검색 데이터**: GSC "질문형 쿼리"(어떻게/얼마/vs/후기/추천), People Also Ask, 자동완성.
- **커뮤니티·리뷰**: 관련 카페·레딧·앱스토어 리뷰·경쟁사 리뷰의 질문·불만.
- **영업 손실 사유**: 잃은 딜에서 고객이 마지막에 물었던 것.

### A-2. Big 5 버킷 분류
수집한 질문을 5버킷에 배치. **빈 버킷 = 회피하고 있다는 신호**(기회):

| 버킷 | 이 회사의 대표 질문 예시(채우기) | 회피 이유(솔직히) |
|---|---|---|
| 가격·비용 | | |
| 문제·단점 | | |
| 비교(vs) | | |
| 리뷰 | | |
| 베스트(N선) | | |

### A-3. 우선순위 (RICE-lite)
각 질문을 3축으로 1~3점, 합산 높은 순:
- **검색 수요**(그 질문을 실제로 많이 검색하나) ×
- **구매 영향**(이 질문이 구매 결정을 크게 좌우하나 — 보통 가격·비교가 최상위) ×
- **경쟁 공백**(경쟁사가 안 답하고 있나).
→ 상위 10개를 "1차 발행 큐"로. 가격·비교 글은 거의 항상 상위 — **가장 무섭지만 가장 효과적인 글부터**.

### A-4. 질문 → 글 매핑 (1질문 = 1글 원칙)
한 글이 한 질문에 완결로 답한다(여러 질문 뭉치면 검색·의도 흐려짐). 제목은 고객이 검색한 그 문장 그대로.

## B. 토픽 클러스터 설계 절차

목표: 개별 글이 아니라 "주제 권위"를 쌓는 링크 구조를 만든다(hub-and-spoke).

### B-1. 필러(pillar) 선정
- 우리가 **주제 권위를 갖고 싶은 큰 주제** 1~3개. 너무 넓으면(예 "마케팅") 안 되고, 너무 좁으면(롱테일 1개) 클러스터가 안 나옴 — "장문 가이드 한 편으로 다 훑을 수 있는 폭".
- 필러 페이지 = 그 주제 전체를 폭넓게 다루는 허브(실무상 3,000~5,000단어, 규칙 아님). 세부는 클러스터 글로 위임하고 링크.

### B-2. 클러스터 도출 (20~30개)
- 필러 주제의 **하위질문·롱테일·유스케이스**를 20~30개로 분해. A단계의 Big 5 질문이 그대로 클러스터가 됨.
- 각 클러스터 = 세부 질문 1개 = 글 1편. 검색 의도 태그(정보/비교/거래) 부착.

### B-3. 내부링크 규칙 (이게 핵심)
- **모든 클러스터 글 → 필러로 역링크**(설명형 앵커텍스트, "여기" 금지).
- **필러 → 각 클러스터로 링크**(목차·본문에서).
- 강한 연관 클러스터끼리 상호 링크. 새 글 발행 시 **기존 관련 글에서 새 글로 링크 추가**(고아 페이지 방지).
- 점검: 클러스터인데 필러로 링크 없는 글 = 클러스터 밖 고아 → 링크 보강 또는 감사 대상.

### B-4. 클러스터 대시보드(1행=1글)
`필러 | 클러스터 제목 | 타깃 질문 | 검색의도(TOFU/MOFU/BOFU) | 상태 | URL | →필러 링크 有無`

## C. 에디토리얼 캘린더 & 발행 워크플로우

### C-1. 캘린더 필드 구성(스프레드시트/노션)
| 필드 | 설명 |
|---|---|
| ID | 고유번호 |
| 제목(작업) | 고객 검색 문장 기반 |
| Big 5 버킷 | 가격/문제/비교/리뷰/베스트/기타 |
| 필러·클러스터 | 소속 |
| 검색 의도 | 정보/비교/거래 |
| 퍼널 | TOFU/MOFU/BOFU |
| 타깃 페르소나 | |
| 1차 CTA | 그 글의 다음 행동 |
| 담당(작성/검수/발행) | |
| 상태 | 아이디어→초안→검수→발행→갱신예정 |
| 발행일 / 차기 리뷰일 | |
| 성과 링크 | GA4/GSC 지표 |

### C-2. 발행 주기(출발점, 리소스에 맞춰)
- **깊이 > 빈도**. 얕은 글 주 5편보다 최고의 답 주 1편. 1인/소팀이면 주 1~2편으로도 클러스터가 6개월이면 완성.
- 새 글:갱신 = 시간이 지날수록 **갱신 비중↑**(레거시 글 업데이트가 신규보다 ROI 높은 구간이 온다).

### C-3. 리퍼포징(1콘텐츠 → 다채널)
"제작:배포 노력 ≈ 1:1"(만들면 온다는 환상 금지). 한 필러/클러스터를:
- 블로그 원문 → 뉴스레터 핵심 3포인트 → 비교표/체크리스트 인포그래픽 → 60~90초 요약 영상(쇼츠) → 캐러셀(링크드인/인스타) → Q&A는 영업 자료·FAQ로.
- ⚠️ 채널 문법·후크·협찬 표기는 **biz-social-media** 담당(여기서 넘김).

## D. 콘텐츠 감사(Content Audit) 절차

목표: 자원이 성과 없는 글에 묶이는 걸 막고 주제 권위를 지킨다. 분기~반기 1회.

### D-1. 인벤토리
- 크롤러(Screaming Frog)·CMS 추출로 전체 URL 목록. 색인 가능·콘텐츠 페이지만(태그·페이지네이션 제외).

### D-2. 성과 데이터 결합(1행=1URL)
- **GA4**: 세션·평균 참여시간·전환/전환기여.
- **GSC**: 노출·클릭·CTR·평균 순위·주력 쿼리.
- 비교 창: 최근 30/60/90일 vs 직전 동기간.

### D-3. 4판정 부여
| 판정 | 조건(출발점) | 조치 |
|---|---|---|
| **Keep As Is** | 트래픽·전환 양호, 최신 | 유지, 다음 리뷰일만 표기 |
| **Update** | 순위 3~15위·노출 있는데 CTR/전환 낮음 or 정보 낡음 | 리라이트·최신화·내부링크 보강 후 재발행 |
| **Consolidate & Redirect** | 같은 의도 글이 여러 개로 자기잠식(keyword cannibalization) | 최강 글로 병합 후 301 |
| **Delete** | 트래픽 0·전환 0·주제 이탈·회생 불가 | 삭제(필요 시 유사 페이지로 301) |

- **프루닝(pruning)**: 저가치 글을 제거·병합·리다이렉트해 클러스터를 정예화 → 주제 권위 보존. "글이 많을수록 좋다"는 틀림.

### D-4. 감사 후 조치 로그
판정·실행일·기대효과·재측정일을 캘린더에 반영. 90일 후 전후 비교로 판정 정당성 확인.

## E. 콘텐츠 × 퍼널 × 검색 의도 매핑 표

발행 전 이 글이 어디에 놓이는지 확정(빗나가면 이탈). Big 5는 대부분 고려·전환에 강함.

| 퍼널 | 검색 의도(Broder 3종) | 대표 질문/포맷 | 대표 Big 5 | 1차 CTA |
|---|---|---|---|---|
| **TOFU(인지)** | 정보형(informational) | "X란?", "왜 Y가 문제인가", 가이드·용어 | 문제 | 뉴스레터 구독·다음 글 |
| **MOFU(고려)** | 상업조사·비교형 | "A vs B", "X 고르는 법", 후기·비교표 | 비교·리뷰·베스트 | 자료 다운로드·비교표·데모 신청 |
| **BOFU(전환)** | 거래형(transactional) | "X 가격/비용", "X 도입 절차", 케이스 | 가격 | 견적·무료체험·구매 |
| (재방문) | 내비게이션형 | 브랜드명·제품명 직접 검색 | — | 로그인·구매 |

- ⚠️ TOFU 검색자에게 "지금 구매" CTA를 붙이면 이탈. 단계에 맞는 다음 행동만.
- ⚠️ 키워드 볼륨·난이도·기술 SEO(스키마·사이트맵)는 **biz-seo-marketing** 담당(여기서 넘김).

## F. 실무 함정 체크리스트

- [ ] 가격·비교·단점 글을 **회피**하고 있지 않은가(빈 Big 5 버킷 = 최대 기회).
- [ ] 클러스터 글이 필러로 **역링크**되어 있는가(고아 페이지 없나).
- [ ] 같은 의도로 여러 글이 서로 **자기잠식**하고 있지 않은가(→ 병합).
- [ ] 검색 의도와 CTA가 퍼널 단계에 맞는가(TOFU에 구매 CTA 금지).
- [ ] 발행 후 **배포·리퍼포징**을 하는가(제작만 하고 방치 금지, 배포 ≈ 제작 노력).
- [ ] 협찬·후원 콘텐츠에 **표기**가 있는가(미표기 = 표시광고법 위반, 신뢰·검색 평판 붕괴).
- [ ] 성과를 발행 수가 아니라 **유입·리드·영향 매출**로 측정하는가.
- [ ] E-E-A-T를 "점수·랭킹 신호"로 오해하지 않는가(개념 프레임일 뿐, 직접 랭킹 요인 아님).
- [ ] AI 양산 저품질 대량생산으로 클러스터를 **묽게** 만들고 있지 않은가.
