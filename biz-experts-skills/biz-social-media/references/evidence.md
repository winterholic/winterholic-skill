# biz-social-media — 채널 & 출처 (검증판·심화)

> SKILL.md 보강. **부패 빠름 — 플랫폼 공식이 진실원. 모든 수치·스펙에 시점 라벨.** 최초 검증 2026-06-30, 심화·재검증 2026-07-01. 1단계 참조. 실전 운용은 `playbook.md`.

## 1. 플랫폼 알고리즘 (공식 문서가 진실원)

### 1-1. Instagram — "하나의 알고리즘 없음"
- **Instagram은 단일 "알고리즘"이 아니라 표면(surface)별 별도 랭킹 시스템**을 쓴다: Feed / Stories / Reels / Explore 각각 다른 신호 가중. Adam Mosseri, "Shedding More Light on How Instagram Works" (about.instagram.com). https://about.instagram.com/blog/announcements/shedding-more-light-on-how-instagram-works
- **Reels 상위 3신호(2025-01 Mosseri 공개, 2026-07 재확인)**: ① **Watch time(시청시간)** = 1순위 배분 신호 ② **Likes per reach(도달 대비 좋아요율)** — 기존 팔로워 도달에 더 중요 ③ **DM 공유(sends)** — **신규 도달에 가장 강력한 신호**(수동적 좋아요보다 "능동 추천"으로 해석). 근거: Mosseri 2025-01 발언을 다수 매체가 재인용(later.com, buffer.com 등 2차). 순서·비중은 시점·표면별 변동 — **"3~5배" 같은 배수는 2차, 인용 시 근거 명시**.
- 표면별 강조(2차 정리, 2026-07): Reels=시청시간·sends / Feed=관계 강도 / Stories=최근성·시청 이력 / Explore=참여 속도·관심 매칭. → 시점 라벨 붙여 지침으로.

### 1-2. TikTok — For You 추천 시스템(공식)
- **신호 우선순위: 사용자 상호작용 > 영상 정보 > 기기/계정 설정.** 강한 관심 지표(긴 영상 **끝까지 완주** = completion)가 약한 지표보다 큰 가중. 상호작용 중 **공유(share)가 최고 가중**(가장 높은 노력의 행동), 그다음 **저장(save)**. https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content · https://www.tiktok.com/transparency/en/recommendation-system
- **팔로워 수·과거 바이럴 여부는 직접 요인 아님**(팔로워 많으면 초기 노출은 유리하나 랭킹의 직접 변수 아님) — 공식 명시. → 소규모 계정도 완주율·공유로 도달 가능(팔로워≠도달의 근거).
- **초 단위 retention curve 제공(공식)**: TikTok은 크리에이터에게 초 단위 시청 유지 곡선(어디서 이탈·리플레이했는지)을 제공 — 인스타는 평균 시청시간만 제공. **후크 진단에 실질적 차이.**
- **팔로워 우선 테스트(2026 보도, 2차·확인 필요)**: 신규 영상을 팔로워에게 먼저 노출 후 비팔로워로 확장한다는 보도 — 공식 확정 여부 확인 필요.

### 1-3. YouTube — 검색과 추천은 별개(공식)
- **검색(관련성+참여+품질)과 추천(홈·다음 동영상·Shorts 피드)은 별개 시스템**, 유기 노출을 돈으로 파는 상품은 없음. https://support.google.com/youtube/answer/16089387 · https://support.google.com/youtube/answer/11914225
- **핵심 지표: watch time · CTR(썸네일·제목 클릭률) · audience retention(시청 지속률).** ⚠️ **2024~2025 변화(2026-07 확인, 지침)**: YouTube는 **시청자 만족도 설문(satisfaction surveys)** 가중을 raw watch time보다 높였다고 공개 — 만족도 높으면 짧은 영상이 긴 영상을 앞지르기도. "watch time + satisfaction = session contribution"으로 사고(Todd Beaupre, 2025 언급, 확인 필요). CTR "4~6% 평균, 7%+ 양호"는 커뮤니티 통설(2차, 확인 필요).
- **롱폼 ≠ Shorts 별도 모델(2025 언급, 확인 필요)**: Shorts 모델은 첫 1~3초 swipe-vs-watch 비율·리플레이율·공유 중시. 롱폼 모델은 CTR·평균 시청 지속(AVD)·세션 기여·만족도 설문 중시. → **같은 채널이라도 포맷별로 최적화 지점이 다름.**

### 1-4. 기타 채널(2차·시점 라벨 필수)
- **X(구 Twitter)**: 2023 추천 알고리즘 일부 오픈소스 공개, 이후 잦은 변경 — 현 가중은 **확인 필요**. 초기 노출 후 참여(리트윗·답글) 속도가 확산 좌우(2차).
- **LinkedIn**: 초기 소수 노출 후 참여(특히 댓글·체류)로 확산 판정, 외부 링크 도달 하락은 통설(2차, 확인 필요). "dwell time(체류)" 중시(LinkedIn 엔지니어링 블로그 언급, 시점 확인 필요).
- **Threads**: 알고리즘 지속 변동, 공식 랭킹 문서 빈약 — **확인 필요**. Mosseri가 답글·재공유 중시 언급(2차).

## 2. 페이스북 유기 도달 하락 (검증 — 확정)

## 3. 한국 공정위 추천·보증 심사지침 (검증 — 확정)
「추천·보증 등에 관한 표시·광고 심사지침」(공정위 예규). **2020-06-22 개정, 2020-09-01 시행(확정).** **경제적 이해관계**(현금·무료 상품/서비스·할인 혜택 + 동업·고용·친족 등 이익 공유) 공개 의무 — 명확·눈에 띄게·추천과 같은 언어로·플랫폼별·소비자가 실제 보는 곳(해시태그 더미·"더보기" 뒤 금지). 집행은 표시광고법(시정명령/과징금). https://www.law.go.kr/LSW//admRulInfoP.do?admRulSeq=2100000190311
- **부속 「추천보증심사지침 안내서: Q&A로 알아보는 경제적 이해관계 표시」**(공정위 배포·개정): ① 추천·보증/경제적 이해관계 설명 ② 구체적 표시 방법 ③ 민원사례 Q&A 3부 구성. **매체별(네이버 블로그·인스타그램·유튜브·틱톡 등) 바람직한 표시 방법을 사진과 함께 안내**, **표시문구는 반드시 게시물 제목 또는 첫 부분에 게재**하도록 함. https://www.ftc.go.kr/www/selectReportUserView.do?key=10&rpttype=1&report_data_no=8706 (안내서는 개정되므로 최신본·정확 문구는 공정위 누리집 확인 필요.)
- **정확 문구(안내서 예시, 2026-07 easylaw.go.kr 재확인)**:
  - **사용 가능**: "광고"·"유료광고"·"상업광고"(모든 경우 통용) / 금전="광고비 지급"·"수수료 지급" / 무상제공="OO 협찬"·"OO 무료 제공/대여" / 할인="OO 할인 지원" / 적립="OO 적립금(포인트) 지급" / 전속="전속 모델"·"모델 활동비 지급" / 이익공유="수익 배분"·"공동구매" / 임직원="직원 리뷰".
  - **사용 불가(공식 부적절 예시)**: 체험단·체험 후기·기자단·서포터즈·원고료·파트너스·"내돈내산" / 영어·외래어 표기(Advertisement·AD·PR·Sponsor·컬래버레이션·파트너십·앰버서더). **한국어 콘텐츠는 한국어로 표기.**
  - **위치**: 동영상=제목 또는 영상 내 시작·끝 삽입 + 반복 표시 / 실시간 방송=제목·자막·음성으로 시작·끝 + 반복 공개. **부적절 위치=댓글·본문 중간(다른 글과 구분 안 됨)·"더보기" 뒤.**
  - **범위**: 돈 여부가 아니라 "경제적 이해관계" 유무로 판단 — **무료 협찬(공짜 제공)만 받아도 표시 대상.**

## 4. 후크 (지위 — 지침이지 공식 스펙 아님)
Mosseri는 Reel **첫 ~3초**를 결정적으로 프레이밍(시청시간=주요 분배 신호이므로 초반 이탈이 치명적). **"3초 하드 임계"는 인터뷰 프레이밍이지 공식 수치 스펙 아님 — 지침으로 표기.** 시청 완료율·재시청(loop)이 강한 신호(TikTok completion·IG watch time과 정합). DM 공유>좋아요 등 순서는 Mosseri 언급, **"3~5배" 배수는 2차·확인 필요**.

## 5. 교정
- **팔로워 수 ≠ 도달**(유기 도달 하락 + 팔로워는 랭킹 직접 변수 아님). 팔로워는 허영, **도달·저장·공유·완주율**이 실질.
- **뒷광고 = 공정위 표시 의무**(2020-09-01 시행), 표시는 제목/첫 부분·매체별.
- **채널 알고리즘은 공식 문서가 진실원.** 블로그·컨설팅 글은 2차 — 반드시 시점 라벨. 이 문서의 수치도 검증 시점(2026-07) 기준이며 재확인 대상.
