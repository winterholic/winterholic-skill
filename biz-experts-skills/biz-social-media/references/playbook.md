# biz-social-media — 실전 운용집 (Playbook)

> 일류 소셜 매니저의 바로 쓰는 도구. **채널·수치는 부패 빠름 — 모든 스펙에 시점 라벨, 실행 전 공식 최신 확인.** 이론·출처는 `evidence.md`.

---

## (a) 채널별 문법 요약표 (2026-07 기준 — 발행 전 재확인)

| 채널 | 대표 포맷 | 길이(통상) | 후크 위치 | 해시태그 | 발행 빈도(출발점) | 1순위 신호(공식) |
|---|---|---|---|---|---|---|
| **Instagram Reels** | 세로 9:16 영상 | 7~30초(짧을수록 완주↑) | 첫 3초 | 3~5개(콘텐츠 관련) | 주 4~7 | watch time·DM sends |
| **Instagram Feed** | 캐러셀·단일 이미지 | 캐러셀 5~10장 | 1장·첫 줄 | 3~5개 | 주 3~5 | 관계 강도·저장 |
| **Instagram Stories** | 세로·인터랙티브 | 15초 단위 | 즉시 | 스티커 | 매일(가능하면) | 최근성·완주·답장 |
| **TikTok** | 세로 9:16 영상 | 15~60초 | 첫 1~3초 | 콘텐츠+니치 | 주 5~14(양 유리) | 완주율·share·save |
| **YouTube 롱폼** | 가로 16:9 | 8분+(retention 중요) | 썸네일·제목·첫 15초 | 설명란 | 주 1~3 | watch time·CTR·retention·**만족도 설문** |
| **YouTube Shorts** | 세로 9:16 | ~60초 | 첫 3초 | #Shorts | 주 5+ | 완주·재시청 |
| **LinkedIn** | 텍스트·문서 캐러셀 | 텍스트 3~8줄+"더보기" | 첫 2줄(잘리기 전) | 3~5개 | 주 2~5 | 초기 참여·댓글·체류(2차) |
| **X** | 짧은 텍스트·스레드 | 1트윗+스레드 | 첫 트윗 | 1~2개 | 매일 다회 | 참여 속도(2차·확인 필요) |

## (b) 후크 패턴 카탈로그 (첫 3초/첫 줄)

후크의 임무: **스크롤을 멈추게 하고 다음을 보게 만든다.** 광고처럼 보이면 실패.

| 패턴 | 구조 | 예시(첫 줄/첫 3초) |
|---|---|---|
| **결과 선(先)제시** | 끝 결과를 먼저 | "재고 정리 3시간 → 20분 됐어요" |
| **문제 지목** | 아픈 지점 콕 | "인스타 팔로워는 느는데 매출은 그대로?" |
| **반전·의외** | 통념 뒤집기 | "팔로워 늘리기, 사실 제일 안 중요합니다" |
| **숫자·구체** | 측정 가능한 수치 | "이 3가지만 바꿨더니 저장 5배" |
| **호기심 갭** | 결말 감추기 | "이거 모르고 광고비 다 날렸어요" |
| **직접 호명** | 타깃 특정 | "동네 카페 사장님만 보세요" |
| **과정 예고** | 볼 이유 명시 | "0원으로 릴스 만드는 법, 끝까지 보면 다 나와요" |
| **긴장·데드라인** | 시급성 | "오늘 안에 안 바꾸면 이번 캠페인 놓칩니다" |

작성 규칙: ① 첫 3초 안에 "왜 봐야 하는지" 답 ② 자막 필수(무음 시청) ③ 낚시(클릭베이트)와 호기심 갭 구분 — 본문이 약속을 지켜야 신뢰·완주율 유지 ④ 후크 A/B: 같은 본문에 후크 2~3종 테스트.

## (c) 콘텐츠 필러(pillar) & 발행 캘린더

**필러 = 반복 발행할 3~5개 주제 축.** 브랜드 정체성 + 오디언스 가치의 교집합.

필러 구성 프레임(예: 동네 베이커리):
1. **교육/노하우** (홈베이킹 팁) — 저장·공유 유발, 신규 도달
2. **비하인드/스토리** (새벽 반죽 과정) — 관계·신뢰
3. **제품/오퍼** (신메뉴·한정) — 전환 (전체의 20~30% 이내, 팔이 과하면 이탈)
4. **UGC/후기** (손님 사진 리포스트) — 사회적 증거·참여
5. **트렌드/재미** (밈·챌린지, 브랜드 적합 필터 통과분만)

발행 캘린더 원칙:
- **지속 가능한 리듬 > 몰아치기.** 주 3회 4주 유지가 주 10회 1주 폭발 후 소멸보다 낫다.
- 필러별 비율 사전 배분(예: 교육 40 / 스토리 20 / 제품 20 / UGC 15 / 트렌드 5).
- **배치 제작(batch)**: 한 번에 촬영·편집 몰아 재고 확보 → 리듬 유지.
- 채널별 재가공(1소스 멀티유즈): 롱폼 1개 → Shorts 3개 → 캐러셀 1개 → X 스레드 1개. **복붙 금지, 문법 맞춰 재가공.**

## (d) 공정위 표기 체크리스트 (협찬/광고)

경제적 이해관계(현금·무상제공·할인·제휴·고용·친족)가 있으면 **반드시** 표시. (근거: `evidence.md` §3)

- [ ] **위치**: 게시물 **제목 또는 첫 부분**에 표시(끝·해시태그 더미·"더보기" 뒤 ❌)
- [ ] **명확성**: "광고", "협찬", "유료 광고", "○○로부터 제품 제공받음" 등 소비자가 즉시 이해하는 표현(모호한 "#gifted"·이모지·외국어 단독 ❌ — 최신 안내서 확인 필요)

**정확 문구 대조 (공정위 안내서 예시, 2026-07 재확인):**

| 상황 | ✅ 사용 가능 | ❌ 사용 불가 |
|---|---|---|
| 모든 경우 | 광고 · 유료광고 · 상업광고 | Advertisement · AD · PR · Sponsor |
| 금전 | 광고비 지급 · 수수료 지급 | 원고료 |
| 무상 제공 | ○○ 협찬 · ○○ 무료 제공/대여 | 체험단 · 체험 후기 · 서포터즈 · 기자단 |
| 할인/적립 | ○○ 할인 지원 · ○○ 적립금 지급 | 파트너스 · "내돈내산" |
| 관계 | 전속 모델 · 수익 배분 · 직원 리뷰 | 컬래버레이션 · 파트너십 · 앰버서더 |

> **한국어 콘텐츠는 한국어로 표기**(영어·외래어 단독 부적절). **무료 협찬만 받아도 표시 대상**(돈 여부 아닌 경제적 이해관계 유무로 판단).
> **위치 상세**: 동영상=제목 또는 영상 내 시작·끝 삽입 + 반복 표시 / 실시간 방송=제목·자막·음성으로 시작·끝 + 반복 공개 / 부적절=댓글·본문 중간·"더보기" 뒤.
- [ ] **같은 언어**: 콘텐츠 본문과 같은 언어로
- [ ] **매체별 방식**: 영상은 영상 내 자막·음성 병행, 이미지는 이미지 위, 블로그는 본문 상단(공정위 안내서 매체별 예시 준수)
- [ ] **지속 노출**: 영상 중 잠깐만 뜨고 사라지지 않게(전체 구간 인식 가능)
- [ ] **실행 원칙**: 협찬 표기 뺄 것을 요청받으면 거부 — 뒷광고는 표시광고법 위반(시정명령·과징금). 자연스러운 표기 문구로 대안 제시.

> 정확한 권장 문구·매체별 세부는 **공정위 최신 안내서**가 진실원. 이 체크리스트는 원칙이며 실행 전 원문 확인.

## (e) 소셜 KPI 세트 (팔로워는 결과, 지표 아님)

**팔로워 수·좋아요 = 허영 지표.** 팔로워는 도달을 보장하지 않고(유기 도달 하락 + 랭킹 직접 변수 아님, `evidence.md` §2·§1-2), 알고리즘·실제 가치는 **행동 신호**로 드러난다.

| 목표 | 1차 지표 | 채널별 강조 |
|---|---|---|
| **신규 도달** | 도달·노출·**공유(share)/DM sends** | TikTok share·IG DM sends = 신규 도달 최강 신호 |
| **가치 인정** | **저장(save)**·완주율 | TikTok save·IG 저장 = "다시 볼 가치" |
| **관계·충성** | 재방문·답글·댓글·체류 | Stories 답장·LinkedIn 댓글 |
| **전환** | 프로필 방문·링크 클릭·전환·CAC | 링크 스티커·바이오 링크 |
| **콘텐츠 건강** | 완주율(watch time %)·loop | Reels/Shorts/TikTok 공통 1순위 |

해석 원칙:
- **완주율·공유·저장이 낮으면** 팔로워가 늘어도 도달은 안 는다 → 콘텐츠(후크·가치) 문제, 팔로워 이벤트로 못 고침.
- **저장 높은 포맷 = 강화 대상**(4주 뒤 상위 포맷 더블다운).
- 팔로워 급증인데 저장·공유 정체 → 가짜/무관 팔로워 의심(허영).
- 모든 벤치마크 수치는 **자기 계정 baseline** 기준 상대 비교 — 업계 절대치는 시점·니치별 상이(확인 필요).

## 실무 함정 체크리스트
- [ ] 한 콘텐츠 전 채널 복붙(❌) → 채널 문법 재가공(✅)
- [ ] 후크 없이 설명부터(❌) → 첫 3초 결과·문제·반전(✅)
- [ ] 자막 누락(무음 시청 무시)
- [ ] 제품·오퍼 비중 과다(팔이만) → 필러 비율 20~30% 이내
- [ ] 협찬 미표기/끝에 숨김 → 제목·첫 부분 명확 표기
- [ ] 팔로워·좋아요만 리포트 → 도달·저장·공유·완주율 병기
- [ ] 알고리즘 스펙을 블로그 통설로 인용 → 공식 문서·시점 라벨 확인
