# PBR 워크플로 · 라이팅 · 포맷 실무 사양 (실전)

> 근거: Burley "Physically Based Shading at Disney"(SIGGRAPH 2012) · Khronos glTF 2.0 · Paul Debevec IBL(1998) · Polycount Wiki. 툴은 변하므로 원리 위주.

## 1. PBR 머티리얼 워크플로

### Metallic-Roughness (표준·기본)
glTF 2.0 코어. 입력 맵:
| 맵 | 색공간 | 내용 |
|----|--------|------|
| **Base Color(Albedo)** | **sRGB** | 순수 색만 — 조명·AO·그림자 굽지 말 것 |
| **Metallic** | Linear(Non-Color) | 0=비금속, 1=금속(중간값 드묾) |
| **Roughness** | Linear | 0=거울, 1=완전 확산 |
| **Normal** | Linear | 탄젠트 스페이스 표면 방향 |
| **AO** | Linear | 앰비언트 오클루전(틈새 그늘) |
| **Height/Displacement** | Linear | 실제 변위(parallax/tessellation) |
| **Emissive** | sRGB | 자체 발광 |

- ⚠️ **Specular-Glossiness는 deprecated 확장** — 신규는 Metallic-Roughness.
- **ORM 패킹**(실시간 최적화): R=AO, G=Roughness, B=Metallic 한 텍스처.

### 색공간 규칙 (최빈 실수)
- **Base Color·Emissive만 sRGB**, 나머지 데이터 맵은 전부 **Linear/Non-Color**. 데이터 맵을 sRGB로 읽으면 값이 감마 왜곡돼 재질이 어긋남.

### 알베도 값 위생
- 비금속 알베도 = 대략 **sRGB 50~240** 범위(숯~신설). 순수 0/255 금지(물리적으로 없음).
- 금속은 base color가 곧 반사색(0.5~0.98 반사율).

## 2. UV·텍셀 밀도
- **텍셀 밀도(texel density)** = 표면 실측 단위당 텍스처 픽셀. 에셋 전체 **일관** 유지(예: 512px/m). 불일치 시 어떤 면은 선명·어떤 면은 흐림.
- **UDIM**: 여러 1001+ 타일로 고해상 분할(영화·고품질). 실시간은 아틀라스/트림시트 선호.
- UV 심(seam)은 눈에 안 띄는 곳(겨드랑이·안쪽)·하드엣지 경계에.

## 3. 노멀맵 & 베이크
- **노멀맵은 지오메트리를 추가하지 않는다** — 픽셀 단위로 빛 반사 각도를 속여 디테일 착시. 실루엣은 여전히 로폴.
- **하이폴→로폴 베이크 절차**: 하이폴 스컬프 → 로폴 리토폴 → UV → **케이지 베이크** → 텍스처.
- **케이지(cage)**: 로폴을 살짝 부풀린 사본. 레이를 케이지에서 안쪽으로 쏴 하이폴 표면 노멀 기록. 타이트→누락(구멍), 느슨→왜곡(스큐). 마진 1~2단위에서 시작해 조정.
- 베이크 품질 = 로폴 UV 레이아웃 + 스무딩 그룹 + 케이지. 하드엣지는 UV로 분할해야 그라디언트 오류 없음.

## 4. 라이팅 (IBL + 3점)
- **IBL(Image-Based Lighting)**: HDRI 환경맵으로 사방 조명·반사. Debevec(1998). PBR 사실감의 핵심 — 재질이 정확해도 IBL 없으면 밋밋.
- **3점 조명(고전)**: Key(주광)·Fill(그림자 완화)·Rim/Back(윤곽 분리). 스튜디오·제품샷.
- **선형 색공간에서 라이팅 계산** 후 최종에 톤매핑/감마(sRGB) 적용. sRGB 공간에서 라이팅하면 빛 합산이 틀림.
- **ACES 색관리**: ACEScg 작업공간 + OpenEXR(HDR, float). 영화·고품질 파이프.

## 5. 실시간 vs 오프라인
| | 실시간(게임·XR) | 오프라인(영화·제품 CG) |
|---|---|---|
| 렌더 | 래스터화 + 하이브리드 RT | 패스트레이싱(몬테카를로 GI) |
| 폴리 | 로폴+노멀맵 | 하이폴 직접 |
| 예산 | 프레임당 ~16ms(60fps) | 프레임당 분~시간 |
| 조명 | 라이트맵 베이크 + 실시간 | 풀 GI 계산 |

## 6. 포맷 선택
- **glTF 2.0(.glb 바이너리)**: 웹·실시간·XR 사실상 표준(ISO/IEC 12113:2022). PBR 코어 지원.
- **USDZ**: Apple AR Quick Look·iOS. 비압축 ZIP(OpenUSD).
- **FBX**: DCC 툴 간 교환(리깅·애니 포함), 상용.
- **OBJ**: 지오메트리+UV만(구식, 머티리얼 빈약).
- 웹 배포: glb + Draco/메시 최적화 압축 + KTX2 텍스처(GPU 압축).

## 7. 흔한 실수 (교정)
- ❌ 데이터 맵(러프니스·노멀)을 sRGB로 읽음 → 재질 전부 어긋남. Non-Color로.
- ❌ 베이스컬러에 AO·그림자 구워넣음 → 이중 그늘. 베이스컬러는 순수 색만.
- ❌ 에셋마다 텍셀 밀도 제각각 → 선명도 불균일. 통일값 유지.
- ❌ 재질만 신경 쓰고 IBL 없음 → 밋밋. HDRI 환경 조명 필수.
- ❌ 노멀맵으로 실루엣 개선 시도 → 안 됨(굴곡은 착시). 실루엣은 지오메트리로.
