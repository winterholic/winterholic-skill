## 1. Apple PPO vs Apple CPP vs Google Play Experiments 비교표

| 항목 | Apple PPO (Product Page Optimization) | Apple CPP (Custom Product Pages) | Google Play Store Listing Experiments |
|---|---|---|---|
| **목적** | 기준 대비 A/B → 최선 크리에이티브 탐색 | 트래픽 소스별 상시 맞춤 페이지 | A/B → 최선 크리에이티브/텍스트 탐색 |
| **텍스트 테스트** | ❌ 불가(아이콘·스크린샷·프리뷰만) | ✅ 프로모텍스트 변형 가능 | ✅ 짧은설명·전체설명 텍스트 가능 |
| **아이콘 테스트** | ✅ 가능 | ✅ 가능 | ✅ 가능 |
| **스크린샷 테스트** | ✅ 가능 | ✅ 가능 | ✅ 가능 |
| **프리뷰(영상) 테스트** | ✅ 가능 | ✅ 가능 | ✅ 가능 |
| **최대 변형 수** | 기준 + 3 treatment | 최대 **70페이지**(2025-10-29, 이전 35) | 최대 3변형 |
| **실험 기간** | 최대 90일 | 상시(승자 선정 없음) | 기간 유연(최소 통계적 유효 기간 권장) |
| **신뢰도 기준** | ≥90% 권장 | N/A(비교 없음) | Google이 통계 유의성 계산 |
| **트래픽 분배** | 랜덤(기준 vs treatment) | 트래픽 소스별 고정 URL | 랜덤 |
| **승자 적용** | 수동 선택 후 기준에 적용 | 해당 없음(소스별 상시 운영) | 수동 선택 후 기준에 적용 |
| **키워드 할당** | ❌ 불가 | ✅ 가능(2025-10-29 신기능) | N/A |
| **딥링크** | ❌ | ✅ iOS 18+ | N/A |
| **동시 실험 수** | 1개 | 상시 70개 운영 가능 | 복수 가능(확인 필요) |
| **공식 링크** | https://developer.apple.com/app-store/product-page-optimization/ | https://developer.apple.com/app-store/custom-product-pages/ | https://play.google.com/console/about/store-listing-experiments/ |

**핵심 차이 요약**:
- PPO = "무엇이 더 잘 전환하는가" 과학 실험 (비주얼 한정).
- CPP = "어떤 오디언스에 어떤 페이지를" 상시 운영 (채널별 맞춤 + 검색 키워드 할당).
- Google Experiments = PPO + 텍스트까지 가능 → Apple보다 더 넓은 실험 범위.

## 2. CVR(전환율) 최적화 요소 — 우선순위 & 실무

### 전환 영향력 위계 (벤더 컨센서스 — 앱·카테고리별 상이)
```
아이콘 ≈ 첫 스크린샷(1~3컷) > 평점·리뷰수 > 프리뷰 영상 > 나머지 스크린샷 > 설명
```
⚠️ 순위는 벤더 A/B 관찰 컨센서스. 앱·카테고리·마켓에 따라 다름 → 자기 앱 실험 필수.

### 아이콘
- 검색결과·추천 피드에서 첫 노출. **스크린샷 보기 전에 탭 결정** 발생.
- 단순·명료·카테고리 맥락 — 작은 크기에서 식별 가능해야.
- 경쟁사 차별화: 카테고리 내 유사 아이콘 피함.
- PPO·CPP·Google Experiments 모두 아이콘 A/B 가능 → 필수 테스트 항목.

### 첫 스크린샷 (1~3컷)
- 검색결과에서 아이콘 우측에 노출(세로 스크린샷 2~3컷). 사용자 대부분 이것만 보고 결정.
- **기능 나열 ❌ → 핵심 가치·감성 후크 ✅**: "무엇을 할 수 있나"보다 "어떤 느낌인가".
- 첫 컷에 앱의 핵심 결과물(output) 표시 — 사용자 목표 달성 장면.
- 캡션/텍스트 오버레이: 2~5단어 임팩트 문구. 작은 해상도에서 읽힐 것.
- 세로/가로 방향: 게임은 가로, 유틸·라이프스타일은 세로 일반적(카테고리 관행 파악).

### 프리뷰 영상
- 자동재생(무음). 첫 3초가 핵심 — 사운드 없이도 전달되는 장면.
- ≤30초(Apple 제한). 실제 앱 UX 중심(광고 스타일 ❌).
- 프리뷰 추가가 전환을 **올릴 수도 내릴 수도** 있음 — A/B 필수(Game Hive 사례 등).

### 평점·리뷰
- **4.0 이상이 전환 임계점**(벤더 컨센서스, 확인 필요). 3.0 미만은 즉각 타격.
- 리뷰 수도 신뢰 신호 — 100+ 리뷰와 10 리뷰는 전환에서 다름.
- 최신 리뷰 품질 중요 — 오래된 부정 리뷰가 최신이면 악영향.

### 짧은 설명 (Google Play만)
- 검색결과에 아이콘 하단에 노출 → Apple 설명과 달리 **전환에 직접 영향**.
- 핵심 가치 제안 80자 내 압축. 주요 키워드 포함(인덱싱 + 전환).

## 3. Apple PPO 실험 설계 실무

### 준비
1. **가설 먼저**: "게임 플레이 스크린샷이 UI 스크린샷보다 전환율 높을 것" — 측정 가능한 형태로.
2. **한 번에 1개 변수**: 아이콘만, 또는 스크린샷만. 여러 변수 동시 변경 시 원인 불명.
3. **트래픽 충분한지 확인**: 소규모 앱은 90일 내 통계적 유의성 미달 가능.

### 실행 제약
- 동시에 1개 PPO만 운영 가능.
- 테스트 시작 후 treatment 변경 불가(새 테스트 시작 필요).
- 대체 아이콘 사용 시 모든 variant를 앱 바이너리에 포함 필요.

### 결과 해석
- ≥90% 신뢰도에서 승자 선택. 미달 시 테스트 연장 또는 새 가설.
- 90일 초과해도 미달이면 가설 재검토(변수가 실제 영향 없거나 차이 미세).
- 승자 크리에이티브 → 기준에 적용 → 다음 변수 테스트 반복.

## 4. Apple CPP 활용 전략

### 핵심 용도
- **UA 채널별 맞춤**: Apple Search Ads 캠페인 A, B, C 각각 다른 CPP → 채널 오디언스에 최적화 크리에이티브.
- **키워드 세그먼트별 맞춤**(2025-10-29~): 키워드 그룹별로 CPP 할당 → "피트니스" 검색 사용자에겐 운동 스크린샷, "명상" 검색엔 힐링 스크린샷.
- **시즌·캠페인 맞춤**: 크리스마스 크리에이티브, 블프 할인 프로모텍스트 등.
- **오디언스 세그먼트**: 리인게이지먼트(기존 사용자 복귀 캠페인)에 별도 페이지.

### PPO vs CPP 언제 쓰나
| 상황 | 권장 도구 |
|---|---|
| "어떤 아이콘이 더 나은가" 과학적 검증 | PPO |
| "광고 캠페인별 맞춤 페이지" | CPP |
| "키워드별 다른 크리에이티브" | CPP (2025-10-29~) |
| "텍스트(설명) A/B 테스트" | Google Experiments (Apple 불가) |
| "시즌 한정 크리에이티브" | CPP |

## 5. Google Play Store Listing Experiments 실무

### Apple PPO 대비 장점
- **텍스트 테스트 가능**: 짧은 설명, 전체 설명 A/B → 카피라이팅 최적화.
- **피처 그래픽 테스트**: Play Store 전용 피처 그래픽(태블릿/미디어 상단 배너).
- 메타데이터 전체 업데이트 없이 실험 가능(제목 제외 — 제목 변경은 전체 업데이트 필요).

### 주의
- 실험 중 대조군(기준) 수정 불가.
- 트래픽이 적은 앱은 유의성 달성 시간이 길어짐.
- 동시 실험 수 제한은 공식 가이드에서 명시 수치 없음(확인 필요).

## 6. 실험 우선순위 — 어디서 시작할까

```
1단계: 아이콘 A/B (영향 크고 빠름)
2단계: 첫 스크린샷 1~3컷 가설 검증
3단계: 프리뷰 유무·버전 테스트
4단계: 텍스트(짧은 설명 등 — Google만)
5단계: CPP로 채널·키워드별 세분화
```
