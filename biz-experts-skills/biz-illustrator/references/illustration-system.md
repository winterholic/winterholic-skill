# 일러스트 스타일 시스템 · 재현성 · 포맷 실무 사양 (실전)

> 근거: IBM Design Language(illustration) · Airbnb "Building a Visual Language"(Saarinen) · Albers/Itten · WCAG 2.1. 2026-07 검증.

## 1. 스타일 시스템 = 재현성 장치
일러스트 시스템의 목적은 **"작가가 바뀌어도 같은 스타일이 나오게"** 하는 것. 규칙을 한 번 정의하고 반복 — 에셋마다 재발명하면 통일 붕괴(브랜드 가이드라인과 같은 논리).

## 2. 규칙 요소 (시스템에 명시할 것)

| 요소 | 규칙 예 |
|------|---------|
| **선 굵기(line weight)** | 종류 **≤ 4개**, 명확히 구별될 때만 혼용. 계층별 굵기 지정(외곽 굵게·디테일 얇게) |
| **팔레트** | 핵심 색 소수(4~6)로 제한 + 명도 단계 확장. 색 수↑ = 통일↓ |
| **그리드** | 공통 그리드(24/48px)에 형태 맞춤 → 세트 정렬감 |
| **모서리 반경(corner radius)** | 통일 반경(예: 모두 4px 라운드) — 어떤 건 각지고 어떤 건 둥글면 이질감 |
| **조명·그림자** | 광원 방향·그림자 각도·강도 통일(3D/입체 일러스트 핵심) |
| **원근·시점** | 정면/아이소메트릭/투시 중 하나로 고정 |
| **인물 비율·스타일** | 머리:몸 비율, 얼굴 디테일 수준, 손·발 표현 규칙 |
| **디테일 밀도** | 미니멀/디테일 수준 통일 |

- IBM Design Language: 라인 스타일 = 제한된 굵기 세트 + 그리드로 일관성.
- Airbnb 3D 일러스트: 균일 형태·깊은 그림자·균형 팔레트를 시스템으로 규정(규칙 없으면 AI 렌더도 제각각).

## 3. 색 운용 (두 학파 실무 적용)
- **Itten(조화·상징)**: 팔레트 설계 — 보색·유사색·삼각 배색으로 조화. 색 심리(따뜻/차가움, 문화적 의미).
- **Albers(상대성)**: 같은 색도 인접 색에 따라 다르게 보임 — 배경·인접 요소 고려해 색 조정. "색은 맥락 의존."
- 실무: Itten으로 팔레트 짜고, Albers 원리로 실제 배치에서 미세 조정.

## 4. 구성 (composition)
- **실루엣 명료성(Appeal)**: 실루엣만으로 무엇인지 읽혀야(Thomas & Johnston). 검게 채워 테스트. ⚠️ Appeal=명료·가독·매력(귀여움 아님 — 악당도 appeal).
- **초점·시선 흐름**: 룰 오브 서드(1797, J.T. Smith 명명)·대각선·여백으로 시선 유도. 초점 1개 명확히.
- **여백(negative space)**: 채우기 강박 금지. 여백이 형태를 살림.

## 5. 접근성 (일러스트도 대상)
- **정보 전달 일러스트**는 색만으로 구분 금지(WCAG 1.4.1, A) — 형태·라벨·패턴 병행.
- 텍스트 포함 시 대비: 본문 **4.5:1**, 큰 텍스트/UI 그래픽 **3:1**(1.4.3/1.4.11). 반올림 금지.
- 인물 표현 다양성(persona spectrum, MS Inclusive Design) — 성별·연령·인종·장애 대표성.
- `alt` 텍스트 제공(장식용은 빈 alt).

## 6. 포맷 선택
| 포맷 | 용도 | 특성 |
|------|------|------|
| **SVG** | 아이콘·플랫/라인·로고 | 벡터, 무한 확대, 경량, CSS/애니 제어. 현행 Rec=SVG 1.1(2011) |
| **PNG** | 복잡 렌더·투명 필요 | 래스터, 무손실, 큰 용량 |
| **WebP/AVIF** | 웹 배포 | 경량 래스터 |
| **PDF/AI/EPS** | 인쇄·원본 | 벡터, 편집 가능 |
| **PSD** | 회화·텍스처풍 원본 | 레이어 보존 |

- 규칙: 확대·재편집·작은 아이콘 = 벡터(SVG). 회화·질감·3D = 래스터. 웹 최종 = WebP/AVIF.
- 명명: `illust-{주제}-{변형}.{ext}` (예: `illust-empty-state-search.svg`).

## 7. 흔한 실수 (교정)
- ❌ 일러스트마다 스타일 제각각 → 시스템 없음. 규칙(선 굵기·팔레트·그리드) 정의·반복.
- ❌ 선 굵기 5+종 혼용 → 산만. ≤4종, 명확 구별 시만.
- ❌ 색 10+개 팔레트 → 통일 붕괴. 핵심 소수 + 명도 확장.
- ❌ 정보를 색만으로(빨강=위험) → 1.4.1 위반. 형태·아이콘 병행.
- ❌ 확대 필요한데 PNG로 제작 → 깨짐. 벡터(SVG)로.
