# 분기 리듬 & CFR 운영

> evidence.md 보강. 설정→체크인→회고→채점 리듬 · 신뢰도 트래킹 · CFR 3요소. 검증: CFR=Doerr *Measure What Matters*(evidence.md §3, What Matters 공식 정의), 주간 리듬=Wodtke *Radical Focus*(§1).

## 1. 분기 리듬 4단계

```
[분기 전 ~2주]     설정(Setting)      전략 우선순위 → O/KR 초안 → 정렬 조율
[분기 중 매주]     체크인(Check-in)   진척·신뢰도·CFR 대화
[분기 중 월 1회]   중간 조정(Mid-Q)   신뢰도 급락 KR 재점검(목표는 유지)
[분기 말 ~1주]     회고+채점(Grade)   0~1 채점 → 원인 분리 → 다음 분기 입력
```

### ① 설정 (분기 시작 전)
- 전략에서 이번 분기 **가장 중요한 것 3개 안팎**을 좁힌다(→ biz-product-strategy). OKR은 전략의 실행 좁히기지 전략 자체가 아니다.
- top-down(회사 방향) + bottom-up(팀 자율 KR) 혼합. 상위 OKR 공유 후 팀이 기여 KR을 스스로 제안 → 조율.
- committed/aspirational 유형 지정(writing-and-grading.md §3).

### ② 주간 체크인 (Wodtke 리듬)
- **월요일 커밋 미팅**: 이번 주 우선순위(OKR에 기여하는 것) 확인 + 각 KR **신뢰도(0~10 또는 %)** 업데이트.
- **금요일 wins/축하**: 진척·작은 승리 공유(Recognition — CFR).
- 30분 이내. 진척 없는 KR은 왜 막혔는지(병목) 대화(Conversation — CFR).

### ③ 신뢰도 트래킹 (조기 경보)
각 KR을 "분기 말 달성 자신감"으로 매주 매긴다(예: 5/10 = 반반).
- 신뢰도가 **주 단위로 계속 하락** → 실행 격차/외부 변수. 목표를 낮추지 말고 **자원·우선순위**를 조정.
- 상시 9~10/10 → 목표가 너무 안전(aspirational인데 stretch 부족).
- Wodtke의 4사분면 위클리 트래커: (1)이번 주 P1~P4 (2)다음 4주 예정 (3)OKR 신뢰도 (4)health metrics(유지 지표는 여기, KR 아님).

### ④ 회고 + 채점 (분기 말)
- KR별 0~1 채점 → O 평균(`scripts/okr_score.py`).
- **원인 분리**: 저조한 O가 "목표 과대(aspirational 정상 범위인가)" vs "실행 격차(무엇이 막았나)"인지 나눈다.
- 채점은 **다음 분기 설정의 입력** — 처벌 아님. 낮은 점수도 학습 데이터(Klau).
- 배운 것 1~3줄 문서화 → 다음 설정 단계로 이월.

## 2. CFR — OKR을 살아있게 하는 지속 대화 (Doerr)

OKR이 "무엇을"이면 CFR은 "그 과정을 어떻게 대화하는가". 3요소:

| CFR | 무엇 | 언제·어떻게 |
|---|---|---|
| **Conversation** | 진척·전술·병목에 대한 1:1/체크인 대화 | 주간 체크인, 격주 1:1. "이 KR 어디서 막혔나?" |
| **Feedback** | 현재 행동↔의도 간극을 좁히는 양방향 피드백 | 상시·수시. 구체적·행동 지향. (심화는 → biz-management) |
| **Recognition** | 크고 작은 성과에 대한 실시간 긍정 인정 | 금요 wins, 즉시성이 핵심. 결과뿐 아니라 시도도 |

**왜 CFR이 없으면 OKR이 죽는가**: OKR만 세우고 대화가 없으면 분기 말 채점 때에야 실패를 안다. CFR은 매주 궤도를 수정하고, 특히 **평가와 분리된 안전한 대화**를 만들어 야심 찬 목표를 솔직하게 세우게 한다(sandbagging 방지의 문화적 장치).

> CFR의 Feedback/Recognition을 성과관리 제도로 확장하는 것은 biz-management 영역. 여기서는 OKR 리듬 안의 대화 도구로 한정.

## 3. 미니 운영 체크리스트

- [ ] 이번 분기 O 3개 안팎, O당 KR 3개 안팎으로 좁혔나
- [ ] 각 O/KR에 committed/aspirational 유형을 표기했나
- [ ] KR에 기준선·목표치·측정 방법이 다 있나(활동 아닌 결과인가)
- [ ] 유지·건강 지표를 KR이 아니라 health metric으로 분리했나
- [ ] 주간 체크인(신뢰도) + 금요 wins 리듬이 캘린더에 잡혔나
- [ ] OKR 달성률을 보너스·고과에 직결하지 않기로 합의했나
- [ ] 분기 말 채점 결과를 다음 분기 설정 입력으로 이월하는 절차가 있나
