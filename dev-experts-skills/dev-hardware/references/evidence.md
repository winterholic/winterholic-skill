# dev-hardware evidence — 실증 사례

## 1. 중고 사기 패턴 분류 — 반복되는 수법의 카탈로그 (커뮤니티 집적 + 사용자 피해 경험 반영)

- **수법 분류**:
  1. **시간 압박형**: "지금 다른 사람도 보러 온다"·"오늘만 이 가격" — 검증 시간을 빼앗는 게 목적. 정상 매물은 기다려준다.
  2. **위장형**: 채굴 GPU 세척·팬 교체 / 침수·수리 이력 은폐 / 하급 모델 스티커 갈이(GPU·SSD 용량 위조는 해외 직구에서 특히) — 외관이 아니라 부하 동작과 소프트웨어 판독(GPU-Z·CrystalDiskInfo 실용량 검사)으로만 검출.
  3. **구성품 바꿔치기형**: 정품 박스에 하급 쿨러·짝퉁 케이블 — 인수 시 구성품 대조표.
  4. **벽돌형**: "어제까지 됐다" — 현장 부팅·부하 없이는 진위 판정 불가. 택배 거래의 주력 수법이라 안전결제+개봉 영상이 방어.
- **공통 신호**: 검증 요청에 대한 거부감 — 절차를 제안했을 때의 반응 자체가 가장 싼 필터다.

## 2. 무명 파워 연쇄 사망 — "파워가 죽을 때 혼자 안 죽는다" (커뮤니티·리뷰 집적)

- **무슨 일**: 정격 미달·보호회로(OVP/OCP/SCP) 부실 파워의 고장이 12V 레일 이상으로 보드·디스크를 동반 사망시키는 사례가 조립 커뮤니티의 고전 장르 — 전문 리뷰(부하 장비 계측)에서 정격 표기의 절반에서 셧다운되거나 발화하는 무명 제품이 반복 적발돼 왔다.
- **더 흔한 저강도 피해**: 즉사가 아니라 전압 리플로 인한 간헐 재부팅·콜드부팅 실패 — "소프트웨어 다 갈아도 안 고쳐지던" 미스터리의 단골 진범(진단 순서에서 파워 교체 테스트가 상위인 이유).
- **선택 규칙**: 보증 기간(7~10년)을 품질 신호로 + 전문 리뷰 계측 존재 여부 — 80PLUS 인증만으로는 보호회로 품질을 말해주지 않는다.

## 3. 최소 구성 진단 분기표 — "안 켜져요"의 이진 탐색 (조립 실무 표준)

- **0단계 — 정의 분리**: "안 켜짐"을 3종으로: ① 팬도 안 돎(전원 계통) ② 팬은 도는데 화면 없음(POST 실패) ③ 화면까지 오고 OS 실패(→ 소프트웨어, 이 스킬 졸업).
- **① 전원 계통**: 콘센트→케이블→파워 스위치(I 표시)→24핀/8핀 재장착→파워 단독 점프 테스트(클립) — 순서대로.
- **② POST 실패**: 케이스 밖 최소 구성(보드+CPU+램1+파워) → 비프음/디버그 LED 해독(보드 매뉴얼) → 램 1개·슬롯 로테이션(POST 실패 최다 원인) → CMOS 클리어 → 통합그래픽으로 GPU 배제 — 한 번에 한 변수.
- **케이스 단락 함정**: 케이스 조립 후에만 실패하면 스탠드오프 위치 오류(보드 뒷면 단락)·전면 패널 커넥터 오결선 의심 — "맨보드에선 되는데"의 단골.
- **원리**: 변수를 절반씩 배제하는 이진 탐색(dev-git-advanced bisect와 동형) — 추측 구매는 탐색이 끝난 뒤의 마지막 수단.

> 출처: 조립·중고 커뮤니티 사고 집적 · PSU 전문 계측 리뷰 관행 · 보드 제조사 진단 매뉴얼. 2026-06 기준 — 세대별 스펙은 구매 시점 확인.

## 1차 출처 (웹 검증 2026-06)

검증 도구·표준의 공식 출처. 세대별 스펙·시세가 아니라 **변하지 않는 원리/도구**라 1차 링크가 유효하다.

- **80 PLUS = 효율 인증, 품질·보호회로 보증 아님** — 공식 프로그램 운영사 CLEAResult <https://www.clearesult.com/80plus/> · 제조사 정리(Seasonic) <https://seasonic.com/insights/seasonic-80-plus-certification/>. 효율 등급(80%@20/50/100% 부하)만 측정하고 OVP/OCP/SCP/OTP 등 보호회로는 별도 항목 — 높은 등급은 고품질과 *상관*은 있으나 보증은 아님(안티패턴 2, 본문 §2의 핵심 주장 확인됨). 2025-03 데이터센터용 Ruby 등급 신설도 효율 한정.
- **memtest86 ≠ memtest86+ (둘은 다른 프로젝트)** — PassMark MemTest86 <https://www.memtest86.com/> 는 프리웨어(무료판은 16코어 제한·Secure Boot 지원, Pro 유료) / 오픈소스 MemTest86+ <https://www.memtest.org/> 는 완전 무료·GPL(단 Secure Boot 미지원이라 BIOS에서 끄고 부팅). 둘 다 부팅 USB로 OS 없이 DDR4/DDR5 검사 — 중고/불안정 시 1패스 의무(본문 워크플로우). 본 스킬의 "전부 무료"는 memtest86+(memtest.org) 기준이 정확.
- **부하·모니터링 도구 공식 배포처** — OCCT <https://www.ocbase.com/> (CPU/GPU/RAM/PSU 올인원, HWiNFO 센서 엔진 내장) · HWiNFO <https://www.hwinfo.com/> (실시간 온도·전압·클럭 센서) · FurMark <https://geeks3d.com/furmark/> (GPU 부하·아티팩트 유도). 전부 공식 무료 — 거래 현장 USB 운용 전제(워크플로우 A 검증) 성립.
- **BIOS 업데이트 닭-달걀 함정의 현대적 해법: BIOS Flashback** — ASUS USB BIOS Flashback <https://rog.asus.com/tag/usb-bios-flashback/> (Gigabyte=Q-Flash Plus, MSI=Flash BIOS Button, ASRock=BIOS Flashback). CPU·램·GPU 없이 24핀 전원 + FAT32 USB만으로 바이오스 갱신 가능 — "신형 CPU 인식하려면 구형 CPU 필요"의 닭-달걀이 **해당 기능 탑재 보드에선 해소**된다. 단 저가/소형 보드는 미탑재가 많아 구매 전 스펙시트로 Flashback 지원 여부 확인이 새 체크 항목.
