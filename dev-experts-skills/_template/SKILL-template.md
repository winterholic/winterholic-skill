# dev-experts 스킬 템플릿 (Phase 1+ 제작용)

> 이 파일은 스킬이 아니라 **제작 보일러플레이트**다. 새 전문가를 만들 때 아래 골격을 복사해 `dev-<이름>/SKILL.md`로 시작한다.
> DoD 원본: `../dev-experts-plan.md` §6 · 제작 파이프라인: §8 (3-pass) · 오픈소스 흡수: §7 + `../README.md` 소스맵.

## 제작 절차 요약 (3-pass)

```
제작 진행 체크리스트 (응답에 복사해 진행):
- [ ] Pass 1 소스: 공식 문서 + 거장 원전 + 오픈소스 스킬 1~3개 조사 (WebSearch/web-browse 적극 사용)
- [ ] Pass 1 초안: 아래 골격대로 SKILL.md 작성
- [ ] Pass 2 채점: skills-estimate → 약점 Top 3 보강 → 85점(B+) 미만이면 반복
- [ ] Pass 3 무장: 안티패턴 5쌍+ / 실전 케이스(유명 장애) / scripts 실행 검증 / 버전 라벨
- [ ] README.md 카탈로그 상태 ⬜→✅ 갱신
```

## 작성 원칙 (Anthropic 공식 베스트 프랙티스 흡수분)

1. **Claude는 이미 똑똑하다** — LLM이 아는 일반론은 쓰지 않는다. "그 거장이 실제 가르치는 기준·함정"과 정량 임계치만. 문단마다 "이 토큰값을 하는가?" 자문.
2. **본문 500줄 미만** — 넘으면 references/로 분리. 참조는 SKILL.md에서 1단계만(레퍼런스→레퍼런스 금지). 100줄 넘는 레퍼런스는 목차 의무.
3. **description은 3인칭** + what + when(트리거) + SKIP. 1024자 이내.
4. **자유도 매칭** — 여러 접근이 유효한 영역은 휴리스틱(높은 자유도), 깨지기 쉬운 절차는 정확한 명령 시퀀스(낮은 자유도, "이 명령 그대로 실행")로 쓴다.
5. **기본값 1개 + escape hatch** — "A도 되고 B도 되고" 금지. 기본 권장 1개, 벗어날 조건 명시.
6. **시한성 정보 금지** — "2026년 8월 이전이면..." 식 서술 대신 버전 라벨 + 필요시 "구버전 패턴" 접이식 섹션.
7. **scripts는 표준 라이브러리만** (python 3.10), 에러를 스스로 처리(Claude에게 떠넘기지 않기), 매직넘버에 근거 주석. 작성 즉시 실제 실행 검증. 출력 문자열은 ASCII만(PS 콘솔 cp949 함정 — em-dash 금지).
8. **eval 먼저** — 본문을 쓰기 전에 "이 스킬이 없으면 Claude가 틀리는 시나리오 3개"를 적는다. 그 갭을 메우는 내용만 쓴다(상상한 요구사항 문서화 금지). 시나리오는 SKILL.md 맨 아래 주석이 아니라 라우터 eval 또는 케이스 섹션으로 산다.
9. **채점 반복 결손 3종을 초안부터 포함** (2026-06-11 Phase 0~1 채점 실측 — 빼먹으면 77~84점에 멈춘다):
   - **파일 배치 규칙** (C3): 워크플로우에 "새 파일 어디에·기존 파일 덮어쓰기 금지" 1줄
   - **사용자 거부 처리** (D2): "사용자가 권고를 거부하면" 섹션 — 따르되 리스크 1줄 기록(partial), veto급은 1회만 경고, 반복 거부는 프로젝트 CLAUDE.md 규칙화 제안
   - **친절함** (E): 용어 풀이·비유 1개 + copy-paste 가능한 명령 코드블록 3개+ (grep·검증 명령)

## scripts/ 구성 가이드

- 용도: 스캐폴딩 생성기 / 설정 lint / 체크리스트 실행기 (주식의 계산기에 대응).
- 강제: python 3.10 표준 라이브러리만 · 인자 없이 실행하면 데모 동작 · 에러 자체 처리 · 매직넘버 근거 주석 · 출력 ASCII만.
- **stdin 읽기는 명시 인자(`-`)로만** — `sys.stdin.isatty()` 분기는 에이전트/CI 환경에서 영원히 블로킹된다(2026-06-11 실측).
- 파일 일괄 수정 스크립트는 `[IO.File]::WriteAllText` + UTF8 no-BOM 패턴 준수(frontmatter 보호).
- **작성 후 즉시 `python scripts/<이름>.py` 실행해 출력 1~3줄을 제작 응답에 첨부** — 미실행 스크립트는 출고 금지.
