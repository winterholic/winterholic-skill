# evidence + 출고 전 체크리스트

## 실증·출처

- **OWASP Top 10:2025** (owasp.org/Top10/2025, 2025-11 Global AppSec 공개 → 2026-01 최종 확정) + **OWASP Cheat Sheet Series** — 항목·처방의 1차 출처. 2025판 핵심 변경: A01 #1 유지(SSRF 통합) · A02 보안 설정 오류 #5→#2 · **A03 Software Supply Chain Failures 신설** · A05 암호 실패 #2→#5 하락 · **A10 Mishandling of Exceptional Conditions 신설**. 589개 CWE 분석(2021판 ~400개에서 확대). Cheat Sheet는 주제별(XSS Prevention·SQL Injection Prevention) 구체 처방의 표준.
- **Equifax 침해 (2017)**: 미 하원 감독위원회 공식 보고서(2018) — Struts CVE-2017-5638 미패치 → 1.4억 명 유출. SKILL.md 실전 케이스.
- **OWASP ASVS** — 검증 수준별 요구사항 표준(점검 깊이 결정에 참조).
- **SameSite·CSP**: MDN·OWASP 문서 — 안티패턴 5·6의 1차 근거.
- 오픈소스 차용 표기: security-review류 스킬·SAST 도구(색인 인지, 본문 비복사). **역흡수**: 신뢰 경계 지도 우선·출력 맥락별 인코딩 구분·위협 모델링 경량판·거부 시 등급 분리 부재 — 본 스킬 차별점. 자동 도구는 패턴만, 이 스킬은 관점.

## 출고 전 보안 체크리스트

- [ ] 신뢰 경계 지도 작성 — 전 입력 지점의 검증 위치 확인
- [ ] 쿼리·명령 문자열 조립 0 (`sec_scan.py` 0건)
- [ ] 출력 맥락별 인코딩 (자동 이스케이프 끈 곳 정제 확인)
- [ ] 모든 리소스 접근에 서버측 인가 (IDOR 점검)
- [ ] 비밀: 코드·로그·URL 0
- [ ] CSRF 방어(SameSite + 토큰) 또는 헤더 토큰 인증
- [ ] 보안 헤더 세트 적용
- [ ] 디버그·스택트레이스 운영 노출 0
- [ ] 입력 검증 allowlist 우선
- [ ] 의존성 알려진 취약점 0 (dev-dependency-security)
- [ ] [2025 A03] 빌드/배포 공급망 무결성 — SBOM·아티팩트 서명·신뢰 소스
- [ ] [2025 A10] 예외/에러 경로 fail-closed, 부하·이상조건에서 인가 우회 없음
- [ ] 고위험(인증·암호)은 라이브러리 위임
- [ ] [심각] 거부 결정은 리스크와 함께 기록됨
