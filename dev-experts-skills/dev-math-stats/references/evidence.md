# dev-math-stats evidence — 실증 사례

## 1. Literary Digest 1936 — 거대 표본의 참패 (통계학 정사)

- **무슨 일**: 1,000만 명에게 설문 발송·236만 응답 — "랜던 57%" 예측. 실제: 루스벨트 61% 압승. 갤럽은 5만 표본으로 정답 + Literary Digest의 오답까지 예측. 잡지는 신뢰 붕괴로 폐간.
- **패인 해부**: ① 표집틀 편향 — 명부가 자동차·전화 보유자(대공황기 공화당 성향 부유층) ② 무응답 편향 — 23% 자발 회신(불만층이 더 응답하는 구조). 크기는 편향을 1도 줄이지 못하고 **확신만 키웠다**.
- **개발 현장 대응표**: 앱스토어 리뷰(극단 만족/불만만 씀) · 설문 응답자(시간 있는 사용자) · 에러 리포트 동의자 · 살아남은 세션 로그(크래시 유저는 로그가 없다) — 전부 같은 구조. 처방: 결론 전 "응답하지 않은/보이지 않는 쪽은 누구인가"를 1회 묻기.

## 2. 평균 회귀 — 칸만의 비행 교관 일화와 운영 지표 (행동경제학 고전)

- **무슨 일**: Kahneman이 이스라엘 공군에서 관찰 — 교관들은 "칭찬하면 다음에 못하고, 질책하면 다음에 잘한다"며 질책 효과를 확신. 실제는 극단 수행(아주 잘함/못함) 다음 시도가 평균으로 돌아오는 회귀일 뿐 — 개입과 무관했다.
- **운영 번역**: "최악의 주 다음에 개선 작업 → 다음 주 좋아짐"은 개입 없이도 절반쯤 일어난다 — 장애 많던 달 이후의 모든 조치가 효과적으로 보이는 구조적 착시. A/B 없는 사후 개선 평가의 만성 오염원.
- **처방**: ① 극단 선별 후 평가엔 대조군(같은 극단, 무개입) ② 불가하면 회귀 기대치를 먼저 추정(과거 극단값들의 자연 복귀 폭) ③ 최소한 보고서에 "회귀 효과 미분리" 1줄 — 모르는 척이 최악.

## 3. 몬테카를로 검산 — 몬티홀과 생일 문제로 보는 "루프가 수식을 이긴다" (실전 도구 실증)

- **무슨 일**: 몬티홀 문제(바꾸면 2/3)는 수학자 폴 에르되시조차 시뮬레이션을 보고서야 수긍한 일화로 유명 — 직관 배반 확률은 논증보다 빈도가 설득력 있다. 생일 역설(23명이면 50%)·중복 충돌 확률(해시·ID 생성) 등 실무 확률 질문 대부분이 10줄 시뮬레이션으로 종결된다.
- **실전 골격**:
  ```python
  import random
  def once():  # 과정을 그대로 코드로 — 가정이 강제로 명시된다
      doors = [0,0,1]; random.shuffle(doors)
      pick = 0; opened = next(i for i in (1,2) if doors[i]==0)
      switched = next(i for i in (1,2) if i!=opened)
      return doors[switched]
  print(sum(once() for _ in range(100_000)) / 100_000)  # ≈ 0.667
  ```
- **사용 수칙**: ① N=10⁵면 오차 ~0.3%(1/√N) — 판단 충분 ② 시드 고정으로 재현 ③ 결과가 직관과 다르면 시뮬레이션 가정부터 재검(시뮬레이션도 가정을 코딩한 것) — 단 그 가정이 눈에 보인다는 게 수식 대비 결정적 장점.

> 출처: 1936 선거 사례(통계학 교과서 정사) · Kahneman *Thinking, Fast and Slow* · 몬티홀 일화(vos Savant 사건). 2026-06 기준.
