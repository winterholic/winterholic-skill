# dev-geo-maps evidence — 실증 사례

## 1. Null Island — (0,0)에 모이는 버그들 (GIS 업계 공인 현상)

- **무슨 일**: 지오코딩 실패·결측·좌표가 0으로 적재되는 버그가 전 세계적으로 흔해, (0,0) 지점에 "존재하지 않는 데이터의 섬"이 형성되는 업계 통용 개념. Natural Earth 데이터셋은 실제로 (0,0)에 1제곱미터 가상 지물을 두어 이런 데이터를 걸러내는 용도로 쓴다.
- **국내판 변형**: (0,0)뿐 아니라 ① 좌표 순서 뒤집힘(한국 데이터가 인도양·동아프리카로) ② TM 좌표를 도 단위로 오독(수십만 단위 그대로) ③ 시군구 중심좌표로 일괄 대체된 "가짜 정밀" 좌표.
- **방어 검증**: 적재 검증 3종 — 범위 체크(한국 33~39/124~132) + (0,0)·NULL 분리 + 동일 좌표 과밀 감지(한 지점에 수백 POI = 중심점 대체 의심). 실패는 NULL로 남겨 "모름"과 "원점"을 구분.

> 출처: Natural Earth v1.3 릴리스노트(2011-01) — (0,0)에 scale rank 100(절대 표시 안 함)의 1m² 폴리곤을 명시적으로 추가, "대부분 지도 서비스가 지오코딩 실패를 0,0으로 라우팅하므로 플래그용"으로 기술. WGS84 기준. (naturalearthdata.com 릴리스노트 / Library of Congress·Atlas Obscura 교차확인) — 2026-06 기준.

## 2. Google Maps 요금 개편 (2018) — 무료 가정 위에 지은 설계의 척구서

- **무슨 일**: Google Maps Platform 개편 발표 **2018-06-11**, 새 요금 발효 **2018-07-16**. 18개 API를 Maps·Routes·Places 3개로 통합하고, **유효 API 키 + GCP 결제 계정 등록을 필수화**. 무료 티어는 "월 $200 크레딧" 형태로 전환(약 28,000회/월 동적 지도 로드 상당) — 결제 미등록·초과 시 워터마크('for development purposes only') 지도 또는 에러. Mapbox·OSM(Leaflet) 이주 붐의 직접 원인.
- **설계 교훈**: ① 호출 구조가 곧 비용 구조 — "페이지 로드마다 지오코딩"과 "전 목록 경로 계산"는 요금 폭탄 ② 캐시 가능한 호출(지오코딩 결과)과 불가한 호출(실시간 경로)을 구분해 설계 ③ SDK 결합을 한 모듈로 좁혀 제공자 교체 가능성 확보 — 약관·요금은 일방 변경되는 외부 변수다.
- **국내 적용**: 카카오·네이버도 무료 쿼터+초과 과금/제휴 모델 — 쿼터 알림과 호출 대시보드를 기능 출시와 동시에.

## 3. 한국 좌표계 지뢰밭 — 공공데이터 혼재 실증

- **무슨 일**: 국내 공공·민간 데이터의 좌표계가 제공처·시대별로 혼재 — WGS84(EPSG:4326), GRS80 기반 TM(중부원점 EPSG:5186 등 원점별 4종), 옛 Bessel 기반(KATEC·TM128 — 과거 일부 지도 서비스). 같은 "TM"이라도 원점이 다르면 수백 km 어긋난다.
- **국내 지도 SDK 좌표계**(load-bearing): 카카오맵 좌표 수집/표출에 **EPSG:5181(KGD2002 중부원점 변형)**, 네이버지도는 **EPSG:5179(UTM-K, GRS80)**, 표준 WGS84는 EPSG:4326 — SDK별로 내부 투영이 다르니 좌표를 SDK 간 그대로 옮기지 말 것.
- **실무 절차**: ① 데이터 명세에서 EPSG 코드 확인(명세에 없으면 제공처 문의 — 추측 금지) ② 값의 자릿수로 1차 추정(도 단위 2~3자리 소수 vs 미터 6~7자리 정수) ③ pyproj로 변환 후 알려진 장소 1곳 눈 검증 ④ 저장은 4326 통일 + 원본 좌표계를 메타로 보존(변환 오류 시 재변환 가능).
- **이 스킬과의 연결**: 안티패턴 2. tour-data류 다중 소스 프로젝트에서 "일부 데이터만 어긋남"의 원인 1순위.

> 출처: Natural Earth/GIS 커뮤니티(Null Island) · Google Maps Platform 개편 공지·업계 반응(2018-06-11 발표/2018-07-16 발효) · 국토지리정보원 좌표계 문서 + epsg.io(4326/5179/5181/5186 정의) 교차확인. 2026-06 기준.
