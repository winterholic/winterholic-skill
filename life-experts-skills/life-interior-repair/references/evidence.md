## 1. 임대차 하자 책임 구분 상세

근거 골격(민법, 확인 필요):
- **제623조(임대인의 의무)**: 임대인은 목적물을 사용·수익에 필요한 상태로 유지하게 할 의무 → 대규모 수선·구조적 하자·노후 설비 교체는 임대인.
- **제615조·제654조(임차인의 원상회복 의무)**: 통상의 사용·수익 범위의 관리, 종료 시 원상회복 → 소모품·간단 관리·과실 훼손은 임차인.
- **제634조(임차인의 통지의무)**: 하자 발견 시 임대인에게 통지 → 통지 게을리해 확대된 손해는 임차인 부담 가능.

분쟁 빈발 회색지대:
| 항목 | 쟁점 | 실무 경향 (확인 필요) |
|---|---|---|
| 보일러 | 노후 자연고장 vs 임차인 관리소홀 | 노후·자연고장=임대인 / 동파 등 관리소홀=임차인 |
| 결로·곰팡이 | 단열결함(구조) vs 환기부족(생활) | 원인 입증 싸움 — 단열=임대인, 환기=임차인 |
| 변기·배관 막힘 | 노후 vs 이물질 투입 | 노후=임대인 / 이물질=임차인 |
| 도배·장판 | 자연 노후 vs 과실 훼손 | 노후 감가=임대인 / 못·낙서·오염=임차인 |

원칙: **특약 > 실제 원인 > 일반 경향**. 표는 출발점일 뿐 분쟁조정 판단이 우선.

## 2. 곰팡이 원인 3분류 진단표

| 구분 | 위치 신호 | 시기 신호 | 책임 경향 | 1차 대응 |
|---|---|---|---|---|
| 결로 | 외벽·창틀·북향벽·가구 뒤 | 겨울·환절기 집중 | 환기부족=임차인 / 단열결함=임대인 | 환기 하루 2회·제습·가구 벽 띄우기 |
| 누수 | 천장·배관 주변·아래로 번짐 | 계절무관·점점 확대 | 건물하자/윗집=임대인측 | 밸브차단·관리실/윗집 통보 |
| 생활습관 | 욕실·세탁실·주방 | 상시 | 임차인 | 환풍기·물기 제거·환기 |

판별 핵심: **결로는 "온도차 큰 면+겨울", 누수는 "위→아래로 확산+계절무관"**. 둘이 헷갈리면 누수 우선 점검(골든타임).

## 3. 원상복구 분쟁 패턴

- **신품 복원 요구**: 임대인이 거주 연수 무관하게 도배·장판 신품가 전액 청구 → 자연 감가분은 임대인 부담이 일반 해석(확인 필요).
- **입주 전 하자 전가**: 기존 흠을 임차인 훼손으로 → 입주 사진으로 방어.
- **과다 청구 후 보증금 일부 반환 지연**: 합의 안 되면 임차권등기명령·분쟁조정·소액소송(→ life-legal).

방어 3종: ① 입주 당일 전체 사진/영상 ② 하자 발견 즉시 통보 기록 ③ 퇴거 시 청소·상태 사진.

## 4. 셀프 가능선 / 전문가선

| 셀프 OK (실패해도 회복 쉬움) | 전문가 필수 (실패 비용 큼) |
|---|---|
| 실리콘 코킹·줄눈 | 전기 증설·분전반 |
| 전구·콘센트 커버·방충망 | 가스 배관·연소기 |
| 간단 도배·페인트 | 방수(욕실·옥상·베란다) |
| 문손잡이·경첩 | 상수도 본관·누수 탐지 |
| 무타공 선반(임대 원복용) | 구조벽·확장부 |

판단 기준: **실패 시 손해가 출장비를 넘으면 전문가**. 가스·전기·방수는 예외 없이 전문가.
