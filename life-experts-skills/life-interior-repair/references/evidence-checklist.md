# evidence + 안내 전 체크리스트 — 집 수리·하자 (시공·법률 자문 아님)

> 가스·전기·방수·구조는 셀프 금지 영역 — 누출·감전·화재 위험 시 안내보다 먼저 119/대피·차단. 책임 소재(임대인 vs 임차인)는 단정하지 않고 분쟁조정·법률 경로로. 상세는 `evidence.md`, 조항·출처는 `sources.md`.

## 실증·출처

- **임대인 수선의무 — 민법 제623조**(2026-06 확인): 임대인은 목적물을 인도하고 계약 존속 중 사용·수익에 필요한 상태를 유지할 의무. 누수·보일러 동파·구조적 하자는 통상 임대인 영역. 출처: 민법 제623조(law.go.kr) · 한국부동산원·LH 임대차분쟁조정위 조정사례.
- **임차인 통지의무 — 민법 제634조**: 수선 필요·하자 발견 시 임대인에게 지체 없이 통지. 미통지로 손해 확대 시 임차인 불리 → 발견 즉시 기록 남는 통지(사진·문자).
- **원상회복 — 민법 제654조(제615조 준용)**: 임대차 종료 시 원상회복 의무. 단 **자연마모·통상 생활기스는 공제 대상 아님**(세월에 따른 감가). 출처: 민법 제654·615조.
- **분쟁조정 처리기간 60일(+30일 연장 가능)**: 유지·수선의무 분쟁도 조정 대상. 운영기관 분산 — **한국부동산원·LH**(adrhome.reb.or.kr) / **대한법률구조공단**(hldcc.or.kr, ☎132). 출처: 임대차분쟁조정위 안내(2026-06 확인).
- **셀프 vs 전문가 경계**: 셀프 OK(실리콘 코킹·줄눈·전구/콘센트 커버·간단 도배·방충망) / **전문가 필수(가스·전기 증설·상수도 본관·방수·구조·누수탐지)** — 안전·배상 리스크가 출장비를 압도.

## 안내 전 체크리스트 (안전 게이트 먼저)

- [ ] **안전 게이트 먼저** — 가스 냄새/누출·누전·감전·천장 누수 확산이면 셀프 조언 멈추고 **차단·대피·119/관리실/한국가스안전공사** 우선
- [ ] **셀프 금지 영역 명확** — 가스·전기 증설·방수·상수도 본관·구조벽은 "전문가 필수"로 단정(셀프 유도 금지)
- [ ] **책임 소재 단정 금지** — 결로(임차인 관리 영역多) vs 누수(건물 하자/윗집 영역多) 판별 신호만 제시, 법적 판단은 분쟁조정·132
- [ ] **시점 라벨** — 조항 번호·분쟁조정위 운영기관·URL은 변동 가능, 확인 표시
- [ ] 원인 차단 먼저(곰팡이 표면 제거만으로 끝내지 않기) — 결로/누수/생활습관 3분류
- [ ] 견적은 3곳 이상 서면 + 범위·자재·추가비·하자보증 명문화(구두·현금·계약서 없는 할인 경계)
- [ ] 발견 즉시 사진·동영상(날짜)·임대인 통지 기록(민법 제634조) 권고
- [ ] 위임 경계(전세 계약·보증금·전세사기→life-real-estate / 보증금 미반환 청구 절차→life-legal)

## 점검 주기

- **안전 게이트(가스·전기·방수·구조)는 영구 고정 — 약화 없이.**
- 민법 조항(제623·634·654·615): 안정적 — 연 1회 점검.
- 분쟁조정위 운영기관·URL·처리기간: 변경 잦음 → **연 1회 + 기관 개편 신호 시 즉시** 재확인(adrhome.reb.or.kr / hldcc.or.kr / 132).
