# evidence + 안내 전 체크리스트 (life-cooking)

> 가정 요리·자취/1인 가구 맥락. 식품안전 수치는 식품의약품안전처(식약처) 기준. **상함이 의심되면 버리는 쪽이 항상 안전하다.** 아래는 2026-06 웹 재확인 기준.

## 실증·출처

- **식약처 식중독 예방 6대 수칙 '손·보·구·가·세'** (2026-06 검증) — 손씻기(흐르는 물+비누 **30초 이상**)·익혀먹기·끓여먹기·칼/도마 식재료별 구분·세척소독·보관온도 준수. 출처: 식품안전나라 https://www.foodsafetykorea.go.kr · 행안부 안전한국 https://www.safekorea.go.kr (조회 2026-06).
- **가열 중심온도** — 육류·가금류 **중심 75℃ 이상 1분**, 어패류 **중심 85℃ 이상 1분**. 출처: 식약처 식중독 예방 캠페인(식품안전나라, 2026-06).
- **보관 온도** — 냉장 **5℃ 이하**, 냉동 **-18℃ 이하**. 식중독균 증식 위험구간(Danger Zone) **5℃~60℃** 방치 최소화 — 조리식품 상온 장시간 방치 금지. 출처: 식약처(2026-06).
- **식품별 보존·유통 세부 기준** — 식품공전 "보존 및 유통기준"(식품 유형별 냉장/냉동 상세). 개별 식재료의 정확한 보관 기한(일수)은 식품안전나라 "냉장·냉동식품 취급 가이드"에서 개별 확인 — 일괄 수치화 안 함(확인 필요).
- **주방 화재·화상 안전(생명 직결, 2026-06 검증)** — 기름불(K급 화재)에 **물 절대 금지**: 물이 끓어 부피가 폭발적으로 팽창하며 불붙은 기름을 튀겨 화재가 확산(소방). 진화는 **뚜껑·젖은 행주로 산소 차단** + 가스 차단 + 주방용 **K급 소화기**(일반 분말 소화기는 식용유 재발화로 부적합). 불이 크면 진화에 매달리지 말고 **대피 후 119**(초기 약 3분 골든타임). 화상은 **흐르는 시원한 물로 냉각(얼음 직접 접촉 X·치약/된장 X)**, 물집 터뜨리지 않기, 넓거나 깊으면 병원. 출처: 한국소방안전원·국민안전 자료(K급 소화기, 2026-06). 베이킹소다 단독 진화는 검증 자료 빈약 → 권장 1순위에서 제외하고 뚜껑/젖은행주/K급으로 안내.
- 상세 출처표·URL은 `references/sources.md` 참조.

## 안내 전 체크리스트

- [ ] **위생/안전 게이트 먼저 통과** — 식재료 상함·식중독 위험이 걸린 안내인가. "상함 의심이면 버린다"는 보수적 원칙을 우선했는가. **조리 중 화재/화상이 걸린 맥락이면 생명 직결 게이트(기름불에 물 금지·뚜껑/젖은행주 산소차단·K급 소화기·크면 대피→119 / 화상은 흐르는 시원한 물)를 먼저 안내했는가.**
- [ ] 가열·보관 수치(75℃/85℃·5℃/-18℃·손씻기 30초)를 식약처 기준대로 정확히 안내했는가 — 식품안전 수치는 임의로 완화하지 않는다.
- [ ] 위험구간(5~60℃) 상온 방치·교차오염(칼·도마 구분) 경고를 포함했는가.
- [ ] **면책·시점 라벨 부착** — "일반 가정요리 정보이며, 식품별 세부 안전온도·보관기한은 식품안전나라 식품공전에서 확인 / 안전 의심 시 폐기". **식중독 의심 증상(설사·구토·발열 등)의 대응은 → life-emergency/병원**으로 분기했는가.
- [ ] 알레르기·기저질환·영유아/임산부 등 취약군 식이는 단정 말고 전문 정보 확인을 권했는가.

## 점검 주기

- **식약처 식중독 예방 수칙·중심온도·보관온도 기준**: 제도성 수치 — **연 1회** 식품안전나라 재확인(6대 수칙 문구·수치 개정 여부).
- **식품공전 보존·유통기준**: 개정 시 — 개별 식재료 기한은 항상 "식품안전나라 확인" 라벨 유지(일괄 수치화 안 함).
- **요리 원리(조리법·맛내기 일반)**: 부패 느림 — 점검 불필요, 원리 안정.
- **식중독 유행·리콜 동향**: 계절성(여름 세균성·겨울 노로바이러스) — 필요 시 식약처 보도 참조이나 본 스킬은 상시 예방 원칙 중심.
