# life-cooking — 근거·기본기 정리

> 보관 기한·안전온도는 "확인 필요"(식품안전나라 기준). 스킬은 원리·습관·소진 설계 위주. 상함이 의심되면 버리는 쪽이 항상 안전하다.

## 1. 간(소금) 기본기

- 더하긴 쉽고 빼긴 어렵다 → 약하게 시작, 마지막에 맛보며 조정.
- 국·찌개는 졸면 농축 → 졸임 후 간 본다.
- 짜졌을 때: 물·재료로 희석. 설탕으로 가리기는 임시방편.
- 소금/간장/된장은 짠맛 외 풍미가 달라 용도 구분.

## 2. 불 조절 기본기

- 신호는 시간이 아니라 색·물기·향·소리.
- 센불: 수분 날리기·겉면 색내기(볶음·구이 초반).
- 중약불: 속까지 익히기·졸이기.
- 마늘·고춧가루·양념은 약불(타면 쓴맛 — 자취 쓴맛 1순위).
- 고기: 센불로 겉 → 줄여 속.

## 3. 기름·팬 기본기

- 팬·기름 예열 후 재료 투입(차가운 기름 = 눌어붙음·기름 흡수).
- 적정 온도 신호: 볶음=물 한 방울 자글, 튀김=재료 넣으면 잔잔히 끓음.
- 연기 = 과열(발연점 초과·탄내) → 불 줄이거나 다시.
- 코팅팬: 중불 이하·실리콘/나무 도구·부드러운 세척. 강화력·구이는 무쇠/스테인리스.

## 4. 재료별 보관·상함 판단

| 구분 | 온도 기준 | 예시 |
|---|---|---|
| 실온 | — | 감자·양파·바나나·미개봉 통조림 |
| 냉장 | **5℃ 이하**(식약처) | 손질 채소·유제품·개봉 후 소스(기한 메모) |
| 냉동 | **-18℃ 이하**(식약처) | 육류·해산물·소분 식재료(시간 늦출 뿐, 무기한 아님) |

- 식중독균 증식 위험구간 **5~60℃** — 조리식품 상온 장시간 방치 금지(식약처, 2026-06).
- 가열: 육류 중심온도 75℃·어패류 85℃ 각 1분 이상. 손씻기 30초 이상. → `sources.md`

- 개봉 후 기한·소분 날짜 메모.
- 상함 신호: 이상한 냄새·점액·변색·곰팡이·부풀어 오른 포장 → 버린다.
- "아까워서" 먹는 판단의 기대비용이 가장 나쁨(낭비 < 식중독). 육류·달걀·해산물·조리식품은 특히 보수적으로.
- 안전온도·세부 기한은 식품안전나라 확인.

## 5. 1인 식단 루프 예시

- 공통 재료(양파·달걀·대파·밥) 베이스 → 여러 요리에 돌려쓰기.
- 한 번 손질 → 며칠 분 소분/냉동(소진율↑).
- 변주: 1일 볶음 → 2일 같은 베이스 덮밥 → 3일 국/찌개로 소진.
- 선입선출: 먼저 산 것·상하기 쉬운 것부터.
- 못 먹을 양은 안 산다(대용량 단가보다 소진율이 진짜 비용).

## 6. 안전 경계

- 영양·열량 설계는 → life-nutrition.
- 식중독 의심 증상(구토·발열·탈수)은 → life-emergency/병원.
- 알레르기·지병 식이는 의사·영양사.
- 정밀 제과·발효·저온조리 안전온도는 전문 자료 확인.
