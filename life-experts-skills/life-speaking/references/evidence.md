## 1. 원칙 출처

- **피라미드 원칙(Barbara Minto, 원전 1987 / 개정판 1996·2002)** — 결론 먼저, 근거로 받친다. 도입은 SCQ로 청중의 질문을 세움. 말하기에선 더 강하게(되돌려 못 들으므로). (연도 정정: 기존 1985 표기는 오류.)
- **Garr Reynolds 『Presentation Zen』(2008) / Nancy Duarte** — 슬라이드 단순화, 한 장 한 메시지, 텍스트보다 시각.
- **Chris Anderson 『TED Talks』(2016, TED 큐레이터)** — "하나의 아이디어"에 집중, 시간 제한으로 압축 강제.
- **redundancy 원리(Mayer, Cambridge Handbook of Multimedia Learning Ch.10)** — 동일 정보를 화면 텍스트로 읽으며 동시에 음성으로 들으면 인지부하로 둘 다 저하 → 슬라이드 낭독 금기의 인지과학 근거.

## 2. 발표 구조 템플릿

**정보 전달형**
1. 핵심 메시지 한 줄(두괄)
2. 포인트 3개(각 근거/예시)
3. 마무리: 메시지 반복 + "그래서 무엇을 하면 되나"

**설득형(제안)**
1. 문제·기회(청중이 공감할 통점)
2. 해결책(내 제안) + 근거 3
3. 대안 대비 우위 / 예상 반론 선제 답
4. 행동 요청(구체적)

**데모/시연형**
1. 무엇을·왜 보여줄지(맥락)
2. 라이브 데모(실패 대비 녹화 백업 준비)
3. 결과·핵심 포인트
4. 주의점·적용법

## 3. 슬라이드 원칙

- 한 장 한 메시지. 제목이 곧 메시지(명사구가 아니라 주장).
- 텍스트는 키워드. 문장 통째 금지(읽게 됨).
- 글자보다 도표·그림·코드 하이라이트.
- 발표자 노트에 상세 대본, 슬라이드엔 최소.
- 색·폰트 일관. 데이터는 핵심만 강조.

## 4. Q&A 대응 스크립트

| 상황 | 대응 |
|---|---|
| 모르는 질문 | "좋은 질문입니다. 그 부분은 확인 후 공유드리겠습니다." (둘러대기 금지) |
| 적대/공격적 질문 | 라벨링: "그 부분 우려가 크신 것 같습니다." → 핵심만 답, 감정 대응 X |
| 너무 긴/다중 질문 | "두 가지를 물으신 것 같은데, 먼저 ○○부터…" 분해 |
| 범위 밖 질문 | "오늘 주제를 벗어나니 끝나고 따로 이야기하시죠." |
| 답을 모르는 게 들킬까 봐 | 모름 인정이 둘러대기보다 신뢰 ↑ |

- 사전 준비: 예상 질문 5개+ 답변. 가장 약한 부분·반론을 미리 답해둔다.
- 질문 받으면 한 박자 쉬고(생각 시간) 답. 질문을 되짚어 확인(오해 방지).

## 5. 불안 관리

- 떨림은 정상 — 각성(arousal)을 "위협/진정 대상"이 아니라 "흥분/준비됨"으로 재해석(reappraisal)하면 수행이 개선(Brooks 2014, *J. Exp. Psychol. Gen.* 143(3):1144–1158). "진정해"보다 "흥분된다"가 효과적.
- ⚠️ 정상 무대 긴장과 임상 불안 구분: 회피·공황·일상 기능 저해면 사회불안장애 가능 → life-mental-care + 전문가(CBT/노출치료). 아래 기법은 정상 범위 대상.
- 통암기 금지(단일 실패점). 구조(메시지→3포인트→마무리)를 외워 길 잃지 않게.
- 도입 첫 30초를 확실히 준비(가장 떨리는 구간).
- 호흡·천천히 말하기(불안하면 빨라짐). 물 한 모금으로 호흡 정비.
- 리허설이 최선의 처방 — 익숙함이 불안을 줄인다.

## 6. 리허설 체크리스트

- [ ] 핵심 메시지가 한 줄로 나오는가
- [ ] 모든 슬라이드가 그 메시지를 뒷받침하는가(아니면 삭제)
- [ ] 소리 내어 1회 이상, 실제 시간 측정했는가
- [ ] 시간 초과면 무엇을 뺄지 정했는가
- [ ] 슬라이드 전환·데모가 매끄러운가(데모는 백업 녹화)
- [ ] 예상 Q&A 5개+ 답을 준비했는가
- [ ] 첫 30초·마지막 30초가 강한가
