# life-career 근거 자료

> 목차: 1) 이력서/경력기술서 2) 시장가 조사법 3) 이직 신호 4) 면접 유형 5) 총보상 비교
> 한국 IT 채용 관행 기반(2026-06). 연봉·플랫폼·트렌드 수치는 부패 빠름 — 모두 "확인 필요". 출처: 공식 SW기술자 임금실태조사(SPRi/과기정통부, 통계법 승인) + 원티드/점핏/잡플래닛 등 플랫폼(자발응답·등록자 편향 주의) + 헤드헌터 시장 청취. 정확한 출처·URL·표본 성격은 `sources.md` 참조 — 플랫폼 통계는 공식 조사와 교차 권장.

## 1. 이력서/경력기술서 — STAR + 정량

- **STAR**: Situation(상황) → Task(과제) → Action(내가 한 것) → Result(정량 결과).
- 약한 표현 → 강한 표현:
  - "API 개발" → "주문 API 응답 p95 800ms→120ms 단축(N+1 제거·캐시 도입), 피크 타임 타임아웃 X건→0"
  - "DB 설계 참여" → "조회 패턴 분석해 인덱스·파티셔닝 재설계, 일배치 시간 4h→40m"
  - "장애 대응" → "결제 장애 RCA 주도, 재발방지 알림·서킷브레이커 도입으로 동류 장애 0"
- 원칙: 동사로 시작, 수치로 끝. "참여/지원" 같은 약한 동사 지양. 기술 스택은 별도 섹션, 본문은 임팩트.
- 분량: 경력은 최근·관련 위주. 신입은 프로젝트의 깊이(왜 그렇게 만들었나)로 변별.

## 2. 시장가 조사 3출처법

| 출처 | 강점 | 약점 |
|---|---|---|
| 커뮤니티(잡플래닛·블라인드 등) | 분포 감 | 자발응답·과장 편향, 확인 필요 |
| 헤드헌터/리크루터 | 실제 오퍼 기반 최신 | 포지션 편향, 영업 목적 |
| 동종 경력 지인 | 신뢰도 높음 | 표본 적음 |
| 실제 면접/오퍼 | 가장 정확한 신호 | 시간 비용 |

- 직무·연차·지역·회사 규모(스타트업 vs 대기업)별로 범위가 다름 → 단일 숫자 아닌 범위로.
- 현 연봉 기준 인상률 사고 금지(저평가 복제). 시장가 기준으로 역산.
- (2026 기준 플랫폼/수치는 확인 필요)

## 3. 이직 신호 체크리스트

이직 검토 = 아래 중 둘 이상:
- [ ] 성장 정체 — 새로 배울 게 없고 같은 일 반복, 기술 갈라파고스화
- [ ] 시장가 괴리 — 내부 인상률이 시장 상승을 못 따라감(외부 검증 필요)
- [ ] 명확한 상위 기회 — 더 나은 도메인/규모/보상/성장
- [ ] 조직 리스크 — 재무 불안정·잦은 핵심 인력 이탈

이직 아님(다른 스킬):
- 단순 번아웃·일시적 갈등 → life-mental-care 먼저. 충동 이직 후회 흔함.
- 재직 1년 미만에 반복 → 잡호핑 신호 누적 주의(통상 1.5~2년+ 권장, 절대규칙 아님).

## 4. 면접 유형별 대비

- **기술 면접**: 깊이 질문 대비(왜 그 기술? 트레이드오프?). 모르면 "모릅니다" 대신 "○○로 추론하면…, ○○는 확인 필요".
- **코딩 테스트**: 말로 사고 과정 공유, 엣지케이스 먼저 짚기, 시간복잡도 언급.
- **시스템 디자인**: 요구사항 명확화(QPS·데이터량) → 큰 그림 → 컴포넌트 → 병목·트레이드오프. 정답 없음, 사고가 평가 대상.
- **행동/컬처핏**: STAR로 구체 사례. "갈등 해결/실패 경험"은 배움·개선으로 마무리.
- 역질문: 회사/팀에 대한 좋은 질문 준비(성장·기술부채·온콜 등) — 평가에 포함.

## 5. 총보상 비교표

| 항목 | 체크 |
|---|---|
| 기본 연봉 | 세전/세후, 계약 연봉 vs 성과급 포함 |
| 인센티브/성과급 | 확정 vs 변동, 지급 이력 |
| 스톡옵션/RSU | 행사가·베스팅·실현 가능성(상장 여부) |
| 복지 | 식대·교육비·재택·장비·연차 |
| 비금전 | 성장·기술 스택·온콜 부담·워라밸·평판 |
| 안정성 | 회사 재무·런웨이(스타트업) |

- 연봉만 비교하면 함정 — 변동성 큰 보상(스톡·성과급)은 기대값+리스크로.
- 협상 전술(라벨링·캘리브레이티드 질문·비금전 카드)은 → life-negotiation.
