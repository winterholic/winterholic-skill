# life-career — 실증·체크리스트 (evidence-checklist)

> 연봉·시장 수치는 부패가 빠르고 출처별 편차가 크다. 단일 숫자 단정 금지 — "범위 + (연도, 출처) + 표본 편향" 형식 유지. 최종 조회: 2026-06.

## 실증·출처

- **SW기술자 임금실태조사 (공식 승인통계)** — 통계법 §27 승인(통계승인 제375001호). 기본급+제수당+상여+퇴직급여충당+법인부담(4대보험) 포함 **월평균임금(M/M)**. 17개 직무별 + 사분위(상위25%/50%/하위25% = 고급/중급/초급 추정) 공표. **발표 주체는 한국AI·SW산업협회(구 한국SW산업협회)/과기정통부** — SPRi가 아님. 2026년 적용분(2025년 조사)은 전년 대비 +4.7%, 예: IT기획자 월 ≈1,185만, 응용SW개발자 월 ≈775만, 정보보안전문가 월 ≈1,041만. **이는 발주·단가용 월 인건비라 개인이 받는 연봉 체감과 크게 다름 — 단순 ×12 연봉 환산·시장가 단정 금지.** 출처: 한국AI·SW산업협회 https://www.sw.or.kr/site/sw/ex/board/List.do?cbIdx=304 (조회 2026-06)
- **시장 체감 연봉(플랫폼 통계, 모두 자발응답·등록자 편향)** — 단일 출처 신뢰 금지, 3출처 교차로 범위만:
  - 원티드 인사이트(등록자 표본) https://community.linkareer.com/employment_data/5092525
  - 점핏(사람인, 이직자 표본 — 상단 편향 가능) '2025 개발자 연봉 리포트' https://zdnet.co.kr/view/?no=20251031165659
  - 잡플래닛(리뷰·자발응답) https://www.jobplanet.co.kr/contents/news-7926/
  - (조회 2026-06, 구체 수치는 부패 빠름 — 사용 시 직접 재확인)
- **시장가 3출처 교차법** — ① 커뮤니티(잡플래닛·블라인드 등) ② 헤드헌터/리크루터 청취 ③ 동종 경력 지인. 직무·연차·지역별 **범위**로. 가장 정확한 신호는 "실제 받은 오퍼".
- **협상 전술**(라벨링·BATNA 등)은 본 스킬 범위 밖 → life-negotiation으로 위임.
- 상세 출처표·표본 편향 주석: `references/sources.md`

## 안내 전 체크리스트

- [ ] **이직 동기 게이트** — 동기가 단순 번아웃인지 성장 정체·시장가 괴리인지 점검했는가. 번아웃이 섞였으면 → life-mental-care를 먼저 안내(충동 이직 후회 방지)했는가
- [ ] 시점 라벨 — 연봉·시장 수치에 "(2026 기준, 직접 3출처 확인 필요)" 부착, 단일 숫자 단정 금지
- [ ] 공식 SW임금조사 수치를 "시장 연봉"으로 오인 제시하지 않았는가(월 단가 ≠ 개인 연봉)
- [ ] 시장가는 단일 커뮤니티가 아니라 3출처 교차 범위로 안내했는가(자발응답 편향 명시)
- [ ] 이력서 조언은 '한 일' 나열이 아니라 '낸 성과'(STAR+정량)로 유도했는가
- [ ] 재직기간·잡호핑 기준(1.5~2년+)은 절대 규칙이 아니라 출발점으로 안내했는가
- [ ] 오퍼 비교는 연봉 단독이 아니라 총보상(스톡·복지·성장·워라밸)으로 권했는가
- [ ] 민감정보(현 연봉·회사명)는 파일 저장 시 [REDACTED] 마스킹했는가

## 점검 주기

- **시장 체감 연봉 수치(플랫폼)**: 부패 최속 — 사용 시 매번 직접 재확인, 본문에 수치 하드코딩 금지.
- **공식 SW기술자 임금실태조사**: 연 1회 공표(연초 적용) — 매년 1회 갱신.
- **채용 트렌드·관행(재직기간·잡호핑 통념)**: 경기 영향 큼 — 연 1회.
- **위기 신호 경로(번아웃 → life-mental-care)**: 라우팅 자체는 안정적, 연 1회 점검.
- 충돌 시 본문보다 `references/sources.md`(최신 조회)가, 시장가는 사용자 직접 3출처 조사가 우선.
