## 피싱 식별 3종 확인 (불변 원칙)

1. **URL 도메인** 직접 확인(naver.com vs naver-login.com·navor.com) — 의심되면 링크 말고 앱/북마크로 직접 접속.
2. **발신자 진위** 공식 번호/메일과 대조, 메신저 본인인증 요청은 다른 채널로 확인.
3. **긴급성 압박**("지금 안 하면 정지/벌금/택배반송") = 피싱 공통 신호.

> 인증번호(OTP)는 누구에게도 전달하지 않는다 — 메신저 사칭 본인인증 가로채기 차단.

## 잔존 "확인 필요" (UI·정책 부패 빠름)

- **서비스별 보안설정 메뉴 위치·명칭**(네이버 "내 정보 보안설정", 카카오 "카카오계정 보안" 등): UI 개편으로 자주 변동 → 각 서비스 공식 보안설정 페이지에서 확인.
- **유출 여부 조회 서비스**(내 이메일/비번 유출 점검): 서비스명·운영 변동 가능 → KISA 보호나라 점검 메뉴 우선.
- 개인정보 유출 신고 세부 포털 URL: privacy.kisa.or.kr / privacy.go.kr 이원화 — 정확한 창구는 118 안내 확인.
