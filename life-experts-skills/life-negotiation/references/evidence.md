# life-negotiation 근거 자료

> 목차: 1) Voss 기법 카탈로그 2) 연봉 협상 대사집 3) 중고거래 흥정 대사집 4) 협상 준비 체크리스트
> 출처: Chris Voss & Tahl Raz, 『Never Split the Difference』(2016, HarperBusiness) + Fisher & Ury, 『Getting to Yes』(초판 1981, Houghton Mifflin)의 BATNA·원칙협상 개념. 정확한 서지·URL은 `sources.md` 참조.

## 1. Voss 기법 카탈로그

| 기법 | 정의 | 예 |
|---|---|---|
| 전술적 공감(tactical empathy) | 상대 감정·관점을 이해했음을 보이기(동의가 아님) | 전 기법의 토대 |
| 라벨링(labeling) | 상대 감정·입장에 이름 붙이기 | "It seems like…/~처럼 들리네요", "~라고 느끼실 것 같습니다" |
| 미러링(mirroring) | 상대 말 마지막 1~3단어를 올림 억양으로 반복 | "예산이 빡빡하다…?" → 상대가 더 설명 |
| 캘리브레이티드 질문 | "How/What"으로 상대가 스스로 풀게 | "제가 어떻게 하면 될까요?" "무엇이 필요할까요?" |
| 'No' 유도 | 'Yes' 강요 대신 'No' 할 여지 주기 | "지금 무리한 요청일까요?" |
| "That's right" | 상대 처지를 요약해 진짜 동의 끌어내기 | 빈말 "you're right" 경계 |
| 억양(밤늦은 DJ 목소리) | 차분·낮은 톤으로 신뢰·진정 | 갈등 국면에서 톤 낮추기 |
| 앵커링 | 첫 숫자가 기준점 | 정보 우위 시 선앵커, 아니면 후행 |
| 비금전 카드 | 금액 외 조건으로 가치 창출 | 사이닝·연차·원격·교육비·직급 |
| BATNA | 협상 결렬 시 최선의 대안 (Fisher & Ury) | "안 되면 나는 ___" |
| 손실 회피 프레이밍 | 얻는 것보다 잃는 것 강조가 더 강력 | "이 기회를 놓치면…" |

## 2. 연봉 협상 대사집 (한국 맥락)

- **정보 캐기**: "이 포지션 연봉 밴드가 어느 정도로 잡혀 있을까요?" "성과에 따른 조정 여지는 어떻게 보면 될까요?"
- **시장가 근거**: "비슷한 경력·직무의 시장 범위를 알아봤더니 ○○~○○ 정도더라고요. (출처 언급) 이 안에서 조율 가능할까요?"
- **라벨링**: "정해진 밴드가 있어 회사 입장에서도 쉽지 않으신 것 같습니다."
- **캘리브레이티드**: "밴드 상단으로 가려면 제가 무엇을 더 보여드리면 될까요?"
- **비금전 전환**: "기본급 조정이 어렵다면 사이닝 보너스/연차/원격근무/교육비 쪽은 어떨까요?"
- **재검토 약속 받기**: "지금 어렵다면 6개월 후 성과 리뷰 때 재조정하는 걸 문서로 남길 수 있을까요?"
- **금기**: 현 연봉을 먼저 다 까는 것(밴드 하단 앵커가 됨), 절박함 노출, 다른 오퍼 거짓말(들통 시 신뢰 붕괴).

## 3. 중고거래 흥정 대사집

- **정보 캐기(미러링)**: "혹시 급하게 정리하시는 거예요?" / (상대 "이사 때문에요") "이사 때문이시군요…?"
- **라벨링**: "오래 안 쓰셔서 빨리 보내고 싶으신 것 같네요."
- **범위 앵커(정보 우위 시)**: "비슷한 매물들이 ○○ 정도던데, 직거래로 ○○에 정리 가능할까요?"
- **캘리브레이티드**: "제가 오늘 바로 가지러 갈 수 있는데, 그러면 가격을 조금 맞춰주실 수 있을까요?" (즉시성·편의를 카드로)
- **침묵**: 제안 후 답을 기다린다. 먼저 "안 되면 어쩔 수 없고요"로 깎지 않는다.
- **안전**: 가격에만 몰두하다 사기 신호(시세 과도 이탈·선입금 유도·외부 링크)를 놓치지 않는다 → life-fraud-response. 직거래·안전결제 우선.

## 4. 협상 준비 체크리스트

- [ ] 목표값과 마지노선(walk-away)을 숫자로 정했는가
- [ ] BATNA(결렬 시 대안)를 최소 1개 확보했는가 — 없으면 협상 전에 만든다
- [ ] 상대의 제약·기한·동기를 추정/조사했는가
- [ ] 시장 데이터를 3출처 이상 교차했는가 (연봉: 잡플래닛·블라인드·동료/리크루터)
- [ ] 금액 외 카드(비금전 조건)를 준비했는가
- [ ] 내 숫자를 먼저 말할지(선앵커) 상대 먼저 듣게 할지 정했는가
- [ ] 라벨링·캘리브레이티드 질문 문장을 미리 1~2개 준비했는가
- [ ] 합의를 글로 남길 계획인가
