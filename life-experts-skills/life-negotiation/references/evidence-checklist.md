# life-negotiation — 실증·출처 체크리스트

> 협상 스킬은 "제도 수치"가 거의 없는 **원칙 기반**(느린 부패)이다. 검증 대상은 핵심 이론의 서지·정의이며, 시장가·연봉 데이터 등 빠르게 변하는 숫자는 본 스킬이 직접 보유하지 않고 사용자/외부 출처로 넘긴다(확인 필요 처리).

## 안내 전 체크리스트

- [ ] **윤리 게이트(최우선)**: 거짓 정보·허위 경쟁 오퍼 날조·협박/강압·기만으로의 유도가 섞였는가? → 그런 전술은 **안내하지 않는다**. 협상은 "정보·대안·프레이밍"이지 사기·강요가 아니다. 불법(담합·뇌물·갈취) 신호가 보이면 즉시 중단하고 선을 분명히 한다.
- [ ] **관계 게이트**: 상대와 장기 관계인가(가족·직장·거래처)? → 단기 승리 전술(앵커링 남용·압박)이 관계를 깨지 않도록 톤 조정.
- [ ] BATNA를 먼저 확보/명시했는가(없으면 협상력 없음 — 화법보다 대안 우선)?
- [ ] "마지노선" 숫자를 임의로 박지 않고 **유보가치**로 판단하게 안내했는가?
- [ ] 인용한 시장가·시세에 **시점 라벨**(예: "2026 기준, 확인 필요")을 붙였는가? 구체 숫자는 본 스킬이 단정하지 않는다.
- [ ] **면책 라벨**을 남겼는가: "본 안내는 협상 일반론·정보 제공이며 법률·계약·세무 자문이 아닙니다. 계약서 서명 전 해당 분야 전문가 확인 권장."
- [ ] 상대를 적이 아닌 "함께 문제를 푸는 쪽"으로 프레이밍했는가(사람/문제 분리)?

## 점검 주기

- **윤리/관계 게이트·면책·시점 라벨**: 즉시·매 안내마다(부패 없음 — 항상 적용).
- **핵심 이론 서지(BATNA·4원칙·prospect theory·Voss)**: 원칙이라 거의 불변. 연 1회 또는 신판 출간 시 확인.
- **하버드 PON 공식 정의 페이지(URL)**: 연 1회 링크 유효성 점검(URL 변경 가능 — 확인 필요).
- **시장가·연봉·시세 숫자**: 본 스킬이 보유하지 않으므로 점검 대상 아님 — 안내 시점마다 사용자/외부 출처로 즉시 확인.
