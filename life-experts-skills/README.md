# life-experts — 일상 전문가 스킬군

주식·개발이 아닌 **일상의 의사결정**(돈·법·건강·일·생활 실무)에서 거장/근거 기반 전문가를 미리 만들어두고 꺼내 쓴다. 일상 의사결정은 빈도는 낮지만 건당 비용이 크다(잘못된 계약·미숙한 사고 대응이 수백만 원을 좌우) — 주식 분석과 똑같이 "체크리스트와 함정 목록"이 가장 큰 가치를 만드는 영역.

> **설계 근거**: `~/.claude\sub-skills\life-experts-plan.md` (카탈로그 §3 · 안전 규율 §2 · DoD §4 · Phase §5).
> **품질 기준점**: dev-experts 92종·stock-experts 21종에서 검증된 제작 공식의 이식.

## 이 폴더의 성격

- **자동 로드되지 않는 전용 폴더**다. 34개 description이 매 세션 컨텍스트를 상시 점유하는 것을 피하기 위함.
- 사용하려면: ① 라우터 `life-concierge/SKILL.md`를 먼저 Read해 긴급도·영역·전문가 상담 필요성을 판정하고 ② 해당 전문가 `SKILL.md`를 Read해 그 매뉴얼대로 안내한다.
- **전역 디스패처**: `~/.claude/skills/life-experts/SKILL.md`가 설치되어, 일반 세션에서 일상 의사결정 질문이 나오면 이 폴더로 자동 라우팅된다.
- 본문의 `(→ life-x)`는 해당 전문가 스킬로의 위임 표시다.

## 제1원칙 — 안전 규율 (모든 스킬 적용 · 위반 시 출고 금지)

LLM 일반 답변과의 차이는 한국 제도 고정·단계별 행동 절차·함정 카탈로그·**전문가에게 넘겨야 하는 선의 명시**에 있다. 잘못된 의료·법률 정보의 피해는 잘못된 주식 분석보다 직접적이므로 더 엄격하게 적용한다.

1. **자문 아님 면책 의무**: 법률(→ 변호사·대한법률구조공단 132)·세무(→ 세무사·국세청 126)·의료(→ 의사)·보험(→ 손해사정사) 영역 스킬은 출력 말미에 **"본 안내는 정보 제공이며 자문이 아닙니다 — <해당 전문가> 상담을 권합니다"** 명시. 단정·확정 표현 금지("반드시 이긴다" ❌ → "이런 절차가 일반적이다" ✅).
2. **시점 라벨 의무**: 한국 제도(세율·청약·지원금·법령·금리)는 부패가 빠름 — 모든 제도 수치에 **"(YYYY 기준, 확인 필요)"** + 공식 출처(국세청·법제처·금융감독원·복지로·정부24)를 동봉. 수치를 추측으로 메우지 않는다.
3. **응급 상황 최우선 분기 (긴급 게이트)**: 건강·사고·응급 스킬은 워크플로우 **1단계**에 "이 증상/상황이면 분석 말고 즉시 119(응급)/112(범죄)/119 화재"를 둔다. 분석보다 신고가 먼저다.
4. **민감 정보 저장 금지**: 주민번호·계좌번호·카드번호·진단명·상세 주소는 분석 파일에 저장하지 않고 `[REDACTED]`로 마스킹. (stock-domain 면책 규율 + 개인정보 최소수집 이식)

## 공통 규칙 (모든 스킬 적용)

1. **우선순위 사다리**: `사용자의 실제 상황·최신 공식 고지 > 이 스킬군의 전문가 > LLM 일반 지식`. 제도는 늘 변하므로 스킬과 공식 출처가 다르면 **공식 출처가 이긴다** — 스킬은 절차·함정 위주, 수치는 출처 확인.
2. **안티패턴 우선**: 잘 하는 법은 LLM이 이미 안다. 스킬 가치의 절반은 ❌/✅ 안티패턴 카탈로그(스킬당 5쌍 이상)에 있다.
3. **절차형 스킬은 타임라인 표 의무**: 사고·사기·이사처럼 "언제까지 무엇을" 이 중요한 영역은 24시간/72시간/2주 단위 타임라인 표를 둔다(골든타임을 놓치면 비용이 급증하는 영역).
4. **계산은 scripts로**: 복리·대출 상환·전월세 전환율·열량 수지·과실비율 등 계산 가능한 곳만 표준 라이브러리 스크립트(실행 검증). 계산기 없는 영역은 SKILL.md만.
5. **차별성 방어선**: 일반 상식 수준이면 만들 가치 없음 — 한국 제도 고정·타임라인 표·함정 카탈로그·"전문가에게 갈 선"이 LLM 일반 답변 대비 차별점. 이게 없는 문단은 쓰지 않는다.
6. **경로 표기**: 스킬 내부 참조는 상대 경로 + 슬래시(`references/x.md`). 폴더 밖을 가리킬 때만 절대 경로.
7. **참조 깊이 1단계**: SKILL.md → references/*.md 까지만. 100줄 넘는 레퍼런스는 맨 위 목차 의무.

## 빠른 사용 (Quick Start)

1. **라우터부터** — `life-concierge/SKILL.md`를 읽어 (긴급도 × 영역 × 전문가 상담 필요성)을 판정, 전문가 1~2명을 고른다. **긴급 신호가 있으면 라우팅 전에 119/112부터.**
2. **그 전문가 SKILL.md의 "긴급 게이트 → 워크플로우 → 안티패턴"** 순으로 따라 안내한다. 심화는 `references/`로 미룬다.
3. **면책 라벨**(법·세·의료·보험)과 **시점 라벨**(제도 수치)을 빠뜨리지 않는다.
