# evidence + 안내 전 체크리스트 (life-emergency)

> 이 스킬은 **교육·사전 학습용**이다. 실제 진행 중 응급은 이 문서·체크리스트보다 **119 통화 안내가 항상 우선**한다. 아래 출처는 2026-06 웹 재확인 기준.

## 실증·출처

- **2025년 한국 심폐소생술 가이드라인** (질병관리청·대한심폐소생협회 공동, **2025-12-09** 제14차 급성심장정지조사 심포지엄 발표 — 2020년판 이후 5년 만의 전면 개정) — 성인 가슴압박 **약 5cm·분당 100~120회**(기존 유지), 압박:인공호흡 30:2(미훈련 시 가슴압박 지속)의 현행 근거. 웹 검증된 개정점: ①1세 이상 소아 일반인 AED 사용 권고 ②여성 환자 AED 시 브래지어 미제거·위치 조정 ③119 전화 CPR 지시 시 AED 안내. 출처: 정책브리핑 https://www.korea.kr/briefing/policyBriefingView.do?newsId=156742024 · 질병관리청 보도자료(2025-12-09) · 질병관리청 교육자료 게시판 https://www.kdca.go.kr/bbs/kdca/49/309908/artclView.do (조회 2026-06). 가슴압박 깊이 5cm vs 5~6cm 표기는 정량 기준 표 비고 참조.
- **응급의료에 관한 법률 제5조의2 (선의의 응급의료 면책)** — 생명이 위급한 응급환자에게 고의·중대한 과실 없이 응급처치를 한 일반인은 민사책임·상해 형사책임 면제, 사망 시 형사책임 감면. 안티패턴 3("확신 없어 가슴압박 안 함")을 막는 법적 근거. 출처: 법제처 국가법령정보 https://www.law.go.kr (조회 2026-06). 구체 적용·해석은 법률 전문가 확인.
- **소방청 119·응급의료포털(E-Gen)** — 119 신고 시 구급상황요원의 전화 CPR 실시간 지도, 인근 AED 위치 안내. 목격자 CPR + 신속한 AED가 생존율을 가르는 1차 근거. 출처: https://www.e-gen.or.kr (조회 2026-06).
- **신고 번호 (불변 — 최고 가치 확인 항목)**: 응급·화재 **119** / 범죄·폭력 동반 **112** / 자살·자해 위기 **109**(2024-01-01 자살예방상담전화 통합번호, 1393·1577-0199 통합·유지 — life-mental-care 연계). 모두 2026-06 유효 확인.

## 안내 전 체크리스트

- [ ] **긴급/위기 신호 게이트 먼저 통과** — "지금 실제 진행 중 응급인가?" 의식없음·호흡없음·가슴통증·심한출혈·뇌졸중 의심·화재/가스/붕괴면 안내를 멈추고 **즉시 119(범죄동반 112) 안내가 1순위**, 분석·이 문서 읽기는 그 다음.
- [ ] 자해·자살 위기 신호면 **109**로 즉시 분기(→ life-mental-care). 응급처치 매뉴얼로 다루지 않는다.
- [ ] 절차 안내는 "신고가 처치보다 먼저"(혼자면 119 스피커폰) 순서를 깨지 않았는가.
- [ ] 안티패턴 위반 경고를 포함했는가 — 의식저하 시 먹이기 금지·경련 중 입에 물건 금지·화상 민간요법 금지·기도폐쇄 손가락 후비기 금지·가벼운 출혈 지혈대 금지.
- [ ] **면책·시점 라벨 부착** — "정보 제공·교육 목적이며 의료처치 처방이 아님 / 실제 상황은 119 안내 우선 / 가이드라인 수치는 2025-12 개정본 기준, 갱신 시 KACPR·질병관리청 최신본 확인".
- [ ] 가슴압박 깊이는 "약 5cm"(2025 가이드라인)로 안내하되, 출처별 5~6cm 병기 차이를 숨기지 않았는가.
- [ ] 정식 능력은 대한적십자사·소방서 **실습 교육(CPR·AED)**으로 익히도록 권했는가.

## 점검 주기

- **신고 핫라인(119·112·109)**: 변경 즉시 갱신 — 최고 우선. 통합·번호 개편 보도가 보이면 그 자리에서 확인.
- **CPR 가이드라인 수치(압박 깊이·속도·비율, AED 권고)**: 다음 정식 개정 추적(직전 2025-12, 한국·ILCOR은 약 5년 주기). 개정 발표 시 정량 기준 표·생존사슬 즉시 갱신.
- **선의의 응급처치 면책 법령**: 연 1회 이상 법령 개정 여부 확인(응급의료법 제5조의2).
- **재난 행동요령(지진·화재·정전)**: 소방청·행정안전부 국민행동요령 개정 시 — 제도성이라 연 1회 점검.
