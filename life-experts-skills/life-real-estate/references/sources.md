# life-real-estate 출처 레퍼런스 (검증된 제도 수치 + 공식 URL)

> 보증보험 요건·전세가율·세금 우선순위는 자주 바뀐다. 본 문서는 **조회일 시점 검증값 + 공식 출처 URL** 축적 — 실사용 시 HUG/SGI/정부24/법제처에서 당해 기준 재확인. 조회: 2026-06. 면책: 법률자문 아님(변호사·법률구조공단 132).

## 1. 전세보증금반환보증 — HUG vs SGI 비교 (2025~2026 기준, 확인 필요)

| 구분 | HUG(주택도시보증공사) | SGI서울보증 |
|---|---|---|
| 보증한도 | 수도권 7억 이하·그 외 5억 이하 전세금 | 아파트 한도 없음 / 아파트 외 10억 이내 |
| 담보인정비율 | (전세보증금+선순위채권) ≤ 주택가격의 90% | LTV 구간별 |
| 전세가율 | 90% 이하 | (상품 조건) |
| 빌라 주택가격 산정 | 공시가격 × 140%(또는 HUG 인정 감정가) | 시세·감정가 |
| 보증료율(참고) | 비교적 저렴(상품·구간별) | 아파트 연 0.229%·기타 0.260%, LTV 구간 최대 30% 할인 |
| 신규가입 시기 | 임대차기간 1/2 경과 전 | 임대차기간 1/2 경과 전, 전입+확정일자 완료 |

> 빌라 전세금이 공시가격의 126%(공시가 140% × 전세가율 90%) 이내여야 HUG 가입 가능(2025 기준).
