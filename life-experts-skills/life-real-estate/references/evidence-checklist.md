# life-real-estate — 실증·출처 / 안내 전 체크리스트 / 점검 주기

> 본 파일은 정보 제공용이며 **법률·세무 자문이 아니다**. 제도 수치는 자주 바뀌므로 안내 전 공식 출처에서 당해 기준을 재확인한다(시점 라벨 필수). 전세사기 피해 의심은 분석보다 즉시 핫라인 안내가 먼저다.

## 실증·출처

조회 시점: **2026-06**. 수치 옆 날짜는 해당 제도의 확인 시점이며, 미검증·변동 항목은 "확인 필요"로 표기.

- **HUG 전세보증금반환보증 "126% 룰"** (2026-06 확인 필요) — (전세보증금+선순위채권) ≤ 주택가격 × 90%(담보인정비율). 빌라·다세대는 주택가격을 **공시가격 × 140%**로 산정 → 결국 **공시가격의 약 126%(140% × 90%) 이내**라야 가입. 전세가율 90% 이하 요건. 보증한도 수도권 7억·비수도권 5억 등(정확 수치 확인 필요).
  - HUG 안심전세포털: https://www.khug.or.kr · 상품개요: https://www.khug.or.kr/hug/web/ig/dr/igdr000001.jsp
  - HF(한국주택금융공사) 전세지킴보증: https://www.hf.go.kr/ko/sub02/sub02_05_01.do
- **전세사기피해자 지원 특별법** (유효기간 **2027-05-31까지**, 2025-05-31 이전 최초 임대차계약 체결자 한정 — 2026-06 기준, 확인 필요) — 경·공매 유예·정지, LH 우선매수권 양도/직접행사(공공임대 거주), 저리 대환·신규 전세대출 등.
  - 정책브리핑(연장 발표): https://www.korea.kr/news/policyNewsView.do?newsId=148942753
  - 국가법령정보센터(법령 원문): https://www.law.go.kr (법령명: 전세사기피해자 지원 및 주거안정에 관한 특별법)
  - 신청: 전세사기피해자 지원관리시스템 jeonse.kgeop.go.kr · 관할 지자체
- **전월세 전환율 상한** (주임법 제7조의2·시행령 제9조) — 한국은행 기준금리 + 대통령령 비율(연 2%) **또는 연 10%** 중 낮은 쪽. 기준금리 2.50%면 약 4.5%. **기준금리는 변동 → 확인 필요**.
  - 국가법령정보센터 주택임대차보호법: https://www.law.go.kr (제7조의2)
  - 렌트홈 임대료 계산: https://www.renthome.go.kr
- **대항력·우선변제권 확보** — 전입신고 + 확정일자(정부24/주민센터). 대항력은 전입신고 익일 0시 발생. 잔금·이사 당일 등기부 재열람 필수.
  - 정부24: https://www.gov.kr · 인터넷등기소: https://www.iros.go.kr
- **핫라인** (2026-06, 통화 전 확인 필요) — HUG 전세사기예방센터 ☎ 1588-1663 · 전세피해지원센터 ☎ 1533-8119 · 대한법률구조공단 ☎ 132.
- **세금(취득세·재산세·종부세, 임대인 미납국세 열람 등)** — 세율·공제는 매년 개정 → **국세청·위택스에서 당해 기준 확인 필요**. 본 스킬은 구체 세액을 단정하지 않는다.
  - 국세청: https://www.nts.go.kr · 위택스(지방세): https://www.wetax.go.kr

## 안내 전 체크리스트

- [ ] **위험신호 게이트(최우선)**: 이미 보증금 미반환·집주인 잠적·경매/공매 통지·임차권등기 필요 상황인가? → 예방 안내보다 **즉시 행동**(임차권등기명령 → 보증기관 사고접수 → 핫라인 1588-1663/1533-8119/132). 골든타임 우선.
- [ ] **깡통전세 게이트**: 전세가율(전세보증금 ÷ 매매시세)이 **80% 초과**인가? 보증금+선순위채권이 매매가/공시가 126%를 초과하는가? → 고위험 경고, 보증보험 가입 가부 먼저 확인.
- [ ] **전세사기 2차 피해 차단**: "수수료 내면 빨리 처리" 류 연락은 사기 — 공식 지원은 국토부·LH·HUG 통해서만, 별도 수수료 없음을 안내.
- [ ] 등기부(갑구 소유권/가압류·가처분, 을구 근저당)와 전입세대·확정일자 실제 확인을 안내했는가?
- [ ] 보증한도·전세가율·전월세 전환율·세율 등 인용한 수치에 **조회 시점(2026-06)**과 "확인 필요" 라벨을 붙였는가?
- [ ] **면책 라벨** 포함: "정보 제공이며 법률·세무 자문이 아님 — 구체 판단은 변호사·세무사·법률구조공단 132".
- [ ] 특별법 적용 가능성 안내 시 **유효기간(2027-05-31)·계약시점 요건(확인 필요)**을 명시했는가?

## 점검 주기

- **제도·수치(보증 한도·전세가율·전월세 전환율·세율·LTV/DSR)**: 최소 **연 1회** + 정부 발표 시 즉시 — HUG 안심전세포털·국토부·국세청·법제처.
- **전세사기특별법 유효기간/연장 여부**: 현행 2027-05-31 만료 예정 → **2027년 상반기 전 재확인** + 연장·일몰 뉴스 모니터링.
- **기준금리(전월세 전환율 상한 직결)**: 한국은행 금통위 발표 시마다 갱신 — 인용 시 항상 "확인 필요".
- **핫라인(1588-1663·1533-8119·132)**: 번호 변경 가능 → **인용 즉시·통화 전 확인**, 위험신호 게이트에서는 무조건 우선 안내.
