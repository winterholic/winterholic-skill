# life-real-estate 증거·체크리스트

> 모든 제도 수치(보증한도·전세가율 기준·세금 우선순위)는 자주 바뀐다. 본 문서는 **판독법·함정 패턴·체크 항목** 위주이며, 수치·요건은 HUG·정부24·법제처에서 당해 기준 확인. (2026 기준, 확인 필요)

## 1. 등기부등본 판독표

| 구분 | 무엇이 적히나 | 위험 신호 |
|---|---|---|
| 표제부 | 부동산 표시(주소·면적·구조) | 계약 대상과 불일치 |
| 갑구 | 소유권 관련 — 소유자, 가압류·가처분, **신탁** | 신탁등기(소유권이 신탁사) / 가압류 / 잦은 소유권 이전 |
| 을구 | 소유권 외 권리 — **근저당권**, 전세권 | 채권최고액이 시세 대비 큼 / 계약 후 신설 |

- **채권최고액**: 실제 빚의 약 110~120%로 설정되는 통상치 — 보증금 안전선 계산 시 채권최고액 기준으로 보수적 판단.
- **신탁등기**: 소유권이 신탁회사에 있어, 등기상 소유자(위탁자)와 계약하면 무효일 수 있음 — 신탁원부 확인, 신탁사 동의 필요.

## 2. 보증금 안전선 계산

```
회수 가능액(보수적) = 정확한 시세 − 선순위 채권최고액 − 임대인 체납세금(특히 당해세)
안전 조건: 회수 가능액 ≥ 내 보증금
```

- 빌라·다세대: **분양가 ≠ 시세**. 인근 실거래가(국토부 실거래가 공개시스템)로 보수적 산정.
- 전세가율(시세 대비 보증금 비율)이 높을수록 경매 시 손실 위험 — 통상 80% 초과를 경계론으로 본다(확인 필요).

## 3. 대항력 · 우선변제권 3요소

| 권리 | 필요 조건 | 효력 |
|---|---|---|
| 대항력 | 점유(이사) + 전입신고 | 전입 다음날 0시 발생 — 집을 비워주지 않을 권리 |
| 우선변제권 | 대항력 + 확정일자 | 경매 배당에서 후순위 채권자보다 먼저 배당 |

- **세 가지(점유·전입·확정일자)를 잔금 당일 즉시 완성**. 하나라도 늦으면 그 사이 설정된 근저당에 밀린다.
- 확정일자는 주민센터·등기소·온라인(인터넷등기소/정부24)에서.

## 4. 전세사기 수법 분류

1. **잔금 직전 근저당 설정** — 계약 후 잔금 전에 대출받아 근저당을 새로 끼움 → 잔금 직전 등기부 재발급으로 방어.
2. **깡통전세** — 시세 이하/이상의 보증금, 집값 하락 시 회수 불능 → 보증금 안전선 계산.
3. **바지 임대인·명의 대여** — 무자력자 명의로 계약 → 소유자=계약자=계좌 일치 확인.
4. **신축 빌라 분양가 거품** — 분양가를 시세로 위장 → 인근 실거래로 시세 확인.
5. **동시진행** — 매매·전세를 같은 날 처리해 등기 시점 차이 악용.
6. **신탁 사기** — 신탁등기 상태에서 위탁자가 무단 계약 → 신탁원부 확인.
7. **숨은 당해세** — 임대인 미납 국세(당해세)가 확정일자보다 우선 → 체납 열람.

## 5. 잔금일 체크리스트

- [ ] 잔금 직전 등기부등본 **재발급** — 새 근저당·가압류 없는지
- [ ] 송금 계좌가 **소유자 본인 명의**인지(대리인이면 위임장·인감증명)
- [ ] 잔금 후 **즉시 전입신고**(정부24/주민센터)
- [ ] **확정일자** 받기(주민센터/온라인)
- [ ] **점유** 시작(이사·실거주)
- [ ] **보증보험** 가입(가능 시, HUG/SGI)
- [ ] 계약서·이체내역·등기부 사본 보관

## 6. 보증금 미반환 시 행동 (긴급)

1. **임차권등기명령** — 이사 가야 하면 먼저 신청해 대항력·우선변제권 보전(이사 후에도 권리 유지).
2. **내용증명 → 지급명령 → 보증금반환소송** (→ life-legal).
3. **보증보험 가입자**면 보증기관(HUG/SGI)에 사고 접수.
4. **대한법률구조공단 132** 무료 상담.
