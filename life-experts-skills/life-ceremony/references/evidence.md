# life-ceremony 근거 자료 (코어스펙 1겹)

> SKILL.md의 축의/부의 관행·예법·장례 단계·상조 함정 상세. 경조사 관행은 지역·관계·세대차가 크므로 "관행·확인 필요"이며 당사자 집안 관행이 우선. 상조 약관은 공정위·한국소비자원 확인.

## 목차
1. 축의/부의 액수 관행
2. 봉투 작성 형식
3. 부의 복장·조문 예법
4. 상 당했을 때 단계별 체크리스트
5. 상조 함정 카탈로그

## 1. 축의/부의 액수 관행

기준: **관계 깊이 × 상호성(과거 받은 만큼)**. 일률 금액 아님.

| 관계 | 통상 범위 (관행·확인 필요) | 메모 |
|---|---|---|
| 직장 동료·먼 지인 | 5만원대 | 식사 참석 여부 고려 |
| 친한 동료·자주 보는 사이 | 5~10만원 | |
| 친한 친구 | 10만원대 | |
| 가족·매우 가까운 사이 | 그 이상 | 관계·집안 관행 |

변수: 지역·세대(고연령 관행 차이)·식사 참석·과거 본인이 받은 액수(상호성 핵심). 액수보다 '성의 있는 적정선'.

## 2. 봉투 작성 형식

| 경조사 | 앞면 문구 | 뒷면/안쪽 |
|---|---|---|
| 결혼 | 축 결혼 / 祝結婚 / 축 화혼 | 본인 이름(필요 시 소속) |
| 장례 | 부의(賻儀) / 근조(謹弔) / 조의(弔意) | 본인 이름(필요 시 소속) |
| 돌·생신 | 축 ○○ | 본인 이름 |

핵심: 경조사 종류에 맞는 문구 + **뒷면 본인 이름**(혼주·유족이 누가 냈는지 알아야 답례·상호성 기록). 종류 안 맞는 문구(부의에 '축')는 결례.

---

## 3. 부의 복장·조문 예법

복장:
- 어두운 색(검정·남색·진회색) 단정.
- 화려한 색·무늬·과한 액세서리·진한 화장 회피.
- 모르면 '튀지 않는 것'이 정답.

조문 순서(일반):
1. 빈소 입장, 상주에게 가벼운 목례.
2. 영정 앞에서 분향 또는 헌화(종교·관행 따라) 후 절(2회) 또는 묵념.
3. 상주에게 절(1회) 또는 목례 + 짧은 위로("삼가 조의를 표합니다" / "얼마나 상심이 크십니까").
4. 오래 머물지 않기. 큰 소리·웃음·사진·축하성 표현 금지.

종교(기독교 등)에 따라 절 대신 묵념·기도일 수 있음 — 유족 관행 따름.

## 4. 상 당했을 때 단계별 체크리스트

| 시점 | 할 일 | 메모 |
|---|---|---|
| 즉시 | 사망진단서/검안서 확보, 장례식장·빈소 결정 | 병원사망=진단서 / 외부=검안 |
| 즉시~당일 | 부고 연락(가까운 순), 상조 있으면 연락 | 부고: 고인·상주·일시·장소·발인 |
| 장례 중 | 빈소 운영, 조문 응대, 장지(매장/화장) 결정 | 패키지 항목·가격 사전 확인(끼워팔기 경계) |
| 발인 | 발인·운구·장지 절차 | 화장은 예약·시간 확인 |
| 사후 | 사망신고(기한 내), 금융·통신·각종 해지, 상속 | 상속·세금은 → life-tax/legal |

핵심: 경황없는 틈에 고가 옵션이 끼워팔리기 쉬움 — 항목·가격 명세 요구. 체크리스트가 곧 바가지 방어.

## 5. 상조 함정 카탈로그

상조 = **할부 선결제 서비스(보험 아님)**. 가입 전 체크:

| 함정 | 내용 | 방어 |
|---|---|---|
| 낮은 중도 해약 환급률 | 해약 시 납입액 전액 환급 아닐 수 있음 | 가입 전 환급률표 확인 |
| 만기 후 추가비용 | '기본'만 포함, 실제 장례엔 추가 옵션비 | 포함/제외 항목 명세 확인 |
| 회사 폐업 리스크 | 폐업 시 선수금 손실 가능 | 선수금 보전(공제조합·은행 예치) 여부 확인 |
| 끼워팔기 이중부담 | 가전·여행 결합이 별도 할부로 | 본 계약과 분리해 따짐 |
| 청약철회 미인지 | 할부거래법상 철회 기간 놓침 | 청약철회 기간 확인 |
| 방치 손실 | 안 쓸 상품 계속 납입 | 환급률 확인 후 해약 |

분쟁: 한국소비자원·공정거래위원회. 폐업 시 선수금 보전기관에 환급 청구(권리는 챙겨야 받음). 수치·제도는 확인 필요.
