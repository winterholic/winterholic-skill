# life-moving — 근거·체크리스트

> 제도 수치는 모두 "확인 필요"(정부24·인터넷등기소·국토부 허가이사종합정보·한국소비자원 기준). 스킬은 절차·함정 위주.

## 목차
1. 이사 유형 비교
2. 업체 검증 체크리스트
3. 견적 항목(빠지면 추가요금) 목록
4. 이사 전후 행정 타임라인 상세
5. 파손·추가요금 분쟁 대응
6. 공과금·정산 체크리스트

---

## 1. 이사 유형 비교

| 유형 | 특징 | 적합 |
|---|---|---|
| 포장이사 | 포장·운반·정리 일괄, 가장 편함·비쌈 | 짐 많음·바쁨·고가품 |
| 반포장 | 운반·큰가구는 업체, 잔짐 포장은 본인 | 비용 절충 |
| 용달(일반이사) | 운반만, 포장·정리 직접 | 1인·소량·근거리 |

## 2. 업체 검증 체크리스트

- [ ] 국토부 허가이사종합정보에서 **허가이사 등록** 확인.
- [ ] **적재물배상책임보험** 가입 여부(파손 보상 전제).
- [ ] 사업자등록·계약서 발행.
- [ ] 후기·분쟁 이력 검색(추가요금·파손 클레임).
- [ ] 방문/영상 견적 가능 여부(전화 견적만이면 경계).

## 3. 견적 항목 (총액 아닌 항목별로)

인부 수 · 차량 톤수 · **사다리차** · 에어컨 분리/설치 · 세탁기·정수기 등 가전 이전 · 장롱 분해/조립 · 포장재 포함 여부 · **폐기물·대형가전 처리** · 보관(보관이사 시) · 주차/엘리베이터 조건 · 추가요금 발생 조건.
→ 빠진 항목 = 당일 추가요금 후보. 견적서끼리 항목을 맞춰야 진짜 비교.

## 4. 이사 전후 행정 타임라인 상세

- **전입신고**: 전입 후 14일 이내(미신고 시 5만원 이하 과태료 — 주민등록법, 2026-06). 정부24 온라인 또는 주민센터.
- **확정일자**: 이사 당일 권장(보증금 우선변제 순위). 인터넷등기소 또는 주민센터. 대항력=전입신고+점유, 우선변제력=확정일자.
- **세대주 변경·전입세대 정리**: 필요 시.
- **우편물 주소이전**: 우체국 주거이전 서비스(일정 기간 새 주소로 전달).
- **각종 주소 변경**: 은행·카드·보험·통신·관공서·택배.

## 5. 파손·추가요금 분쟁 대응

- **사전 방어**: 항목별 서면 견적 + 추가요금 조건 계약서 명시 + 귀중품 직접 운반.
- **당일**: 작업 전 견적 재확인. 가전·가구 현장 검수 → 이상 시 즉시 사진 + 업체 확인 서명.
- **분쟁 시**: 한국소비자원(1372) 이사화물 분쟁해결 기준 참고, 계약서·사진·견적서 증거.
- **추가요금 요구 시**: 계약·견적에 없던 항목이면 거부 근거가 됨 — 당일 구두 합의는 가급적 문자/녹취로.

## 6. 공과금·정산 체크리스트

- [ ] 도시가스 전출 정산(예약 후 계량 확인) — 미정산은 따라옴.
- [ ] 전기·수도 정산.
- [ ] 관리비 일할 정산(관리사무소).
- [ ] **장기수선충당금 반환 요청** — 소유자 부담이 원칙(공동주택관리법 §30①), 임차인 대납분은 퇴거 시 반환 청구 대상(시행령 §31⑧, 2026-06). 종료 후에도 청구 가능.
- [ ] 인터넷/통신 주소이전 또는 해지(위약금 확인).
- [ ] 정기구독·배송지 변경.
