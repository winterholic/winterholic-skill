# evidence — 사기 수법 분류 · 지급정지/환급 절차 · 신고 채널

> 본 문서는 정보 제공이며 법률 자문이 아니다. 제도 수치·절차·신청처는 변경이 잦으므로 신청 직전 공식 출처(112·1332·은행 고객센터)에서 현행 기준을 확인할 것. 명시 수치는 "(확인 필요)"로 표기.

## 1. 사기 수법 분류 (작동 원리 · 공통 신호)

| 유형 | 미끼 | 작동 원리 | 막는 안티패턴 |
|---|---|---|---|
| 기관 사칭 (검찰·경찰·금감원) | "계좌가 범죄 연루, 안전계좌로 이체" | 권위+공포+시간압박. '안전계좌'는 존재 안 함 | 1, 2 |
| 대출 빙자 | "저금리 대환, 기존 대출 먼저 상환/작업비" | 급전 필요자 표적, 선입금·앱 유도 | 1, 2 |
| 메신저피싱 (가족·지인) | "폰 고장, 인증/돈 급해" | 음성 회피(채팅만), 신분증·상품권·계좌 요구 | 1, 3 |
| 악성앱(미러링·원격) | "대출앱/보안앱/지원금앱 설치" | 화면·문자(OTP)·은행앱 탈취, 콜포워딩으로 콜백 가로챔 | 2, 긴급게이트 4 |
| 중고거래 사칭 | 시세 이하 매물 + 가짜 안전결제 링크/선입금 | 카드·계좌 탈취 또는 잠적, '수수료 환불' 2차 요구 | 4 |
| 투자 빙자 (리딩방·코인) | 단톡방·SNS 고수익 | 가짜 거래소서 수익 가장 → 출금 시 세금·보증금 추가입금 요구 | 6, 4 |

**공통 위험 신호 (얼굴 말고 이걸 본다)**: ① 시간압박("지금 당장") ② 검증 회피(끊지 말라·혼자 처리) ③ 선입금/선수수료 ④ 출처불명 앱·링크 ⑤ 개인정보·OTP·비밀번호 요구 ⑥ '안전계좌'·'수사협조 이체' 같은 존재하지 않는 절차.

**철칙**: 공공기관·금융기관은 전화로 현금 인출·계좌 이체·앱 설치·OTP/비밀번호를 요구하는 절차가 없다.

## 2. 긴급 대응 체크리스트 (0~1시간 — 골든타임)

- [ ] 송금한 **은행 고객센터에 즉시 전화 → "보이스피싱 지급정지" 신청** (24시간, 인출 전 동결이 핵심)
- [ ] **112** 신고 → 접수번호/사건번호 확보
- [ ] **1332**(금감원) 상담 — 지급정지·절차 안내
- [ ] 악성앱 설치/원격제어 허용 시: 기기 **비행기모드·전원 차단** → 데이터/와이파이 끊기 → **다른 기기로** 은행·인증서·주요 계정 비밀번호 변경
- [ ] 추가 송금 요구는 모두 거부 (가족에게도 즉시 고지)

> 의심만으로도 일단 지급정지 신청이 낫다 — 오신청은 해제 가능하지만 인출된 돈은 회수 불가.

---

## 3. 증거 보전 체크리스트 (차단 전에 먼저)

- [ ] 통화 녹음 / 통화 시각·상대 전화번호
- [ ] 문자·카톡 대화 화면 캡처 (시각이 보이게)
- [ ] 계좌이체 내역: 거래일시·상대 계좌번호·예금주·금액
- [ ] 설치한 앱 이름·링크·문자 원문 캡처
- [ ] 사건사고사실확인원 발급(경찰)
- [ ] 위 보전 **후에** 번호·계정 차단

증거 없는 신고는 처리 지연 → 골든타임 손실. 분노로 먼저 삭제·차단하지 말 것.

## 4. 지급정지 → 채권소멸 → 환급 절차 (통신사기피해환급법 취지, 확인 필요)

대략의 흐름(정확한 요건·기간은 1332/은행 확인 필요):

1. **지급정지**: 피해자 신고로 사기이용계좌를 동결. 인출 전이어야 잔액 보전 가능.
2. **피해구제 신청**: 경찰 신고 후 은행에 피해구제 서류 제출.
3. **채권소멸절차 개시**: 금융감독원이 사기이용계좌 명의인의 채권소멸을 공고.
4. **이의제기 기간**: 명의인이 이의 없으면 채권 소멸.
5. **환급**: 소멸 후 피해자에게 잔액 비율로 환급 (총 수개월 소요, 기간 확인 필요).

핵심: **환급액은 동결 시점의 잔액 한도** — 늦게 신고해 이미 인출됐으면 환급할 돈이 없다. 그래서 0~1시간이 전부다.

## 5. 명의도용 차단 · 추가 피해 예방 (72시간 내)

- **어카운트인포(내 계좌 한눈에, 금융결제원)**: 본인 명의 전 계좌·대출 조회 → 모르는 계좌/대출 확인
- **엠세이퍼(KAIT)**: 본인 명의 휴대폰 신규 가입 제한 → 명의도용 개통 차단
- **개인정보노출자 사고예방시스템(금감원)**: 등록 시 신규 계좌·카드 발급에 본인확인 강화
- **계좌 비밀번호·인증서·은행앱 재설정**, OTP 재발급
- 주민번호 노출 시 카드사·통신사에 도용 가능성 통지

## 7. 2차 사기 경계

1차 피해자 명단은 사기 조직 간 거래된다 → 절박한 피해자가 최적 표적.

- "피해금 환급해주겠다" / "그 사기범 잡아주겠다" + 선수수료·개인정보 요구 = **2차 사기**
- 공공기관·금융기관은 환급 명목으로 돈·개인정보를 먼저 요구하지 않는다
- 환급은 통신사기피해환급법 공식 절차(지급정지→채권소멸→환급)로만 진행 — 유료 '대행' 제안은 사기
- 피해 직후 수주간이 2차 사기 표적기 — 의심 연락은 모두 1332/112로 진위 확인
