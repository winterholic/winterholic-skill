# evidence + 안내 전 체크리스트 (life-fraud-response)

> 진행 중 사기는 이 문서·체크리스트보다 **즉시 은행 지급정지·112·1332가 먼저**(긴급 게이트). 골든타임은 분 단위. 아래는 2026-06 웹 재확인 기준.

## 실증·출처

- **신고·차단 핫라인 (최고 가치 확인 — 모두 2026-06 유효)**:
  - 보이스피싱 통합신고 **112** (경찰·금융·KISA 통합 단일 창구, 보이스피싱지킴이 https://www.counterscam112.go.kr) — 출처: 금융위·정책브리핑.
  - 금융 민원·상담·지급정지 안내 **1332** (금융감독원, https://www.fss.or.kr).
  - 사기이용계좌 **지급정지**: 각 은행 24시간 고객센터 — 환급의 핵심 골든타임.
  - 악성앱·스미싱·피싱사이트 신고 **118** (KISA 인터넷침해대응, https://www.boho.or.kr).
  - 명의도용 차단: 엠세이퍼 https://www.msafer.or.kr (KAIT) / 어카운트인포 https://www.payinfo.or.kr (금융결제원).
  - 온라인 사기 신고: 경찰 ECRM https://ecrm.police.go.kr · 이력조회 더치트 https://thecheat.co.kr.
- **통신사기피해환급법 (전기통신금융사기 피해 방지 및 피해금 환급에 관한 특별법) — 환급 절차 (2026-06 검증)**:
  - 전화·구술로 즉시 지급정지 신청(제4조) → **지급정지 후 3영업일 내** 피해구제신청서+신분증 사본 제출(시행령 제3조, 미제출 시 지급정지 해제 가능) → 금감원 채권소멸절차 개시 공고(**2개월**, 제5·7조) → 이의 없으면 공고일부터 **2개월** 후 채권소멸(제9조) → 채권소멸일부터 **14일 내** 금감원 환급금액 결정·통지(제10조). 출처: 법제처 국가법령정보 https://www.law.go.kr · 찾기쉬운 생활법령 https://www.easylaw.go.kr (조회 2026-06).
- **수법 무관 공통 신호(불변 원칙)**: 공공기관은 전화로 '안전계좌' 이체·앱 설치·OTP/비밀번호를 요구하지 않는다 → '안전계좌'는 100% 사기 키워드. 환급·수사에 선수수료는 없다(→ "환급 도와준다"는 2차 사기). 정상 안전결제는 외부 링크로 오지 않는다.
- **AI 음성복제·딥페이크 (2025~2026 신종, 확인 필요)**: 가족·지인·임원의 목소리/얼굴을 복제해 송금을 유도 — '본인 같음'은 더 이상 신원 증거가 아니다. 다른 경로 콜백 + 사전 약속어(코드워드) 확인. 출처: 금융감독원·경찰청 보도자료 동향(2026-06 조회).

## 안내 전 체크리스트

- [ ] **긴급/위기 신호 게이트 먼저 통과** — "지금 송금/통화/앱설치/원격제어 중인가?" 예면 안내를 멈추고 **즉시 ①송금은행 지급정지 ②112 ③1332 ④(악성앱 시)기기 차단·비번 변경** 4단계를 그 자리에서. 분석·복기는 그 다음.
- [ ] "조금 더 알아보고"를 권하지 않았는가 — 의심만으로도 먼저 묶는다(오신청은 풀 수 있으나 인출된 돈은 못 되돌림).
- [ ] 증거 보전(통화·문자·이체내역·상대 계좌/번호 캡처)을 **차단보다 먼저** 하도록 안내했는가.
- [ ] **지급정지 후 3영업일 내 피해구제 서류 제출** 의무를 빠뜨리지 않았는가(미제출 시 지급정지 해제 위험).
- [ ] **2차 사기('환급 대행'·선수수료) 경고**를 포함했는가 — 1차 피해자는 2차 표적.
- [ ] **면책·시점 라벨 부착** — "정보 제공이며 법률 자문이 아님 / '반드시 환급'은 단정 불가(인출 여부·잔액·절차에 따라 다름) / 제도 절차·기간은 신청 직전 1332·112·은행 현행 확인".
- [ ] 형사 고소·민사·명의도용 확산은 변호사·대한법률구조공단(132)·경찰 상담으로 에스컬레이션했는가.

## 점검 주기

- **신고 핫라인(112·1332·118·ECRM·엠세이퍼·어카운트인포)**: 변경 즉시 갱신 — 최고 우선.
- **환급 절차·기간(3영업일·공고 2개월·환급 14일)**: 통신사기피해환급법·시행령 개정 추적, **연 1회 이상**. 법은 개정이 잦으니 신청 직전 1332 현행 확인을 항상 병기.
- **사기 수법 최신 동향**: 신종 수법(미러링 앱·콜포워딩·생성형 AI 음성/딥페이크 사칭·QR 피싱 등)은 부패가 빠름 — **분기~반기** 단위로 금감원·경찰청 보도자료 점검, 실전 케이스 카탈로그 갱신.
- **명의도용 구제·개인정보노출자 등록 제도**: 제도 변경 시 — 연 1회 점검.
