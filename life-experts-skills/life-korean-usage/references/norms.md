# life-korean-usage — 규범 조항 요약

> 판정 시 **근거로 인용할 조항**을 모아 둔 참조표. 원문은 https://korean.go.kr/kornorms 에서 확인한다. 출처·고시번호는 `evidence.md`.

## 한글 맞춤법 — 장 구성

| 장 | 범위 | 이 스킬에서 자주 쓰는 항 |
|---|---|---|
| 제1장 | 총칙 | 제1항(소리대로 적되 어법에 맞도록) |
| 제2장 | 자모 | — |
| 제3장 | 소리에 관한 것 | 제5항(된소리), 제30항(사이시옷) |
| 제4장 | 형태에 관한 것 | 제19·25항(접미사·부사 파생) |
| **제5장** | **띄어쓰기** | **제41~50항 — 실무 최다** |
| 제6장 | 그 밖의 것 | 제51항(부사 `-이/-히`), 제57항(혼동어 구별) |

### 제1항 — 총칙 (판정의 대원칙)
> 한글 맞춤법은 표준어를 **소리대로 적되, 어법에 맞도록** 함을 원칙으로 한다.

두 원리가 충돌할 때 "어법에 맞도록"(형태를 밝혀 적기)이 왜 이기는지의 근거. `꼬치`가 아니라 `꽃이`로 적는 이유.

### 제5장 띄어쓰기 (핵심)

| 항 | 규정 | 실무 포인트 |
|---|---|---|
| 제41항 | 조사는 앞말에 **붙여 쓴다** | 조사가 겹쳐도 붙임 — `집에서처럼`, `학교에서만이라도` |
| 제42항 | 의존 명사는 **띄어 쓴다** | `아는 것`, `할 수`, `떠난 지` |
| 제43항 | 단위 명사는 띄어 쓴다 | 순서·숫자와 어울리면 **붙임 허용** — `10개`, `제1장` |
| 제44항 | 수는 만(萬) 단위로 띄어 쓴다 | `12억 3456만 7898` |
| 제45항 | 두 말을 이어 주거나 열거하는 말은 띄어 쓴다 | `국장 겸 과장`, `청군 대 백군` |
| 제46항 | 단음절 단어가 연이어 나올 때 **붙여 쓸 수 있다** | `좀더 큰것` — **허용 규정** |
| 제47항 | 보조 용언은 띄어 씀이 원칙, **붙여 씀도 허용** | `도와 드리다`/`도와드리다` 둘 다 ○ |
| 제48항 | 성과 이름은 붙여 쓰고, 호칭·관직명은 띄어 쓴다 | `홍길동 씨`, `충무공 이순신 장군` |
| 제49항 | 고유 명사는 단어별로 띄어 씀이 원칙, **붙임 허용** | `한국 대학교 사범 대학`/`한국대학교 사범대학` |
| 제50항 | 전문 용어는 단어별로 띄어 씀이 원칙, **붙임 허용** | `만성 골수성 백혈병`/`만성골수성백혈병` |

> **허용 규정(46·47·49·50항)에 주의**: "붙여 쓸 수 있다"는 붙여 써도 **맞다**는 뜻이다. 원칙형으로만 교정하면 과잉 교정이므로 반드시 **[선호]** 라벨을 쓴다.

### 제30항 — 사이시옷

순우리말 또는 순우리말+한자어로 된 **합성어**로서 앞말이 모음으로 끝날 때, 다음 경우 사이시옷을 받쳐 적는다.
1. 뒷말 첫소리가 **된소리로 나는** 것 — 나뭇가지, 바닷가, 촛불
2. 뒷말 첫소리 `ㄴ, ㅁ` 앞에서 **`ㄴ` 소리가 덧나는** 것 — 아랫니, 빗물
3. 뒷말 첫소리 모음 앞에서 **`ㄴㄴ` 소리가 덧나는** 것 — 나뭇잎, 뒷일

**한자어끼리는 사이시옷을 적지 않는다.** 단 예외 6개만 인정:
> **곳간(庫間) · 셋방(貰房) · 숫자(數字) · 찻간(車間) · 툇간(退間) · 횟수(回數)**

자주 틀리는 것: `개수(個數)` ✕`갯수` / `초점(焦點)` ✕`촛점` / `대가(代價)` ✕`댓가` / `시가(時價)` ✕`싯가` — 모두 한자어 조합이라 사이시옷을 못 쓴다.

### 제51항 — 부사 `-이 / -히`

- 분명히 `-이`로만 나면 `-이`: 깨끗이, 가붓이, 일일이, 틈틈이
- 분명히 `-히`로만 나면 `-히`: 극히, 급히, 딱히, 속히
- `-이/-히` 둘 다 나면 `-히`: 솔직히, 가만히, 각별히

실무 판별: **`-하다`가 붙는 어근이면 대체로 `-히`**, 첩어·`ㅅ` 받침 뒤·`-하다`가 안 붙으면 `-이`.

## 표준어 규정 — 구조

| 부 | 내용 |
|---|---|
| 제1부 | 표준어 사정 원칙 (제1~26항) |
| 제2부 | 표준 발음법 (제1~30항) |

### 제1항 — 표준어의 정의
> 표준어는 **교양 있는 사람들이 두루 쓰는 현대 서울말**로 정함을 원칙으로 한다.

> ⚠️ 이 정의는 **공적 상황의 공통 규범**을 정한 것이지 방언이 틀렸다는 뜻이 아니다. 사용자가 방언을 의도적으로 쓴 경우 교정 대상이 아니다.

### 복수 표준어 (제18·19·26항)
같은 뜻의 두 형태가 널리 쓰이면 **둘 다 표준어**로 삼는다. 교정하지 않는다. 목록은 `error-patterns.md` §8.

> 표준어는 국립국어원 심의로 **수시 추가**된다. 오래된 기억으로 "비표준어"라 단정하지 말고 표준국어대사전을 조회한다.

## 외래어 표기법 — 제1장 표기의 기본 원칙

| 항 | 원칙 |
|---|---|
| 제1항 | 외래어는 국어의 **현용 24자모만으로** 적는다 |
| 제2항 | 외래어의 1음운은 원칙적으로 1기호로 적는다 |
| 제3항 | 받침에는 **ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅇ**만 쓴다 |
| 제4항 | **파열음 표기에는 된소리를 쓰지 않음**을 원칙으로 한다 |
| 제5항 | 이미 굳어진 외래어는 **관용을 존중**하되 범위와 용례를 따로 정한다 |

- 제3항 근거로 `커피숍`(✕커피숖), `로봇`(✕로보트) 처리.
- 제4항 근거로 `카페`(✕까페), `파리`(✕빠리), `버스`(✕뻐스).
- **제5항 때문에 원칙만으로 단정 불가** — 개별 표기는 용례 조회 필수.
- 2017-14호 개정에서 `-어(語)`·`-산(山)` 등 띄어쓰기 규정 변경.

## 국어의 로마자 표기법 — 요점

- 현행: 문체부 고시 제2014-42호.
- 원칙: **국어의 표준 발음법에 따라 적는다**(전사법). 로마자 이외의 부호는 되도록 쓰지 않는다.
- 음운 변화를 반영: `종로 → Jongno`(✕Jongro), `신라 → Silla`, `왕십리 → Wangsimni`.
- **인명**: 성과 이름 순, 이름은 붙여 쓰되 음절 사이 붙임표(-) 허용. **인명·회사명은 그동안 써 온 표기를 쓸 수 있다** → 여권·명함 표기가 규범과 달라도 교정 대상 아님.
- **행정구역**: `도·시·군·구·읍·면·리·동`은 `do, si, gun, gu, eup, myeon, ri, dong`으로 적고 앞에 붙임표를 넣는다 — `제주도 → Jeju-do`.

> 고유명사(상표·회사·인명)는 **당사자 공식 표기가 규범보다 우선**한다. 규범은 권고이고, 여권·법인등기 표기를 임의로 바꾸라고 하면 실무상 해가 된다.

## 판정 시 인용 형식

근거를 댈 때 아래 형식을 쓴다. 항 번호를 모르면 [선호]나 [확인]으로 강등한다.

```
[규범] 맞춤법 제42항(의존 명사 띄어쓰기)
[규범] 맞춤법 제30항(사이시옷) — 한자어 조합이라 미적용
[규범] 표준어 규정 제1항 / 표준국어대사전 표제어
[규범] 외래어 표기법 제1장 제4항(파열음 된소리 불가)
[선호] 번역투 — 규범 위반 아님
[확인] 표준국어대사전 미등재 — 조회 필요
```
