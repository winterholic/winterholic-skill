# life-korean-usage — 오류 패턴 사전

> 실무에서 빈발하는 오류를 판별법 중심으로 정리. **암기가 아니라 판별 규칙**을 익히는 것이 목적이다. 근거 조항은 `norms.md`, 출처는 `evidence.md`.
> 라벨 규칙: **[규범]** = 고쳐야 함 · **[선호]** = 권장일 뿐 · **[확인]** = 사전 조회 필요.

## 1. 형태가 헷갈리는 쌍 — 판별법

| 쌍 | 판별법 | 예 |
|---|---|---|
| **되 / 돼** | 그 자리에 `되어`를 넣어 말이 되면 `돼` | 안 **돼**요(안 되어요 ○) / **되**고 있다(되어고 ✕) |
| **-이 / -히** | 부사 파생. `-하다`가 붙는 어근이면 대체로 `-히`, 첩어·`ㅅ`받침 뒤는 `-이` | 깨끗**이**, troubleshooting 없이 → 솔직**히**, 각별**히** / 일일**이**, 틈틈**이** |
| **율 / 률** | 모음이나 `ㄴ` 받침 뒤 = `율`, 그 외 = `률` | 비**율**, 백분**율**, 실패**율**(모음) / 합격**률**, 경쟁**률**, 출석**률** |
| **든지 / 던지** | 선택·나열 = `든지`, 과거 회상 = `던지` | 가**든지** 말**든지** / 얼마나 춥**던지** |
| **체 / 채** | 그런 척 = `체`, 그 상태 그대로 = `채` | 모르는 **체**했다 / 옷을 입은 **채** 잤다 |
| **로서 / 로써** | 자격·신분 = `로서`, 수단·도구·기한 = `로써` | 학생으**로서** / 대화**로써** 해결 |
| **-데 / -대** | 내가 직접 겪음 = `-데`, 남에게 들음 = `-대` | 가 보니 좋**데** / 걔가 온**대** |
| **-던 / -든** | 과거 = `-던`, 선택 = `-든` | 먹**던** 밥 / 먹**든** 말**든** |
| **안 / 않** | `아니` = `안`(부사, 띄움), `아니하` = `않`(용언) | **안** 먹었다 / 먹지 **않**았다 |
| **-읍니다 / -습니다** | `-읍니다`는 **폐지**됨(1988) | 있**습니다** (있읍니다 ✕) |
| **왠 / 웬** | `왜인지` = `왠지`, 그 외 전부 `웬` | **왠지** 슬프다 / **웬** 일이야, **웬**만하면 |
| **몇일 / 며칠** | `몇일`은 **없는 말** | **며칠** (몇일 ✕) |
| **금새 / 금세** | `금시에`의 준말 | **금세** (금새 ✕) |
| **오랫만 / 오랜만** | `오래간만`의 준말 | **오랜만**에 / 단 **오랫**동안 |
| **-로써 시작** | 시점은 `-로서`가 아니라 `-로써` | 오늘**로써** 3년 |

## 2. 띄어쓰기 — 같은 형태, 다른 처리

앞말의 품사로 갈린다. **앞이 명사면 조사(붙임), 관형형(-는/-은/-을)이면 의존명사(띄움).**

| 형태 | 조사 (붙임) | 의존명사 (띄움) |
|---|---|---|
| 대로 | 법**대로**, 마음**대로** | 아는 **대로**, 시키는 **대로** |
| 만큼 | 너**만큼**, 하늘**만큼** | 할 **만큼**, 아는 **만큼** |
| 뿐 | 너**뿐**이다, 하나**뿐** | 할 **뿐**, 웃을 **뿐**이다 |
| 만 | 하루**만**에 (조사) | 온 지 사흘 **만**에 (시간 경과=의존명사) |
| 지 | 하는지 (어미, 붙임) | 떠난 **지** 3년 (시간 경과=의존명사) |
| 데 | 하는데 (어미, 붙임) | 가는 **데**까지 (곳·경우=의존명사) |
| 차 | 연수**차** 갔다 (접미사) | 가려던 **차**에 (의존명사) |
| 간 | 이틀**간**, 부부**간** (접미사) | 서울과 부산 **간** (의존명사) |

**단위·수**: 단위명사는 띄어 쓰되(제43항), 숫자와 어울리면 붙임 허용 — `열 개`/`10개`, `한 시간`/`1시간` 둘 다 가능. 순서 표현(`제1장`, `2026년 8월 2일`)도 붙여 쓸 수 있다.

**보조용언**(제47항): `도와 드리다`/`도와드리다` 둘 다 허용. **원칙형만 정답으로 교정하면 과잉** → [선호]로 처리.

## 3. 사물존대 — 서비스 화법 교정표

| ❌ 흔한 표현 | ✅ 규범 표현 |
|---|---|
| 커피 나오셨습니다 | 커피 나왔습니다 |
| 가격은 5만 원이십니다 | 가격은 5만 원입니다 |
| 그 상품은 품절이십니다 | 그 상품은 품절입니다 |
| 사이즈가 없으십니다 | 사이즈가 없습니다 |
| 주문 도와드리겠습니다 | 주문 받겠습니다 / 주문하시겠어요? |
| 결제 도와드릴게요 | 결제해 드리겠습니다 |

**허용되는 간접 높임** (사물이지만 높일 사람에 속함): `선생님 말씀이 있으시겠습니다`, `사장님은 따님이 두 분 있으십니다`, `교수님 연구실이 넓으시네요`.

| ❌ | ✅ | 비고 |
|---|---|---|
| 쓰여지다 | 쓰이다 | |
| 보여지다 | 보이다 | |
| 잊혀지다 | 잊히다 | `잊혀진 계절`은 관용 굳음, 규범형은 `잊힌` |
| 읽혀지다 | 읽히다 | |
| 나뉘어지다 | 나뉘다 | |

판별: 피동 접미사(`이·히·리·기`)가 이미 있는데 `-어지다`를 또 붙였는지 본다. **둘 중 하나만** 쓴다.

## 5. 번역투 — [선호] 등급 (강제 금지)

| 유형 | ❌ | ✅ 권장 | 원천 |
|---|---|---|---|
| 과잉 `-의` | 회의**의** 진행**의** 방식 | 회의를 진행하는 방식 | 일본어 `の` |
| `-에 의해` | 사장**에 의해** 결정되었다 | 사장이 결정했다 | 영어 `by` / 일본어 `によって` |
| `-(으)로부터` | 친구**로부터** 들었다 | 친구에게(서) 들었다 | 영어 `from` — 국립국어원은 오류로 보지 않음 |
| 무생물 주어 피동 | 이 보고서는 ~를 지적하고 있다 | 이 보고서는 ~를 지적한다 | 영어 진행형 |
| `-고 있다` 남용 | 증가하고 있는 추세이다 | 증가하는 추세다 / 늘고 있다 | 진행형 직역 |
| `가지다` | 회의를 **가졌다** | 회의를 **했다** | 영어 `have` |
| `-되어지다` | 판단**되어진다** | 판단된다 | 이중피동 겸함 → 이건 [규범] |
| 복수 `-들` | 많은 사람**들**이 | 많은 사람이 | 한국어는 복수 표지 생략이 자연스러움 |

> **판단 순서**: ① 이 피동/표현이 문맥상 꼭 필요한가? (행위자를 감춰야 하나, 결과가 초점인가) → 필요하면 **그대로 둔다**. ② 불필요하면 [선호]로 대안 제시. **절대 일괄 치환하지 않는다.**

## 6. 중복 표현 (겹말)

| ❌ | ✅ | 이유 |
|---|---|---|
| 역전 앞 | 역전 / 역 앞 | 驛前 = 역 앞 |
| 미리 예습 | 예습 | 豫 = 미리 |
| 과반수 이상 | 과반수 / 절반 이상 | 過半數 = 절반 넘는 수 |
| 계속 이어지다 | 계속되다 / 이어지다 | 중복 |
| 결실을 맺다 | 열매를 맺다 / 결실을 거두다 | 結實 = 열매 맺음 |
| 낙엽이 떨어지다 | 낙엽이 지다 / 잎이 떨어지다 | 落葉 = 떨어진 잎 |
| 시범을 보이다 | 시범하다 / 모범을 보이다 | 示範 = 보여 줌 |
| 박수를 치다 | 박수하다 / 손뼉을 치다 | 拍手 = 손뼉 침 — **단 사전 등재, 관용 인정** |
| 넓은 광장 | 광장 | 廣 = 넓음 |
| 방학 기간 동안 | 방학 동안 / 방학 기간에 | 期間 = 동안 |

> **주의**: `박수를 치다`, `처갓집`, `해변가` 등은 관용으로 굳어 사전에 올랐다. **겹말이라는 이유만으로 일괄 교정하면 안 되고**, 표준국어대사전 등재 여부를 확인한 뒤 판정한다.

## 8. 복수 표준어 — 둘 다 맞다

교정 대상이 **아니다**. 사용자가 어느 쪽을 써도 맞다고 알려 준다.

| 복수 표준어 |
|---|
| 짜장면 / 자장면 |
| 맨날 / 만날 |
| 복숭아뼈 / 복사뼈 |
| 허접쓰레기 / 허섭스레기 |
| 태껸 / 택견 |
| 품새 / 품세 |
| 자장면·간지럽히다·남사스럽다·등물·맨날·묫자리·복숭아뼈·세간살이·쌉싸름하다·토란대·허접쓰레기·흙담 (2011 추가분) |
| 아옹다옹/아웅다웅, 개기다/개개다, 사그라들다/사그라지다, 속앓이/속병, 찌뿌둥하다/찌뿌듯하다 (2014 추가분) |

> 표준어 추가는 국립국어원이 **수시로 심의·발표**한다. 목록을 절대적으로 신뢰하지 말고, 오래된 기억으로 "그건 비표준어"라고 단정하지 않는다 — 이미 표준어로 인정된 경우가 많다.
