# life-concierge — 실증·체크리스트 (evidence-checklist)

> 컨시어지는 안내데스크(라우터)이지 직접 처방이 아니다. **가장 중요한 자산은 1단계 긴급 게이트의 핫라인 번호** — 라우팅보다 항상 먼저, 절대 약화·생략 금지. 최종 조회: 2026-06.

## 실증·출처

긴급 게이트 핫라인 검증 (2026-06 기준 모두 현행 확인):

- **자살예방상담전화 ☎ 109** — 2024년 단일 통합번호로 시행(기존 1393 등 통합). 24시간. → life-mental-care 게이트. 출처: 보건복지부·한국생명존중희망재단 (조회 2026-06)
- **정신건강상담전화 ☎ 1577-0199** — 24시간 정신건강 위기상담, 거주지 정신건강복지센터 연결. 출처: 보건복지부 (조회 2026-06)
- **범죄·신변위협·스토킹 ☎ 112** (경찰) / **화재·구급·응급 ☎ 119** (소방) — 현행. (조회 2026-06)
- **금융 민원·보이스피싱 ☎ 1332** (금융감독원) — 평일 9~18시, 긴급 금융사기 피해는 24시간 신고. 보이스피싱은 송금 은행 지급정지 → 112/1332 순. 출처: 금융감독원 https://www.fss.or.kr · 파인 https://fine.fss.or.kr (조회 2026-06)
- 보이스피싱 진행 중 1차 행동(지급정지 → 112/1332 → life-fraud-response) 순서 확인 — '돈이 비가역적으로 새는' 영역이라 분석보다 행동 우선.
- 영역별 트리거·주/보조 매핑: `references/routing-matrix.md`

> 면책 영역(법·세·의료·보험·부동산 법률·금융) 라우팅 시 안내 말미에 "정보 제공이며 자문 아님 + 해당 전문가 상담 권고"와 제도 수치 "(YYYY 기준, 확인 필요)" 라벨 의무.

## 안내 전 체크리스트

- [ ] **1단계 긴급 게이트를 먼저 통과시켰는가** — 의식저하·가슴통증·호흡곤란·심한출혈·뇌졸중(F.A.S.T)→119, 범죄·협박·스토킹→112, 화재·가스→119/대피, 보이스피싱 진행중→지급정지·112/1332, 자해·자살사고→109/1577-0199. **긴급 신호가 있으면 라우팅·분석을 멈추고 즉시 행동부터** 안내했는가
- [ ] 핫라인 번호를 임의로 바꾸거나 빠뜨리지 않았는가(약화 금지 — 검증된 현행 번호 그대로)
- [ ] 면책·시점 라벨 — 면책 영역(법·세·의료·보험) 전문가로 라우팅 시 자문 아님 라벨 + 제도 수치 시점 라벨 확인했는가
- [ ] 주/보조 1~2명만 선정(동시 3명 이상 금지), '돈·권리가 비가역적으로 새는 쪽'과 '지금 행동 필요한 쪽'을 주로 두었는가
- [ ] 미제작(⬜) 전문가는 Read하지 않고 폴백 형식 + 공식 출처로 진행한다고 한 줄 알렸는가
- [ ] 경계 밖(투자 종목 판단 stock-experts, 코드 dev-experts)은 라우팅하지 않았는가

## 점검 주기

- **긴급 게이트 핫라인 번호(109·1577-0199·112·119·1332)**: 변경 시 **즉시** 반영(예: 109는 2024년 통합 신번호처럼 번호 통합·개편이 일어남). 정기 확인 연 1회+.
- **영역별 라우팅 매핑(routing-matrix.md)**: 전문가 스킬 신설·통폐합 시 갱신 — 분기 1회.
- **면책 영역 목록**: 제도 변화 적음 — 연 1회.
- **각 전문가의 제도 수치**: 라우터는 보유하지 않음 — 해당 전문가 SKILL.md/evidence-checklist.md가 관리.
- 충돌 시 라우터 본문보다 각 전문가 SKILL.md가, 핫라인은 공식 출처(복지부·경찰청·소방청·금감원)가 우선.
