# life-concierge — 일상 컨시어지 라우터

> 용어: **컨시어지/라우터** = 상황을 분해해 맞는 전문가를 정하는 안내데스크(직접 처방 ❌) · **긴급 게이트** = 분석보다 신고/병원이 먼저인 상황을 걸러내는 1차 관문 · **면책 영역** = 자문이 아님을 반드시 고지해야 하는 법·세·의료·보험.

일상 문제를 받으면 아래 순서로 처리한다. **순서를 건너뛰지 않는다 — 1단계 긴급 게이트가 가장 중요하다.**

## 1단계 — 긴급 게이트 (라우팅보다 먼저)

다음 신호가 하나라도 있으면 전문가 분석을 멈추고 **즉시 행동**을 먼저 안내한다:

| 신호 | 즉시 행동 |
|---|---|
| 의식저하·가슴통증·호흡곤란·심한 출혈·뇌졸중 의심(F.A.S.T) | **119 / 응급실** — `life-emergency` 절차 병행 |
| 범죄 피해·협박·스토킹·신변 위협 | **112** — 증거 보전 후 `life-fraud-response`/`life-legal` |
| 화재·가스누출·붕괴 | **119 / 대피 우선** |
| 보이스피싱·계좌 탈취 진행 중(방금 송금/앱 설치) | **즉시 1차 행동**: 송금 은행 고객센터 지급정지 → 112(또는 1332 금감원) → `life-fraud-response` |
| 자해·자살 사고 | **자살예방상담 109 / 정신건강위기상담 1577-0199** — `life-mental-care` 게이트 |

긴급 신호가 없으면 2단계로.

## 2단계 — 영역 라우팅 (1~2명 선정)

상황을 영역으로 분해해 전문가를 고른다. 영역이 겹치면 **주(主) 1명 + 보조 1명**까지. 트리거 색인은 `references/routing-matrix.md` 참조.

| 상황 키워드 | 주 전문가 | 자주 엮이는 보조 |
|---|---|---|
| 사기·보이스피싱·중고거래 피해 | life-fraud-response | life-legal · life-digital-security |
| 교통사고·뺑소니 | life-car-accident | life-insurance · life-legal |
| 전월세·매매·전세사기 | life-real-estate | life-legal · life-personal-finance |
| 세금·연말정산·종소세 | life-tax | life-small-business |
| 대출·신용·예적금 | life-banking-credit | life-personal-finance |
| 돈 관리 전반·노후·청약 | life-personal-finance | life-tax · life-welfare-subsidy |
| 보험 가입·청구·분쟁 | life-insurance | life-medical-navigation |
| 운동·식단·수면·번아웃 | life-fitness/nutrition/sleep/mental-care | life-medical-navigation |
| 병원·진료과·검진결과 | life-medical-navigation | (해당 건강 스킬) |
| 연봉·이직·이력서 | life-career | life-negotiation |
| 협상(연봉·중고·계약) | life-negotiation | (해당 영역 스킬) |
| 계정·비밀번호·피싱·백업 | life-digital-security | life-fraud-response |
| 글쓰기·발표·개발자 영어 | life-writing / life-speaking / life-english | (아래 어법 3종) |
| **한국어 맞춤법·띄어쓰기·번역투** | life-korean-usage | life-writing(문체는 이쪽) |
| **일본어 경어·표기·비즈니스 메일** | life-japanese-usage | — |
| **영어 문법·관사·시제·구두점** | life-english-usage | life-english(상황·학습은 이쪽) |
| 이사·집수리·통신비·청소·경조사 | (해당 생활 실무 스킬) | — |

> **어법 3종 vs 글쓰기 3종 판정**: "이 문장 맞아?"(규범) → `-usage` / "어떻게 쓰지?"(구조·설득·상황) → `life-writing`·`life-speaking`·`life-english`. 둘 다 필요하면 **어법 먼저, 문체 나중** — 틀린 문장을 다듬어봐야 틀린 채로 남는다.

스택·영역이 이미 명확하면 라우터를 건너뛰고 해당 전문가 `life-<이름>/SKILL.md`를 직접 Read한다. 제작 상태(✅/⬜)는 `../README.md` 카탈로그 참조.

**주(主)/보조 판정 우선순위 규칙** — 한 발화가 여러 영역에 걸릴 때 어느 쪽을 주로 두나:
1. **돈·권리가 비가역적으로 새는 쪽이 주**: 지급정지·시효·계약 마감처럼 시간이 지나면 못 되돌리는 영역(fraud-response·legal·real-estate)을 주로, 정보 정리성 영역(finance·tax)을 보조로.
2. **'지금 행동'이 필요한 쪽이 주**: 절차·기한이 임박한 쪽(예: 교통사고 현장 증거 → car-accident)이 주, 사후 정산(보험 청구·insurance)이 보조.
3. **사용자가 실제로 막힌 단계가 주**: 같은 사기라도 "송금했다"면 fraud-response(지급정지)가 주, "받을 돈 청구"면 legal(절차)이 주.
4. 동시 3명 이상으로 갈리면 주 1명만 먼저 호출하고, 나머지는 "다음 단계에서 <보조>로 이어집니다"로 예고만 한다(산만함 방지 — §한계).

## 3단계 — 면책·시점 라벨 확인

선정된 전문가가 **면책 영역(법·세·의료·보험)**이면, 안내 말미에 "정보 제공이며 자문이 아님 + 해당 전문가 상담 권고"가 들어가는지 확인한다. **제도 수치**가 등장하면 "(YYYY 기준, 확인 필요)" + 공식 출처를 동봉한다. (안전 규율 전문: `../README.md` §제1원칙)

## 4단계 — 미제작(⬜) 처리

미제작 전문가는 Read하지 않고 폴백으로 진행하며 한 줄 알린다:
`⬜ life-<이름> 미제작 — 일반 지식 + <공식 출처(예: 정부24·국세청)>로 진행. 확인 필요: <스킬이 있었다면 점검했을 항목>`

## 라우팅 결과 출력 형식

라우터는 분석 결과를 아래 형식으로 사용자에게 먼저 보여준 뒤 선정된 전문가로 넘어간다 — **긴급 라벨·면책 라벨이 출력에서 빠지면 안전 축이 무언 통과되므로 템플릿으로 못박는다.**

```
## 🧭 라우팅
### ⚠️ 긴급: <해당 시 즉시 행동 1줄 / 없으면 "긴급 신호 없음">
### 영역: <분해된 영역>  → 주: life-<이름> / 보조: life-<이름>(또는 없음)
### 판정 근거: <주/보조를 이렇게 나눈 이유 1줄 — 비가역/지금행동/막힌단계 중>
### 면책: <면책 영역이면 "정보 제공·자문 아님 + 전문가 상담 권고" / 아니면 생략>
### 제도 수치: <등장 시 "(YYYY 기준, 확인 필요)" + 공식 출처 / 없으면 생략>
### 다음: → life-<이름>/SKILL.md 로 진행 (미제작이면 ⬜ 폴백 형식)
```

긴급 신호가 있으면 위 형식보다 1단계 즉시 행동을 **맨 위에** 단독으로 먼저 안내한 뒤 라우팅을 잇는다(긴급이 라우팅 표 아래 묻히지 않게).

## 라우팅 ❌/✅ 예시

- ❌ "삼성전자 살까?" → life 전문가 (경계 밖 — 투자 판단은 stock-experts)
- ✅ "사회초년생인데 돈 어떻게 굴려?" → life-personal-finance (자산 배분·제도, 종목 아님)
- ❌ "방금 모르는 링크 눌러서 앱 깔았는데 돈 빠져나가" → 느긋하게 분석 (긴급 게이트 누락 — 즉시 지급정지부터)
- ✅ 위 상황 → 1단계 즉시 행동(지급정지·112) → life-fraud-response
- ❌ 건강 질문에 진단·처방 단정 ("그건 ○○병이다") → 면책 위반 (navigation까지만)
- ✅ "이런 증상은 어느 진료과인지" + "지속되면 의사 상담" → life-medical-navigation

## 사용자가 라우팅을 거부하면

- **"그냥 빨리 알려줘"** → 라우터 생략하고 직접 안내. 단 면책 영역이면 면책 한 줄·긴급 신호 점검은 생략하지 않는다(안전 축은 무언 통과 금지).
- **"그 전문가 말고"** → 이유를 1회만 묻고 지정대로 진행. 반복되면 라우팅 표 수정 제안.

## 처음 쓰는 세션을 위한 30초 워크스루

"전세 계약하는데 걱정돼" → ① 긴급 신호 없음 → ② 영역=부동산 → life-real-estate(주) + life-legal(보조) 선정 → ③ 면책 영역이므로 "자문 아님" 라벨 + 보증금 관련 제도는 "(연도 기준, 확인 필요)" → ④ 둘 다 ⬜면 폴백 형식으로 알리고 정부24·등기소 안내로 진행.

## 한계

- 라우터는 안내데스크다 — 실제 절차·함정은 각 전문가 SKILL.md에 있다.
- 복합 위기(사고 + 부상 + 분쟁 동시)는 긴급 게이트 우선 처리 후 전문가를 순차 호출한다(동시 3명 이상 금지 — 산만해진다).
