# life-small-business 증거·체크리스트

> 간이과세 기준·세금계산서 발행 제한·신고기간·세율은 매년 개정된다. 본 문서는 **선택 관점·함정 패턴·체크 항목** 위주이며 수치는 홈택스·국세청 126에서 당해 기준 확인. (2026 기준, 확인 필요)

## 1. 사업성 판단 — 등록 의무 여부

사업자등록 의무는 "계속적·반복적 영리활동(사업성)" 여부로 본다.

- [ ] 일회성 거래인가, **반복·계속** 거래인가 (반복이면 사업성↑)
- [ ] 영리 목적인가
- [ ] 매출 규모·빈도가 일정 수준인가
→ 사업성이 있으면 등록 의무. 애매하면 국세청 126 확인. 개발자 외주가 반복되면 사업성 인정 가능.

미등록의 손실:
1. 미등록가산세
2. 등록 전 매입의 부가세 매입세액·경비 공제 불가
3. 사후 적발 시 가산세 누적 (소득은 지급명세서·카드매출로 이미 노출)

## 2. 간이과세 vs 일반과세 선택표

| 기준 | 간이과세 | 일반과세 |
|---|---|---|
| 적합 | 영세 B2C, 낮은 매출 | B2B, 매출 큼, 초기 투자 많음 |
| 세부담 | 낮은 부가율·간편 | 표준(매출세액−매입세액) |
| 세금계산서 | 발행 제약(일정 기준 이하 제한, 확인 필요) | 발행 가능 |
| 매입세액 환급 | 제한 | 가능(초기 투자 환급) |
| 신고 | 연 1회 등(간편) | 반기 확정·예정 |

- 간이과세 기준: 직전연도 공급대가 **1억 400만원 미만**(2024.7~ 상향, 종전 8,000만). 부가세 **납부면제는 연 4,800만 미만**. 세금계산서: 4,800만 미만 간이는 영수증만, 4,800만~1억400만 간이는 발급(2026 기준, 확인 필요).
- "무조건 간이가 유리"는 착각 — **거래상대(세금계산서 요구)·환급 필요성·매출규모**로 판단.
- 거래처가 법인/일반과세자면 세금계산서를 요구하는 경우가 많음 → 간이로 못 끊으면 거래 단절.
- 매출이 일반 전환 기준을 넘으면 전환됨(기준 확인 필요).

## 3. 부가가치세 흐름

```
납부세액 = 매출 시 받은 부가세 − 매입 시 낸 부가세
```

- 부가세는 **최종소비자가 부담**, 사업자는 잠시 보관하다 납부.
- "매출 = 내 돈"이 아니다 — 받은 부가세는 별도 보관(통장 분리 권장).
- 신고 누락 = 무신고가산세. 납부 지연 = 납부지연가산세.
- 신고기간(2026 기준, 확인 필요): 일반 1기 확정 7.1~7.25·2기 확정 다음해 1.1~1.25(+예정 4월·10월), 간이 다음해 1.1~1.25 연 1회.
- 부가세율: 일반 10%(영세율 0%·면세 별도).

## 4. 적격증빙 체크리스트

매입세액 공제·경비 인정에 필요한 증빙:
- [ ] 세금계산서(전자)
- [ ] 현금영수증(사업자 지출증빙용)
- [ ] 신용카드 매출전표(사업용 카드)
→ 단순 영수증·간이영수증은 한도/조건 제한.

인프라:
- [ ] 사업용 계좌 홈택스 등록
- [ ] 사업용 신용카드 홈택스 등록
- [ ] 사업/개인 지출 분리

## 5. 세금계산서 실무

- 전자세금계산서: 홈택스/발행대행으로 적시 발행.
- 발행 시기·필수 기재사항 준수(지연·오류 = 가산세).
- 매입분은 반드시 수취해야 매입세액 공제.

## 6. 개발자 부업 함정

1. 매출 늘어도 "부업이니까" 미등록 → 가산세 + 매입공제 손실.
2. "간이가 싸다"고 골랐다가 법인 거래처 세금계산서 요구로 거래 막힘.
3. 서버·장비 초기 매입 환급을 간이라 못 받음.
4. 받은 부가세를 수익으로 써버려 납부 때 현금 부족.
5. 폐업했는데 폐업신고 안 해 신고의무·불이익 지속.

## 7. 시작과 마무리 신고

- 사업개시: 사업자등록(일정 기간 내).
- 변경: 업종 추가·주소·과세유형 정정신고.
- 중단: **폐업신고**(안 하면 무실적이어도 의무·불이익 — 건강보험료 등).
