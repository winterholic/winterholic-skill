# life-small-business evidence + 안내 전 체크리스트

> 간이과세 기준·세금계산서 발행 제한 구간·신고기간·세율·공제 한도는 매년/개정 시 바뀐다. 본 문서는 **출처·체크 항목·점검 주기** 위주이며, 수치 단정은 하지 않는다 — 당해 기준은 홈택스·국세청 126·소진공에서 재확인. 본 문서의 어떤 항목도 세무자문이 아니다. (조회: 2026-06)

## 실증·출처

- **국세청 부가가치세 기본정보** (nts.go.kr, cntntsId=7693, 조회 2026-06) — 사업자등록 20일 내 신청·미등록가산세(공급가액 1%)·간이과세 기준(직전연도 공급대가 1억 400만원 미만, 2024.7~)·간이 납부면제(연 4,800만 미만)·세금계산서 발급구간(4,800만~1억400만 간이는 발급, 4,800만 미만은 영수증)·부가세 신고기간(일반 1·2기 확정 7.25/익년 1.25 + 예정 4월·10월, 간이 익년 1.1~1.25 연1회)의 1차 출처. https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7693&mi=2272
- **국세청 종합소득세 신고·납부기한** (nts.go.kr, cntntsId=7665, 조회 2026-06) — 개인 종소세 신고 다음해 5.1~5.31(공휴일이면 다음날), 성실신고확인 대상은 6.30까지. https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2225&cntntsId=7665
- **국세청 사업자등록 안내 — 휴·폐업** (nts.go.kr, cntntsId=7780, 조회 2026-06) — 폐업 시 지체없이 휴업(폐업)신고서+사업자등록증 제출, 홈택스/손택스 온라인 신고 가능, 부가세 확정신고서에 폐업일 기재 시 폐업신고 갈음. 폐업 후에도 폐업일 다음달 25일까지 부가세 신고·납부 + 해당연도 종소세 신고. 인허가 138개 업종은 통합폐업신고서로 시군구·세무서 일괄. https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7780&mi=2447
- **간이과세 배제기준 고시** (국세청, 매년 개정·2026.1.1 시행분 존재, 정확한 업종·지역 목록 확인 필요) — 배제 업종·지역이면 매출이 기준 미만이어도 간이 적용 불가·일반과세. 수치·목록은 당해 고시로 확인.
- **소상공인 정책자금 융자사업** (중기부·소상공인시장진흥공단, 2026 공고, 조회 2026-06) — 일반·특별·긴급경영안정·신용취약·대환·재도전·청년고용연계·성장기반 등. 자격: 소상공인기본법상 소상공인(상시근로자 5인 미만, 제조·건설·운수·광업은 10인 미만). 금리 분기 변동. 신청 ols.semas.or.kr / 지역센터. 문의 1357·1533-0100. 금리·세부 자격은 → life-banking-credit / life-welfare-subsidy로 위임이 원칙. https://semas.or.kr/web/SUP01/SUP0103/SUP010301.kmdc
- **노란우산공제** (중소기업중앙회, 조회 2026-06) — 소기업·소상공인 폐업·노령 대비 공제. 소득공제 한도 2025년부터 600만으로 상향(종전 500만). 월 5만~100만 납입, 압류 보호, 납입원금 일부 대출. 임의해지 시 소득공제분 환수·1년 미만 수수료. 세부 조건·이율은 공식 확인 필요.
- **4대보험(개인사업자 직원 고용)** (4대사회보험정보연계센터·근로복지공단, 조회 2026-06) — 근로자 1인 이상 고용 시 국민연금·건강·고용·산재 가입 의무, 채용 후 통상 14일 내 취득신고. 영세사업장 두루누리 보험료 지원 제도 존재(대상·요율 확인 필요). 1인 사업자 본인은 지역가입자.
- **법제처 국가법령정보센터** (law.go.kr) — 부가가치세법·시행령(세율 10%·적격증빙·간이과세 조항)의 법령 원문 출처. https://www.law.go.kr
- 면책: 위 출처는 일반 정보 제공용이며 세무자문이 아니다. 구체 등록·과세유형·신고 판단은 세무사 또는 국세청 126.

## 안내 전 체크리스트

사업자·부업 안내를 내보내기 전, 그대로 점검:

- [ ] **면책 게이트** — "정보 제공이며 세무자문 아님 · 세무사/국세청 126 상담 권장"을 안내에 포함했는가 (제거·약화 금지)
- [ ] **시점 라벨** — 인용한 수치·기준에 "(2026-06 확인)" 또는 "확인 필요"를 붙였는가
- [ ] **신고기한 정확성** — 사업자등록(개시 20일 내)·부가세 신고기간·종소세(5.31/성실신고 6.30)·폐업 후 부가세(폐업일 다음달 25일)를 정확히 안내했는가, 추측으로 단정하지 않았는가
- [ ] **폐업신고 누락 경고** — 사업 중단 시 폐업신고(지체없이)와 폐업 후 잔여 신고의무를 빠뜨리지 않았는가
- [ ] **연단위 변동 수치는 "확인 필요"** — 간이 기준(1억400만)·세금계산서 발급구간(4,800만)·간이 배제 업종/지역 고시·노란우산 한도 등 가변값을 단정하지 않고 홈택스/126/소진공 재확인으로 안내했는가
- [ ] **과세유형 선택을 거래구조로** 안내했는가 ("무조건 간이" 단정 금지 — 거래상대·환급·매출·배제기준 고려)
- [ ] **전문가 상담 권고** — 구체적 세액 계산·절세 판단은 세무사, 정책자금·금리는 → life-banking-credit/life-welfare-subsidy로 위임 안내했는가
- [ ] **민감정보 마스킹** — 사업자번호·계좌·매출액 등은 `[REDACTED]` 처리 안내(README 안전 규율)
- [ ] **탈세 조장 금지** — 미등록·신고 누락을 정당화하거나 회피 방법을 안내하지 않았는가

## 점검 주기

- **연 1회 이상 또는 개정 시** — 간이과세 기준(1억400만)·납부면제(4,800만)·세금계산서 발급구간·간이 배제기준 고시(매년 개정, 1.1 시행)·부가세 신고기간·종소세 기한·노란우산 소득공제 한도·두루누리 지원요건을 홈택스·국세청 126·소진공·중기중앙회에서 재확인하고 SKILL.md/sources.md의 시점 라벨 갱신.
- **부패 등급 빠름** — 세법·고시 개정 뉴스(중기부·국세청 정책브리핑)가 있으면 즉시 수치 재검증. 변동 미확인 시 해당 수치는 "확인 필요"로 비워둔다.
- **위임 경계 재점검** — life-tax(종소세·공제)·life-banking-credit/life-welfare-subsidy(정책자금·금리·지원금)와의 중복·충돌을 주기적으로 확인.
