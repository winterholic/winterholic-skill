# life-writing 근거 자료

> 목차: 1) 원칙 출처 2) 문장 다이어트 사전 3) 고쳐쓰기 체크리스트 4) 독자 분석 표 5) 문서 유형별 BLUF 예

> 정확한 서지·URL은 `sources.md` 참조.

## 1. 원칙 출처

- **William Zinsser, 『On Writing Well』(초판 1976)** — 명료함·간결함·인간미. 핵심 명제: "Rewriting is the essence of writing(글쓰기의 본질은 고쳐쓰기다)." 불필요한 요소(clutter) 제거가 좋은 글의 본질.
- **BLUF (Bottom Line Up Front)** — 미군/실무 작문 관행(단일 학술 원전 없음). 결론·요청을 첫 줄에. 바쁜 수신자가 첫 문장으로 판단·행동 가능하도록.
- **피라미드 원칙 (Barbara Minto, 『The Pyramid Principle』 초판 1985, 매킨지)** — 결론 → 근거 → 근거의 근거. 위계의 기준은 중요도. MECE(상호배타·전체포괄, Minto 창안)로 근거 그룹화. SCQ(Situation-Complication-Question) 프레임.
- **George Orwell, "Politics and the English Language"(에세이, 1946)** — 군더더기·상투어·수동태 남용 경계. 6규칙 중 가장 유명: "능동태로 쓸 수 있으면 수동태를 쓰지 마라."

## 2. 문장 다이어트 사전 (삭제·축약 후보)

| 군더더기 표현 | 대체 |
|---|---|
| ~인 것 같습니다 (확신 있을 때) | ~입니다 |
| ~할 수 있도록 하겠습니다 | ~하겠습니다 |
| ~에 대하여 / ~와 관련하여 | (대개 삭제 가능) |
| 다름이 아니오라 / 우선 | (삭제) |
| 개인적으로 생각하기에는 | (삭제, 또는 "제 의견은") |
| 매우·정말·아주 (남발) | (대개 삭제, 강조는 1회만) |
| ~라고 할 수 있습니다 | ~입니다 |
| 의 ~의 ~의 (관형격 연쇄) | 문장 분리 |
| 진행하다/실시하다 (동사 대체) | 직접 동사("회의를 진행" → "회의") |

원칙: 완충어는 자신 없어 보이게 하고, 중복은 핵심을 묽게 한다. 1차 다이어트는 "기능 없는 단어 삭제".

## 3. 고쳐쓰기 체크리스트 (패스별)

**구조 패스**
- [ ] 결론·핵심·요청이 첫 1~2문장에 있는가 (BLUF)
- [ ] 한 문단이 한 주제만 다루는가
- [ ] 내용 3개 이상이면 소제목/번호/불릿으로 위계화했는가
- [ ] 중요도 순인가 (시간·사고 순서가 아니라)

**다이어트 패스**
- [ ] 완충어(~인 것 같다, ~하도록)를 1차 삭제했는가
- [ ] 같은 말 반복·중복 설명이 없는가
- [ ] 한 문장이 한 메시지인가 (길면 분리)
- [ ] 과잉 수식어를 줄였는가

**독자 패스**
- [ ] 독자가 모를 용어·약어를 풀었거나 제거했는가
- [ ] 독자가 할 행동·기한·담당이 명확한가
- [ ] 독자 입장에서 "그래서 뭘?"에 즉답되는가
- [ ] 소리 내어 읽어 안 걸리는가

## 4. 독자 분석 표

| 질문 | 답이 글을 어떻게 바꾸나 |
|---|---|
| 독자는 누구인가 (직책·전문성) | 용어 깊이·약어 사용 여부 |
| 독자가 이미 아는 것 | 배경 설명 분량 |
| 독자가 해야 할 행동 | BLUF의 요청 문장 |
| 독자의 시간·관심 | 길이·구조 밀도 |
| 독자의 우려·반론 | 미리 답할 근거 배치 |

## 5. 문서 유형별 BLUF 예

- **승인 요청 메일**: "○○ 승인 부탁드립니다. 이유 3가지와 기한은 아래와 같습니다."
- **장애/지연 보고**: "X가 Y만큼 지연됩니다. 원인·영향·대안 정리했습니다."
- **제안서**: "A안을 제안합니다. B·C 대비 비용/리스크 우위 때문입니다."
- **회고/postmortem**: "근본 원인은 X였습니다. 재발 방지 조치 3가지를 적용했습니다."
- **블로그/기술글**: 첫 문단에 "이 글을 읽으면 무엇을 얻는가". 결론을 끝까지 아끼지 않는다.
