# evidence + 안내 전 체크리스트 — 근거 기반 학습

> 학습 영역엔 긴급 게이트가 없지만, 수치(간격 일수·인출 비중)는 처방이 아니라 개인 망각곡선으로 보정할 출발점이다 — "확인 필요"를 유지한다. 원논문·메타분석 출처는 `sources.md`, 연구 요약은 `evidence.md`.

## 실증·출처

- **인출 연습(retrieval practice) > 반복 읽기**: Roediger & Karpicke (2006, *Psychological Science*) "Test-enhanced learning" — 한 번 읽고 인출한 집단이 1주 뒤 시험에서 반복 읽기 집단을 크게 앞섬. 단, 학습 직후 자신감은 반복 읽기 집단이 더 높음(유창성 착각). 출처: sources.md.
- **간격 효과(spacing)**: Cepeda et al. (2006, *Psychological Bulletin*) 메타분석 — 분산 학습이 집중(몰아치기)보다 장기 보존 우월, 최적 간격은 보유 기간에 비례. 출처: sources.md.
- **교차 연습(interleaving)**: Rohrer & Taylor (2007) — 수학 유형 섞어 풀기가 블록 학습보다 전이·변별 우월(연습 중엔 더 어렵게 느껴짐). 출처: sources.md.
- **바람직한 어려움(desirable difficulties)**: Bjork (1994) — 학습 중 노력·어려움이 장기 보존을 높임. "쉽게 느껴짐"은 학습량의 지표가 아님.
- **학습법 효과성 등급**: Dunlosky et al. (2013, *PSPI*) — 인출 연습·분산 학습은 높은 효용(high utility), 하이라이트·반복 읽기는 낮은 효용(low utility). 출처: sources.md.
- **간격 스케줄·인출 비중 수치**(1·3·7·14일 / 입력:인출 1:2 이상): 연구 기반 **출발점**이며 개인·과목별 망각 속도로 보정 필요(확인 필요). 도구(Anki 등) 알고리즘 파라미터는 부패 빠름 — 도구 문서 확인.

## 안내 전 체크리스트

- [ ] **수치는 출발점 — "확인 필요" 라벨 유지** — 간격 일수·인출 비중은 개인 망각곡선으로 보정(처방으로 단정 금지)
- [ ] **원리 vs 도구 분리** — 인출·간격·교차 원리는 안정, Anki 등 도구 설정은 부패 빠름(도구 문서 확인 표시)
- [ ] 출처 명시 — 권고의 근거 연구(Roediger&Karpicke·Cepeda·Rohrer·Bjork·Dunlosky) 인용 가능 상태
- [ ] 유창성 착각 경고 — "이해됐다·친숙하다" 느낌은 장기 기억 예측 지표가 아님을 안내
- [ ] 막힐 때 분기 — 원리를 버리지 말고 단위·간격·난도를 조정(실패 모드 표)
- [ ] 한계 명시 — 기능·실기(악기·운동)는 물리 연습량이 별도 변수
- [ ] 위임 경계(집중 환경·시간관리→life-productivity·발표→life-speaking·영어 루프→life-english·글쓰기→life-writing)

## 점검 주기

- 인지 원리(인출·간격·교차·유창성 착각): 매우 안정 — 연 1회 이하 점검으로 충분.
- 출처 논문 링크·메타분석: 연 1회 URL·접근성 확인.
- 도구(Anki/SRS) 알고리즘·기능: 부패 빠름 → 도구 사용 안내 시점마다 최신 문서 확인.
