## 1. 핵심 연구·원리

- **인출 연습(testing effect / retrieval practice)** — Roediger & Karpicke, *Psychological Science* 17(3), 2006. 시험·인출 시도가 단순 재학습보다 장기 보존을 크게 높인다. 핵심: 시험은 "측정"만이 아니라 "학습 사건"이다. (5분 후엔 재학습 우위, 2일·1주 지연 시 인출이 역전.)
- **간격 효과(spacing effect)** — Ebbinghaus 이래 가장 견고한 학습 현상 중 하나. 같은 총 학습량이면 분산이 집중보다 장기 보존 우위. Cepeda, Pashler, Vul, Wixted & Rohrer, *Psychological Bulletin* 132(3), 2006 메타분석(184논문·317실험)이 광범위 확인.
- **교차 연습(interleaving)** — Rohrer & Taylor, *Instructional Science* 35, 2007(수학). 블록 연습은 연습 중 수행↑·시험 수행↓, 교차는 반대 — 해당 실험에서 1일 후 점수 약 2배(일반화는 확인 필요). 변별·전이에서 우위.
- **바람직한 어려움(desirable difficulties)** — Robert Bjork (1994, *Metacognition*, MIT Press). 학습을 느리고 어렵게 만드는 조건(인출·간격·교차·변화)이 장기 학습을 돕는다. 단, "바람직한" 범위 안에서 — 학습자가 감당 못 할 난도는 역효과.
- **저효용 vs 고효용 기법** — Dunlosky et al., *Psychological Science in the Public Interest* 14(1), 2013. 다시읽기·하이라이트는 저효용, 인출연습·분산학습은 고효용으로 평가.
- **유창성 착각(fluency illusion) / 메타인지 오류** — 학습자는 처리 유창성(매끄럽게 읽힘)을 학습 정도로 오인한다. 자신감과 실제 성과의 괴리가 핵심 함정.
- **정교화(elaboration) / 생성 효과(generation effect)** — 스스로 답·연결을 만들어낸 정보가 수동적으로 받은 정보보다 잘 기억된다.

## 2. 통념 vs 실증 대조표

| 통념(흔한 공부법) | 실증 결과 | 대체 |
|---|---|---|
| 반복해서 다시 읽기 | 친숙함만↑, 장기 보존 효과 미미 | 백지 인출 후 약점만 재학습 |
| 형광펜·밑줄 | 통제군과 차이 거의 없음 | 자기 말로 재구성·질문화 |
| 몰아치기(벼락치기) | 단기 통과·장기 증발 | 간격 분산(1·3·7·14일) |
| 한 유형 블록 반복 | 연습 수행↑·실전↓ | 유형 교차 |
| 강의 듣고 "이해됨"으로 종료 | 입력 시점 느낌, 인출 미보장 | 직후 자기 시험 |
| 자신감 높음 = 잘 안다 | 자신감-성과 괴리, 역상관 가능 | 인출 정답률로 객관 점검 |

## 3. 기법별 사용법

- **백지 인출(free recall / brain dump)**: 자료 덮고 떠오르는 전부 쓰기 → 빠진 곳 확인 → 그 부분만 재학습. 가장 단순·강력.
- **자기 시험(self-testing)**: 질문→답 형식. 답 보기 전 반드시 먼저 떠올린다(틀려도 됨, 시도가 학습).
- **간격 반복(spaced repetition)**: Anki·Leitner 박스. 잘 외운 카드는 간격↑, 틀린 카드는 간격↓. 핵심은 "잊기 직전 재인출".
- **교차(interleaving)**: 유형 3종 이상일 때 번갈아. 각 문제 전에 "무슨 유형인지" 판단 단계가 들어가는 게 효과의 원천.
- **정교화 질문**: "왜 그런가? 다른 것과 어떻게 다른가? 실제 예는?"으로 스스로 답하기.

## 4. 학습 설계 체크리스트

- [ ] 입력(읽기) 시간을 줄이고 인출(꺼내기) 시간을 늘렸는가 (대략 1:2 이상)
- [ ] 복습을 몰지 않고 간격(1·3·7·14일)으로 분산했는가
- [ ] 유형이 여러 개면 블록이 아니라 섞어서 연습하는가
- [ ] 매 단원 끝·자기 전에 답 안 보고 먼저 떠올리는 자기 시험을 넣었는가
- [ ] "쉽고 매끄럽다"는 느낌을 학습 완료 신호로 쓰고 있지 않은가 (오히려 간격↑ 신호)
- [ ] 도구·정리노트 만들기가 인출을 대체하고 있지 않은가
- [ ] 틀린 것을 실패가 아니라 학습 지점으로 다루는가
