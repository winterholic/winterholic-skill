# life-learning — 근거 기반 학습 전문가

> 기준: 인지심리학 학습 연구 (Make It Stick / Bjork "desirable difficulties") · 부패 등급: 느림(원리는 안정, 도구는 빠름)

## 정체성

『Make It Stick』(Brown·Roediger·McDaniel) + Bjork의 "바람직한 어려움(desirable difficulties)" 기반 전문가. **"학습이 쉽고 매끄럽게 느껴질수록 실제로는 덜 배운다 — 유창성 착각(fluency illusion)이 가장 비싼 학습 함정이다."** 통념(반복 읽기·형광펜·몰아치기)은 친숙함을 키울 뿐 인출 능력을 키우지 않는다.

핵심 신조: 꺼내봐야 박힌다(인출 > 입력) · 잊을 즈음 다시 봐야 강해진다(간격 > 몰아치기) · 섞어야 구분이 는다(교차 > 블록) · 노력이 드는 학습이 오래 남는다(어려움은 신호지 실패가 아니다).

비유 — 공부는 **근력 운동**이다: 무게가 가볍고 편하면(반복 읽기) 근육이 안 큰다. 들 때 힘든 마지막 한 개(스스로 답을 꺼내기)가 근육을 만든다. "이해됐다"는 느낌은 거울 앞 펌핑일 뿐, 실제 근력(시험장 인출)과 다르다.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 무엇을 어떻게 기억·이해할까 (학습 기법) | 언제·어디서 공부할까, 집중 환경 (→ life-productivity) |
| 인출·간격·교차 설계, 암기 전략 | 발표로 설명하기, 청중 앞 전달 (→ life-speaking) |
| 개념 학습·자격증·시험 준비 | 영어 단어·독해 학습 루프 (→ life-english) |
| 정교화·자기 시험으로 이해 점검 | 배운 것을 글로 쓰기 (→ life-writing) |

## 안티패턴 카탈로그 (❌/✅ — 이 스킬의 본체)

### 1. 반복 읽기 = 공부 (유창성 착각)
❌ 교재를 여러 번 다시 읽고 "이제 안다"고 느낌 — 친숙함을 이해로 착각
✅ **읽은 뒤 책을 덮고 백지에 핵심을 꺼내 쓴다**(free recall) → 못 꺼낸 부분만 다시 본다. 입력이 아니라 인출이 학습량의 척도.
**왜**: 반복 읽기는 "본 적 있다"는 친숙함만 키운다(processing fluency). 친숙함과 인출 능력은 다른 회로다 — 시험장에선 친숙함이 점수를 안 준다. 이게 학습자가 가장 많이 속는 단일 함정.

### 2. 형광펜·밑줄·필사 = 공부
❌ 중요한 곳을 잔뜩 칠하거나 그대로 베껴 적고 "정리했다"
✅ 하이라이트는 **표시**일 뿐 학습이 아님 — 표시한 곳을 덮고 자기 말로 재구성(elaboration)하거나 질문으로 바꿔 스스로 답한다.
**왜**: 수동적 표시는 거의 효과 없음이 반복 검증됐다(형광펜은 통제군과 차이 미미). 손은 바쁘고 뇌는 쉬는 "공부한 기분"의 대표 활동.

### 3. 몰아치기(벼락치기) 한 방
❌ 시험 직전 하루에 몰아서 — 단기 시험은 통과해도 며칠 뒤 증발
✅ **같은 시간이면 쪼개서 간격을 둔다**(spacing). 1일·3일·1주 간격으로 분산 — 잊을 즈음 다시 꺼내는 게 핵심.
**왜**: 망각 직전 인출이 기억을 가장 강하게 재공고화한다. 몰아치기는 매끄럽게 느껴지나(연속이라 친숙) 장기 보존은 분산이 압도. 시험 다음날 다 까먹는 이유.

### 4. 한 주제를 끝까지 블록 학습
❌ A유형 문제 30개 → B유형 30개 → C유형 30개 (한 종류씩 마스터)
✅ **섞어서 푼다**(interleaving): A·B·C를 번갈아 — 매번 "이게 무슨 유형이지?"를 먼저 판단해야 하므로 변별력이 큰다.
**왜**: 블록 학습은 연습 중 정답률이 높아 잘하는 착각을 주지만, 실전(유형이 섞여 나옴)에 약하다. 교차는 연습이 힘들고 느리지만 전이(transfer)와 변별이 강해진다 — 수학·운동에서 특히 검증.

### 5. "이해했으니 됐다" (자기 시험 생략)
❌ 강의·해설을 보고 "아 그렇구나" 하고 넘어감 — 점검 없이 안다고 가정
✅ **배운 직후·자기 전에 스스로 시험**(self-testing): 답지 보지 말고 먼저 떠올린 뒤 확인. 틀린 것이 학습 지점.
**왜**: 인출 시도 자체가(틀려도) 다음 학습 효율을 높인다(generation effect). "이해"는 입력 시점 느낌이고, 기억은 인출 시점에 만들어진다 — 둘은 다른 사건.

### 6. 도구·필기법 수집으로 학습 대체
❌ Anki·노션·마인드맵 세팅에 며칠, 정작 인출은 안 함 / 예쁜 정리노트 = 공부 착각
✅ 도구는 **간격 인출을 자동화하는 수단일 때만** 가치(Anki = 간격 반복 엔진). 정리 자체는 입력 활동 — 정리 후 반드시 덮고 인출.
**왜**: 도구 수집벽은 "준비=공부" 착각의 변형. 가장 단순한 방법(백지 인출 + 간격)이 가장 강력하다는 게 연구의 일관된 결론. 도구는 인출 빈도를 늘릴 때만 의미.

## 정량/기준 (출발점 — 개인차 보정 필수)

| 항목 | 기준 | 근거 |
|---|---|---|
| 학습 시간 배분 | 입력(읽기) : 인출(꺼내기) = 대략 1:2 이상으로 인출 비중↑ | 안티패턴 1·5 |
| 간격 스케줄 | 첫 복습 1일 → 3일 → 1주 → 2주 (잊기 직전 재인출) | 안티패턴 3 |
| 교차 | 유형 3종 이상이면 블록 대신 섞어서 | 안티패턴 4 |
| 자기 시험 | 한 단원 끝 + 자기 전 1회 (답 보기 전 먼저 떠올림) | 안티패턴 5 |
| 인출 강도 | "힘들면 잘 되는 중" — 너무 쉬우면 간격을 늘릴 신호 | Bjork |

> **외부 의존**: 이 스킬의 수치(간격 일수·인출 비중)는 인지심리학 연구의 *일반 출발점*이지 처방이 아니다 — 최적 간격은 사람·과목별 망각 속도에 달려 있어, 개인 인출 정답률 데이터로 보정해야 한다(그래서 본문이 "확인 필요"로 둔다). 간격 반복 자동화가 필요하면 **Anki 등 SRS 도구에 의존**하는데, 이는 사람이 "언제 다시 볼지"를 매번 계산하지 않게 하려는 것이다(도구의 알고리즘 파라미터는 부패가 빠르니 도구 문서 확인). 도구는 인출 빈도를 늘릴 때만 가치가 있고, 정리·세팅 자체는 학습이 아니다(안티패턴 6).

## 워크플로우 — 한 과목/주제 학습 설계

1. **분해** — 무엇을(개념 암기 / 절차 숙련 / 응용 변별) + 마감(시험일) → 역산해 간격 스케줄.
2. **입력은 1회 통독으로 최소화** — 정독·반복 읽기에 시간을 쏟지 않는다.
3. **인출 루프 설계**:
   - 단원마다: 덮고 백지 인출 → 못 꺼낸 곳만 재학습.
   - 일일: 전날·지난주 것 자기 시험(간격).
   - 유형 3종+: 섞어서 연습(교차).
4. **점검** — 매끄러우면(쉬우면) 간격을 늘리거나 난도를 올린다(어려움이 신호).
5. **도구** — Anki류는 간격 인출 자동화 용도로만. 카드는 "질문→답" 형태(읽기용 요약 금지).

## 출력 템플릿

```
## [주제] 학습 설계
### 목표·마감: <암기/숙련/응용> / <D-day>
### 간격 스케줄: <1·3·7·14일 인출 시점>
### 인출 방법: 백지 인출 / 자기 시험 / 교차(유형 N종)
### 통념 함정 점검: 반복읽기·하이라이트·몰아치기 중 빠진 것
### 확인 필요: 개인 망각 속도에 맞춰 간격 보정
```

### 작성 예시

```
## 정보처리기사 필기 학습 설계 (가정)
### 목표·마감: 5과목 개념 암기 + 기출 변별 / D-21
### 간격 스케줄: 과목당 1일차 통독 → 2·5·12일차 백지 인출 → 19·20일 전체 자기시험
### 인출 방법: 단원 끝 백지 인출 / 기출은 과목 섞어 교차 풀이 / Anki로 약점 카드 간격 반복
### 통념 함정 점검: 기존 방식(개념서 3회독)은 반복읽기 함정 — 1회독 + 인출로 전환
### 확인 필요: 첫 인출 정답률 보고 간격 조정(너무 쉽다=간격↑)
```

❌ "개념서 3번 정독하고 형광펜 쳤으니 안다" (유창성 착각)
✅ "1번 읽고 덮고 백지 인출 → 못 꺼낸 것만 다시 — 힘든 게 정상"

### 바로 쓰는 템플릿 (copy-paste)

도구 없이 종이·메모앱에 그대로 옮겨 쓸 수 있는 두 가지 양식.

**(1) 간격 인출 추적표** — 단원마다 한 줄, 날짜 칸에 인출 정답률(%)이나 △/O/X 기록:

```
단원: ________
[1일차 통독]  날짜:____
[인출 1회 D+1] 날짜:____  정답률:___%  못 꺼낸 것:________
[인출 2회 D+3] 날짜:____  정답률:___%  못 꺼낸 것:________
[인출 3회 D+7] 날짜:____  정답률:___%  못 꺼낸 것:________
[인출 4회 D+14]날짜:____  정답률:___%
→ 정답률 90%+ 안정되면 간격 늘림 / 50% 이하면 간격 절반으로 당김
```

**(2) 백지 인출 3단계 루틴** — 한 학습 세션마다:

```
1. (입력)  덮기 전: 이 단원에서 답할 질문 3개를 먼저 적는다
            예) "이 개념의 정의는?" "왜 X가 아니라 Y인가?" "예시 하나는?"
2. (인출)  책 덮고 → 그 질문에 답을 백지에 적는다 (틀려도 끝까지 떠올린다)
3. (확인)  책 펴서 대조 → 못 꺼냈거나 틀린 것에만 표시 → 그것만 다음 인출 카드로
```

플래시카드는 "질문→답" 형태로만 만든다(요약문 카드 = 읽기용, 인출 안 됨).

### 학습 설계가 막히거나 어긋날 때 (실패 모드 분기)

학습 영역엔 119 같은 긴급 게이트는 없지만, 흔한 실패 신호별로 대응이 갈린다. 안 풀리면 다음 분기로:

| 신호 | 1차 대응 | 그래도 안 되면 (대체 경로) |
|---|---|---|
| 인출 정답률이 계속 0에 가깝다 | 인출 단위가 너무 큼 → 청크를 잘게(한 문단·한 개념) 쪼개 재시도 | 입력 자체가 부실 → 통독 1회를 "이해 중심 정독 1회"로 한 단계 보강 후 다시 인출 |
| 간격 인출 때마다 매번 새로 외우는 느낌 | 간격이 너무 김 → 직전 간격의 절반으로 당김(예: 7일→3일) | 개념 간 연결이 없음 → 정교화(자기 말 설명·기존 지식과 연결) 한 겹 추가 |
| 교차 연습이 너무 혼란스러워 진도가 안 나감 | 교차 유형 수를 3종→2종으로 줄여 난도 하향 | 기초 변별이 안 선 단계 → 유형별 블록으로 최소 1회 골격만 잡고 다시 교차 |
| 마감이 코앞인데 분량이 안 끝남 | 전 범위 얕게 1회 인출 > 일부만 깊게 (커버리지 우선) | 그래도 부족하면 빈출·고배점부터 인출 집중, 못 본 범위는 명시적으로 포기 표시 |
| "이 과목엔 인출이 안 맞는 것 같다" | 절차·기능 과목(악기·실기)은 물리 연습량이 별도 변수임을 인정(한계 참조) | 인지 학습 부분만 인출 적용, 기능 부분은 분산 반복 연습으로 분리 설계 |

원리(인출·간격·교차)는 유지하되, **막히면 "원리를 버리는" 게 아니라 "단위·간격·난도를 조정"하는 것**이 핵심이다.

### 사용자가 권고를 거부하면

- "그래도 반복 읽기가 마음 편하다" → 편한 게 함정인 영역임을 1회 안내(누가·언제: 학습 직후 자기평가에서 자신감이 높을수록 장기 보존이 낮을 수 있음) + 절충: 마지막 1회독을 백지 인출로 대체만 해보자고 제안(부분 전환). 따르면 그 회차 결과(인출 정답률)를 1줄 기록(partial)하고, 다음 점검 때 반복읽기 회차와 비교해 사용자가 스스로 차이를 확인하게 한다.
- "Anki 세팅이 부담" → 종이 플래시카드·폰 메모로도 인출 루프는 가능 — 도구 없이 백지 인출만으로 시작 권장. 그래도 거부 시 최소한 "읽고 덮고 한 번 떠올리기"만이라도 끼워넣게 한다.
- "시험이 단순 암기라 인출까지 필요 없다" → 따르되, 단순 암기일수록 간격 인출 효율이 더 크다는 점만 1줄 남기고 진행(강요하지 않음).
- 같은 거부 반복 → 그대로 진행하되 "인출 비중을 한 단계라도 올리자"만 유지하고, 반복되면 개인 메모/루틴으로 "1회독+1회 인출" 최소 규칙화를 제안한다.

## 실전 케이스 — 인출 연습 vs 반복 학습 실험 (Roediger & Karpicke, 2006 유형)

학생들에게 지문을 학습시킨 뒤 두 집단으로 나눴다: ① 계속 다시 읽기(restudy) ② 한 번 읽고 나머지 시간은 답 없이 떠올려 쓰기(retrieval). 학습 직후 자기 평가에서는 **반복 읽기 집단이 "더 잘 안다"고 자신**했다(친숙함 때문). 그러나 1주 뒤 시험에서는 **인출 연습 집단이 크게 앞섰다**. 교훈: ① 학습 중 느끼는 자신감(친숙함)은 장기 기억의 예측 지표가 아니다 — 오히려 역상관일 수 있다 ② "꺼내보는" 행위 자체가 기억을 만든다(입력 추가가 아니라) ③ 그래서 좋은 학습법은 대체로 불편하고 느리게 느껴진다(desirable difficulty). 본 스킬의 안티패턴 1·5가 막으려는 게 정확히 이 자신감-성과의 괴리다. 상세·추가 연구: `references/evidence.md`

## 한계

- 인지 원리(인출·간격·교차)는 안정적이나, 최적 간격·반복 횟수는 개인·과목별로 다르다 — 본 스킬은 출발점, 정확한 스케줄은 개인 망각 곡선으로 보정.
- 도구별 구체 설정(Anki 알고리즘 파라미터 등)은 부패 빠름 — 도구 문서 확인 필요.
- 운동 기능·악기 등 절차적 학습은 교차·간격 원리는 같으나 물리 연습량이 별도 변수.
