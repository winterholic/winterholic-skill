# life-car-accident — 실증·체크리스트 (evidence-checklist)

> 정보 제공이며 법률·보험 자문이 아니다. 부상자·대형사고는 절차보다 **119**가 먼저. 과실비율은 사안별이라 단정 금지. 최종 조회: 2026-06.

## 실증·출처

- **정부 자동차손해배상 보장사업(정부보장사업)** — 뺑소니(보유자 불명)·무보험차·도난(무단운전)차·낙하물 사고로 다른 데서 보상받지 못하는 피해자를 정부가 **책임보험 한도 내**에서 보상하는 사회보장제도. 근거: 자동차손해배상보장법 §30. 보상 범위는 **인적 피해(사망·부상·후유장해)만**, 대물 원칙 제외. 출처: 국토교통부 https://www.molit.go.kr/USR/policyData/m_34681/dtl?id=370 · 자동차손해배상보장법(법제처) https://www.law.go.kr (조회 2026-06)
- **운영기관 변경(2023.1.1~)** — 정부보장사업 보상업무를 **자동차손해배상진흥원**이 수행. 경찰청에서 사고접수를 받아 피해자에게 선제 안내도 시행. 출처: 자동차손해배상진흥원 https://tacss.or.kr/majorproject/gep_03.jsp (조회 2026-06)
- **통합 안내콜센터 ☎ 1544-0049** — 전국 단일 대표번호, 무보험·뺑소니 보장사업은 손보협회로, 유자녀 등 지원사업은 교통공단으로 자동 연결. 출처: 자동차손해배상진흥원 https://tacss.or.kr (조회 2026-06)
- **청구기한: 사고발생일로부터 3년 이내** — 최근 3년 내 자비로 낸 치료비도 영수증 제출 시 보상 가능. 청구는 진흥원에 우편 또는 홈페이지. 출처: 손해보험협회 http://www.knia.or.kr/family/m/car/information · 찾기쉬운 생활법령정보 https://easylaw.go.kr (조회 2026-06)
- **과실비율 인정기준** — 손해보험협회가 사고유형별 도표(기본비율 ± 수정요소) 제공·정비. 출처: 손해보험협회 과실비율 정보포털 https://accident.knia.or.kr (조회 2026-06)
- **과실비율 분쟁심의** — 자동차보험 구상금분쟁심의위원회. **상호협정 당사자는 보험사·공제사이며 피보험자(개인)는 직접 신청 불가** — 가입 보험사·공제사를 통해 신청 요청, 진행상황 확인 가능, 신청비용은 보험사 부담. 구상청구액 2천만원 미만은 소심의위 심의. 출처: 손해보험협회 소비자포털 https://consumer.knia.or.kr/m/consumer/insurance-guide/0104.do · https://accident.knia.or.kr/system (조회 2026-06)
- **사고 후 조치 의무** — 즉시 정차 → 사상자 구호 → 인적사항 제공(도로교통법). 미조치 시 처벌·뺑소니(물피 도주 포함) 성립 가능. 인적 피해 사고는 특정범죄가중처벌법(도주차량) 결부 가능. 출처: 도로교통법·특가법(법제처 https://www.law.go.kr) (조회 2026-06)
- **핫라인**: 경찰 신고·뺑소니 ☎ 112 / 응급·구호 ☎ 119 / 정부보장사업 안내 ☎ 1544-0049 / 손해보험상담 손보협회 ☎ 02-3702-8500
- 상세 출처표: `references/sources.md`

## 안내 전 체크리스트

- [ ] **긴급 게이트 먼저** — 부상자·의식없음·출혈·대형사고면 분석 멈추고 **즉시 119**, 함부로 움직이지 말 것. 고속도로면 가드레일 밖 대피. 뺑소니·범죄면 **112**를 안내했는가
- [ ] 2차 사고 방지(비상등·삼각대·안전지대 대피)를 현장 1순위로 안내했는가
- [ ] 면책·시점 라벨 — "정보 제공이며 법률·보험 자문 아님 + 손해사정사·변호사·보험사 상담 권고" 부착
- [ ] **과실비율을 단정하지 않았는가**("무조건 이긴다" 식 금지) — 인정기준 대조·사안별임을 명시
- [ ] 증거 보전(사진 5종·블랙박스 잠금·목격자)을 "현장에서만 가능"으로 강조했는가
- [ ] 분쟁심의는 개인 직접 신청이 아니라 가입 보험사를 통한다는 점을 정확히 안내했는가
- [ ] 정부보장사업은 인적 피해만·대물 제외·청구기한 3년임을 정확히 안내했는가
- [ ] 민감정보(차량번호·연락처·사고장소)는 파일 저장 시 [REDACTED] 마스킹했는가

## 점검 주기

- **핫라인(112·119·보장사업 1544-0049)**: 변경 시 즉시. 정기 확인 연 1회.
- **정부보장사업 대상·운영기관·청구기한**: 법령·운영 변경 가능 — 연 1회+ 국토부·진흥원 확인.
- **과실비율 인정기준 도표**: 손보협회가 수시 신설·개정(회전교차로·자전거도로 등) — 사용 시 포털에서 해당 유형 직접 대조.
- **분쟁심의 금액기준·절차**: 연 1회 손보협회 확인.
- **구체 과실비율·합의금·보장 한도·자기부담**: 사안 의존 — 매번 손해사정사·보험사·진흥원 확인.
- 충돌 시 본문보다 `references/sources.md`(최신 조회)가, 그보다 공식 출처(국토부·진흥원·손보협회·법제처)가 우선.
