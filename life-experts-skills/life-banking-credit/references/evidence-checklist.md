# life-banking-credit — 실증·체크리스트 (evidence-checklist)

> 정보 제공이며 금융상품 권유·자문이 아니다. 금리·DSR·수수료·보호한도는 정책에 따라 자주 변하므로 실사용 시 금감원 1332·파인·은행에서 당해 기준 재확인. 최종 조회: 2026-06.

## 실증·출처

- **예금자보호 한도 1억원 (2025.9.1 시행)** — 기존 5,000만원에서 24년 만에 상향. 은행·저축은행·신협·새마을금고 등 부보금융사에 원리금 합산 1억원까지. 출처: 금융위원회 보도자료(2025) https://www.fsc.go.kr · 예금보험공사 https://www.kdic.or.kr (조회 2026-06)
- **중도상환수수료 약 절반 인하 (2025.1.13 신규계약~)** — 금융소비자보호법상 중도상환수수료는 원칙적으로 부과 금지이며, 예외로 대출일부터 3년 이내 상환 시에만 실비용(자금운용·모집·행정비용) 범위에서 부과 가능. 2025.1.13 시행으로 산정체계 합리화 → 은행권 고정금리 주담대 약 0.56%, 변동금리 신용대출 약 0.11% 수준으로 절반가량 인하(상품·은행별 상이). 출처: 금융위원회(2025.1.13 시행) https://www.fsc.go.kr (조회 2026-06, 구체 요율은 개별 약정·은행 재확인)
- **스트레스 DSR 3단계 (2025.7.1 시행)** — 전 금융권 사실상 모든 가계대출 대상, 스트레스 금리 1.5% 100% 반영(실제 대출금리에는 영향 없음, 한도 산정용). 단 **지방(수도권 외) 주택담보대출은 지방경기 고려해 2026 연말까지 2단계(0.75%) 적용 유예**(2026.6.18 행정지도 연장), 수도권·규제지역은 2025.10.15 대책으로 최소 3% 상향. 출처: 금융위원회 보도자료 https://www.fsc.go.kr/no010101/84617 · 정책브리핑 https://www.korea.kr/multi/visualNewsView.do?newsId=148943522 (조회 2026-06)
- **DSR 규제비율** — 은행권 40%·2금융권 50%(가계대출). 한도 규제이자 상환 안전선. 차주·상품·시기별 예외 있음. 출처: 금융위·금감원 https://www.fsc.go.kr (조회 2026-06)
- **신용점수제** — NICE·KCB 각각 0~1000점, 2021년 신용등급제 폐지→점수제 전환. 산정요소: 상환이력·부채수준·신용거래기간·신용거래형태·비금융정보. 출처: NICE지키미 https://www.niceinfo.co.kr · KCB올크레딧 https://www.allcredit.co.kr (조회 2026-06)
- **금융 민원·상담 핫라인 ☎ 1332 (금융감독원)** — 평일 9~18시, 긴급 금융사기 피해는 24시간 신고. 온라인 접수 fine.fss.or.kr. 2026년부터 2,000만원 이하 소액 분쟁조정은 금융사 수락의무 강화. 출처: 금융감독원 파인 https://fine.fss.or.kr · https://www.fss.or.kr (조회 2026-06)
- **금리 비교공시** — 표면금리+고정/변동+우대+중도상환수수료+한도 묶음 비교. 출처: 금감원 파인 https://fine.fss.or.kr · 은행연합회 https://www.kfb.or.kr (조회 2026-06)

## 안내 전 체크리스트

- [ ] **긴급 신호 게이트 먼저** — 보이스피싱·계좌 탈취 진행 중(방금 송금/앱 설치)이면 분석 멈추고 즉시: 송금 은행 고객센터 **지급정지** → **112** 또는 금감원 **1332** → life-fraud-response로 전환했는가
- [ ] 면책·시점 라벨 부착 — "정보 제공이며 금융상품 권유·자문 아님" + 제도 수치에 "(2026-06 기준, 확인 필요)"
- [ ] 금리·DSR·수수료·보호한도 같은 변동값을 단정하지 않고 파인·1332·은행 재확인 경로를 함께 안내했는가
- [ ] 예금자보호 한도(1억원)는 부보금융사·원리금 합산 기준임을 명시했는가
- [ ] 중도상환수수료는 "3년 이내 상환 시 예외 부과·상품별 상이"임을 단정 없이 안내했는가
- [ ] 스트레스 DSR은 지역(수도권/지방)·규제지역별로 다르게 적용됨을 반영했는가
- [ ] 민감정보(계좌·연봉·대출액)는 파일 저장 시 [REDACTED] 마스킹했는가

## 점검 주기

- **핫라인 번호(금감원 1332)**: 변경 시 즉시. 정기 확인 연 1회.
- **예금자보호 한도·DSR 규제비율·스트레스 DSR 단계·지역 유예**: 정책 변동성 높음 — **분기 1회+** 금융위 보도자료 확인(특히 부동산·가계부채 대책 발표 직후).
- **중도상환수수료율**: 상품별이라 실사용 시 매번 개별 약정 확인. 제도 기준은 연 1회.
- **신용점수 체계·산정요소**: 안정적 — 연 1회.
- 충돌 시 본문보다 `references/sources.md`(최신 조회)가, 그보다 공식 출처(금융위·금감원·예보)가 우선.
