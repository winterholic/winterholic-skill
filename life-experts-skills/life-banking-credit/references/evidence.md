# life-banking-credit 증거·체크리스트

> 금리·수수료율·DSR 규제·예금자보호 한도는 정책·상품별로 변한다. 본 문서는 **판단 관점·함정 패턴** 위주이며 수치는 파인·은행·금감원 1332에서 당해 기준 확인. (2026 기준, 확인 필요)

## 1. 신용점수 등락 요인표

| 방향 | 요인 |
|---|---|
| ▼ 하락 | 연체(하루도 기록 남음)·다중 신규대출·2금융권 고금리 대출·리볼빙/현금서비스 상시 사용·카드 한도 대비 높은 사용률 |
| ▲ 상승 | 연체 없는 성실 상환·통신비/공과금 성실납부 등록(가점)·낮은 카드 사용률·오래된 신용거래 이력 |
| 영향 없음 | 본인 신용조회(조회 자체는 점수에 영향 없음) |

- 점수는 NICE·KCB가 각각 산정(1~1000점 체계). 토스·카카오·뱅크샐러드 등으로 무료 조회.
- 단기 다중 '대출조회'는 일시 하락 요인 → 비교는 짧은 기간에 몰아서.

## 2. 금리 비교 — 단일 숫자가 아니다

비교 시 함께 봐야 할 조건:
- [ ] 표면금리 (광고 숫자)
- [ ] 고정 vs 변동 (변동은 기준금리 상승 시 오름)
- [ ] 우대금리 충족 가능성 (급여이체·카드실적·자동이체 등 — 충족 비용 고려)
- [ ] 중도상환수수료 (잔존기간 비례, 일정기간 후 면제 흔함)
- [ ] 한도
- [ ] 부대비용(인지세·보증료 등)

→ 공시 교차검증: 은행연합회 공시, 금융소비자포털 **파인(fine.fss.or.kr)**.

## 3. 영업 화법 안티패턴

| 화법 | 의도 | 방어 |
|---|---|---|
| "지금 안 하면 손해" / "오늘만" | 비교 차단(시간 압박) | 결정은 비교 후, 즉석 가입 거절 |
| "고객님만 특별히" | 특별감으로 판단 흐림 | 조건을 문서로 받아 객관 비교 |
| "한도 더 나와요" | 대출액 확대 | 한도≠권장액, 상환능력 기준 |
| 보험·카드·리볼빙 연계 권유 | 판매수수료 | 필요와 분리해 별도 판단 |
| "리볼빙 쓰면 편해요" | 고금리 이자수익 | 리볼빙=고금리 분할, 상시 사용 회피 |

- 핵심: 상담사 인센티브(판매수수료)와 내 목표(총비용 최소화)는 다르다.

## 4. 대환(갈아타기) 손익 판단

```
순이득 = (기존 대출 잔여이자 − 새 대출 총이자) − 중도상환수수료 − 신규 부대비용
대환 유리 조건: 순이득 > 0
```

- 중도상환수수료는 보통 잔존기간에 비례해 감소(대출 초기일수록 큼).
- 금리차만 보고 갈아타면 수수료에 역전될 수 있음 — `scripts/loan_calc.py` 시연 참고(수수료 0.5% vs 1.5%에서 유불리 뒤집힘).

## 5. 예적금 특판 함정

- **표시금리 = 최대(우대 다 채웠을 때) 금리**. 기본금리가 실수령의 바닥.
- 우대조건(카드실적·자동이체·앱가입) 충족 비용이 추가 이자보다 크면 손해.
- 확인: 기본금리 / 우대조건 / 예치한도 / 만기 / **중도해지이율**.
- 고금리 특판은 한도·기간이 짧은 경우 多.
- 예금자보호 한도(원리금 합산)는 금융사별 적용 — **2025.9.1부터 1억원**(기존 5,000만원, 24년 만 상향). 한도 초과분은 분산.

## 6. DSR·상환능력

- **DSR**(총부채원리금상환비율) = 연간 원리금상환액 / 연소득. 한도 규제이자 본인 안전선.
- "한도가 나온다" ≠ "갚을 수 있다". 변동금리면 금리 상승 시나리오까지 견디는지.
- 마이너스통장·카드론·카드 할부도 부채로 잡힐 수 있음.
