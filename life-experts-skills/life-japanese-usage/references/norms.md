# life-japanese-usage — 표기 규범 요약

> 판정 시 **근거로 인용할 조항**. 원문·고시번호는 `evidence.md`, 경어는 `keigo.md`.
> 전제: 内閣告示는 "**よりどころ(준거)**"이며 공용문·법령·보도가 주 적용 대상이다. 창작·광고에는 강제되지 않는다.

## 1. 常用漢字表 (2010, 2,136자)

- 「법령·공용문서·신문·잡지·방송 등 일반 사회생활에서 한자를 쓸 때의 준거」.
- 표 밖의 한자는 **かな 표기 또는 대체어**를 쓴다.

| 표 밖 한자 예 | 대체 |
|---|---|
| 綺麗 | きれい |
| 曖昧 → (2010년 추가로 常用) | 曖昧 ○ (2010 추가분) |
| 貼付 → (2010년 추가) | 貼付 ○ |
| 醤油 | しょうゆ (`醤`은 2010 추가로 常用 ○) |
| 挨拶 | 挨拶 ○ (2010 추가분) |
| 蒐集 | 収集 (대체) |
| 綜合 | 総合 (대체) |

> **2010년 개정에서 196자가 추가되고 5자가 삭제**됐다. 개정 전 기억으로 "이 한자는 常用이 아니다"라고 단정하지 않는다 — `曖`·`昧`·`挨`·`拶`·`貼`·`醤` 등이 이때 들어왔다.

### 이 스킬이 자주 쓰는 표 밖 판정
`鬱`(常用 ○, 2010 추가) / `頗る` `尤も` `此処` — 한자 자체는 常用이라도 **かな가 표준인 어휘**가 있다(§3 참조).

## 2. 送り仮名の付け方 (1973) — 本則·許容·例外

3층 구조다. **許容은 "틀리지 않다"는 뜻**이므로 본칙만 정답으로 교정하면 과잉이다.

### 통칙1 — 활용어는 활용어미를 보낸다 (本則)
`書く` `生きる` `荒い` `潔い`

### 통칙2 — 활용어미 앞에 파생 어간이 있으면 그것도 보낸다
`動かす`(←動く) `照らす`(←照る) `勇ましい`(←勇む)

### 주요 本則 / 許容 대조

| 本則 | 許容 | 비고 |
|---|---|---|
| 行う | 行なう | **本則 `行う` 권장** |
| 表す | 表わす | |
| 現れる | 現われる | |
| 断る | 断わる | |
| 賜る | 賜わる | |
| 申し込む | 申込む | 동사 |
| 打ち合わせ | 打合せ / 打合わせ | 명사 |

### 복합명사 — 送り仮名 생략 (관용 정착)
공용문·게시에서 **관용으로 굳은 복합명사는 送り仮名를 생략**한다.

| 명사형(생략) | 동사형(생략 안 함) |
|---|---|
| 申込(書) | 申し込む |
| 受付 | 受け付ける |
| 取扱(説明書) | 取り扱う |
| 引換(券) | 引き換える |
| 締切 | 締め切る |
| 手続 | 手続き(허용) / 手続く ✕ |
| 貸付 | 貸し付ける |

> 판정법: **명사로 굳어 게시·서식에 쓰이면 생략형**, 문장 속 동사면 붙인다. 애매하면 [선호].

## 3. 漢字 / かな 배분 (公用文作成の考え方 2022)

**형식적으로 쓰이는 말은 かな**로 적는다. 같은 글자도 **실질 의미면 한자**다.

### かな로 적는 것

| 분류 | かな (○) | 한자 (✕ 이 용법에선) |
|---|---|---|
| 형식명사 | こと, もの, とき, ところ, ため, わけ, うち | 事, 物, 時, 所, 為, 訳, 内 |
| 보조동사 | 〜ていく, 〜てくる, 〜てみる, 〜ておく, 〜てしまう | 〜て行く, 〜て来る, 〜て見る |
| 보조(경어) | 〜てください, 〜ていただく, 〜てあげる | 〜て下さい, 〜て頂く, 〜て上げる |
| 접속사 | また, したがって, ただし, なお, および, ならびに | 又, 従って, 但し, 尚, 及び(법령은 한자) |
| 부사 일부 | かなり, ふと, やはり, ぜひ | 可成, 不図, 矢張り, 是非 |
| 형식동사 | できる, なる, ある, いる | 出来る, 成る, 有る, 居る |
| 지시어 | この, その, どの, ここ, そこ | 此の, 其の, 此処 |
| 접미 | 〜など, 〜ぐらい, 〜まで | 〜等, 〜位, 〜迄 |

### 한자로 적는 것 (실질 의미)

| かな 용법 | 한자 용법 |
|---|---|
| そのことは… (형식) | 事件が起きた (실질) |
| 見てみる (보조) | 資料を見る (실질) |
| していただく (보조) | 賞をいただく (실질=もらう 겸양) |
| そのとき (형식) | 時間を計る (실질) |

> 실무 판별: **그 글자를 빼도 뜻이 통하면 형식어 → かな**. `資料を見てみる`에서 뒤의 `みる`를 빼도 문장이 성립하므로 かな.

## 4. 現代仮名遣い (1986)

- 원칙: **현대어의 발음에 따라 적되**, 어원·표기 관습을 일부 남긴다.

| 규칙 | 예 |
|---|---|
| `じ/ぢ`, `ず/づ` | 원칙 `じ·ず`. 단 **2어 연접·동음 반복**은 `ぢ·づ` — `はなぢ`(鼻血), `つづく`(続く), `ちぢむ`(縮む) |
| 조사 `は·へ·を` | 발음과 달리 표기 유지 — `わたしは`, `학교へ`, `本を` |
| 장음 `お段` | 원칙 `う` — `おとうさん`, `とうきょう`. 예외 `お`: `おおきい`, `とおる`, `こおり`, `おおい` |
| 장음 `え段` | 원칙 `い` — `せんせい`, `えいが`. 예외 `え`: `ねえさん`, `ええ` |

> `つずく` ✕ / `つづく` ○ — `続く`는 `つ+つく`의 연접이라 `づ`. 이 예외를 놓치는 오류가 잦다.

## 5. 外来語の表記 (1991)

**第1表**(일반적 표기)와 **第2表**(원음·원철에 가깝게 적을 때)로 나뉜다.

| 항목 | 第1表 (일반) | 第2表 (원음 존중) |
|---|---|---|
| v 음 | バ행 — バイオリン | ヴ — ヴァイオリン |
| ti | チ — チーム | ティ — パーティー |
| di | ジ — ラジオ | ディ — ディレクター |
| fa | ハ행 — ファン(第1表 수록) | フュ 등 |

- **장음 부호**: 원칙적으로 `ー`를 쓴다 — `コンピューター`, `サーバー`.
  > 단 **JIS·기술 문서 관행**에서 3음절 이상은 장음을 생략해 왔다(`コンピュータ`, `サーバ`). 마이크로소프트는 2008년 장음 표기로 전환했고, JTCA 『外来語(カタカナ)表記ガイドライン』(제3판 2015)도 장음 표기를 권장한다. **문서가 속한 업계 규정을 우선**하며 이 스킬은 [선호]로만 안내한다.
- 어말 `-er/-or/-ar`: `ー` — `プリンター`, `エレベーター`.
- 촉음: `ベッド`, `バッグ` (`ベット`·`バック`은 별개 어)

## 6. 数字·기호 (公用文作成の考え方)

| 항목 | 기준 |
|---|---|
| 가로쓰기 수치 | 아라비아 숫자 — `10人`, `3月15日` |
| 관용·개념어 | 한자 숫자 — `一般`, `一部`, `四季`, `二人三脚` |
| 큰 수 | `1億2000万` (조 단위마다 한자 병용 가능) |
| 소수·분수 | `0.5`, `2分の1` |
| 백분율 | `50%` 또는 `50パーセント` |
| 구두점 | `。`(마침) `、`(쉼). 가로쓰기에서 `，`를 쓰던 구 관행은 2022년 지침에서 **`、`로 통일** 방향 |

## 7. 읽기점(読点) — 오독 방지 원칙

절대 규칙이 없다. **끊어 읽지 않으면 뜻이 갈리는 자리**에만 필수.

| 위치 | 예 |
|---|---|
| 긴 주어 뒤 | 昨日会議で決まった件について、報告します。 |
| 종속절 뒤 | 雨が降ったので、中止した。 |
| 접속사 뒤 | しかし、結果は違った。 |
| 병렬 | A、B及びC |
| **오독 방지(필수)** | ここで、はきものを脱いでください。 ↔ ここでは、きものを脱いでください。 |

> 과다한 読点은 리듬을 끊는다. 한 문장에 3개를 넘으면 문장 분할을 먼저 검토한다. 대부분 [선호].
