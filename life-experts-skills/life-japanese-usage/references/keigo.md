# life-japanese-usage — 경어 체계 (敬語の指針 5분류 실무판)

> 『敬語の指針』(平成19年 文化審議会 答申) 기준. 출처는 `evidence.md`. **관계를 모르면 이 문서를 써도 판정할 수 없다** — 화자·청자·화제인물 3자 확정이 먼저다.

## 0. 판정 순서 (반드시 이 순서로)

```
① 화제의 행위자는 누구인가?
   ├─ 상대(높일 사람) → 尊敬語
   └─ 자기 쪽 → ② 로
② 그 행위가 향하는 상대가 있는가?
   ├─ 있고 그 상대가 높일 사람 → 謙譲語Ⅰ (伺う·申し上げる)
   └─ 없거나 높일 대상 아님 → 謙譲語Ⅱ (参る·申す)
③ 청자에게 정중히 → 丁寧語 (です·ます) 를 문말에 겹친다
④ 화제가 사물이고 곱게 → 美化語 (お/ご)
⑤ 사외 대상이면 ①의 "상대"에서 사내 인물을 제외한다 (우치소토)
```

## 1. 5분류 대조표

| 분류 | 누구의 행위 | 향하는 상대 | 대표형 |
|---|---|---|---|
| **尊敬語** | 상대·제3자(높일 사람) | — | いらっしゃる, おっしゃる, なさる, 召し上がる, ご覧になる |
| **謙譲語Ⅰ** | 자기 쪽 | **필요** (높일 상대) | 伺う, 申し上げる, 差し上げる, 拝見する, お目にかかる |
| **謙譲語Ⅱ (丁重語)** | 자기 쪽 | 불필요 | 参る, 申す, いたす, おる, 存じる |
| **丁寧語** | — (문말) | 청자 | です, ます, ございます |
| **美化語** | — (사물) | — | お酒, お料理, ご飯, お花 |

### Ⅰ / Ⅱ 를 가르는 실전 예

| 상황 | 맞음 | 틀림 | 이유 |
|---|---|---|---|
| 사장님 댁에 간다 | 사장님 댁に**伺います** | — | 향하는 상대가 높일 사람 → Ⅰ |
| 동생 집에 간다 | 弟の家に**参ります** | ✕ 弟の家に伺います | 동생은 높일 대상 아님 → Ⅱ |
| 사장님께 말한다 | 社長に**申し上げます** | — | 향하는 상대 있음 → Ⅰ |
| (청자에게) 제 이름을 말한다 | 田中と**申します** | — | 향하는 상대 불필요 → Ⅱ |

## 2. 주요 동사 경어 대응표

| 보통어 | 尊敬語 (상대) | 謙譲語 (자기) |
|---|---|---|
| 行く・来る | いらっしゃる / おいでになる | 伺う(Ⅰ) / 参る(Ⅱ) |
| 言う | おっしゃる | 申し上げる(Ⅰ) / 申す(Ⅱ) |
| 見る | ご覧になる | 拝見する(Ⅰ) |
| 聞く | お聞きになる | 伺う(Ⅰ) / 拝聴する(Ⅰ) |
| 食べる・飲む | 召し上がる | いただく(Ⅰ) |
| する | なさる | いたす(Ⅱ) |
| いる | いらっしゃる | おる(Ⅱ) |
| 知る | ご存じだ | 存じる(Ⅱ) / 存じ上げる(Ⅰ, 사람 대상) |
| 会う | お会いになる | お目にかかる(Ⅰ) |
| もらう | — | いただく(Ⅰ) / 頂戴する(Ⅰ) |
| あげる | — | 差し上げる(Ⅰ) |
| くれる | くださる | — |
| 借りる | お借りになる | 拝借する(Ⅰ) |

> `存じる`와 `存じ上げる`: 사물·사실을 알 때는 `存じております`(Ⅱ), **사람을 알 때는 `存じ上げております`**(Ⅰ). 대상이 사람이면 향하는 상대가 생기기 때문이다.

## 3. 二重敬語 판정

### 원칙
하나의 語에 **같은 종류의 경어를 겹치면** 이중경어다.

| ❌ 이중경어 | ✅ | 무엇이 겹쳤나 |
|---|---|---|
| おっしゃられる | おっしゃる | `おっしゃる`(존경) + `られる`(존경) |
| ご覧になられる | ご覧になる | `ご〜になる` + `られる` |
| お召し上がりになる | 召し上がる | `召し上がる` + `お〜になる` |
| お帰りになられる | お帰りになる | `お〜になる` + `られる` |
| 拝見させていただく | 拝見する | `拝見`(겸양) + `させていただく`(겸양) |
| お伺いさせていただく | 伺います | 겸양 3중 |

### 예외 — 관용 정착
『敬語の指針』은 정착한 형태를 인정한다. 대표적으로 논의되는 것:
- `お伺いする` / `お伺いいたします` — 널리 정착
- `お召し上がりください` — 접객에서 정착

> 겹쳤다는 이유만으로 기계적 교정 ❌. 정착 여부가 애매하면 **[선호]로 강등**하고 "간결형이 더 안전하다" 수준으로 안내한다.

### 敬語連結은 이중경어가 아니다
서로 다른 語에 각각 경어를 쓴 것은 허용된다.
- `お読みになっていらっしゃる` — `お読みになる` + `いらっしゃる` (별개 語) ○
- `召し上がっていらっしゃる` ○

## 4. 우치소토(内外) — 방향 전환

**같은 인물이라도 청자가 누구냐에 따라 높임 방향이 뒤집힌다.**

| 상황 | 표현 | 비고 |
|---|---|---|
| 사내에서 부장을 언급 | 部長は**いらっしゃいます** | 부장 = 소토(높임) |
| 거래처 전화에 부장을 언급 | 田中は**おります** | 부장 = 우치(낮춤), 직함·경칭 제거 |
| 사내에서 사장 지시 전달 | 社長が**おっしゃいました** | |
| 거래처에 사장 지시 전달 | 弊社の田中が**申しております** | |

**경계 판정**: 자기 회사·자기 부서·자기 가족 = 우치. 거래처·손님·타사 = 소토.

> 한국어 화자가 가장 자주 실패하는 지점이다. 한국어는 "사장님께서 말씀하셨습니다"를 거래처에도 그대로 쓰지만, 일본어는 결례가 된다. **이 판정은 관계 정보 없이는 불가능하므로, 관계가 불명이면 [확인]으로 남기고 교정하지 않는다.**

## 5. バイト敬語 (매뉴얼 경어) — [선호] 등급

| ❌ | ✅ | 문제 |
|---|---|---|
| 1,000円**になります** | 1,000円**です** | `なる`=변화. 값은 변하지 않음 |
| コーヒー**のほう**お持ちしました | コーヒーをお持ちしました | `〜のほう`=방향·완곡의 오용 |
| **よろしかったでしょうか** | よろしいでしょうか | 현재 확인에 과거형 |
| 1万円**から**お預かりします | 1万円をお預かりします | `から`의 근거 불명 |
| ご注文**の方**は以上で | ご注文は以上で | 위와 같음 |
| お名前を**頂戴**できますか | お名前を伺えますか | 이름은 받는 물건이 아님 |

> **등급 주의**: 전부 [선호]다. 고시 위반이 아니고 실제로 통용된다. "틀렸다"가 아니라 **"정확하지 않아 격식 있는 자리에서는 피하는 편"**으로 안내한다.

## 6. ビジネスメール 정형구

| 장면 | 표현 |
|---|---|
| 첫 인사(사외) | いつもお世話になっております。 |
| 첫 연락 | 初めてご連絡いたします。〜の田中と申します。 |
| 사내 | お疲れさまです。 (`ご苦労さま`는 윗사람→아랫사람) |
| 의뢰 | 〜していただけますでしょうか。 / ご検討いただけますと幸いです。 |
| 확인 | ご確認のほどよろしくお願いいたします。 |
| 사과 | 大変申し訳ございません。 (`すみません`은 격식 부족) |
| 감사 | 誠にありがとうございます。 |
| 거절 | 誠に恐縮ですが、今回は見送らせていただきます。 |
| 재촉 | 恐れ入りますが、進捗をお知らせいただけますでしょうか。 |
| 맺음 | 何卒よろしくお願い申し上げます。 |

> `ご苦労さま` ↔ `お疲れさま`: 전자는 윗사람이 아랫사람에게 쓰는 말이라 **상사에게 쓰면 결례**. 후자가 안전하다.
> `了解しました` ↔ `承知しました`: 사외·상사에게는 `承知しました` / `かしこまりました`가 안전하다. (`了解`가 실례라는 근거는 명문 규범이 아니라 비즈니스 매너 관행 — [선호] 등급으로 안내)

## 7. 흔한 오용 — 한국어 화자 특유

| ❌ | ✅ | 원인 |
|---|---|---|
| 社長様 | 社長 / 田中社長 | 직함이 이미 경칭. `様` 중복 |
| 各位様 | 各位 | `各位`가 이미 경칭 |
| お客様各位 | お客様 / 各位 | 위와 같음 (단 관용 인정 견해 있음 → [선호]) |
| 私が申されました | 私が申しました | 자기 행위에 존경 `られる` |
| 先生が拝見しました | 先生がご覧になりました | 상대 행위에 겸양 |
| ご注意してください | ご注意ください | `ご〜する`는 겸양형 |
| お待ちしてください | お待ちください | 위와 같음 |
| 部長は席にいらっしゃいません(대외) | 田中は席におりません | 우치소토 미전환 |

> `ご注意してください`가 틀린 이유: `ご〜する`는 **겸양** 형식이라 상대에게 요구할 수 없다. 존경 요구형은 `ご〜ください`.
