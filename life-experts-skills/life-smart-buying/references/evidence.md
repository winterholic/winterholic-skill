# life-smart-buying — 근거·스펙 해독표

> 모델·시세·효율 등급은 모두 "확인 필요"(제조사 스펙시트·소비자원 비교정보·가격비교 시세 기준). 스킬은 해독 절차·함정 위주.

## 목차
1. 품목별 핵심 스펙(수치로 봐야 할 것)
2. 마케팅 용어 → 수치 환원
3. 출시 주기·할인 시즌 메모
4. 신품 vs 중고 판단표
5. TCO·설치 체크리스트

---

## 1. 품목별 핵심 스펙

| 품목 | 마케팅보다 봐야 할 수치 |
|---|---|
| TV | 패널 종류 · 실측 밝기(nit) · 주사율(Hz) · 시청거리 대비 인치 |
| 냉장고 | 실용량(L) · 에너지효율 등급(연간 kWh) · 소음(dB) · 배치 폭 |
| 세탁기 | kg · 인버터 여부(소음·전기료) · 효율 등급 |
| 에어컨 | 냉방능력(평형) · 효율 등급(연간 전기료 직결) · 설치 환경 |
| 청소기 | 흡입력 · 배터리 지속·교체비 · 필터 소모품 주기 |
| 노트북 | CPU 세대 · 램 · 저장장치 · 디스플레이(해상도·밝기) · 무게 |
| 스마트폰 | 칩셋 세대 · 배터리 · 디스플레이 · 업데이트 지원 기간 |

## 2. 마케팅 용어 → 수치 환원

- "프리미엄/플래그십" → 그래서 패널·CPU·용량 수치가 뭔가?
- "초절전/에너지 세이빙" → 에너지효율 등급(1~5등급, 1등급이 5등급 대비 약 30~40% 절감)·연간 kWh는? (한국에너지공단, 2026-06)
- "AI/스마트" → 실사용에 영향 주는 구체 기능인가, 수식어인가?
- "4K/HDR/초고화질" → 실측 밝기(nit)·HDR 규격은? (이름만 HDR 다수)
- "대용량/슬림" → 실용량(L)·실측 치수는?
규칙: 모르는 수식어는 비교 불가 — 같은 항목의 수치로 환원해야 모델 비교 성립.

## 3. 출시 주기·할인 시즌 메모

- 제조사는 신형 출시에 맞춰 직전 모델을 떨이로 민다 → 최신 기능 불필요 시 "직전 모델 떨이"가 가성비 구간.
- 신형 초기: 프리미엄·물량 부족·초기 결함 리스크.
- 대형 할인 시즌·신학기·이사철에 품목별로 값이 빠짐(품목별로 적기 다름, 확인 필요).
- "오늘만 특가"는 가격 그래프로 검증 — 평소가/직전 인상 후 인하가 흔함.

## 4. 신품 vs 중고 판단표

| 따질 것 | 신품 유리 | 중고 고려 |
|---|---|---|
| 핵심 가전(냉장고·세탁기·에어컨) | 수명·전기료 길게 작용, 신품 떨이 | 단기·임시 거주 |
| 소형·취미 기기 | — | 감가 큰 품목, 보증 잔여 확인 |
| 소모품 의존(필터·배터리) | 새 소모품 | 교체비 빼고 계산 |
판단 공식: 신품 최저가 대비 할인폭이 (보증 상실 + 잔여 수명 + 교체 부품)을 정당화하는가? 거래 사기 방어는 → life-fraud-response.

## 5. TCO·설치 체크리스트

- [ ] 본체값 + 연간 전기료(효율 등급 라벨의 연간 kWh) + 소모품 주기·비용 + 설치비 + 기존 가전 폐기·수거 비용.
- [ ] **KC 인증 마크** 확인(전기용품 강제 안전인증 — 미인증 제품 경계, 국가기술표준원).
- [ ] 실측: 문폭·배치 공간·콘센트/배수/전용회로 위치.
- [ ] 배송/설치 일정·반품 조건.
