## 1. 위약금 2종 분리 구조

| 종류 | 정체 | 위약금인가? | 계산 |
|---|---|---|---|
| 약정 할인반환금 | 약정으로 받은 요금 할인을 중도해지 시 일부 환수 | 예 (진짜 추가 손실) | 경과기간 구간별 환수율 — 통신사마다 다름 |
| 단말 잔여 할부원금 | 미납 기기값 | 아니오 (어차피 낼 돈) | 잔여 개월 × 월 할부금 |

오해 패턴: "해지하면 위약금 ○○만원" → 그중 대부분이 단말 할부원금인 경우가 많다. `scripts/penalty_calc.py`로 분리. 환수율 산식은 통신사·약정 종류(공시지원 위약 vs 선택약정 반환금)별로 다르므로 정확액은 통신사 고지 확인.

## 2. 결합할인 락인 메커니즘

- 인터넷+TV+모바일+가족 결합 → 할인 누적, 동시에 약정(통상 3년) 누적.
- 한 회선 이탈/해지 → 결합 할인 전체 재산정 + 위약금 → "한 명 때문에 가족 전체 손해" 구조.
- 더 싼 대안(알뜰폰) 등장해도 결합 위약금이 전환을 막음 = 락인.

판단식: **순이득 = 할인 누계 − (예상 위약금 + 갈아탈 자유의 기대가치)**. 가족 구성·이사·이동 가능성이 크면 결합 신중.

## 3. 공시지원금 vs 선택약정 비교 틀

| | 공시지원금 | 선택약정(25%) |
|---|---|---|
| 할인 대상 | 단말기 출고가 | 매월 통신요금 |
| 유리한 경우 | 지원금 큰 단말·저가요금제 | 고가요금제·자급제·지원금 적은 단말 |
| 조합 | 보통 약정 동반 | 자급제폰+알뜰폰+선택약정이 종종 최저 |

비교법: **24개월 총비용(단말값 + 요금×24 − 할인)**으로 두 안을 나란히. 대리점 권유는 마진 기준이므로 본인이 총액 계산. 스마트초이스 비교 도구 활용.

## 4. 알뜰폰 프로모션 함정

- **0원/초저가 요금제**: ○개월 한정 → 종료 후 정상가 자동 전환. 종료가·종료일 미확인이 핵심 함정.
- **품질 오해**: 통신 3사 망 임대라 커버리지·속도는 모망과 동일. 차이는 고객센터·멤버십·부가서비스·가격 안정성.
- **체크포인트**: 종료 후 요금 / eSIM·본인인증·소액결제·해외로밍 지원 / 고객지원 채널 / 데이터 소진 후 QoS 속도.

방어: 가입 전 "프로모션 종료 후 월 요금" 확정 + 종료일 캘린더 기록.

## 5. 부가서비스·소액결제 누수 카탈로그

| 누수원 | 패턴 | 대응 |
|---|---|---|
| 끼워팔린 부가서비스 | "한 달 무료" 후 자동 과금 | 분기 1회 "이용 중 부가서비스" 점검·해지 |
| 콘텐츠 자동결제 | 음악·OTT·웹툰 묶음 | 안 쓰면 해지 |
| 휴대폰 보험 | 중복·과보장 | 실사용·자기부담금 따져 유지 여부 |
| 소액결제 한도 | 방치 | 필요 최소로 축소(스미싱 피해 한도 겸 축소) |
| 멤버십 유료전환 | 무료→유료 자동 | 갱신 알림 끄기 전 확인 |

원칙: 건당 작아 안 보이지만 연 단위로 쌓인다. "무료 체험"은 해지 안 하면 영구 과금이 기본 설계.
