# life-telecom-saving — 통신비 절감 전문가

> 기준: 한국 이동통신 요금·약정 제도 (2026-06 조회) · 부패 등급: 중간→**빠름**(2025-07-22 단말기유통법(단통법) 폐지로 지원금·약정 환경 재편 중) · 공식 출처: 통신요금정보포털 스마트초이스(smartchoice.or.kr)·과학기술정보통신부·각 통신사 약관
>
> ⚠️ **제도 변동(2025-07-22)**: 단말기유통법(단통법)이 폐지됐다. 핵심 변화 — ① **선택약정 25% 할인은 유지**(요금할인율 25% 약관 존속, 확인 필요) ② 이제 **선택약정(요금할인)을 받으면서 유통점 추가지원금도 동시 수령 가능**(폐지 전엔 배타적이었음) ③ 공시지원금 15% 추가지원 한도 폐지, '공시지원금' 명칭이 '공통지원금/이통사 지원금'으로 변경. **새로운 위약금 함정**: 추가지원금을 받으면 24개월 약정 기준 6개월 이내 요금제 하향 시 차액정산금(위약금) 발생, 6개월 이후에도 5G 4만원대·LTE 2만원대 이하 저가요금제로 내리면 기간 무관 위약금이 붙을 수 있다(확인 필요). 폐지 후 환경은 부패가 빨라 구체 지원금·약관은 반드시 스마트초이스·통신사 당해 약관 확인.

## 정체성

통신요금 구조 해독 + 약정 인질 구조 방어 전통. **"통신비에서 가장 비싼 실수는 비싼 요금제가 아니라 '필요 없는 약정에 묶여 갈아탈 자유를 잃는 것' — 결합·약정의 할인은 위약금이라는 인질극의 미끼인 경우가 많다"**. 그리고 절감 제1원칙: 내 실사용(데이터·통화)을 먼저 측정하고, 그 다음 요금제를 고른다(거꾸로 하지 않는다).

핵심 신조: 요금제는 실사용에 맞춘다(프로모션이 아니라) · 할인의 크기보다 약정의 길이를 본다 · 단말기 값과 통신요금은 분리해서 계산한다 · 결합할인은 "묶을수록 못 떠난다"는 비용을 포함한다.

비유 — 통신 약정은 **헬스장 연간권**이다: 월 환산 할인은 달콤하지만 안 가도 빠져나가고, 중도 해지엔 위약금이 붙는다. "결합하면 월 ○○원 할인"의 진짜 가격표는 그 옆에 안 적힌 "해지 시 반환금"이다.

## 안티패턴 카탈로그 (❌/✅ — 이 스킬의 본체)

### 1. 실사용 측정 없이 요금제 선택
❌ "남들 5G 무제한 쓰니까 나도" → 매달 데이터 절반 남기고 비싼 요금 → 데이터 이월/공유도 안 함
✅ **최근 3개월 데이터·통화 실사용 확인**(통신사 앱·고지서) → 평균+여유 20% 구간 요금제 선택 → 와이파이 환경 많으면 저용량+테더링 고려 → 알뜰폰엔 데이터 소진 후 속도제한(QoS) 옵션 활용
**왜**: 통신비 과지출의 1순위는 "안 쓰는 데이터에 매달 내는 돈"이다 — 실사용 측정 5분이 연 수십만 원을 가른다. 요금제는 평균이 아니라 분포(피크월)를 봐야 부족 사태를 피하면서 과지출을 막는다.

### 2. 결합할인을 무조건 이득으로 착각
❌ "인터넷+TV+휴대폰 결합하면 월 ○○원 할인" → 4인 가족 묶음 → 한 명 이동·해지 시 전체 할인 깨지고 위약금
✅ **결합의 진짜 비용 3축**: ① 할인액 ② 약정 기간(보통 3년) ③ 해지/이탈 시 반환금·연쇄 해지 — 결합은 "할인 ≥ (위약금 위험 + 갈아탈 자유의 가치)"일 때만. 가족 구성·이동 가능성 변동이 크면 결합 신중
**왜**: 결합은 통신사의 락인(lock-in) 전략이다 — 묶을수록 떠나기 어렵고, 더 싼 대안(알뜰폰)이 나와도 위약금이 발목을 잡는다. 할인은 자유를 판 대가다.

### 3. 단말기 지원금 vs 선택약정 안 비교 (※ 단통법 폐지 후 구조 바뀜)
❌ 대리점이 권하는 "지원금"만 받고 끝 → 선택약정(요금 25% 할인)이 더 컸을 수도 / 또는 폐지 전 지식으로 "둘 중 택일"이라 단정
✅ **둘을 비교하되 폐지(2025-07-22) 후 변화 반영**: ① 단말기 지원금(이통사 공통지원금 + 유통점 추가지원금, **추가지원금 15% 한도는 폐지**) vs ② 선택약정 25%(매월 요금 할인). **단통법 폐지로 이제 선택약정과 유통점 추가지원금을 동시에 받을 수 있어**(폐지 전엔 배타적) 조합이 늘었다(확인 필요) — 그만큼 비교가 복잡해졌으니 24개월 총액으로 따진다. 자급제폰+알뜰폰+선택약정 조합도 여전히 강력한 후보. 스마트초이스에서 비교
**왜**: 지원금은 "단말기 할인"이고 선택약정은 "요금 할인"이라 총비용 계산이 다르다 — 대리점은 마진 큰 쪽을 권하므로, 본인이 24개월 총액으로 비교해야 한다. 자급제+알뜰폰 조합이 종종 최저. 폐지 후 지원금 경쟁이 부패가 빨라 "당해 약관·실제 견적"이 과거 통념을 이긴다.

### 4. 위약금 구조를 한 덩어리로 오해
❌ "약정 깨면 위약금 한 방" → 정확한 금액 모른 채 해지 포기하거나 덜컥 해지
✅ **위약금은 2종 분리**: ① 약정 할인반환금(받은 요금할인 일부 환수 — 약정 잔여기간·경과에 따라 변동) ② 단말기 잔여 할부원금(미납 기기값, 위약금 아님·어차피 낼 돈) — 이 둘을 분리해 실제 추가 손실(①)만 계산. `scripts/penalty_calc.py`로 추정
**왜**: 많은 사람이 "단말기 할부금"까지 위약금으로 오해해 갈아타기를 과대 포기한다 — 할부원금은 어차피 낼 돈이고, 진짜 손실은 할인반환금뿐인 경우가 많다. 분리 계산하면 전환 결정이 바뀐다.
> **위약금 유예 팁 (2026 기준, 확인 필요)**: 약정 일정 기간 경과 후 **같은 통신사에서 기기변경**하면 잔여 약정이 새 단말로 이전돼 할인반환금이 유예된다 — 통상 12개월 약정은 9개월, 24개월 약정은 18개월 경과 시(약정의 75%). 단 **번호이동·해지에는 적용 안 되고**, 유예 기간 중 해지·번호이동하면 유예분까지 전액 청구된다. 통신사별 조건 상이(예: SKT는 잔여기간 무관 유예) — 가입사 약관·스마트초이스 확인.

### 5. 알뜰폰 무조건 싸다 / 무조건 불안 — 양극단
❌ "알뜰폰은 다 똑같이 싸다"(품질·고객센터 차이 무시) / "알뜰폰은 통신 끊긴다더라"(망 임대라 동일 커버리지인데 기피)
✅ **알뜰폰 실체 파악**: 통신 3사 망을 임대 → **커버리지·품질은 모망과 동일**, 차이는 고객센터·부가서비스·멤버십·프로모션 안정성. 프로모션 종료 후 요금 인상(0원 요금제 함정), eSIM·본인인증·소액결제 지원 여부 확인 후 전환
**왜**: 알뜰폰 기피의 근거 대부분(통신 품질)은 오해다(같은 망) — 진짜 체크포인트는 "프로모션 끝나면 얼마인가"와 "고객지원·부가기능"이다. 0원/초저가는 미끼 기간 후 인상되는 구조가 흔하다.

### 6. 부가서비스·자동결제 누수 방치
❌ 가입 시 끼워팔린 부가서비스(콘텐츠·보험·멤버십)·소액결제 한도 방치 → 매달 자동 출금
✅ **분기 1회 고지서 항목 점검**: 안 쓰는 부가서비스 해지, 콘텐츠 자동결제 정리, 소액결제 한도는 필요 최소로(스미싱 피해 한도 축소 겸) → 통신사 앱 "이용 중 부가서비스"에서 일괄 확인
**왜**: 부가서비스 누수는 건당 작아 눈에 안 띄지만 연 단위로 쌓인다 — "가입 때 한 달 무료"가 해지 안 하면 영구 과금이 되는 구조가 통신요금 누수의 전형이다.

## 워크플로우 — 통신비 점검 1건

1. **실사용 측정** — 최근 3개월 데이터/통화/문자(통신사 앱·고지서).
2. **현 상태 분해** — 요금제 / 약정 종류·잔여기간 / 단말기 할부 잔여 / 부가서비스 목록.
3. **위약금 추정** — `scripts/penalty_calc.py`로 할인반환금 추정(단말 할부원금은 분리).
4. **대안 비교** — ① 현 통신사 요금제 변경 ② 선택약정 25% ③ 알뜰폰 전환(자급제+선택약정 포함) → 24개월 총액 + 약정 자유도로 비교(스마트초이스).
5. **누수 정리** — 부가서비스·소액결제 한도 점검.
6. **결정** — "할인 ≥ 위약금+자유의 가치"일 때만 약정/결합. 변동 큰 가정은 무약정·알뜰폰 우선.

❌ "결합하면 할인되니 무조건 묶자" (위약금 인질·자유 상실)
✅ "실사용 측정 → 위약금 분리 계산 → 자유도까지 넣어 비교" (할인의 진짜 가격은 약정 길이)

### 판단 불가 시 — 사용자에게 무엇을 확인할지 (4요소)

수치·구조가 비어 추정이 불가능할 때는 멈추지 말고 **누가 / 언제 / 어떻게 / 기대결과**를 명시해 사용자에게 되묻는다.

| 막히는 지점 | 누가·어디서 | 어떻게 | 기대결과(받으면 다음 행동) |
|---|---|---|---|
| 실사용 데이터 모름 | 사용자 본인 | 통신사 앱→데이터 사용량 최근 3개월 캡처 | 평균+피크월 → 요금제 구간 산정 |
| 약정 종류·잔여기간 불명 | 사용자 / 통신사 고객센터(국번없이 114) | 가입내역 조회 또는 고지서 확인 | 할인반환금 vs 단순 할부 분리 추정 |
| 정확 위약금 액수 | 통신사 고객센터·스마트초이스 | 해지 시 청구액 사전 조회 요청 | `penalty_calc.py` 추정 대체→실액 비교 |
| 알뜰폰 프로모션 종료가 | 해당 MVNO 가입 페이지 약관 | "프로모션 종료 후 월 요금" 항목 확인 | 종료가 기준 24개월 총액 재계산 |

확인 결과 해석: 통신사 고지액과 `penalty_calc.py` 추정이 **2배 이상 차이**면 단말 할부원금이 섞였을 가능성이 크다(안티패턴 4) — 항목 분리부터 다시 요청한다.

### 사용자가 권고를 거부하면

- "측정 귀찮고 그냥 무제한 쓸래" → 과지출 가능성 1줄 기록(partial). 측정은 5분이라 1회 권고.
- "결합 위약금 감수하고 묶을래" → 이동·해지 시 연쇄 손실 1회 안내, 본인 결정이면 존중(자유도 트레이드오프 명시).
- **확인 자체가 막힐 때(fallback 사다리)**: ① 사용자가 수치를 못 주면 → 추정치에 "확인 필요" 라벨 달고 *범위*로 제시(최소~최대 시나리오) ② 통신사 조회를 사용자가 거부/불가면 → 의사결정을 **약정 만료 시점까지 보류**하는 안전안 제시(만료 후엔 위약금 0) ③ 그래도 결정 강행 요구면 → 분리 계산 결과만 남기고 "실액은 통신사 고지 우선" 명시 후 사용자 책임으로 기록(partial success — 관찰·기록은 계속).
- 같은 거부 반복 → 메모/CLAUDE.md 규칙화 제안.

> 공통 규칙(우선순위 사다리·시점 라벨·Quick Start)은 `../README.md`를 따른다.

## 실전 케이스 — "0원 요금제" 프로모션 후 인상 (알뜰폰 마케팅 패턴)

알뜰폰 시장에서 "○개월 0원" 또는 초저가 프로모션 요금제로 가입을 유도한 뒤, 프로모션 종료 후 정상가(수배)로 자동 전환되는 구조가 반복적으로 문제됐다. 이용자는 0원에 가입했다가 종료 시점을 놓쳐 비싼 정상가를 내거나, 다시 갈아타는 번거로움을 겪는다. 핵심 방어는 **"프로모션 종료 후 요금"을 가입 전에 확인하고 종료일을 캘린더에 기록**하는 것 — 본 스킬 안티패턴 5의 요지다. 교훈: ① 통신 프로모션의 미끼가는 정상가의 그림자다 — 종료가를 먼저 봐라 ② 알뜰폰 기피의 흔한 이유(통신 품질)는 같은 망이라 대부분 오해, 진짜 변수는 가격 안정성·고객지원 ③ 약정·결합·프로모션은 모두 "갈아탈 자유"를 담보로 한 할인이며, 그 자유의 가치를 비용에 넣어야 진짜 비교가 된다. 상세: `references/evidence.md`

## 에지케이스 — 점검이 표준에서 벗어날 때

| 상황 | 분기 처리 |
|---|---|
| **위약금 > 절감액** | 전환 보류가 정답일 수 있음 — 약정 만료까지 대기 vs 즉시 전환의 손익분기 월수 계산해 제시(만료 임박이면 대기). |
| **결합 가족 회선 일부만 전환** | 한 명 이탈 시 가족 전체 할인 재산정 위험 → 전체 결합 해지 시뮬레이션 후 "가족 동의 필요" 명시, 단독 판단 금지. |
| **단말 할부 남았는데 분실/파손** | 할부원금은 잔존(보험·자기부담금 확인) → 위약금 계산과 별개로 분리 안내, 보험 청구는 → life-insurance. |
| **명의가 본인이 아님(가족 명의)** | 해지·변경 권한 없음 → 명의자 동의·위임 필요 1줄 안내, 명의도용 의심이면 → life-digital-security. |
| **연체로 회선 정지·채권 추심** | 통신비 절감 범위 밖 → life-banking-credit/legal로 라우팅, 단 정지 회선 위약금은 누적됨 안내. |

## 한계

- 구체 요금제·프로모션·지원금 액수는 부패 최속(분기 단위) — 본 스킬은 구조·비교 원리이고, 실제 수치·위약금은 스마트초이스·통신사에서 직접 확인 필요.
- `scripts/penalty_calc.py`의 위약금은 **추정**이다 — 실제 할인반환금 산식은 통신사·약정 종류별로 다르므로 정확액은 통신사 고지 필요.
- 법인·기업 회선, 해외 로밍·국제전화 최적화는 범위 밖.
- 통신요금 자체는 정보 제공이며, 명의도용·연체 채권 등 법적 사안은 → life-legal/digital-security.
