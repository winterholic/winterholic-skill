# life-welfare-subsidy 증거·체크리스트

> ⚠️ 지원금은 부패가 가장 빠른 정보다. 본 문서는 **사업 '유형'과 발굴 절차·함정** 위주이며, 구체 금액·소득기준·신청기간은 적지 않는다 — 반드시 당해연도 공식 사이트에서 확인. (2026 기준, 확인 필요)

## 1. '몰라서 못 받는 돈' — 카테고리별 발굴 체크리스트

탐색은 "유형"으로 하고, 당해 공고에서 요건·금액 확인.

### 청년 (온통청년 youthcenter.go.kr)
- [ ] 청년 자산형성(청년도약계좌류) — 연령·소득·가구 요건, 정부 기여
- [ ] 청년 월세지원 — 소득·거주요건, 지자체별 상이
- [ ] 청년 취업·내일채움류 — 고용 연계
- [ ] 지자체 청년수당·면접수당 — 지역별

### 근로·자녀 (국세청 홈택스)
- [ ] 근로장려금(EITC) — 소득·재산 요건, 정기(5월)/반기 신청
- [ ] 자녀장려금 — 자녀 양육 가구

### 고용 (고용24)
- [ ] 실업급여(구직급여) — 고용보험 기여기간·이직사유 요건
- [ ] 국민취업지원제도 — 구직자 소득지원+취업지원
- [ ] 직업훈련(내일배움카드)

### 교육 (한국장학재단)
- [ ] 국가장학금 — 소득분위(학자금지원구간)
- [ ] 학자금 대출(취업 후 상환 등)

### 주거·생활 (복지로·정부24·지자체)
- [ ] 에너지바우처·문화누리카드 등 바우처류
- [ ] 긴급복지지원(위기상황)
- [ ] 기초생활보장(생계·의료·주거·교육급여)

## 2. 신청주의 — 핵심 원칙

- **자격 ≠ 수급**: 거의 모든 지원은 본인이 신청해야 발생.
- 자동지급 항목은 일부뿐 — 대부분 신청 전제.
- 복지로 **복지멤버십(맞춤형 급여 안내)** 가입 시 받을 수 있는 서비스를 알림받을 수 있음(자동 수급 아님, 안내).

## 3. 함정 패턴

| 함정 | 내용 | 방어 |
|---|---|---|
| 미신청 | 자격 있는데 몰라서/안 해서 미수급 | 복지로 모의계산·맞춤검색 능동 발굴 |
| 작년 정보 | 폐지·변경된 사업을 옛 후기로 신청 | 당해 공고문만 신뢰 |
| 한 번 탈락 포기 | 한 사업 소득컷 걸려 전체 포기 | 사업별 기준 독립 — 재탐색 |
| 예산 소진 | 기간 남아도 예산 동나 조기마감 | 선착순형 즉시 신청 |
| 중복 추측 | 중복 가능/불가를 추측 | 공고 '중복수급' 항목 확인 |
| 부정수급 | 요건 위장으로 수급 | 환수+제재 — 정확한 요건만 |

## 4. 소득 기준의 종류 (서로 다름)

- **기준 중위소득 %**: 보건복지부 매년 고시 — 많은 복지사업의 기준선.
- **소득분위(학자금지원구간)**: 장학금 기준.
- **장려금 소득·재산 요건**: 국세청 별도 기준.
- **청년 사업 소득기준**: 사업별 상이.
→ 한 기준에 걸려도 다른 사업은 별개. "다 안 되겠지"는 일반화 오류.

## 6. 부정수급 주의

- 사후 소득·재산·가구 연계 검증 실시.
- 적발 시 **부정수급액 환수 + 제재(지급제한·가산금)**.
- 위장전입·소득 누락·허위서류는 명백한 부정수급.
- 애매하면 신청 전 관할기관(주민센터·고용센터·복지로 상담) 확인.
