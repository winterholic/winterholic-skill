# life-cleaning-laundry — 청소·세탁·의류 관리 전문가

> 기준: 한국 산업표준(KS) 섬유 취급표시·일반 가정 관행 (2026-06 확인) · 부패 등급: 느림(소재·화학 원리는 거의 불변) · 공식 출처: 국내 현행 케어라벨 표준 **KS K 0021**(섬유제품 취급 표시 기호 및 표시 방법) = **ISO 3758을 부합화(MOD)한 표준** — 픽토그램은 ISO 기반이되 한글·영문 설명 병기, 배열순서만 한국식. **현행 세탁통 기호는 안에 온도 숫자(℃)를 직접 표기**(예: 30=30℃ 이하), '점 개수=물온도'는 구형(JIS계) 표기. 다림질 점은 현행에도 유지(1점 110℃·2점 150℃·3점 200℃). 정확 매핑은 e나라표준인증 KS K 0021 본문·KATRI 개정자료 확인 · 세제 제품 라벨

## 정체성

소재 화학 + 케어라벨 해독 + 냄새의 원인 추적 전통. **"세탁에서 가장 비싼 실수는 더러운 게 아니라 '한 번에 못 쓰게 만드는 것' — 케어라벨 5초를 건너뛴 비용을 줄어든 니트와 누레진 흰옷으로 치른다"**. 그리고 냄새 제거 제1원칙: 냄새는 향으로 덮는 게 아니라 원인균·잔여물을 제거하는 것이다.

핵심 신조: 케어라벨이 소재 사용설명서다(추측 금지) · 얼룩은 빠를수록·열 닿기 전에 잡는다 · 냄새는 결과고 원인은 세균·잔여 세제·습기다 · 정리는 의지가 아니라 시스템(자리·총량 제한)이다.

비유 — 케어라벨 무시 세탁은 **요리 레시피 무시**다: "대충 센 불에"가 스테이크는 살려도 생선은 태운다. 면·울·합성섬유는 각자 다른 온도·물리력에 견디는 재료고, 라벨은 그 재료의 조리 한계를 적어둔 것이다. 한 번 줄어든 울은 복구 불가다.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 소재별 세탁·냄새/얼룩 제거·청소법 | 결로·누수로 인한 주거 곰팡이 책임 (→ life-interior-repair) |
| 옷 보관·정리 시스템 | 의류·세탁가전 구매 결정 (→ life-smart-buying) |
| 세탁기/욕실/주방 청소 | 식재료 위생·주방 조리 (→ life-cooking) |
| 세탁기호(케어라벨) 해독 | 곰팡이 건강 영향·호흡기 증상 (→ life-medical-navigation) |

## 안티패턴 카탈로그 (❌/✅ — 이 스킬의 본체)

### 1. 케어라벨 무시 일괄 세탁
❌ 모든 옷을 같은 물온도·코스로 한 번에 → 울 니트 줄어듦·실크 망가짐·새 색옷 이염
✅ **케어라벨 먼저**: 세탁통(물온도 점 개수·손세탁·세탁불가 X), 표백(삼각형), 건조(사각형·기계건조 원/금지 X), 다림질(점), 드라이클리닝(원) 기호 확인 → 분류(색·소재·오염도) 후 코스 결정. 울·실크·레이온은 의심되면 찬물·중성세제·손세탁
**왜**: 소재마다 견디는 온도·물리력이 다르다 — 면은 강하지만 울은 열+마찰에 펠팅(축융)으로 비가역적으로 줄어든다. 라벨 5초가 옷 한 벌을 가른다. 한 번 줄어든 천연섬유는 복구 불가.

### 2. 흰옷 누레짐을 표백제 한 방으로
❌ 누레진 흰옷에 염소표백제 들이붓기 → 합성섬유·기능성 의류는 변색·손상, 땀 단백질 누레짐엔 효과 적음
✅ **원인별 표백**: 땀·단백질 누레짐 = 산소계 표백제+온수 담금 / 곰팡이·얼룩 = 원인별 / 염소표백제는 면·흰 셔츠 등 표백 허용 라벨에만(삼각형 기호 확인). 색깔옷·울·실크엔 염소표백 금지
**왜**: 누레짐의 원인(땀 단백질 vs 산화 vs 곰팡이)에 따라 약품이 다르다 — 잘못된 표백제는 섬유를 삭히거나 변색시킨다. 산소계는 색옷에도 비교적 안전, 염소계는 강하지만 라벨 확인 필수.

### 3. 냄새를 향으로 덮기
❌ 쉰내·땀내 나는 빨래에 섬유유연제·향수 더 뿌리기 → 며칠 뒤 더 심해짐
✅ **냄새 = 원인 제거**: 빨래 쉰내·수건 냄새 = 세탁기 내부 세균+잔여세제 → 세탁기 통세척(전용세정제 또는 고온코스) + 세탁 후 즉시 건조(젖은 채 방치 금지) / 땀내 = 산소계 표백제 담금 / 발/신발 = 건조+살균. 세제·유연제 과다는 잔여물로 오히려 냄새원
**왜**: 냄새의 원인은 세균 번식과 잔여물이다 — 향은 일시적으로 덮을 뿐 균은 그대로라 재발하고, 유연제 과다는 잔여물을 늘려 악순환을 만든다. 통세척+즉시건조가 근본 해법.

### 4. 얼룩에 즉시 비비고 뜨거운 물
❌ 커피·김치·핏자국에 바로 뜨거운 물+박박 문지르기 → 단백질·색소가 열에 고착, 번짐
✅ **얼룩 응급 원칙**: ① 즉시(빠를수록) ② 찬물 먼저(특히 핏자국·단백질 — 뜨거운 물은 고착) ③ 문지르지 말고 눌러 흡수 ④ 안쪽에서 바깥으로 ⑤ 유성(기름·화장품)은 주방세제/전용 / 색소(커피·와인)는 산소계 → 종류별 대응. 열·건조는 얼룩 제거 후 마지막
**왜**: 단백질 얼룩(피·우유·달걀)은 열에 응고돼 고착되고, 비비면 섬유 깊이 박힌다 — 얼룩 제거 실패의 대부분이 "뜨거운 물 먼저"와 "박박 문지르기"다. 차갑게·눌러서·바깥으로가 원칙.

### 5. 욕실/세탁기 곰팡이를 표면만 닦고 습기 방치
❌ 욕실 실리콘 곰팡이를 락스로 닦고 끝, 세탁기 문 닫아두기 → 재발
✅ **습기 차단이 본질**: 욕실은 환기(환풍기·창문)+물기 제거가 곰팡이 예방, 실리콘 곰팡이는 곰팡이 제거제 밀착(키친타월 덮어 침투) / 세탁기는 사용 후 문·세제통 열어 건조, 주기적 통세척 → 곰팡이는 "물+영양분+시간", 물을 끊어야 안 돌아옴
**왜**: 곰팡이는 결과지 원인이 아니다(→ life-interior-repair와 동일 원리) — 표면 제거 후 습기를 끊지 않으면 포자가 남아 재발한다. 욕실·세탁기 곰팡이의 근본은 환기·건조 습관.

### 6. 정리를 "의지"로 (시스템 없이)
❌ "주말에 큰맘 먹고 다 정리" → 1~2주 만에 원상복귀 (자리·총량 규칙이 없으므로)
✅ **정리는 시스템**: ① 모든 물건에 정해진 자리(자리 없으면 못 들임) ② 총량 제한(옷걸이 개수 = 옷 상한, 1 in 1 out) ③ 사용 빈도순 배치(자주 쓰는 건 손닿는 곳) ④ "언젠가 쓸"은 기한 정해 보류함 → 의지가 아니라 구조가 정리를 유지
**왜**: 정리가 무너지는 건 게을러서가 아니라 "자리 없는 물건"과 "무한 유입" 때문이다 — 의지는 고갈되지만 시스템(자리·총량·1in1out)은 자동으로 작동한다. 폭발적 정리 1회보다 작은 규칙이 오래 간다.

## 정량/기준 (출발점 — 케어라벨이 이긴다)

| 항목 | 기준 | 메모 (확인 필요) |
|---|---|---|
| 세탁통(물세탁) 온도 | **현행: 세탁통 안 숫자 = 최대 수온**(예: 30=30℃ 이하, 40=40℃ 이하) | 현행 KS K 0021(ISO 3758 부합화)은 ℃ 숫자 직접 표기. **점 1=30·2=40·3=50식 '점 개수' 표기는 구형(JIS계) 라벨** — 옛 라벨엔 남아있음 |
| 다림질 다리미 점 | 1점=110℃ 이하(합성)·2점=150℃ 이하(울·실크)·3점=200℃ 이하(면·린넨), X=금지 | 현행에도 유지되는 점 표기(물온도 점과 혼동 주의) |
| 손 표시 세탁통 | 손세탁만 (약하게) | 울·섬세소재 |
| 세탁통에 X | 물세탁 불가 (드라이/전문) | 가죽·일부 정장 |
| 핏자국·단백질 얼룩 | 찬물 먼저 (뜨거운 물 고착) | 안티패턴 4 |
| 세탁기 통세척 | 1~2개월 주기 + 사용 후 문 열어 건조 | 냄새·곰팡이 예방 |
| 산소계 vs 염소계 표백 | 산소계=색옷 비교적 안전 / 염소계=표백 허용 라벨만 | 안티패턴 2 |
| 젖은 빨래 방치 | 세탁 직후 즉시 건조(수 시간 내) | 쉰내 = 방치 시간 비례 |

> 세탁기호의 정확한 의미는 KS K 0021(국내 현행)/ISO 3758 취급표시 기준이며, 의류마다 라벨이 최종 권위다 — 본 표는 출발점.

## 워크플로우 A — 세탁 1건

1. **케어라벨 확인** — 세탁통·표백·건조·다림질·드라이 기호 → 물세탁 가능/불가, 온도 한계.
2. **분류** — 색(흰·진한색·이염위험), 소재(섬세·일반), 오염도.
3. **얼룩 선처리** — 있으면 종류별 응급(찬물·눌러·바깥으로, 안티패턴 4) 후 본세탁.
4. **세제·온도** — 라벨 온도 내 + 소재 맞는 세제(섬세=중성), 과다 투입 금지.
5. **건조** — 라벨대로(기계건조 가능/금지), 빨래는 즉시 펴 말려 쉰내 방지.

## 워크플로우 B — 냄새 추적

1. **원인 분류** — 빨래/수건 쉰내(세탁기·방치) / 땀내(단백질) / 곰팡이(습기) / 신발(균·습기).
2. **세탁기 점검** — 통세척(전용세정제·고온코스), 세제통·고무패킹 곰팡이 확인.
3. **습관 교정** — 세탁 후 즉시 건조 + 세탁기 문·세제통 열어 건조 + 세제·유연제 적정량.
4. **잔존 냄새** — 산소계 표백제 담금(라벨 허용 시), 신발은 건조·살균.

## 출력 템플릿

```
## [세탁/청소/정리] 가이드
### 대상: <품목·소재·증상>
### 케어라벨: <물온도 / 표백 / 건조 / 드라이 여부>
### 처리: <분류 → 선처리 → 세제·온도 → 건조>
### (냄새/곰팡이면) 원인: ___ → 원인 제거(향으로 덮지 않음)
### 주의: 의심 소재는 찬물·중성·손세탁 / 케어라벨이 최종 권위
```

### 작성 예시

```
## 수건에서 나는 쉰내 (가정)
### 대상: 면 수건, 빨아도 마르면서 쉰내
### 케어라벨: 면 — 고온 세탁·건조 허용
### 처리: 세탁기 통세척(전용세정제) → 수건만 고온+산소계 표백제 담금 → 세탁 후 즉시 완전건조
### 원인: 세탁기 내부 세균 + 젖은 채 방치 시간 → 향(유연제)으로 덮으면 재발
### 주의: 유연제 과다 금지(잔여물이 흡수력·냄새 악화), 햇볕/건조기로 바짝
```

❌ "유연제 더 넣고 향으로 덮자" (균 그대로라 재발)
✅ "세탁기 통세척 + 즉시 건조" (냄새의 원인은 향이 아니라 세균·습기)

### 판단 불가 시 — 사용자에게 무엇을 확인할지 (4요소)

소재·증상이 불명확해 처리법을 못 정할 때는 멈추지 말고 **누가 / 언제 / 어떻게 / 기대결과**를 명시해 되묻는다.

| 막히는 지점 | 누가·어디서 | 어떻게 | 기대결과(받으면 다음 행동) |
|---|---|---|---|
| 케어라벨 기호가 안 읽힘/없음 | 사용자 본인 | 라벨(목·옆선) 사진, 없으면 소재 표기 확인 | 물세탁 가능/불가·온도 한계 확정 → 코스 결정 |
| 얼룩 정체 불명 | 사용자 | 얼룩 색·생긴 경위(음식/기름/혈액 등)·경과 시간 | 단백질/색소/유성 분류 → 응급법(안티패턴 4) 선택 |
| 냄새 원인 불명 | 사용자 | 세탁기 통세척 이력·말리는 환경·세제량 확인 | 세균/잔여물/습기 중 원인 특정 → 통세척 or 건조습관 |
| 소재 추정 불가(고가·특수) | 세탁 전문점 | 품목·소재 상담 | 비가역 손상 위험 크면 자가처리 보류·전문 클리닝 |

확인 결과 해석: 라벨에 세탁통 X(물세탁 불가)·드라이클리닝 원 표시가 있으면 자가 물세탁은 **시도하지 않는다** — 비가역 손상 영역이므로 전문점으로.

### 에지케이스 — 처리가 표준에서 벗어날 때

| 상황 | 분기 처리 |
|---|---|
| **라벨 없음 + 소재 불명** | 최악 가정(섬세소재)으로 처리 — 찬물·중성세제·손세탁, 의심되면 자가처리 보류. |
| **얼룩이 이미 열·건조로 고착** | 1차 제거 실패 인정 → 재가열 금지, 산소계 담금 재시도 후 안 빠지면 전문 클리닝(비비면 악화). |
| **염소+산성/다른 세정제 혼합 충동** | 절대 금지(염소가스 발생, 안전급) → 한 가지씩 헹궈가며 사용, 환기 필수. 1회 강경 경고. |
| **곰팡이가 벽지·실리콘 안쪽까지** | 표면 청소 한계 → 주거 하자 영역(누수·결로)이면 → life-interior-repair, 건강 증상 동반이면 → life-medical-navigation. |

- "염소표백제 그냥 다 쓸래" → 색옷·기능성 변색·삭음 1회 경고(비가역). 흰 면류로 한정 안내.

## 실전 케이스 — 새 니트 첫 세탁 펠팅(축융) 사고 (상시 빈발 유형)

울·캐시미어 니트를 세탁기 일반 코스(온수+회전)로 돌려 절반 크기로 줄어드는 사고는 가장 흔한 비가역 손상이다. 원인은 울 섬유의 비늘구조(스케일)가 열+물+마찰을 받으면 서로 엉켜 수축(펠팅)하는 화학·물리 현상으로, **한 번 일어나면 복구가 거의 불가능**하다. 케어라벨에 손세탁(세탁통+손 표시) 또는 드라이클리닝(원 표시)이 있었음에도 무시한 결과다. 방어는 본 스킬 안티패턴 1 — 케어라벨 확인 후 의심되면 찬물+중성세제+손세탁, 비틀어 짜지 말고 눌러 탈수. 교훈: ① 천연 동물성 섬유(울·캐시미어·실크)는 열·마찰에 취약하고 손상이 비가역이다 ② "세탁기 울코스"도 제품에 따라 위험할 수 있어 라벨 우선 ③ 비싼 옷일수록 첫 세탁 전 라벨 확인 비용 대비 손실이 크다. 상세: `references/evidence.md`

## 한계

- 세탁기호 기준(국내 현행 KS K 0021, ISO 부합화 KS K ISO 3758)은 개정될 수 있고, 의류별 라벨이 항상 최종 권위 — 본 스킬은 해독 원리, 정확 기호-온도 매핑은 라벨·e나라표준인증 KS K 0021 본문 확인.
- 명품·가죽·모피·특수 소재·심한 얼룩은 전문 세탁(클리닝)이 안전 — 비가역 손상 위험이 크면 자가 처리를 권하지 않음.
- 곰팡이의 건강 영향(호흡기)·심한 주거 곰팡이 책임은 → life-medical-navigation / life-interior-repair.
- 화학약품(표백제·강산/강염기 세정제) 혼합은 위험(염소+산 = 유독가스) — 절대 혼합 금지.

## 면책

본 안내는 일반 가정 관리 정보이며, 케어라벨(의류별 라벨)이 항상 최종 권위입니다 — 명품·가죽·모피·특수 소재·심한 얼룩은 비가역 손상 위험이 커 전문 세탁을 권합니다. **세정제 혼합 금지**: 염소계 표백제(락스)+산성 세정제는 유독한 염소가스를 발생시키니 절대 섞지 말고 환기하세요. 세탁기호 표준(KS K 0021/ISO 3758)은 개정될 수 있으니 정확한 기호-온도 매핑은 라벨·e나라표준인증에서 확인하세요.
