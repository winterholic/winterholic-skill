## 1. 세탁기호(케어라벨) 해독표

KS K ISO 3758 기반(확인 필요). 5개 기본 기호:

| 기호 | 의미 | 세부 |
|---|---|---|
| 세탁통(물) | 물세탁 | 숫자/점=최고 온도, 손=손세탁, X=물세탁 불가, 통 아래 줄=약하게 |
| 삼각형 | 표백 | 빈삼각형=표백가능, 사선=산소계만, X=표백금지 |
| 사각형 | 건조 | 원 안=기계건조(점=온도), X=기계건조 금지, 가로줄=뉘어 자연건조, 세로줄=걸어 자연건조 |
| 다리미 | 다림질 | 점 개수=온도(1저~3고), X=다림질 금지 |
| 원 | 드라이클리닝 | 글자=용제 종류, X=드라이 금지 |

핵심: **점·숫자가 많을수록 고온 허용, X는 금지, 줄(밑줄)은 약하게**. 의심되면 가장 약한 조건(찬물·중성·손세탁).

## 2. 소재별 취급 가이드

| 소재 | 취약점 | 권장 |
|---|---|---|
| 면 | 강함, 수축 약간·구김 | 고온 OK(라벨 내), 흰면은 염소표백 가능 |
| 울·캐시미어 | 열+마찰=펠팅(비가역 수축) | 찬물·중성·손세탁·눌러탈수, 다수는 드라이 |
| 실크 | 열·마찰·알칼리·강한 빛 | 중성·손세탁·그늘건조, 염소표백 금지 |
| 레이온/비스코스 | 젖으면 약해짐·수축 | 가능하면 드라이, 물세탁 시 약하게 |
| 합성(폴리·나일론) | 열에 약함(녹음)·정전기 | 저온, 염소표백 변색 주의 |
| 기능성(고어텍스 등) | 일반세제·유연제로 기능 저하 | 전용세제·유연제 회피·라벨 준수 |
| 가죽·스웨이드 | 물·세제 | 전문 클리닝 |

## 3. 얼룩 종류별 대응표

응급 5원칙: 빠르게 / 찬물 먼저 / 문지르지 말고 눌러 / 안→바깥 / 열·건조는 마지막.

| 얼룩 | 성질 | 대응 |
|---|---|---|
| 피·우유·달걀 | 단백질(열에 응고) | 찬물 먼저, 절대 온수 금지, 산소계 |
| 커피·홍차·와인 | 색소(탄닌) | 찬물 헹굼, 산소계 표백, 빠를수록 |
| 김치·카레 | 색소+유분 | 주방세제로 유분 먼저, 산소계, 햇볕(카레 강황은 자외선에 분해) |
| 기름·화장품·립스틱 | 유성 | 주방세제/전용 클렌저로 유분 분해 후 세탁 |
| 잉크·볼펜 | 유성/수성 | 종류별, 유성은 알코올 소량 시험 후 |
| 땀·누레짐 | 단백질 산화 | 산소계+온수 담금 |

주의: 약품 혼합 금지(염소표백제+산성세정제 = 유독 염소가스).

## 4. 냄새 원인 추적표

| 냄새 | 원인 | 근본 대응 |
|---|---|---|
| 빨래/수건 쉰내 | 세탁기 내부 세균+잔여세제+젖은 방치 | 통세척 + 즉시 완전건조 + 세제 적정량 |
| 땀내(옷) | 단백질·균 | 산소계 담금, 즉시 세탁 |
| 곰팡이내 | 습기 | 환기·건조·곰팡이 제거제 |
| 신발 냄새 | 균+습기 | 건조·살균·교대 착용 |
| 세탁기 자체 냄새 | 고무패킹·세제통 곰팡이 | 패킹·세제통 청소, 문 열어 건조 |

원칙: 향(유연제·방향제)으로 덮으면 균은 그대로라 재발 + 잔여물로 악화. 원인(균·습기·잔여물) 제거가 유일한 해법.

## 5. 정리 시스템 원칙

의지가 아니라 구조:
1. **자리 고정**: 모든 물건에 정해진 위치. 자리 없으면 들이지 않음.
2. **총량 제한**: 옷걸이 수 = 옷 상한. 1 in 1 out(하나 사면 하나 버림).
3. **빈도순 배치**: 자주 쓰는 것은 손닿는 곳, 드문 것은 위/안쪽.
4. **보류함+기한**: "언젠가 쓸"은 기한(예: 6개월) 정해 보관, 미사용 시 처분.
5. **소량 정리 루틴**: 폭발적 1회 정리보다 매일 5분 제자리.

붕괴 원인: "자리 없는 물건" + "무한 유입". 시스템이 이 둘을 막는다.
