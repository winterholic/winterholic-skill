# evidence + 안내 전 체크리스트 — 보험 (보험 자문 아님)

> 보험은 손실 이전이지 저축이 아니다. 가입·해지·세대 교체는 비가역 손실이 가능 — 단정하지 않는다. 산정·분쟁은 손해사정사·금감원 1332. 상세는 `evidence.md`, 수치 검증표는 `sources.md`.

## 실증·출처

- **실손 세대 구분**(2026-06 확인): 1세대(~2009.9)·2세대(~2017.3)·3세대(~2021.6)·4세대(2021.7~2026.5)·**5세대(2026-05-06~)**. **2026-05-06 5세대 출시로 4세대 신규가입 사실상 종료.** 정확한 세대 경계일은 협회 공시 확인 필요. 출처: 손해보험협회 비교공시 · 금융위 보도자료(2026).
- **4세대 자기부담**: 급여 20% / 비급여 30% + 비급여 할증(직전 1년 비급여 수령 100~150만 +100%·150~300만 +200%·300만↑ +300%). **비급여 할증제는 2024-07-01부터 본격 시행**(2021.7 출시 후 3년 경과 시점). 출처: 금융위 보도자료(sources.md).
- **5세대 실손(2026-05-06~)**: 비급여 할인·할증제 유지하되 중증 비급여는 할증 제외, 비중증 비급여 중심으로 자기부담 강화 방향(세부 자기부담률·한도는 **확인 필요** — 약관·금융위 자료). 출처: 금융위(2026, 확인 필요).
- **암 면책·감액**: 가입 후 90일 면책 + 1~2년 50% 감액(상품별 상이 — 약관·청약서 확인 필요).
- **고지의무 질문기간**: 항목별 3개월/1년/5년 상이(청약서·표준약관 확인 필요).
- **청구권 소멸시효 3년**(상법 제662조): 보험금 청구는 3년 내.
- **부당 승환 규제**: 신·구 계약 6개월 이내 비교 고지 없는 교체 규제(보험업법 — 2026 확인 필요).
- **분쟁조정 — 금융감독원 ☎1332**(무료, 2026-06 유효) · 금융소비자정보포털 '파인' fine.fss.or.kr('내 보험 다보여' 가입내역 조회).

## 안내 전 체크리스트

- [ ] **면책 라벨 보존** — "정보 제공이며 보험 자문 아님, 산정·청구·분쟁은 손해사정사·금감원 1332" (삭제·약화 금지)
- [ ] **비가역 경고** — 해지·세대 교체는 면책기간 리셋·복원 불가·나이 상승 — 단정 금지·1회 명확 경고
- [ ] **시점 라벨** — 세대 경계·할증률·자기부담·승환 규제는 변동, 약관·파인·협회 공시 확인 표시
- [ ] **수치 날조 금지** — 5세대 세부 자기부담·암 감액률 등 미확정 수치는 "확인 필요" + 출처 포인터(임의 숫자 금지)
- [ ] 4세대 안내 시 **비급여 할증 2024-07-01 시행** 반영, 5세대 출시(2026-05-06) 언급

- 실손 세대·자기부담·할증률: **연 1회 이상** + **5세대 세부 약관 확정·4세대 종료 후속 고시 발표 시 즉시 재확인**(금융위/협회).

- 시효(상법 제662조)·고지의무·승환 규제: 법령 개정 추적, 연 1회.
