# life-medical-navigation — evidence (코어스펙 1겹)

> **이 문서는 길안내 자료다. 진단·치료가 아니다.** 증상→과 매핑은 "이런 증상은 흔히 어느 과에서 보는가"이지 "당신은 ○○병"이 아니다. 검진 수치·소견의 해석은 전부 의사 몫이며, 이 문서는 용어 풀이까지만 한다. 응급 신호는 SKILL.md의 응급 게이트(즉시 119)를 따른다.
> 모든 제도 수치는 (2026 기준, 확인 필요) — 건강보험심사평가원·보건복지부·국민건강보험공단·보험사 약관·응급의료포털(1339)에서 확인.

## 목차

1. 증상→진료과 매핑표 (길안내, 진단 아님)
2. 의료전달체계 (1·2·3차) 와 진료의뢰서
3. 응급실 vs 야간진료 판단
4. 실손보험 급여/비급여 & 청구 절차
5. 2차 소견(second opinion) 절차
6. 건강검진 결과지 용어 (정상/경계/요관찰/이상 — 해석은 의사)
7. 금지선 체크리스트 (이 스킬이 절대 하지 않는 것)

## 1. 증상→진료과 매핑표 (길안내, 진단 아님)

> "흔히 이 과에서 본다"는 출발점 안내다. 증상이 여러 계통에 걸치거나 애매하면 **내과·가정의학과**가 1차 분류(triage) 관문이 된다. 어느 과인지 가르는 것은 진찰의 일이다.

| 주된 증상 양상 | 흔히 보는 1차 과 | 비고 (동반 증상 따라 달라짐) |
|---|---|---|
| 발열·기침·콧물·인후통(감기 양상) | 내과 / 가정의학과 / 이비인후과 | 호흡곤란·고열 지속은 진료 앞당김 |
| 복통·소화불량·설사·속쓰림 | 내과(소화기) / 가정의학과 | 갑작스러운 극심한 복통은 응급 평가 |
| 근육·관절·뼈 통증, 삔 곳, 허리·무릎 | 정형외과 | 저림·근력저하 동반은 신경 쪽도 고려 |
| 팔다리 저림·감각이상·방사통 | 신경과 / 신경외과 / 정형외과 | 갑작스러운 한쪽 마비는 **즉시 119** |
| 두통·어지럼·손발 저림 | 신경과 | "생애 최악의 갑작스러운 두통"은 **응급** |
| 피부 발진·두드러기·여드름·점 변화 | 피부과 | 전신 두드러기+호흡곤란은 **아나필락시스, 119** |
| 콧물·코막힘·귀·목·어지럼(이석) | 이비인후과 | |
| 눈 충혈·시야·통증 | 안과 | 갑작스러운 시야 상실은 응급 평가 |
| 소변·빈뇨·혈뇨·옆구리 통증 | 비뇨의학과 / 내과(신장) | |
| 여성 생리·산부인과 영역 | 산부인과 | |
| 가슴 두근거림·숨참·흉통 | 내과(순환기) | **갑작스러운 심한 흉통·호흡곤란은 119** |
| 우울·불안·불면·번아웃 | 정신건강의학과 | 자가관리·위기 신호는 → life-mental-care(109) |
| 치아·잇몸 | 치과 | |
| 어느 과인지 모를 때 / 증상 여러 개 | **내과 / 가정의학과 (분류 관문)** | 1차에서 적합 과로 연결 |

**원칙**: 표는 "어느 문으로 들어갈지"의 안내다. 들어간 뒤 병명을 정하는 것은 의사다. 동반 증상(저림·발열·체중감소·야간 악화 등)을 진료실에서 빠짐없이 말하는 것이 환자의 일.

## 2. 의료전달체계 (1·2·3차) 와 진료의뢰서

한국 의료는 단계형 전달체계로 설계돼 있다(2026 기준, 확인 필요).

| 단계 | 기관 | 역할 |
|---|---|---|
| 1차 | 동네의원 (의원급) | 1차 진료·분류·만성질환 관리. 대부분의 경증이 여기서 끝난다 |
| 2차 | 병원·종합병원 | 입원·전문 진료. 1차에서 의뢰되거나 직접 방문 |
| 3차 | 상급종합병원(대학병원 등) | 중증·희귀·고난도. **원칙적으로 진료의뢰서 필요** |

**진료의뢰서**: 하위 단계 의료기관이 상위 단계로 환자를 보낼 때 발급하는 서류.
- 상급종합병원(3차)에서 요양급여(건강보험 적용)를 받으려면 원칙적으로 의뢰서가 있어야 한다 — 없이 가면 진료비 본인부담이 크게 오른다(예외 항목 존재, 확인 필요).
- 발급: 현재 다니는 1차·2차 의료기관 의사가 "상급에서 봐야 한다"고 판단하면 써준다.
- 챙길 것: 의뢰서 + 그동안의 검사기록·영상(CD)·복용약 목록 → 같은 검사 반복 방지.
- **왜 순서가 중요한가**: 경증의 3차 직행은 본인부담↑·대기↑이고, 중증·희귀질환 환자의 진료 슬롯을 밀어낸다. 순서 준수 = 비용 절감 + 시스템 작동.

## 3. 응급실 vs 야간진료 판단

| 구분 | 어디로 | 예 |
|---|---|---|
| **응급 (즉시 119/응급실)** | 119·응급실 | 심한 흉통·호흡곤란, 한쪽 마비·말 어눌·얼굴 처짐(뇌졸중), 의식저하, 심한 출혈·외상, 갑작스러운 극심한 두통, 경련, 아나필락시스 |
| **야간·휴일 진료 (응급 아님)** | 야간진료 병원·약국 | 밤에 열나는 아이(상태 양호), 가벼운 외상, 야간 단순 통증 — 문 연 곳을 1339/E-gen으로 찾기 |
| **다음 평일 진료로 충분** | 동네의원 | 며칠 된 경증, 만성질환 정기, 검진 결과 상담 |

- **응급의료정보 1339** / **응급의료포털 E-gen**: 야간·휴일 문 연 병원·약국 검색, 응급 상담.
- 판단 기준: "지금 처치가 늦으면 비가역적 손상이 오는가"가 응급의 핵심. 애매하면 1339 상담 또는 응급실 — 과소평가의 비용이 비가역인 신호(흉통·마비·의식·심한 출혈·극심한 두통)는 망설이지 않는다.

## 4. 실손보험 급여/비급여 & 청구 절차

> 보험 상품 구조·약관 해석·분쟁은 → life-insurance. 여기서는 **병원 이용 시 청구 실무**만.

**급여 vs 비급여**:
- **급여**: 건강보험이 적용되는 항목(공단 부담 + 본인부담). 영수증에 '급여' 표기.
- **비급여**: 건강보험 미적용으로 환자가 전액 부담(일부 특진·비급여 검사·일부 약제 등). 실손 약관·자기부담 조건이 급여와 다르다.
- 청구 전 영수증에서 급여/비급여 구분을 확인해야 보장 범위·자기부담을 정확히 계산.

**청구 서류 체크리스트** (보험사·금액 따라 가감, 약관 확인 필요):
- [ ] 진료비 영수증
- [ ] 진료비 세부산정내역서 (가장 자주 누락 → 반려 원인)
- [ ] (입원·고액·특정질환) 진단서 또는 진료확인서
- [ ] 본인 신분증 사본 / 보험금 수령 계좌
- [ ] (해당 시) 처방전·약제비 영수증

**유의**:
- 서류 한 장 누락 → 보완 요청으로 지급 지연. 발급은 진료 당일·퇴원 시 한 번에 받아두는 게 효율적.
- **청구권 소멸시효**: 통상 3년(상법·약관, 확인 필요) — 묵혀두면 청구 불가 위험.
- 소액·통원은 모바일 앱 간편청구가 가능한 보험사가 많다.
- 진단명·상세 의료정보는 민감정보 — 분석 파일에 저장 금지, `[REDACTED]` 처리.

## 5. 2차 소견(second opinion) 절차

중대한·비가역적 결정(큰 수술, 장기 치료, 암 등)에서 다른 전문의 의견을 듣는 정당한 권리.

1. **언제**: 큰 수술·장기 치료·중대 진단, 또는 제시된 치료에 확신이 안 설 때.
2. **준비**: 기존 병원에서 **검사기록·영상(CD)·판독지·진료기록 사본**을 발급받는다(의료법상 본인 기록 발급 가능, 확인 필요) → 같은 검사 반복 방지.
3. **어디로**: 같은 전문과의 다른 병원·다른 전문의. 3차가 필요하면 의뢰서 경로.
4. **정리**: 2~3곳 선에서 종합 — 무한정 도는 닥터쇼핑은 치료 시기를 놓치고 검사를 중복시킨다.
5. **태도**: "확인"이 목적이지 "원하는 답 찾기"가 아니다. 의견이 갈리면 근거(검사·가이드라인)를 물어 비교.

## 6. 건강검진 결과지 용어 (정상/경계/요관찰/이상 — 해석은 의사)

> **이 절은 용어가 무슨 뜻인지까지만 설명한다. 당신의 수치가 어떤 의미인지(정상 범위 안인지, 무슨 병인지)는 의사가 판단한다.** 이 스킬은 수치를 해석하지 않는다.

| 표기 | 일반적 의미 (검진기관 표기 관행, 확인 필요) | 길안내 |
|---|---|---|
| 정상 | 해당 항목 기준 범위 내 | 정기 검진 유지 |
| 정상B / 경계 / 요주의 | 기준 경계선 근처 — "지금 병"이 아니라 주의·생활관리·추적 신호 | 생활습관 + 다음 검진 추적, 권고 시 진료 |
| 요관찰 | 추적 관찰 권고 | 권고 주기대로 추적, 변화 시 진료 |
| 질환의심 / 이상 / 재검·정밀검사 권고 | 추가 검사·진료가 필요하다는 신호 | **미루지 말고 해당 과 예약** — 확진은 의사 |

- 검진 결과지는 **진단서가 아니라** "의사와 이야기할 출발점"이다.
- '재검·정밀권고'는 "병이 확정됐다"가 아니라 "확인이 필요하다"는 뜻 — 방치(골든타임 상실)도 과잉공포(불필요 불안·과잉검사)도 둘 다 비용.
- 자주 보는 항목 용어: 공복혈당·당화혈색소(혈당 관련), 혈압, 총콜레스테롤·LDL·HDL·중성지방(지질), AST·ALT·γ-GTP(간), 크레아티닌·eGFR(신장), BMI·허리둘레(비만). **각 수치의 정상 범위 판정과 임상적 의미는 의사에게.**

## 7. 금지선 체크리스트 (이 스킬이 절대 하지 않는 것)

- [ ] "당신은 ○○병"이라는 **병명 단정** — 금지. "이런 증상은 흔히 ○○과에서 본다"까지만.
- [ ] 검진 **수치를 해석**해 정상/비정상·중증도를 단정 — 금지. 용어 풀이까지만.
- [ ] **약 처방·복용 지시** — 금지. 약은 의사·약사.
- [ ] 응급 신호를 "무슨 과일까"로 **분석** — 금지. 즉시 119(응급 게이트).
- [ ] 진단명·계좌·주민번호 등 **민감정보 저장** — 금지. `[REDACTED]`.
- [ ] 면책 라벨·응급 게이트 **누락** — 금지. 모든 출력에 동봉.

> 이 6줄 중 하나라도 어기면 출고 금지. 이 스킬의 가치는 "진단하지 않으면서 가장 빠르고 싼 길을 안내하는" 자제력에 있다.
