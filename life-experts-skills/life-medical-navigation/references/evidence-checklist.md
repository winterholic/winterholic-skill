# evidence + 출고 전 체크리스트

> 진단·치료가 아니라 "어느 문으로 가는가"(navigation)만. 상세 실증·매핑은 `evidence.md`, 출처 검증표는 `sources.md`, 여기서는 **출처 색인 + 출고 전 체크리스트 + 점검 주기**. **0단계 응급 게이트를 통과 못 하면 나머지는 무시하고 119** — 이 문서의 어떤 항목도 응급 신고보다 앞서지 않는다.

## 실증·출처 (색인 — 전체 검증표는 `sources.md`)

- **의료전달체계 1·2·3차 / 진료의뢰서**: 보건복지부 의료전달체계 + 진료협력센터 안내(서울대병원 등) — 상급종합 의뢰서 미지참 시 **건강보험 수가 100% 본인부담**(2026-06 조회, sources.md에서 **확인됨**). 안티패턴 2·3, 워크플로우 3의 1차 근거.
- **국가건강검진 항목·참고 정상치**: 국민건강보험공단 일반건강검진 안내(2026-06 조회). **수치 정상범위 판정·해석은 의사** — 이 스킬의 금지선. 안티패턴 4의 근거.
- **응급 게이트 / 응급의료정보**: 중앙응급의료센터 E-gen + **1339**(야간·휴일 문 연 병원·약국). 응급 신호(흉통·호흡곤란·FAST·의식저하·극심한 두통·경련·아나필락시스)는 "무슨 과" 분석 대상이 아니라 즉시 신고 대상.
- **실손 청구 / 청구권 소멸시효**: 보험사 약관 일반 + 상법 제662조 — 소멸시효 **3년**(2026-06 조회, sources.md에서 **확인됨**, 2015-03-12 이전 사유는 2년). 구조·분쟁은 → life-insurance.
- 오픈소스/타 스킬 차용 표기: 일반 의료정보는 색인 인지·본문 비복사. **역흡수**(본 스킬 차별점): "진단 아닌 길안내"라는 금지선·증상→과 매핑을 진단이 아닌 환승 안내로 프레이밍·검진 수치는 용어만 풀고 해석은 의사로 위임·응급 게이트 최우선. 일반 증상검색 도구는 병명을 띄우지만, 이 스킬은 "의사에게 갈 이유"만 출력.

## 출고 전 체크리스트 (안전 축 먼저)

- [ ] **응급 게이트가 본문 최상단·체크블록 0단계 양쪽에 존재** — 흉통/FAST/의식저하/극심한 두통/경련/아나필락시스 → 즉시 119
- [ ] **면책 문구 보존·강화** — "정보 제공이며 진단·의료자문 아님, 증상 해석·진단·치료는 의사" (약화·삭제 금지)
- [ ] **금지선 명시** — 검진 수치·소견 해석·병명 단정 안 함(용어 풀이까지만)
- [ ] 증상→과 매핑은 "흔히 ○○과에서 본다"까지만 — 병명 확정 표현 0
- [ ] 전달체계 순서(1차→의뢰서→2·3차) + 상급종합 직행 시 본인부담↑ 안내
- [ ] 실손 청구 서류 체크리스트(세부산정내역서 누락 경고) + 급여/비급여 구분
- [ ] 민감정보(진단명·계좌·검진수치) 저장 금지, [REDACTED] 처리
- [ ] 권고 거부 시 안전 경고 1회 후 길안내 중단 않고 partial 모드(관찰 트리거 유지)
- [ ] 제도 수치(본인부담·실손 약관·청구 시효)에 시점 라벨 + 공식 출처 재확인 안내
- [ ] 위임 경계 정확(보험 구조→life-insurance, 자가관리→life-mental-care, 응급술기→life-emergency, 실제 응급→119)

## 점검 주기 (부패 중간 — 반기, 요양급여·실손 약관 수년 주기)

- **응급 게이트·면책·금지선은 영구 고정** — 제도가 바뀌어도 약화하지 않는다(강화만).
- 의료전달체계·진료의뢰서 본인부담 규정 변동 시 sources.md 표 갱신(심평원·복지부·진료협력센터).
- 국가건강검진 항목·대상(짝수/홀수년 출생) 연도 표기 갱신 — 2026년 기준 짝수년 출생자.
- 실손 청구 소멸시효(상법 제662조 3년)·서류 요건 약관 개정 추적.
- 응급의료정보 채널(1339·E-gen) 유효성 확인.
