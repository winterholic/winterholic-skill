# evidence + 안내 전 체크리스트 (life-english)

> 개발자 실무 영어(읽기·쓰기·협업)에 한정. 시험 영어·일반 회화 유창성은 범위 밖. 아래는 2026-06 재확인 기준.

## 실증·출처

- **Krashen, S. (1985) *The Input Hypothesis*** — 이해 가능한 입력(i+1) 대량 노출이 습득의 핵심이라는 입력가설. 안티패턴 1("입력 없이 문법책만")의 원전. 출처: https://www.sdkrashen.com/content/books/the_input_hypothesis.pdf (학술 고전, 부패 없음).
- **Swain, M. (1985) Communicative competence: comprehensible output** — 출력(아웃풋) 가설: 산출이 "내가 뭘 모르는지"를 드러내고 피드백 없는 출력은 화석화(fossilization)된다. 안티패턴 2·6의 근거. 출처: Gass & Madden (Eds.), *Input in Second Language Acquisition* (1985).
- **글로벌 오픈소스 협업 영어 규범(관찰 기반)** — 대형 레포(리눅스 커널·주요 프레임워크) 이슈/PR은 짧고 직접적이며 관용(LGTM·nit·PTAL·WIP·SGTM)이 강하다. 기여자 다수가 비원어민이라 "오해 없는 단순 영어"가 사실상 표준. 안티패턴 3·4("추측 직역"·"과한 격식")의 근거. 용례 출처: 활동 중인 레포의 실제 이슈/PR, `"표현" site:github.com` 검색.
- **개발 영어 관용표현집** — 즉시 복붙용 검증된 표현(리뷰/이슈/PR/회의/커밋)은 `references/evidence.md` 내장. 직역 대신 실제 용례 모방이 핵심.
- **LLM 시대 함정(안티패턴 7, 도구 변화 빠름)** — LLM 번역/교정이 개발자 영어 실무에 일상화됐다. 근거: ① 인출연습(retrieval practice)이 단순 재학습보다 장기 정착에 우월하다는 것은 SLA·인지심리에서 강하게 지지되는 원리 → 산출을 통째로 LLM에 위임하면 이 단계가 사라짐. ② LLM은 그럴듯하지만 실제로는 안 쓰는 표현(환각)을 생성할 수 있어 용례 교차검증 필요. **단, "LLM 의존이 인출효과를 실제로 깎는다"는 직접 검증 실증 연구는 미확인 — 원리에서 도출한 합리적 추론으로 표기**(웹 확인 2026-06, 단일 결정적 출처 없음).

> 이 도메인은 **학습 원리(부패 없음)와 관용표현(중간 부패)**으로 갈린다. 원리는 1985년 고전이 그대로 유효하고, 관용·커뮤니티 규범은 레포·시점마다 다르다.

## 안내 전 체크리스트

- [ ] **(이 스킬에는 의료·안전 긴급 게이트가 없다)** — 대신 **법적·대외 공식 게이트**: 계약·NDA·라이선스 등 법적 효력 영어, 투자·대관·언론 등 대외 공식 문서는 자체 종결 금지 → 초안만 제시하고 변호사/법무·원어민 에디터 검수로 에스컬레이션했는가.
- [ ] 영작이 추측 직역이 아니라 **실제 용례 기반**인가. 용례로 검증 못 했으면 **"용례 미확인 — 자연스러움 미보장" 라벨**을 붙였는가.
- [ ] 개발 영어 규범(간결·직접·정중)을 지켰는가 — 과한 격식·미사여구·콩글리시 직역을 ❌/✅로 교정했는가.
- [ ] 학습은 1회성이 아니라 **닫힌 루프(입력→출력→피드백)**로 안내했는가 — 한쪽만이면 화석화 위험 1줄 경고.
- [ ] **LLM 사용 경계(안티패턴 7)** — 산출을 LLM에 통째로 위임하지 않고 "직접 초안(인출) → LLM 교정 → 용례 교차검증" 순서를 권했는가. LLM 환각(안 쓰는 표현 생성)·인출연습 우회 리스크를 1줄 고지했는가. (인출연습 우월성은 지지되는 원리, "LLM이 그 효과를 깎는다"는 직접 연구는 미확인 — 추론으로 표기.)
- [ ] **시점·범위 라벨 부착** — "관용표현·커뮤니티 규범은 변하며 실제 활동 레포의 현재 관행이 우선 / 시험 영어·일반 회화는 범위 밖 / 중요 공식·계약 영어는 전문 검수 권장".

## 점검 주기

- **학습 원리(Krashen 입력가설·Swain 출력가설)**: 부패 없음 — 점검 불필요(학술 고전).
- **개발 영어 관용표현·커뮤니티 규범(LGTM·nit·PTAL 등)**: 중간 부패 — 신조어·규범 변화 시 `references/evidence.md` 표현집 갱신, 반기~연 1회.
- **용례 출처(레포 검색·corpus)**: 이 스킬의 사실상 의존성 — 출처가 막히면 권고가 추측으로 퇴화하므로 대체 경로(내장 표현집·보수적 중립 표현) 유지.
- **시험 제도 수치(토익·오픽 점수·응시료)**: 본 스킬 미취급(실무 영어 한정) — 변동값이라 단정 안 함, 필요 시 공식 주관처 확인.
