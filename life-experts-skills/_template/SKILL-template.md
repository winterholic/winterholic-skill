# life-experts 스킬 템플릿

> 이 파일은 스킬이 아니라 **제작 보일러플레이트**다. 새 일상 전문가를 만들 때 아래 골격을 복사해 `life-<이름>/SKILL.md`로 시작한다.
> 안전 규율(제1원칙)·공통 규칙: `../README.md`. 제작 공식 원본: `../../dev-experts/_template/SKILL-template.md`(3-pass·작성 원칙 공유).

## 일상 스킬 특수 DoD (dev DoD에 추가)

- [ ] **면책 라벨** (법·세·의료·보험·금융 해당 시): 출력 말미 "정보 제공이며 자문이 아님 + <전문가> 상담 권고"
- [ ] **긴급 게이트** (건강·사고·응급·정신건강): 워크플로우 1단계에 "이러면 분석 말고 즉시 119/112/병원"
- [ ] **시점 라벨**: 모든 제도 수치에 "(YYYY 기준, 확인 필요)" + 공식 출처(국세청·법제처·금감원·복지로·정부24)
- [ ] **타임라인 표** (절차형 — 사고·사기·이사 등): 24h / 72h / 2주 단위 "언제까지 무엇을"
- [ ] **민감정보 [REDACTED]**: 주민번호·계좌·진단명은 분석 파일에 저장 금지
- [ ] 실전 케이스 = 실제 제도·판례·사건 유형 (전세사기 패턴·중고 사기 수법 등)
- [ ] scripts = 계산 가능한 곳만(복리·상환·전환율·과실·열량), 표준 라이브러리·실행 검증
