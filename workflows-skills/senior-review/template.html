💡쉽게 말하면

DB 비밀번호가 코드 파일에 그대로 적혀있어요. 이 파일이 GitHub에 올라가면 누구나 비밀번호를 볼 수 있습니다. 도둑이 집 열쇠를 현관문에 테이프로 붙여둔 상태와 같아요.

코드

src/foreign_flow/db.py python L22-28 ↗
22 23 24 25 26 27 28
DATABASE_URL = os.getenv( "FOREIGN_FLOW_DATABASE_URL", # default 값에 비밀번호 노출 ↓ "postgresql://pgadmin:Kktest123!@172.30.1.20:5432/web_app",)

문제

default 값에 실제 비밀번호(Kktest123!)와 DB 주소가 박혀 있어 GitHub에 노출됩니다. 기존 backend/app/config/는 비밀번호를 .env로 분리하는 패턴인데 이 신규 모듈만 다릅니다.

🎯왜 이게 중요한가
  • 사용자 영향: 외부 공격자가 DB에 직접 접속 가능 → 데이터 유출·조작 가능
  • 운영 영향: GitHub public repo면 자동 봇이 1분 내 스캔 → Secret rotation 즉시 필요
  • 법적 영향: 개인정보 포함 DB라면 PIPA 위반 신고 대상
