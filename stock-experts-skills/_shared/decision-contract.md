# 공통 의사결정 계약

종목 추천·관찰목록·시장 브리핑처럼 사용자의 행동에 영향을 주는 출력에 적용한다. 단순 개념 설명이나 과거 사실 조회에는 적용하지 않는다.

## 1. 증거 계약

- 모든 증거는 `as_of` 이전에 공개된 정보만 사용한다.
- 숫자·사건마다 출처와 공개시각을 보존한다. 공개시각을 확인할 수 없으면 `data_gaps`에 넣고 선행 신호로 채점하지 않는다.
- 가격·지지·저항·적정가를 제시할 때는 계산 입력과 산식을 함께 남긴다. LLM이 숫자를 직접 만들어서는 안 된다.
- 같은 사실을 여러 전문가가 반복해도 증거 수는 1개다. 독립된 출처·방법만 추가 증거로 인정한다.

## 2. 새 정보 게이트

이전 리포트 이후 아래 중 하나가 달라졌을 때만 같은 종목을 다시 추천 또는 핵심 브리핑 대상으로 올린다.

- 공시·실적·정책·계약 등 새로운 사건
- 추세 전환·돌파·무효화처럼 사전에 정의한 가격 상태 변화
- 수급·시장 폭·거래대금 집중의 유의미한 상태 변화
- 기존 논거를 강화하거나 깨는 신규 반증

달라진 것이 없으면 `stance=no_new_edge`로 출력하고 추천 칸을 비운다. 종목을 매일 다르게 채우는 것도 목표가 아니다.

## 3. 필수 출력 필드

| 필드 | 의미 |
|---|---|
| `stance` | `candidate`·`watch`·`avoid`·`abstain`·`no_new_edge` 중 하나 |
| `horizon` | 판단 시간축. 당일·D5·D20·D60처럼 분리하고 서로 섞지 않는다 |
| `evidence` | 결론을 지지하는 증거. 값·출처·공개시각 포함 |
| `counterevidence` | 결론을 깨는 반증과 대안 설명 |
| `data_gaps` | 결측 데이터와 그 결측이 판정에 주는 영향 |
| `new_information` | 이전 판단 이후 달라진 사실. 없으면 빈 목록 |

추가로 행동 가능한 판단에는 `price_zones`, `invalidation`, `catalyst`를 붙인다. 산출 근거가 없으면 빈 값을 숨기지 말고 `data_gaps`로 보낸다.

## 4. 판정 규칙

1. 필수 데이터가 없으면 그 축만 `abstain`한다. 가짜 정밀도로 적정가를 채우지 않는다.
2. 장기 가치와 단기 추세가 다르면 하나로 평균내지 않고 시간축별 `stance`를 따로 낸다.
3. 증거와 반증을 함께 비교한다. 반증이 더 강하면 후보를 강등한다.
4. 확신도는 사후 캘리브레이션 자료가 있을 때만 확률로 쓴다. 자료가 없으면 `상·중·하`와 근거를 쓴다.
5. 추천하지 않음·판단 보류·새 정보 없음도 정상 결과로 기록한다.
