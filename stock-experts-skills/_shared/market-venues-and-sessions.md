# 시장·거래소·세션 레퍼런스

> 검증일: 2026-07-31. 거래시간·대상 종목은 거래소 공지 직후 재검증한다.

## 1. 한국 주식 거래장소

| venue | 범위 | 핵심 세션 | 분석상 주의 |
|---|---|---|---|
| KRX KOSPI·KOSDAQ | 상장 주식·DR·ETF·ETN 등 | 정규장 09:00~15:30, 시간외 별도 | 시가·종가 단일가와 연속매매를 분리한다 |

## 2. KRX 현물 세션

`장전`은 하나의 세션이 아니다. 전일종가 거래, 대량·바스켓, 주문접수와 시가
단일가를 구분한다. `장후`도 종가매매와 단일가를 분리한다.

```text
venue / session_name / order_accept_from / trade_from / trade_to
price_method / eligible_instruments / last_trade_at / quote_age
```

휴장일, 연말 단축, 임시휴장, 거래정지, VI·서킷브레이커가 있으면 평시 시간표보다
당일 공지가 우선한다.

## 3. KRX 파생 주·야간 세션

야간시장은 18:00~다음 날 06:00이고 종료일 기준 거래일로 귀속한다. 분석 전에
당일 거래대상과 휴장 여부를 다시 확인한다.

- 지수선물: KOSPI200, 미니 KOSPI200, KOSDAQ150
- 지수옵션: KOSPI200·미니·위클리, KOSDAQ150·위클리
- FICC: 미국달러선물, 3년·10년 국채선물

가격만으로 방향을 확정하지 않는다. 주간 종가 대비 수익률, 거래량, OI, 베이시스,
호가 스프레드를 함께 사용한다.

- [KRX 야간시장](https://global.krx.co.kr/contents/GLB/02/0201/0201041004/GLB0201041004.jsp)

## 4. 글로벌 세션

| 구분 | 필수 시간 처리 |
|---|---|
| 미국 현물 | 정규·프리·애프터마켓을 구분하고 거래소 현지시각과 KST를 모두 저장 |
| 미국 선물 | 거의 24시간이라도 일일 점검·휴지 구간과 RTH/ETH를 분리 |
| 유럽·아시아 | 현지 휴장과 한국 개장 전·후 중첩을 표시 |
| 암호자산 | 24/7이지만 거래소별 점검·유동성·기준가격이 다름 |

DST 전환일에는 고정 KST 시간을 재사용하지 않는다. `timezone`, `UTC offset`,
`DST 적용 여부`를 캘린더에서 계산한다. 미국 휴장·조기폐장일의 얇은 선물 움직임은
평시와 같은 신뢰도를 주지 않는다.

## 5. 세션 판정 규칙

1. `observed_at`과 `quote_age`가 없으면 실시간 신호로 사용하지 않는다.
2. 직전 기준가격이 어느 venue·세션의 가격인지 명시한다.
3. 세션이 겹치지 않는 자산의 수익률은 공통 구간으로 재정렬한다.
4. 휴장·DST·롤오버·만기일이면 구조적 변화를 먼저 의심한다.
5. NXT와 KRX 가격이 다르면 거래대금·호가·체결 가능성을 확인하고 한쪽을 임의로 정답으로 고르지 않는다.
