# 사건 조기탐지 계약

목표는 급등 뒤 이유를 붙이는 것이 아니라, 기준시각 전에 공개된 새 사건을 상장사와 검증 가능하게 연결하는 것이다.

## 시간 게이트

- 원문 게시시각과 수집시각을 모두 보존하고, 분석 기준시각에 실제 **관측 가능 시각**이었는지 확인한다.
- 기준시각 이후 기사·가격·거래량은 사후 채점에는 쓸 수 있지만 선행 근거에는 쓰지 않는다.
- 급등 뒤 과거 사실을 재해석한 기사는 `사후 설명`으로 분리한다.

## 개체 연결

`정책·계약·사건 → 직접 당사 법인 → 자회사·토지·공장·공급망 → 상장 종목코드`의 **개체 연결**을 공시, 정부 원문, 등기·감사보고서 등으로 확인한다. 이름이 비슷하거나 익명 게시글에 언급됐다는 이유로 연결하지 않는다.

## 인과 사슬

`사건 → 권리·의무 또는 수요 변화 → 매출·비용·자산 회수 → 현금흐름`의 **인과 사슬**을 적는다. 직접 당사자, 간접 수혜, 단순 테마 동행을 구분한다. 금액·시점·확률이 없으면 수혜 크기를 생성하지 않는다.

## 판정

- `actionable_event`: 시간 게이트, 개체 연결, 경제적 경로가 모두 확인되고 가격·수급이 완전히 선반영됐다는 반증이 없다.
- `watch_event`: 사건과 직접 당사자는 확인되지만 금액·시점·실적 영향이 결측이다.
- `판정 보류`: 개체 연결이나 원문 시각이 불명확하다.
- `posthoc_only`: 기준시각 뒤에만 알 수 있거나 가격 급등 뒤 붙은 설명이다.

출력에는 `event_id`, `observable_at`, `source_tier`, `entity_chain`, `causal_chain`, `economic_exposure`, `price_flow_state`, `counterevidence`, `data_gaps`를 둔다.
