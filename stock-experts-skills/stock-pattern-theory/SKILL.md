# stock-pattern-theory — 고전 패턴 이론 / Elliott·Wyckoff派 매니저

> **시장상품 공통 게이트**: 패턴 판정 전 `_shared/market-instruments-and-sessions.md`에서 현물·선물·ETF, venue·세션·롤·기업행동을 확인한다. 세션 단절과 연속선물 조정을 파동으로 오인하지 않는다.

## 정체성

시장을 **군중심리가 만드는 반복적·프랙탈 구조**로 보고, Elliott Wave(구조·타깃)와 Wyckoff(기관 행동·국면)로 차트를 해석한다. "어디까지·왜"를 묻는 보조 분석가 — 단독 매매보다 다른 기술 스킬의 구조적 맥락 제공에 강하다.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 파동 구조·국면 카운트 | 추세 단계 매매 (→ trend) |
| 피보 되돌림·확장 타깃 | 모멘텀 돌파 (→ swing) |
| 기관 축적/분산 행동 | 분 단위 진입 (→ intraday) |

## Elliott Wave — 5-3 구조

- 추세 방향 **5파(충격/motive)** → 조정 **3파(A-B-C)** = 한 사이클(5-3). 프랙탈(상위~하위 단위 반복).
- **절대 규칙 3가지** (위반 시 카운트 무효):
  1. 3파는 1·3·5 중 가장 짧을 수 없다.
  2. 2파는 1파 시작점 아래로 100% 되돌리지 않는다.
  3. 4파는 1파 가격 영역과 겹치지 않는다(선물 예외 제외).
- **피보나치**: 되돌림/확장 0.236·0.382·0.5·0.618·1.0·1.618·2.618. 2파≈1파 0.618, 4파≈3파 0.382가 흔함. 정확 타깃 아닌 **빈도 높은 종료 구간**.

## Wyckoff — 축적/분산 사이클

- 시장 4국면: **Accumulation → Markup → Distribution → Markdown**. Composite Man(거대 기관) 의도를 가격·거래량으로 역추적.
- **Accumulation 5단계(A~E)**: A 매도클라이맥스(SC) → B 매집 → **C Spring(거짓 하향돌파 후 반등=핵심 매수신호)** → D SOS·상단 돌파 → E Markup. Distribution은 거울상(UTAD가 Spring의 반대).
- **3법칙**: 수요-공급 / 원인-결과(횡보 폭이 추세 크기 결정, P&F로 목표 측정) / 노력-결과(거래량 vs 가격변동 괴리=전환 단서).

## 쉽게 이해하기 (비유)

- **Elliott 5-3 파동** = 밀물·썰물처럼 크고 작은 파동이 같은 리듬으로 반복되는 것. 밀물이 5번 밀려오고(추세 5파) 한 번 빠졌다가(조정 3파) 다시 밀려온다 — 이 리듬이 하루짜리 잔파도에도, 몇 년짜리 큰 파도에도 똑같이 들어있다(프랙탈).
- **Composite Man** = "숨어서 물량을 쌓는 큰손 딜러" 비유. 개인은 소량이라 시장가로 바로 체결되지만, 큰손은 물량이 너무 커서 티 안 나게 오래 걸려 사 모으고(Accumulation), 다 모으면 값을 슬슬 올려 팔아치운다(Distribution) — 그 흔적을 거래량·가격 패턴으로 역추적하는 것이 Wyckoff.
- **Spring** = 그네를 밀기 전에 살짝 뒤로 당기는 동작. 가격이 지지선을 잠깐 거짓으로 뚫고 내려가 겁먹은 개미들의 투매를 유발한 뒤(약한 손 털어내기) 바로 반등 — "진짜 붕괴"와 구분하려면 그 하향 돌파 구간에서 거래량이 오히려 줄어드는지를 확인한다(공급이 말랐다는 신호).
- **초보자 walkthrough**: ①먼저 큰 그림(Wyckoff 국면: 지금 모으는 중? 파는 중?) ②그 안에서 몇 번째 파동인지(Elliott) ③절대 3규칙으로 그 카운트가 말이 되는지 검증 ④피보로 "여기까지 갈 수도" 구간 표시 ⑤무효화 레벨 하나 정해두고, 깨지면 미련 없이 버린다 — 순서만 지키면 파동 이름을 몰라도 구조는 읽힌다.

## 두 방법의 결합

상호 보완 — Wyckoff Accumulation이 Elliott Wave 1·2에 대응하는 경우가 많음. Wyckoff="왜·누가", Elliott="구조·어디까지".

## 분석 워크플로우

1. 큰 시간대에서 현재 국면(Wyckoff) + 파동 위치(Elliott) 1차 카운트.
2. 절대 규칙으로 카운트 유효성 검증(위반 시 대안 카운트 제시).
3. 피보 되돌림·확장으로 목표·무효화 레벨 산출.
4. 거래량으로 노력-결과 점검(Spring/SOS 확인).
5. 결론 — 주(主) 카운트 + 대안 카운트 + 무효화 레벨. **확정적 단정 금지, 시나리오로 제시.**

## 판정 분기 & 데이터 거부 시 처리

| 상황 | 처리 |
|---|---|
| 절대 3규칙 통과 + 거래량(노력-결과) 확인 + 다른 신호와 confluence | 주 카운트 채택, 단정 아닌 **시나리오**로 제시 |
| 절대 3규칙 위반 | 카운트 **무효** → 대안 카운트 제시 |
| 무효화 레벨 돌파 | 즉시 카운트 폐기(재라벨 금지 — Prechter 교훈) |
| 카운트가 둘 이상 유효(모호) | **주 + 대안 + 무효화 레벨** 병기, 확률로 가중 |
| 거래량·수급 데이터 결측 | 가격 구조만으로 잠정 카운트, "노력-결과 검증 불가" 분리. 외국인·기관 순매수를 Composite Man 보조 증거로 폴백 |
| 사용자가 데이터 제공 거부 | partial 결론 + 신뢰도(상/중/하), 전체 보류 금지. 단독 매매신호 금지·유동성 높은 종목 한정. 투자자문 아님·자기책임. |

**"확인 필요" 4요소 예시** (거래량 결측 상황): ①**무엇이 막혔나** — Spring 구간의 거래량 데이터가 없어 노력-결과 검증 불가. ②**누가·어디서** — 사용자가 HTS·데이터 벤더에서 해당 구간 일별 거래량을 조회해 제공. ③**기대 결과** — 거래량 감소 확인되면 Spring 신뢰도 상향, 증가·불변이면 "거짓 Spring(진짜 붕괴)" 가능성으로 재평가. ④**부분 결론** — 가격 구조만으로 잠정 Wave 2 마무리 카운트 제시하되 "노력-결과 검증 불가"로 별도 표기, 신뢰도 "중" 이하로 하향.

## 거장의 실전 규율 (검증된 엣지)

- **학술 평결**: Lo-Mamaysky-Wang(J.Finance 2000) — 패턴을 **자동 인식하면 일부 증분 예측력 보유**(특히 유동성 높은 종목, 1962–96). 완전 무의미는 아니다.
- **단 주관성이 최대 약점**: 재량적 패턴 읽기(특히 **Elliott 카운트**)는 사후확증·재라벨로 **반증 곤란**. "이상 탐지 최적 패턴 ≠ 수익 최적"(LMW).
- **거장 규율**: Wyckoff(Composite Man·Spring/SOS·3법칙·**거래량 확인**), Elliott(절대 3규칙 + **주 카운트 + 대안 + 무효화 레벨** 시나리오).
- **단독 신호 금지**: 패턴은 추세·거래량·펀더와 **confluence**로만. 무효화 레벨로 반증 가능하게(무한 변명 경계). 유동성 높은 종목에서만.
- **breadth 국면 인지**: 2023-2025 미국 Magnificent 7·2025 국내 반도체 쏠림처럼 소수 종목이 지수를 견인하는 국면에서는 시총가중 벤치마크 대비 RS·SOS/SOW 판정이 왜곡됨 — 상세는 아래 "스크리너 구현 가드레일" 참조.

> 상세: `references/evidence-and-master-playbook.md`. 예측력은 약하고 체계화·유동성 의존 — 맥락·확률 도구로 한정.

### 실전 케이스 — Prechter의 양면 (1987 / 1990s)

엘리어트 이론가 Robert Prechter는 1987년 10월 초 매도를 권고했고 직후 Black Monday(10/19, 다우 **−22.6%**)가 와 명성을 얻었다. 그러나 같은 카운트 체계로 이후 1990년대 대세 상승장 내내 약세를 유지해 추종자들은 사상 최대 강세장을 통째로 놓쳤다. 교훈: ① 파동 카운트의 한 번의 극적 적중은 체계의 검증이 아니다 ② 무효화 레벨이 깨졌으면 카운트를 버려야 하는데, "더 큰 파동의 조정"으로 재라벨하는 순간 반증 불가능한 신앙이 된다 — 이 스킬이 주 카운트+대안+무효화를 강제하는 이유.

## KRX 적용

- 지수·대형주처럼 **유동성 큰 종목**에서 파동·국면이 비교적 깨끗 — 소형주는 거래량 왜곡으로 신뢰도↓.
- **±30% 가격제한**으로 1파/3파 연장(extension)이 미국 대비 압축되어 나타날 수 있음.
- 외국인·기관 순매수 데이터를 Wyckoff "Composite Man" 행동의 보조 증거로 활용(국내 특유 수급 지표).
- 테마·정책 이슈로 충격파가 펀더멘털과 무관히 발생 → 거래량·수급으로 교차검증.
- **메가캡 쏠림 국면 주의**: 삼성전자·SK하이닉스 등 소수 종목이 KOSPI 시가총액가중지수 수익률을 독점하는 국면에서는 나머지 종목 대다수가 "지수 대비 약세"로 왜곡 표시됨(2023-2025 미국 Magnificent 7·S&P 500 쏠림과 구조적으로 동일 — 아래 가드레일 참고). 시장구조 상세는 `~/.claude\stock-experts\_shared\krx-market-structure-2026.md` 참조(다른 스킬과 병행 작성 중이라 아직 파일이 없을 수 있음).
- **단일종목 레버리지 상품**(국내 2026-05-27 첫 출시, 기초자산 삼성전자·SK하이닉스)의 일별 리밸런싱 수급이 대형주 캔들 형태·종가 근접 패턴을 왜곡할 가능성 — 대형주 패턴 신뢰도는 이 시점 이후 데이터로 재검증 필요("확인 필요": 국내 정량 실증 아직 없음).

## 스크리너 구현 가드레일

패턴/파동 이론을 자동 추천 시스템(코드)으로 옮길 때 발생하는 구조적 맹점 — 사람이 눈으로 볼 때는 자연스럽게 걸러지던 왜곡이 알고리즘에서는 그대로 신호가 된다.

- **벤치마크 선택 원칙**: 패턴 완성 신호의 RS(상대강도) 확인 필터를 시총가중 지수(KOSPI 등) 단일 의존 금지. **동일가중 지수** 또는 **메가캡(시총 상위 1~2종목) 제외 지수**를 병행 계산해 "지수 대비"와 "동일가중/ex-메가캡 대비"가 크게 어긋나면 쏠림 국면으로 별도 표시.
- **breadth·Wyckoff SOS/SOW 왜곡 감지**: 상승종목수/하락종목수(advance-decline)가 지수 수익률과 반대로 움직이거나(지수↑ but decline종목多), 소수 종목의 지수 기여도가 비정상적으로 클 때 → **패턴/국면 판정 신뢰도를 자동 하향**(확신도 1단계 강등)하고 거래량·수급 등 확인 지표를 추가 요구. Wyckoff SOS(Sign of Strength)·SOW가 실제로는 개별 종목이 아닌 지수 구성 편중을 반영할 수 있음을 명시.
- **최소 필요 데이터**: 종목별 OHLCV, 동일가중/ex-메가캡 벤치마크 시계열, advance-decline(상승/하락 종목수), 외국인·기관 순매수.
- **흔한 구현 오류**: ① 패턴 인식 파라미터를 과거 성공 사례에 맞춰 조정하는 과적합·사후확신 편향(hindsight bias) ② 상장폐지·거래정지 종목을 데이터셋에서 제외해 생기는 생존편향(survivorship bias) — 백테스트 성공률이 실제보다 부풀려짐 ③ 캔들 패턴 계산 시 아직 마감되지 않은 당일봉을 완성봉처럼 인덱싱하는 정렬 오류(look-ahead bias)로 이어짐.
- 상세 리서치·출처는 `references/evidence-and-master-playbook.md` 4절 참조.

### 계산기 빠른 사용 예시 (copy-paste)

데모 그대로 실행(가상 지수 2,350→2,720 상승 파동):
```bash
python scripts/fib_levels.py
# 되돌림: {'0.236': 2632.7, '0.382': 2578.7, '0.5': 2535.0, '0.618': 2491.3, '0.786': 2429.2}
# 확장(되돌림 저점 2,580 기준): {'1.0': 2950.0, '1.272': 3050.6, '1.618': 3178.7, '2.618': 3548.7}
# 무효화 레벨: {'Wave 2 무효화 레벨': 2350, ...}
```
내 종목 값으로 바꿔 쓰려면 함수를 직접 임포트:
```python
from fib_levels import retracements, extensions, invalidation
retracements(swing_low=71000, swing_high=85000)          # 2파 되돌림 구간
extensions(swing_low=71000, swing_high=85000, retrace_low=76000)  # 3파 목표 구간
invalidation(wave1_start=71000)                            # 무효화 레벨
```
암산용 근사 공식: `되돌림 = 고점 - (고점-저점) × 비율`, `확장 = 기준점 + (고점-저점) × 비율` (0.618/1.618 우선 확인).

## 한계

**사후확증·주관성**이 가장 큰 약점 — 카운트가 분석가마다 다르고 틀리면 "상위 파동"으로 재라벨 가능(반증 곤란). 자기실현·자기파괴 모두 가능. Gann(각도·시간주기)은 실증 근거가 더 약함. 따라서 단독 매매신호보다 **맥락·시나리오 도구**로 쓴다.
