# 레퍼런스 — Elliott Wave & Wyckoff Method

> 원저작: R.N. Elliott *The Wave Principle*(1938); Richard Wyckoff *Studies in Tape Reading*(1910).
> vault 소스: `sources/stock-investing/elliott-wave-wyckoff-method.md`. 스킬 실행용 가공본.

## 1. Elliott Wave — 5-3

추세 5파(충격) → 조정 3파(A-B-C). 프랙탈. 1·3·5 추진, 2·4 조정.

### 절대 규칙 3 (위반=무효)
1. 3파는 1·3·5 중 최단일 수 없다.
2. 2파는 1파 시작점 아래로 안 내려간다.
3. 4파는 1파 영역과 안 겹친다(선물 예외).

### 피보나치
되돌림/확장 0.236·0.382·0.5·0.618·1.0·1.618·2.618. 2파≈0.618×1파, 4파≈0.382×3파. 정확 타깃 아닌 빈도 구간.

## 2. Wyckoff — 축적/분산

4국면: Accumulation→Markup→Distribution→Markdown. Composite Man을 가격·거래량으로 역추적.

### Accumulation 5단계
A 매도클라이맥스(SC)/PS → B 매집 → **C Spring(거짓 하향돌파 후 반등=핵심 매수신호)** → D SOS·상단 돌파 → E Markup. Distribution 거울상(UTAD=Spring 반대).

### 3법칙
수요-공급 / 원인-결과(횡보 폭→추세 크기, P&F 목표) / 노력-결과(거래량 vs 가격 괴리=전환 단서).

## 3. 결합

Wyckoff Accumulation ↔ Elliott Wave 1·2. Wyckoff="왜·누가", Elliott="구조·어디까지".

## 4. Gann (보조)

각도·시간주기 기반, 더 신비주의적 → 실증 근거 약함. 참고만.

## 5. KRX 적용

유동성 큰 지수·대형주에서 신뢰↑. ±30% 제한으로 파동 연장 압축. 외국인·기관 순매수를 Composite Man 보조 증거로. 테마 충격파는 거래량·수급 교차검증.

## 5.5 심화 — SKILL.md 비중복

- **교대 법칙(alternation)**: 2파가 급격·깊은 조정이면 4파는 완만·횡보(또는 반대) — 다음 조정의 '형태'를 좁히는 실전 단서.
- **연장(extension)**: 충격 1·3·5파 중 **하나만** 연장되며 대개 3파. 3파 연장이면 5파는 1파와 길이 유사 → 목표 산출의 기본 가정.
- **파동 등급(degree) 표기**: 카운트는 반드시 상위 등급 맥락 안에서 — "일봉의 5파"가 "주봉의 3파 내부"인지 명시해야 재라벨 꼼수를 막는다(무효화 레벨도 등급별로).
- **Wyckoff P&F 목표 산출**: 원인-결과 법칙의 실행 — 트레이딩 레인지의 **가로 폭(칸 수) × 박스값 × 반전값**을 돌파점에 더해 목표. 횡보가 길수록 추세가 크다의 정량화.
- **거래량-국면 매칭**: SC(매도클라이맥스)는 거래량 폭증, **Spring은 저거래량이 이상적**(팔 사람이 없다는 증거), SOS 돌파는 다시 거래량 증가 — 국면 라벨마다 '맞는 거래량'이 있고, 어긋나면 라벨을 의심하라.
- **ST·LPS 재테스트**: 진입은 Spring/SOS 당일 추격보다 **재테스트(ST in B, LPS)** 에서 — 리스크(직전 저점)가 명확해 손익비가 좋다.

## 6. 비판과 한계

사후확증·주관성(카운트 분기, 재라벨로 반증 곤란). 자기실현/파괴 모두 가능. Gann 근거 약함. → 단독 신호보다 맥락·시나리오 도구.
