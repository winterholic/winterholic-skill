# 레퍼런스(심화 2) — Elliott 고급 패턴 · Wyckoff 이벤트 상세

> 목적: 기본 5-3 구조를 넘어 **Elliott 6대 패턴·다이애고널·조정 조합**과 **Wyckoff 국면 내 이벤트(약어)** 를 실전 카운팅 수준으로.
> 웹 출처: elliottwave-forecast·stockcharts ChartSchool·elliott-wave-trading, Wyckoff 표준 용어.

## 1. Elliott 6대 패턴

1. **Impulse(충격)**: 5파(1-2-3-4-5), 3대 규칙 적용(3파 최단 불가·2파 100% 미초과·1-4 불중첩).
2. **Diagonal(다이애고널, 쐐기형)**:
   - **Leading diagonal**: 1파 또는 A파 위치, 5-3-5-3-5, 1·4 중첩 허용.
   - **Ending diagonal**: 5파 또는 C파 위치, 3-3-3-3-3, 추세 소진 신호.
3. **Zigzag(지그재그)**: 조정, 5-3-5(A-B-C), 날카로운 조정.
4. **Flat(플랫)**: 3-3-5(A-B-C), 횡보 조정. **Regular / Expanded / Running** 3종.
5. **Triangle(삼각)**: 3-3-3-3-3(A-B-C-D-E), 힘의 균형, 보통 마지막 파동 직전.
6. **Combination(조합)**: 조정의 횡보 연장(W-X-Y 등).

### 카운팅 가이드라인
- **교대(alternation)**: 2파가 날카로우면 4파는 완만(반대도). 
- **3파 연장(extension)**: 충격파 중 한 파동이 흔히 연장(보통 3파).
- 피보 비율로 파동 길이·되돌림 검증(→ elliott-wyckoff 기본편).

## 2. Wyckoff 이벤트 (국면 내 표지)

### Accumulation
- **PS**(Preliminary Support) → **SC**(Selling Climax, 매도 절정) → **AR**(Automatic Rally, 자동 반등) → **ST**(Secondary Test) → **Spring/Shakeout**(거짓 하향 돌파) → **Test**(스프링 재확인) → **SOS**(Sign of Strength) → **LPS**(Last Point of Support) → Markup.

### Distribution (거울상)
- **PSY**(Preliminary Supply) → **BC**(Buying Climax) → **AR** → **ST** → **UTAD**(Up-Thrust After Distribution, 거짓 상향 돌파) → **SOW**(Sign of Weakness) → **LPSY**(Last Point of Supply) → Markdown.

### 핵심 매매 포인트
- **Spring** 후 Test에서 거래량 축소 확인 → 매수(저위험 진입).
- **SOS** 돌파 + **LPS** 되돌림 = 추가 매수.
- **UTAD**·**LPSY** = 분배 매도/공매도 신호.

## 3. 결합 운용

- Wyckoff 이벤트로 "국면·전환점"을, Elliott 파동으로 "구조·목표"를, 캔들/거래량으로 "확인"을. 시간대별 중첩.
- Wyckoff Accumulation Phase C(Spring) ≈ Elliott Wave 2 저점에 자주 대응.

## 4. KRX 적용

- 유동성 큰 지수·대형주에서 이벤트가 선명. ±30% 제한으로 Spring/UTAD의 폭이 압축.
- 외국인·기관 순매수를 Composite Man(거대 기관) 행동의 보조 증거로.

## 5. 비판과 한계

고급 패턴일수록 **카운트 분기·재라벨 여지** 증가 → 반증 곤란(사후확증). 다이애고널·조합은 특히 주관적. 단정 금지, **주 카운트 + 대안 카운트 + 무효화 레벨**로 시나리오 운용.
