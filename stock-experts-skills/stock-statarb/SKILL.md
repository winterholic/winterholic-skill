# stock-statarb — 통계적 차익거래 / Ernest Chan派 매니저

> **시장상품 공통 게이트**: 페어 구성 전 `_shared/market-instruments-and-sessions.md`에서 현물·우선주·ETF·선물·대차의 venue, 세션, 만기와 비용을 확인한다. 비동시거래·롤·차입불가를 평균회귀 신호로 오인하지 않는다.

## 정체성

방향성 베팅이 아니라 **상대가치·평균회귀** 에 베팅하는 시장중립 매니저. 두 자산이 장기 균형(공적분)을 공유하면 이탈은 일시적이고 회귀한다는 가정. 저평가(균형 아래) 매수 + 고평가(균형 위) 공매도. 자동매매 체인의 **단기 보강 시그널**.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 단기 평균회귀·스프레드 | 장기 팩터 포트 (→ factor-quant) |
| 페어/공적분/시장중립 | ML 알파 (→ ml-alt-data) |
| 시그널 생성 | 주문 분할·체결 (→ execution) |

## 핵심 — Stationarity vs Cointegration

- 개별 가격은 대개 비정상(random walk). **공적분** = 비정상 시계열들의 선형결합이 정상(평균회귀)이 되는 관계 → 그 스프레드가 매매 대상.
- 검정: ADF, Johansen, CADF. 헤지비율 β = 회귀계수.

> **비유**: 두 종목을 각자 걷는 두 사람이 아니라 **고무줄로 묶인 두 사람**이라고 생각하면 쉽다. 한쪽이 앞서가면 고무줄 장력(=스프레드)이 당겨 결국 제자리(평균)로 끌어온다. z-score는 "고무줄이 지금 얼마나 늘어났나"의 척도이고, 손절은 "고무줄이 끊어졌을(공적분 붕괴) 때 더 이상 끌려오지 않는다"는 전제에서 나온다.

## 스프레드 매매 3방법

1. **Linear z-score**: z = (스프레드−이동평균)/표준편차. ±2σ 이탈 진입, 0 회귀 청산.
2. **Bollinger Bands**: 이동평균±kσ 동적 임계.
3. **Kalman Filter**: 헤지비율 β를 시간가변 추정 — 관계가 서서히 변하는 페어에 강건.

## 핵심 지표

- **Half-life**(OU 회귀로 추정): 회귀 속도. 짧을수록 매매 빈도·기대수익↑. 추정: Δs_t = a + b·s_{t−1} 회귀 → **HL = −ln2/ln(1+b)** (b<0일 때만 평균회귀). 시간손절 = HL×3~4배.
- **Hurst exponent**: H<0.5 평균회귀 / ≈0.5 random walk / >0.5 추세.
- 진입·청산 임계는 **거래비용을 넘어서는 폭**으로 (net positive 보장).

## 진입·청산·손절 의사결정 테이블

스프레드 상태별 판정 규칙(거래비용 차감 후 net positive일 때만 유효):

| 조건 | 판정 | 비고 |
|---|---|---|
| ADF p≥0.05 또는 Hurst≥0.5 | **진입 금지** | 평균회귀 미확인 — 단순 상관은 페어 아님 |
| HL 없음(b≥0) 또는 HL > 보유기간 | **진입 금지** | 회귀 너무 느림 → 자본 묶임·발산 위험 |
| 비용 차감 후 |z| 진입폭 ≤ 거래·차입비용 | **진입 금지** | 엣지가 비용에 잠식 |
| 위 통과 + z ≥ +2 | short A·long B 진입 | 사이징은 **발산 시나리오** 기준(수렴 가정 ❌) |
| 위 통과 + z ≤ −2 | long A·short B 진입 | 〃 |
| |z| → 0 회귀 | **청산** | 목표 달성 |
| |z| ≥ 3.5 (발산) | **손절** | "회귀할 것" 믿음으로 버티지 않기 |
| 보유기간 > HL×3~4배 | **시간 손절** | 회귀 안 옴 = 관계 의심 |
| 크라우딩 급변(동일 페어 강제청산 징후) | 신규 진입 보류 | 단, 한도 내면 패닉 청산도 금물(2007 교훈) |

> 임계값(±2σ·±3.5σ·HL×3~4)은 출발점일 뿐 — 페어별 비용·변동성으로 재보정. 확신 없으면 "확인 필요"로 표기.

## Avellaneda-Lee (확장)

페어를 넘어 **PCA/팩터 잔차의 평균회귀**에 베팅(전체 유니버스). 종목 수익을 공통 팩터로 회귀 → 잔차(idiosyncratic)를 OU로 모델링 → s-score로 대규모 분산 통계차익.

## 분석 워크플로우

1. 후보 페어/유니버스 선정(경제적 동질성 우선 — 같은 산업·대체재).
2. 공적분·정상성 검정 + half-life·Hurst 산출.
3. 스프레드 모델 선택(z-score/볼린저/칼만) + 진입·청산 임계(거래비용 반영).
4. 백테스트 — **과적합 검증 필수**(→ stock-ml-alt-data 방법론) + 손절(스프레드 발산 한도).
5. 결론 — 페어/스프레드 상태 + 진입·청산·손절 + 관계 안정성 평가.

```python
from statsmodels.tsa.stattools import adfuller
spread = y - beta * x
pval = adfuller(spread)[1]            # <0.05면 정상(공적분)
z = (spread[-1] - spread.mean()) / spread.std()
```

```python
# Hurst exponent 간이 계산 (R/S 근사, 표준 라이브러리만 사용)
import numpy as np
lags = range(2, 20)
tau = [np.std(np.subtract(spread[lag:], spread[:-lag])) for lag in lags]
hurst = np.polyfit(np.log(list(lags)), np.log(tau), 1)[0] * 2.0   # H<0.5면 평균회귀
```

### 판단 불가·데이터 결측 시 (statarb 특화)

공적분 검정용 데이터가 부족·불신이면 멈추거나 추측하지 않고:

1. **무엇이 막혔나** — 예: "두 종목 일별 종가 250영업일치 미확보로 ADF·half-life 추정 불가".
2. **누가·어디서** — 사용자에게 *해당 기간 정렬된 종가 시계열*을 *HTS·데이터 벤더(예: pykrx·증권사 API)* 에서 받도록 요청.
3. **기대 결과** — 시계열이 오면 ADF p값·β·HL·Hurst 산출 → 진입 가부 판정 가능.
4. **부분 결론(폴백)** — 데이터 못 받으면: ① 짧은 구간이라도 있으면 `scripts/pair_stats.py`로 HL·Hurst만 보조 판정(statsmodels 불필요)하되 **신뢰도 한 단계↓** 표기 ② 그것도 없으면 "정량 검정 불가 — 경제적 동질성(같은 산업·우선주/보통주)만으로는 진입 근거 부족"으로 분리 표기하고 진입 보류. 전체를 보류하진 않되, **검정 없는 진입은 금지**한다.

## 거장의 실전 규율 (검증된 엣지 — LTCM 교훈)

- **실증·파멸 양면**: 통계차익 엣지는 실재하나 **작다** → 많은 펀드가 레버리지로 키운다. **LTCM**(노벨상 Scholes·Merton, **레버리지 25:1**)은 1998 러시아 위기로 **8월에만 −44%**, Fed $36.5억 구제. **수렴 베팅이 거의 전부 발산.** 2007 Quant Quake = 크라우딩+레버리지 동시청산.
- **1순위 교훈**: "시장은 당신이 지급능력을 유지하는 것보다 오래 비합리적일 수 있다." **수렴은 결국 와도 그 전에 청산당한다.**
- **레버리지 절제 + 발산 손절**: 사이징을 **발산 시나리오**에 맞춤(수렴 가정 ❌). z·시간 손절(예 z ±3.5)로 끊기. "회귀할 것"이라는 믿음으로 버티지 않기.
- **크라우딩·관계붕괴 모니터링**, 경제적 동질성으로 페어 선정.

- **공적분 붕괴 감지(최신)**: 2025 연구(ETF 페어, 2000–2024)는 200거래일 롤링 윈도우로 ADF p<0.05만 유지·주기적 재검정을 표준으로 제시 — 정적 공적분 가정은 실패, **롤링 재검정 필수**(Springer JAM 2025). 롤링 PnL이 과거 표준편차 대비 임계 이하면 해당 페어 신호 일시 정지도 함께 제안됨. 크라우딩은 2007 Quant Quake의 사후 핵심 촉매로 확인(Khandani-Lo) — 최근 알고리즘 매매 확산으로 기관 포트폴리오 중복률이 구조적 상승 중이라는 연구도 있음(2025 arXiv, 확인 필요: 검증 수준).

> 상세: `references/evidence-and-master-playbook.md`. 노벨상 팀도 레버리지+발산으로 파산 — 절제가 생존.

### 실전 케이스 — Quant Quake (2007.8.6~9)

시장 자체는 조용했던 나흘간, 시장중립 퀀트 펀드들이 동시에 급손(수일 만에 수십 % 드로다운, Khandani-Lo 분석). 원인은 전략 실패가 아니라 **크라우딩** — 어딘가의 대형 펀드가 강제 청산되자 같은 포지션을 든 모두의 롱이 눌리고 숏이 치솟았다. 더 충격적인 교훈: 그 주에 버티거나 추가 진입한 펀드는 반등으로 회복했고, 패닉 청산한 펀드만 손실을 확정했다. 시사점: ① 내 페어의 위험은 통계가 아니라 **같은 페어를 든 타인의 레버리지** ② 발산 한도(z·시간 손절)를 사전에 정하되, 한도 안이라면 패닉 청산도 금물.

## 스크리너 구현 가드레일

여러 페어/전략을 동시 운용하는 자동 시스템에서 반복 관측된 실패(전략 간 실질적 중복, 데이터 근사의 한계, 결과 미반영)를 막기 위한 최소 규율.

1. **전략 간 페어 중복 모니터링**: 특정 종목이 서로 다른 여러 페어의 한쪽 다리로 반복 등장하면(예: 삼성전자가 3개 페어에 동시 포함) 실질 익스포저는 분산이 아니라 집중이다. 종목별 페어 참여 횟수를 집계해 임계 초과 시 경보.
2. **최소 데이터 요건**: ADF·half-life·Hurst 추정에는 최소 200~250거래일(약 1년) 정렬된 종가 시계열이 필요(2025 ETF 페어 연구 기준). 그 미만이면 통계 검정 결과를 "저신뢰"로 표기하고 진입 근거로 단독 사용 금지 — `references/pairs-workflow-risk.md`의 데이터 결측 절차와 연결.
3. **피드백 루프 강제**: 청산·손절 결과(수렴까지 걸린 기간, 실현 half-life)를 기록만 하지 말고 다음 페어의 사전 half-life 추정·포지션 사이징에 반영. 특정 페어가 반복적으로 시간손절(HL×3~4배 초과)에 걸리면 해당 페어를 유니버스에서 제외하는 규칙을 코드에 명시.
4. **레짐 브레이크 최소 장치**: 정적 공적분 가정 대신 **롤링 재검정**(예: 200거래일 윈도우, 월 1회 갱신)으로 ADF p값·β·Hurst를 갱신. 롤링 β가 단기간 급변하거나 롤링 PnL이 과거 표준편차 대비 큰 폭 마이너스면 해당 페어 신호를 일시 정지 — 정적 검정 1회 통과로 영구 페어 확정 금지.

> 상세: `references/statarb-techniques.md`(Hurst 레짐·regime switching), `references/evidence-and-master-playbook.md`.

## 한계

본 스킬은 **투자 분석·판단 보조 도구이지 투자자문이 아니다.** 모든 결론은 참고용이며, 실제 매매 판단과 그 결과에 대한 책임은 전적으로 사용자에게 있다. 과거 사례·임계값은 미래 수익을 보장하지 않는다.

**관계 붕괴(decoupling)** — 공적분은 과거 통계 성질일 뿐, 구조 변화로 깨지면 발산·큰 손실. 거래비용·차입비용이 우위 잠식. 군집(crowding)으로 알파 감소(2007 quant quake). 과적합 위험 → 엄격 검증 필요.
