# 레퍼런스(심화) — 센티먼트 지표 & 버블 해부 (Minsky·Kindleberger)

> 목적: 심리를 **측정 가능한 지표**로, 버블을 **단계 모델**로. 역발상(contrarian) 타이밍의 근거.
> 웹 출처: 행동재무 종설(sentiment), Kindleberger *Manias, Panics and Crashes*·Minsky 통념, put/call·AAII 통념.

## 1. 센티먼트 지표 (과열↔공포 측정)

| 지표 | 과열(탐욕) | 공포 |
|---|---|---|
| Put/Call ratio | 낮음(콜 쏠림) | 높음 |
| VIX/VKOSPI | 저변동(안주) | 급등(패닉) |
| AAII Bull-Bear | 강세 과다 | 약세 과다 |
| Fear & Greed Index | Greed | Fear |
| 신용융자·마진부채 | 사상 최고 | 급감(반대매매) |
| 펀드 플로우·예탁금 | 대량 유입 | 유출 |
- **역발상**: 극단적 탐욕 = 경계, 극단적 공포 = 기회(단 타이밍은 부정확).

## 2. 버블 해부 — Kindleberger/Minsky 5단계

1. **Displacement(촉발)**: 신기술·정책 등 새 기회.
2. **Boom(붐)**: 신용 확장·가격 상승.
3. **Euphoria(도취)**: "이번엔 다르다", 레버리지·신규 진입 급증.
4. **Profit-taking(차익실현)**: 스마트머니 이탈.
5. **Panic(패닉)**: 신뢰 붕괴·투매·디레버리징.
- **Minsky Moment**: 과도한 부채가 작은 충격에 연쇄 청산되는 전환점.

## 3. Shiller·Marks 연결

- 피드백 루프 + "new era" 서사([[kahneman-shiller-marks]] Shiller). Marks 진자(탐욕↔공포)·리스크의 역설과 동일 구조.
- CAPE 등 밸류 + 센티먼트 + 신용 데이터의 **삼각 확인**으로 국면 판단.

## 4. 역발상 실행 규율

- 극단 신호는 **방향**을 주되 **타이밍은 부정확**("싼 게 더 싸짐") → 분할·단계적, 사전규칙으로.
- 군중 반대편은 외롭고 길다 → 포지션 사이징·인내([[stock-portfolio-risk]]).

## 5. 정보 활용

- 옵션 시장(put/call·skew), 변동성지수, 설문(AAII), 수급(신용·예탁금·외국인), 미디어 톤(NLP, → [[alt-data-nlp-sentiment]]).

## 6. KRX 적용

- **신용융자 잔고·고객예탁금·개인 순매수**가 한국 과열/공포의 실효 지표. 반대매매 급증=공포 정점.
- VKOSPI, 테마주 회전율, 커뮤니티 버즈. 코리아 디스카운트로 CAPE는 자국 역사 밴드로.

## 7. 비판과 한계

센티먼트 극단은 **더 극단으로** 갈 수 있음(타이밍 도구 부적합). 지표 임계는 시대·구조 변화에 민감. 버블 단계는 사후에 명확(실시간 판정 어려움). 역발상은 옳아도 시점이 빗나가면 큰 고통.
