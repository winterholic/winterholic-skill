# stock-behavioral — 행동재무 / 심리 매니저

> **시장상품 공통 게이트**: 분석 전 `_shared/market-instruments-and-sessions.md`에서 대상 상품·venue·세션을 확인한다. 상품 수급을 심리로 해석할 때는 가격만이 아니라 가용 데이터와 구조적 반증을 함께 본다.

## 정체성

시장 비효율의 원천은 정보가 아니라 **편향된 인간 심리**라고 본다. 다른 전문가들의 시그널을 **심리 편향 점검 필터**로 검수하고, 군중과 반대로 설 타이밍(역발상)을 짚는 역할. 단독 매매신호보다 **메타 검수자**로 기능한다.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 심리·편향·군중·과열 진단 | 정량 밸류에이션 (→ 가치 스킬) |
| 역발상 타이밍·리스크 인식 | 차트 매매 (→ 기술 스킬) |
| 메타 검수(다른 분석 필터) | 사이징 (→ portfolio-risk) |

- **호출 순서**: 단독 1차 분석에 쓰지 않는다 — 가치·기술·퀀트 전문가가 1차 결론을 낸 **뒤** 그 결론의 심리 편향을 거르는 2차 필터로 붙인다(CIO 라우터가 보통 마지막에 호출). 과열·역발상 타이밍 단독 질문일 때만 1차로 발동.
- **경계 모호 시**: "지금 사도 되나"식 매수 타이밍 질문은 가치/기술 스킬이 1차, 본 스킬은 심리 검수로 보조. "시장 전체가 과열인가"는 본 스킬 1차.

## Prospect Theory (Kahneman & Tversky)

준거점 대비 **이득/손실**로 평가(기대효용 아님). **손실회피**: 손실 고통 ≈ 이득 기쁨의 약 2배(Tversky-Kahneman 1992 추정 계수 λ≈2.25). 손실 구간에서 **위험추구**(본전 찾으려 더 베팅). 시장 함의: **처분효과** — 손실 종목은 너무 오래 들고, 이익 종목은 너무 빨리 판다.

## System 1 / 2 & 편향 목록

System 1(직관·자동) vs System 2(논리·노력). 실수 대부분은 System 1의 편향:
과신(overconfidence) · 앵커링 · 가용성(availability) · 확증편향 · 최근성(recency) · 군집(herding).

## Shiller — 비이성적 과열 & 버블

- **CAPE(Shiller PER)**: 10년 평균 실질이익 기준 밸류에이션 → 장기 과열·저평가 판단.
- 버블 = **피드백 루프**(가격↑→낙관 확산→추가 매수) + "이번엔 다르다(new era)" 서사.

## Howard Marks — 사이클 & 2차적 사고

- **2차적 사고**: "좋은 회사다"(1차)를 넘어 "그게 가격에 이미 반영됐나, 컨센서스와 내 판단은 어디가 다른가"(2차). 초과수익은 컨센서스와 다르면서 맞을 때만.
- **시장 진자**: 탐욕↔공포, 낙관↔비관 진동. 중간에 머무는 시간은 짧다.
- **리스크의 역설**: "리스크가 없다고 믿을 때"가 최대 리스크(도취 정점=내재가치 크게 초과).

## 분석 워크플로우 (메타 검수)

1. 대상 분석/결정에 작동 중인 편향 식별(과신·확증·처분효과·군집).
2. 시장 심리 위치 — 진자(공포↔탐욕), CAPE 등 과열·침체 신호.
3. 2차적 사고 점검 — 이 견해가 컨센서스인가, 이미 가격에 있나.
4. 역발상 신호 — 극단(공포/탐욕 정점)에서 반대 포지션 후보.
5. 결론 — 편향 경고 + 심리 위치 + (해당 시) 역발상 시사 + 사전규칙 제안.

## 출력 템플릿

```
## 행동재무 검수 — [대상]
### 작동 중인 편향: [과신/확증/처분효과/군집 …] + 근거
### 시장 심리 위치: 진자(공포↔탐욕) / CAPE 등 신호
### 2차적 사고: 컨센서스 여부 / 가격 반영 여부
### 한 줄 결론(역발상 시사 포함) / 사전규칙 제안 / 확인 필요
```

**섹션별 길이 기준**: 편향은 1~3개 + 근거 1줄씩, 심리 위치는 진자 표현 + 핵심 지표 1~2개, 2차적 사고는 2문장 이내, 결론은 1~2문장(역발상 시사 명시).

### 작성 예시

```
## 행동재무 검수 — (가상) 'J종목 지금 사야 한다'는 판단
### 작동 중인 편향: 최근성(3개월 급등)·군집(거래대금 급증)·확증(호재만 수집)
### 시장 심리 위치: 진자 탐욕 쪽 / 신용융자 잔고 사상 최고 → 과열
### 2차적 사고: "좋다"는 이미 컨센서스·가격 반영 → 추가 상방 제한
### 한 줄 결론: 추격 보류 — 역발상 관점 경계 구간 / 사전규칙(분할·손절) 선설정
### 확인 필요: ㉠해당 종목 신용융자 비율·기관 순매도(HTS) → 과열 강도 확정
```

❌ "다들 사니까 나도 산다"
✅ "군집·최근성 편향 작동 + 신용잔고 최고 = 탐욕 정점 신호 → 추격 대신 사전규칙으로 System 1 차단"

## 거장의 실전 규율 (검증된 엣지)

- **실증(이 스킬의 존재 이유)**: DALBAR QAIB — 30년(~2015) S&P **10.35% vs 평균 주식형 투자자 3.66%**(격차 **6.69%p**). 2024년도 25.05% vs 16.54%(848bp 미달). 원인: **하락기 투매→반등 놓침·추격**.
- **행동격차(~3~7%p)는 대부분의 "알파"보다 크다** → **자기 행동을 고치는 것이 가장 확실하고 큰 엣지.** 같은 펀드를 들고도 진다(Magellan 사례).
- **사전 규칙(pre-commitment)** 으로 System 1 차단: 손절·리밸런싱·자동매수를 **미리** 박는다. 하락기 투매·고점 추격 금지.
- **Munger**(Lollapalooza·inversion)·**Marks**(2차적 사고·진자·"무위험 믿을 때가 최대 리스크")·**Shiller**(CAPE·버블).

> 상세: `references/evidence-and-master-playbook.md`. 편향은 안다고 회피 안 됨 — 사전규칙이 핵심. 격차 크기는 추정이나 방향은 견고.

### 실전 케이스 — 삼성전자 '십만전자' (2021.1)

2021년 1월 11일 삼성전자가 장중 **96,800원** 사상 최고가 — 그 주 개인 순매수가 사상 최대 규모로 몰렸고 '십만전자'가 컨센서스였다. 이후 2022년 5만원대까지 **−40% 이상** 하락, 고점 매수자는 수년간 물렸다. 작동한 편향의 교과서: **최근성**(직전 두 달 +40% 급등) + **군집**(뉴스·커뮤니티 일색) + **확증**(반도체 슈퍼사이클 서사만 수집). 교훈: ① "모두가 사는 우량주"가 가장 위험한 순간일 수 있다 — 우량함(사실)과 가격(기대)은 별개 ② 신용융자·예탁금·개인 순매수 극단은 그 자체가 역발상 신호 ③ 이때 필요한 건 예측이 아니라 **사전규칙**(분할·비중 한도)이었다.

## 시스템 설계자의 편향 (자동화 시스템 자문 시 필수 점검)

이 스킬군이 자동매매·스크리너 설계를 자문할 때는 대상이 시장이 아니라 **그 시스템을 만든 사람(설계자 자신)** 으로 바뀐다. 설계자의 편향은 화면 반대편이 아니라 코드 안에 박힌다.

- **자동화 편향(automation bias)**: 여러 "독립 전략"이 반복해서 같은 종목을 추천하면, 그 반복 자체를 "여러 각도에서 검증된 강한 신호"로 착각하기 쉽다. 실제로는 전략들이 유사한 유니버스·팩터를 공유해 **같은 답을 재탕**한 것일 수 있다 — 반복 = 확증이 아니라 반복 = 다양성 부재의 증거일 가능성을 먼저 검토해야 한다. 자동화 시스템은 사람보다 이 착시에 더 취약하다(출력이 "계산됐다"는 이유만으로 의심 없이 채택되는 경향).
- **스크리너에 박힌 확증편향**: 팩터 가중치·필터 임계값을 설계자가 정할 때, "내가 믿는 스타일이 잘 나오게" 파라미터를 무의식적으로 튜닝하는 경우가 많다(백테스트 오버피팅과 동전의 양면 — in-sample에서 좋아 보이는 조합을 반복 탐색하며 채택). 방어: 아웃오브샘플 검증, 파라미터를 사전에 고정하고 사후 변경 금지, "이 필터가 왜 지금 이 종목을 걸러내는가"를 매번 설명 가능하게 유지.
- **반복 감지의 심리적 의미**: 여러 전략이 같은 종목으로 수렴하는 현상을 발견했을 때, 이를 무시하거나("우연이겠지") 정당화하려는("역시 좋은 종목이니까") 충동 자체가 확증편향의 발현이다. 올바른 반응은 즉시 "왜 수렴했는가"를 데이터로 확인(유니버스 중복? 팩터 상관? 공통 데이터소스?)하는 것 — stock-portfolio-risk의 다전략 중복보유 모니터가 이 확인을 코드로 강제하는 장치다.
- **실무 함의**: 설계자 자신이 시스템 출력을 검수할 때도 System 1(직관적 신뢰)이 아니라 System 2(반복 원인을 구조적으로 추적)로 전환해야 한다 — 이 스킬이 다른 전문가 결론을 걸러주듯, 자기 시스템의 출력도 걸러야 한다.

## KRX 적용

- **테마·군중 쏠림**: 한국은 개인 비중이 높고 테마주(정책·이슈) 쏠림·회전율이 극단적 → 군집·최근성 편향이 가격에 크게 반영. 역발상 기회와 함정이 동시에 큼.
- **CAPE 적용**: 코스피 CAPE는 코리아 디스카운트로 구조적으로 낮음 → 미국 기준 절대 비교 금지, **자국 역사 밴드**로 상대 판단.
- **수급 심리 지표**: 신용융자 잔고·예탁금·개인 순매수 급증을 과열(탐욕) 신호로, 반대매매·투매를 공포 신호로 활용.
- 사전규칙(손절·리밸런싱)을 미리 박아 System 1 개입을 줄이는 것이 특히 중요.

## 엣지케이스 · 데이터 거부 처리

- **심리 지표 결측**: 신용융자·예탁금·put/call·VIX 중 일부만 있으면 가용 지표만으로 진자 위치를 "잠정(신뢰도 하)"로 표기하고, 막힌 지표는 "판정 불가"로 분리(README 폴백 사다리). 전부 결측이면 정성 서사(뉴스 일색·"이번엔 다르다")만으로 방향만 제시하고 과열 강도는 보류.
- **거부·결측 사유별 처리**:
  - *수급 데이터 제공 거부*: 점수화는 중단하되 "작동 중인 편향" 정성 진단(최근성·군집·확증)은 계속 — 부분 결론 + "정량 과열 확정엔 ㉠지표 필요" 명시. 억지로 수치 추정하지 않는다.
  - *데이터 자체가 존재하지 않음(비상장 초기·해외 소형주 등)*: 정성 서사(뉴스 톤·검색량 체감)로 대체하고 "대용 지표 폴백" 명시.
  - *시간 부족으로 일부만 확인*: 확인된 지표만으로 잠정 판정 + 미확인 지표 목록을 "확인 필요"에 별도 명시.
  - *다른 전문가 결론과 심리 판단이 정면 충돌*(예: 가치 스킬은 매수, 본 스킬은 탐욕 정점 경고): 단독으로 어느 한쪽을 폐기하지 말고 `stock-chief-strategist`로 재상정해 교차검증(다른 학파 관점 재확인) 후 종합.
- **역발상 신호가 애매한 중간 구간**(공포·탐욕 어느 정점도 아님): 역발상 포지션을 제시하지 말고 "중립 — 사전규칙 유지"로 결론. 진자 중간 구간에서의 역발상 베팅은 금지(중간 체류는 짧으나 방향 예측 불가).

> 이 스킬은 메타 검수자다 — 단독 매수·매도 신호를 내지 않는다. 다른 분석의 심리 필터로만 쓰고, 본 진단은 투자 권유가 아니다(자기책임·실데이터 재확인).
