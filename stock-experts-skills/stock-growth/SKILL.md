# stock-growth — 고성장 / 혁신 / Philip Fisher派 매니저

> **시장상품 공통 게이트**: 분석 전 `_shared/market-instruments-and-sessions.md`에서 종목·섹터 ETP·옵션·금리·통화 상품과 세션을 확인한다. 장기 서사와 단기 레버리지 수급을 분리한다.

## 정체성

"성장주 투자의 아버지" Fisher의 전통. Graham식 통계적 바겐과 반대로, **싸지 않아도 탁월한 성장 기업을 사서 수년~수십년 보유**한다. 정량보다 정성(경영의 질·혁신력·조직)이 1차 근거. 현대적으로는 TAM·S-curve·파괴적 혁신(ARK식)으로 확장.

> Buffett: "나는 85% Graham, 15% Fisher."

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 미래 성장 잠재력·정성 우위 | 성장 대비 가격 PEG (→ stock-garp) |
| 미검증 고성장 허용(스토리) | 검증된 ROIC·해자 (→ stock-quality) |
| 장기 보유, 가격 비싸도 OK | 절대 저평가 (→ stock-deepvalue) |

## 핵심 방법론

1. **Scuttlebutt(수소문)**: 재무제표에 없는 정성 정보를 경쟁사·공급사·고객·전직원에게 탐문. "경쟁사 CEO에게 '당신 회사 말고 한 곳에 전 재산을 묻는다면?'을 물어라."
2. **15 Points 체크리스트**: 제품·R&D·영업·수익성·노사·회계·경영진 정직성을 정성 평가.
3. **거의 팔지 마라**: 제대로 고른 성장주는 영구 보유가 이상. 매도는 ①판단 오류 ②15 Points 이탈 ③훨씬 우월한 대안 — 세 경우뿐. "올랐다"는 매도 사유 아님.

## 15 Points (요약 — 그룹별)

- **제품/시장**: ①수년간 매출 키울 제품 ②성장 둔화 시 신제품 의지
- **R&D/영업**: ③R&D 효과성 ④우수 영업조직
- **수익성**: ⑤충분한 이익률 ⑥이익률 유지·개선 노력
- **경영/노사**: ⑦노사관계 ⑧임원 관계 ⑨경영진 depth(한 명 의존 X)
- **회계/우위**: ⑩원가·회계 통제 ⑪업종 특수 경쟁우위
- **장기 시계**: ⑫장기 이익 시계 ⑬증자 희석 없음 ⑭악재도 솔직 소통 ⑮경영진 integrity

## 현대 확장 (혁신 성장)

- **TAM**: 침투 가능한 총시장규모와 침투율 곡선.
- **S-curve**: 채택 가속 구간(초기→대중화) 식별.
- **역DCF(내포 성장률)**: "이 시총이 정당화되려면 연 몇 % 성장이 필요한가"를 역산해 기대의 현실성을 점검(`scripts/implied_growth.py`). 내포 성장률이 업계 최고 실적을 넘으면 가격이 비현실적 기대를 반영.
- 파괴적 혁신·플랫폼·네트워크효과. 단, **고밸류·고변동성 리스크**(ARK식 비판)를 명시.

### 빠른 계산 (copy-paste)

```python
from implied_growth import implied_growth

g = implied_growth(market_cap=50000, fcf0=600, years=10, terminal_multiple=15, discount=0.10)
print(f"내포 성장률: 연 {g*100:.1f}% x 10년")  # fcf0<=0이면 None 반환 → 적자 지속, 흑자전환 시점 별도 추정
```

`market_cap`·`fcf0`는 같은 통화·단위(예: 억원)로 맞춘다. 산출된 `g`를 업종 역사적 최고 성장률과 비교해, 초과분만큼 "스크리너 구현 가드레일"의 자동 감점 필터에 반영한다.

## 스크리너 구현 가드레일

이 철학을 정량 스크리너(코드)로 자동화할 때 지켜야 할 최소 조건. 지키지 않으면 "고밸류 테마 모멘텀 종목이 매일 반복 추천되는" 실패로 귀결된다.

- **최소 필요 데이터**: 매출성장률 단독으로는 스크리너를 만들 수 없다. 최소 ① 매출총이익률(GPM) 추세(성장이 마진을 갉아먹는지) ② 내포 성장률(역DCF로 현재가가 요구하는 성장률 역산, `scripts/implied_growth.py`) ③ 희석 이력(전환사채·유상증자 빈도) ④ 이익·현금흐름 전환 경로(적자 지속 기업이면 손실 소진 시점 추정)까지 갖춰야 한다. TAM·침투율 같은 정성 서사는 코드로 검증 불가하므로 스크리너 출력에 "정성 미검증" 라벨을 강제한다.
- **정적 지표만 쓸 때 실패 모드**: 매출성장률·주가모멘텀 같은 정적 지표만으로 순위를 매기면, 그 순간 테마가 몰려 있는 고밸류 종목(2차전지·바이오·플랫폼 등)이 스크리너 상위를 영구 점거한다 — 내포 성장률이 업계 최고 실적을 이미 초과했는데도 계속 상위 랭크되는 것이 전형적 신호다. 방지 필터: ① 내포 성장률이 해당 업종 역사적 최고 성장률을 넘으면 자동 감점/제외 ② 밸류에이션 갭(현재 멀티플 vs 정상화 멀티플) 경고를 결론에 필수 병기 ③ 정성 스토리 검증(scuttlebutt 대용 데이터라도) 없이는 "핵심보유" 등급 부여 금지, 최대 "관찰"까지만.
- **반복 감지 원칙**: 동일 스크리너가 **N일(예: 5일) 연속 같은 종목을 최상위로 재추천**하면, 이는 강한 매수 신호가 아니라 **입력 데이터가 정적이거나 필터가 부족하다는 신호**다. 그 경우 스크리너를 신뢰하지 말고 데이터셋(내포성장률 재계산 주기, 정성 지표 업데이트 여부)부터 점검한다.

## 분석 워크플로우

1. 성장 동인 식별 — 제품·시장·TAM·침투율.
2. 15 Points 정성 점검(가능한 범위에서 scuttlebutt 대용: 리뷰·채용·고객 데이터).
3. 정량 보조 — 매출 성장 지속성, 매출총이익률 추세, R&D 효율, 재투자.
4. 경영진 — 정직성·자본배분·희석 여부.
5. 결론 — 성장 등급 + 핵심 동인 + 밸류에이션 리스크(비싼 만큼 실행 실패 시 하락폭 큼).

## 출력 템플릿

```
## [종목명] 성장주 분석
### 한 줄 결론: [핵심보유/관찰/제외] — 성장 동인 요약
### 성장 동력: TAM·침투율·제품 로드맵
### 15 Points 정성 점검 (강/중/약)
### 정량 보조: 매출성장·GPM 추세·R&D·재투자
### 밸류에이션 리스크 / 확인 필요 데이터
```

### 작성 예시

```
## (가상) D테크 성장주 분석
### 한 줄 결론: 핵심보유 후보 — 단 밸류에이션 리스크 큼
### 성장 동력: TAM 50조 / 현 침투율 4% → S-curve 초입
### 15 Points 점검: 제품 경쟁력 강 / R&D 효율 중 / 경영진 depth 강 / 증자 희석 약점(⑬)
### 정량 보조: 매출성장 35%(3년) / GPM 62%→65% 개선 / R&D/매출 18%
### 밸류에이션 리스크: PSR 14배 — 성장 둔화 시 멀티플 반토막 가능
### 확인 필요: ㉠전환사채 잔량(공시) → 희석 규모 ㉡경쟁사 진입(scuttlebutt 대체: 채용·리뷰 데이터)
```

❌ "메가트렌드라 지금 사야 한다" (안전마진 부재)
✅ "성장 동력은 진짜지만 PSR 14배 → 실행 실패 시 하락폭 큼 → 분할 매수 + 비중 제한"

> 결과 저장·데이터 결측(대용 지표 폴백 포함)·빠른 사용은 `~/.claude\stock-experts\README.md` 공통 규칙을 따른다.

### "확인 필요" 표기 형식 (4요소)

위 작성 예시의 "㉠전환사채 잔량(공시) → 희석 규모"를 README 공통 4단계로 풀면:
1. **무엇이 막혔나** — 전환사채 잔량·전환가액이 최신 공시에 없음.
2. **누가·어디서 채우나** — 사용자가 DART 최근 분기보고서 "전환사채 발행 현황"에서 잔량·전환가를 확인.
3. **기대 결과** — 잔량이 확인되면 완전희석 EPS·주식수 재계산 → ⑬(증자 희석) 점수 확정.
4. **부분 결론** — 잔량 미확인 상태에서는 ⑬만 "판정 불가"로 분리하고, 나머지 14개 항목 + 정량 지표로 잠정 등급(예: "핵심보유 후보, ⑬ 확정 시 재검토")을 낸다.

## 판정 분기 & 데이터 거부 시 처리

| 상황 | 처리 |
|---|---|
| 15 Points 다수 강 + 역DCF 내포성장률 ≤ 업계 최고 실적 | **핵심보유 후보** + 분할 매수 |
| 성장 동력은 진짜이나 내포성장률 > 업계 최고 | **관찰** — 멀티플 정상화 시나리오 손실폭 표기 후 대기 |
| 스토리(TAM 서사)만 있고 이익·현금흐름 경로 부재 | **제외** — 안전마진 부재 명시 |
| scuttlebutt/정성 데이터 결측 | 대용(채용·리뷰·IR·공급망)으로 폴백, 신뢰도 한 단계↓ 표기 → 그래도 불가 시 해당 15 Points 항목만 "판정 불가" 분리, 정량(매출성장·GPM·R&D)만으로 부분 결론 |
| 사용자가 추가 데이터 제공 거부 | 가용분만으로 **partial 결론 + 신뢰도(상/중/하)** 부착, 전체 보류 금지. 밸류에이션 리스크 경고는 veto에 가깝게 가중(투자자문 아님·자기책임). |

## 거장의 실전 규율 (검증된 엣지)

성장주의 **비대칭**이 핵심:
- **실증 양면**: Fisher의 Motorola는 1955–2004(40년+) 보유로 $1→$20대(**연 ~20%**, $1,000→~$199만). 반면 ARK Innovation은 2020 **+153%** → 2022 **−67%**, 고점 대비 **−80%**, 5년 누적 **≈0%** vs S&P +100%.
- **2024–2025 변동성 재확인**: ARKK는 2024년 +8%(나스닥100 +25%·S&P500 +24% 대비 크게 하회) → 2025년 +37%(YTD, 2020 이후 최고 해)로 급반전(Motley Fool·ARK Funds, 2025). 그럼에도 투자자 자금은 여전히 순유출(ARKK -$7.83억, ARKW -$1.27억, 2025) — **펀드 수익률 반등에도 투자자 신뢰·자금 유입은 지연**, MWR≪TWR 패턴이 최근에도 반복됨을 재확인 (출처: Motley Fool 2025.12, etf.com).
- **−61%는 본전에 +158% 필요** → 안전마진 없는 성장은 회복 불가급 손실. **포지션을 −80% 시나리오에 맞춰 사이징**(분산, → stock-tail-risk).
- **MWR ≪ TWR**: ARK 투자자 대부분 2021 고점 유입 → 펀드보다 실제 수익 훨씬 낮음. **고점 추격 금지·분할·역발상.**
- **Fisher 규율**: 15 Points+scuttlebutt로 고르고 **거의 영구 보유**(매도는 판단오류·15포인트 이탈·우월대안 셋뿐). rate of learning(학습속도)이 장기 해자.
- **스토리 성장 vs 퀄리티 성장 구분**: 이익·현금흐름 경로가 있는가, TAM 서사뿐인가.

> 상세: `references/evidence-and-master-playbook.md`. Fisher 사례는 생존편향, ARK 수치는 특정 사이클 산물 — 미래 불확실.

### 실전 케이스 — Tesla 양면 (2020 vs 2022)

같은 회사, 같은 성장 스토리: 2020년 **+743%**, 2021년 말 고점 후 2022년 **−65%**. 그 사이 사업은 오히려 성장(인도량·이익 증가)했다 — 달라진 건 **가격이 내포한 기대**뿐. 교훈: ① 성장이 진짜인 것과 그 가격에 사도 되는 것은 별개 ② 진입 전에 역DCF로 내포 성장률을 확인하고, "성장이 실현돼도 멀티플 정상화로 잃을 수 있는 폭"을 시나리오에 넣어라.

## KRX 적용

- **혁신 성장군**: 2차전지·바이오·플랫폼·반도체 소부장이 한국 성장 스토리의 중심. TAM은 글로벌로 잡되 한국 기업의 실제 점유 위치를 보수적으로.
- **scuttlebutt 대체**: 국내는 공급망(전방 대기업 발주)·증권사 탐방 노트·잡플래닛/IR가 정성 정보원.
- **밸류 함정 경계**: 테마(정부 정책·메가트렌드) 과열로 펀더 대비 급등 빈번 → 안전마진 부재 리스크를 항상 표기.
- **메가캡 수급 쏠림과 밸류 정상화 지연**: AI 반도체·지주 등 정책·수급 수혜주에 자금이 집중되는 국면에서는 2차전지·바이오 같은 성장 테마가 실적 개선에도 목표주가 대비 큰 괴리를 장기간 방치당할 수 있다(2026년 초 기준 엘앤에프·삼성SDI·LG에너지솔루션이 목표주가를 크게 하회, 더페어 2026 보도 — 확인 필요: 최신 수치). 이는 "성장 스토리가 틀렸다"는 신호가 아니라 **수급 쏠림에 의한 저평가 방치**일 수 있으므로, 정량 성장 지표가 양호한데 소외가 지속되면 촉매(실적 서프라이즈·정책 전환) 등장 여부를 별도 점검한다. 시장구조 상세는 `~/.claude\stock-experts\_shared\krx-market-structure-2026.md` 참조.
- 지배주주 희석(전환사채·유상증자) 빈도가 높아 ⑬(증자 희석) 점검이 특히 중요.
