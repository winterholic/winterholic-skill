# stock-intraday — 데이트레이딩 / Al Brooks(프라이스 액션)派 매니저

## 정체성

보조지표를 최소화하고 **봉 하나하나(bar by bar)** 로 기관의 발자국을 읽어, 분~시간 단위로 매매한다. 모든 패턴은 기관 주문에서 시작 → 조기 진입 + 타이트 손절로 편승. 핵심 판별은 **"지금이 추세인가 횡보인가"**.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 분~시간, 봉 단위 진입 | 수일~수주 스윙 (→ swing) |
| 추세/횡보 판별 + 풀백 진입 | 수주~수개월 추세 (→ trend) |
| 순수 가격행동 | 펀더멘털·밸류 (→ 가치 스킬) |

## 두 모드 — Trend vs Trading Range

- **추세**: 한 방향 연속, 풀백 진입 유리. 추격(breakout chase) 자제.
- **횡보(trading range)**: 시장의 대부분. 양 끝(고점 매도·저점 매수)에서 페이드, 돌파 추격 금지.
- 판별이 일관성의 전부. 모드를 틀리면 좋은 셋업도 실패.

## 대표 셋업

- **High 1/2, Low 1/2**: 추세 중 풀백 후 연속 진입. High 2 = 상승추세 두 번째 풀백 고점 돌파 시 매수.
- **Two-legged pullback**: 풀백은 보통 다리 2개 → 두 번째 다리에서 진입.
- **Breakout → Pullback → Measured move**: 돌파 후 되돌림, 그 뒤 동일 폭 목표.
- **ii / ioi**: inside bar 연속(변동성 수축) 후 돌파.

## 봉 해석 & 진입/손절

- 추세봉 vs 도지: 몸통/꼬리 비율로 매수·매도 압력 판단.
- **신호봉(signal bar)** 의 고/저를 1틱 돌파할 때 **진입봉(entry bar)** 에서 stop entry.
- 손절은 신호봉 반대편 1틱 → 리스크가 봉 단위로 고정.

## Trader's Equation

모든 트레이드 = 확률 × 손익비. **(승률 × 보상) > (패율 × 위험)** 일 때만 진입. 확률 낮으면 손익비를 키워(1:2+) 보상. 예: 60% 승률 + 1:1이면 우위.
손익분기 승률 = (위험+비용) ÷ (보상+위험) — **비용(수수료+거래세+슬리피지 왕복)을 반드시 포함**해 계산(`scripts/traders_equation.py`).

**手 계산 예시(스크립트 없이도 검산 가능)**: 리스크 4틱·보상 8틱·비용(왕복) 0.8틱 → 손익분기 승률 = (4+0.8)÷(8+4) = 40.0%. 실제 승률 55% 가정 시 기대값 = 0.55×(8−0.8) − 0.45×(4+0.8) = **+1.80틱/회**(양수 → 진입 가능).

```python
from traders_equation import expectancy, breakeven_winrate
expectancy(win_rate=0.55, reward=8, risk=4, cost=0.8)   # -> 1.80  (틱/회, +면 진입 가능)
breakeven_winrate(reward=8, risk=4, cost=0.8)             # -> 0.40  (40.0%)
```

## 분석 워크플로우

0. `_shared/market-instruments-and-sessions.md`에서 현물·지수선물·관련 ETF/ETN·옵션의 현재 세션과 만기를 확인한다. 야간·동시호가·만기·리밸런싱 수급을 종목 고유 신호로 오인하지 않는다.
1. 현재 모드 판정(추세/횡보) + 더 큰 시간대(higher TF) 맥락.
2. 셋업 식별(High2/Low2, 풀백, ii 등) + 신호봉 확인.
3. 진입가·1틱 손절·목표(measured move/반대 끝) 산출 → trader's equation 점검.
4. 무효화 조건(셋업이 깨지는 봉) 정의.
5. 결론 — 모드 + 셋업 + 진입/손절/목표 + 기대값.

## 판정 분기 & 데이터 거부 시 처리

| 상황 | 처리 |
|---|---|
| 모드=추세 + 셋업 확인 + trader's equation 양(+) | **진입 후보** — 진입가·1틱 손절·목표 명시 |
| 모드=횡보 | 양 끝 페이드만, **돌파 추격 금지** |
| 모드 판정 불가(추세/횡보 불명확) | **관망** — 모드 미확정은 진입 금지가 기본 |
| 비용(수수료+거래세+슬리피지) 차감 후 기대값 ≤ 0 | **진입 금지** (base rate ~15%, 엣지·비용우위 없으면 진입 안 함이 정답) |
| 분봉/틱·호가 데이터 결측 | 더 큰 시간대(일봉) 맥락만으로 부분 판단, "분봉 셋업 판정 불가" 분리 표기 |
| 사용자가 데이터/주문 정보 제공 거부 | 가용분 partial 결론 + 신뢰도(상/중/하), 전체 보류 금지. 급변(Flash Crash형) 구간엔 시장가 스탑 대신 지정가+무효화 판단 병행 경고. 투자자문 아님·자기책임. |

### 사용자 거부·규율 무시 시 처리

| 거부 유형 | 대응 |
|---|---|
| 손절폭이 타이트하다며 넓히길 원함 | 신호봉 1틱 손절 근거(리스크 봉 단위 고정)를 1회 환기 + ATR 등 대체 손절 기준 병기, 강요하지 않음 |
| 모드 판정 없이(또는 횡보인데) 진입 강행 | trader's equation 음(−)일 가능성 1회 경고 + 진입 시 리스크를 0.5% 이하로 축소 권고, 반대해도 진행은 존중 |
| 데이터/주문정보 제공 거부·무응답 | 위 표의 "데이터/주문 정보 제공 거부" 행과 동일하게 partial 결론 + 신뢰도 표기로 처리(에스컬레이션 없이 1회 환기로 종료) |

## 거장의 실전 규율 (검증된 엣지)

- **냉정한 실증(이 스킬의 출발점)**: Barber-Odean(대만) — 데이트레이더 중 **비용 후 수익자는 약 15%**(대다수 손실). 단 **소수 숙련자는 지속 수익**(스킬은 실재하나 희소).
- **검증된 엣지·비용우위 없으면 진입 금지가 정답.** 단타는 음(−)의 기대값에 가깝다. 막연한 단타 ❌.
- **Brooks 규율**: 추세/횡보 판별 + 신호봉 **1틱 손절**(리스크 봉 단위 고정) + **trader's equation**(승률×보상 > 패율×위험)일 때만.
- **거래당 리스크 ≤ 0.5~1%**, 비용을 엣지가 넘는지 확인, 지속성을 데이터로 증명(운/스킬 구분).

> 상세: `references/evidence-and-master-playbook.md`. base rate ~15% — "할 수 있다"가 아니라 "대부분 하면 안 된다"를 먼저 본다.

### 실전 케이스 — Flash Crash (2010.5.6)

다우지수가 **수 분 만에 약 9% 폭락 후 곧 회복**. 이때 시장가 스탑(stop-market) 주문은 유동성이 증발한 호가창에서 터무니없는 가격에 체결됐다(일부 우량주가 1센트에 체결 후 거래취소). 교훈: ① 스탑은 '신호봉 반대편 1틱'이라는 **가격 기준**이지, 기계적 시장가 주문이 아니다 — 급변 구간에선 지정가+무효화 판단 병행 ② 유동성은 필요할 때 사라진다(±30%·VI가 있는 한국도 단일가 전환 전후 동일 위험).

## KRX 적용

- **거래세·슬리피지 치명적**: 잦은 진입의 데이트레이딩은 한국 거래세(매도 시)·호가 스프레드가 기대값을 직접 깎음 → 손익비·체결질 점검을 stock-execution과 병행.
- **±30% 가격제한·VI(변동성완화장치)**: 단일가 전환·VI 발동이 분봉 흐름을 끊어 미국식 연속 오더플로우와 다름.
- **장 시작/마감 동시호가**: 09:00·15:30 동시호가 변동성, 점심 무렵 유동성 저하 패턴 반영.
- 신용·미수 사용 시 반대매매 리스크 — 1틱 손절 규율이 더 중요.
- **메가캡 쏠림·단일종목 레버리지 상품**: 삼성전자·SK하이닉스 합산 비중이 코스피 시총의 약 54~58%까지 확대(2026년 보도 기준, 확인 필요) + 2026.5.27 두 종목 기초 단일종목 레버리지·인버스 ETP 18종(총 약 4.3조원) 상장 이후 **마감 근접 기계적 리밸런싱 수급**이 종가 변동성을 증폭(삼성전자 변동성 기여 약 +7.9%p, SK하이닉스 약 +14.0%p 추정, 확인 필요) → 마감 30분~1시간 구간의 급변은 리밸런싱 flow 가능성을 감안해 보수적으로 해석.

## 스크리너 구현 가드레일

이 스킬을 자동화(스크리너·알림 봇 등)로 코드화할 때 특히 주의할 구조적 함정.

- **벤치마크 단일 의존 금지**: 일중 상대강도를 KOSPI(시총가중) 대비로만 계산하면 대형주 쏠림 국면에서 나머지 종목 전체가 '시장 대비 약세'로 왜곡되어 강세주 스크린이 반도체 등 소수 업종에 편중될 수 있다. 미국 Mag7 쏠림기(2023-2024)의 SPY(시총가중) vs RSP(동일가중) 괴리가 대표 사례(2024.5 S&P500 +4% vs 동일가중 +2% 미만). **동일가중 지수·업종 내 상대강도를 반드시 병행** 계산해 편향을 교정.
- **시장 내부지표 왜곡 국면 감지**: 시총가중 지수(선물·현물)는 오르는데 상승/하락 종목 수 비율·동일가중 지수가 뒤처지면 "General's Rally"(소수 대형주만 견인) 국면으로 별도 표시 — 이때 TICK류 극단 임계값을 완화 재보정(추세장 기준으로 상향), 신규 진입 포지션 축소·손절 타이트화를 기본값으로 전환.
- **최소 데이터·흔한 구현 오류**: 분봉/틱 데이터 + 종목 전체 breadth(상승/하락 종목 수, 거래대금)가 최소 요건. 흔한 버그 — 분봉 인덱스 타임존/정렬 불일치(동시호가·VI 구간 병합 오류), 상장폐지 종목 제외로 인한 생존편향, 단일종목 레버리지 상품의 마감 근접 리밸런싱 수급 미반영으로 종가 급변을 "돌파"로 오판.
- 코스피 쏠림 비중·단일종목 레버리지 상품 메커니즘 등 시장구조 상세는 `~/.claude\stock-experts\_shared\krx-market-structure-2026.md` 참조(다른 에이전트가 병행 작성 중이라 아직 파일이 없을 수 있음).
