# 레퍼런스(심화) — DDM & 배당 안전성 정량

> 목적: Weiss 수익률 밴드에 더해 **배당의 지속가능성**을 정량 점검(밴드 신호의 전제). 배당 컷은 대개 6~12개월 전 예측 가능.
> 웹 출처: CFA Institute(dividend safety·DDM), arborinvestmentplanner·fairvaluelabs(coverage), suredividend(Chowder).

## 1. DDM (배당할인) & Gordon Growth

- `P = D1 / (r − g)`(고든 성장). 다단계 DDM: 고성장기 배당 개별 할인 → 안정기 고든.
- 적정 r(자기자본비용), g(지속가능 배당성장 = ROE × 사내유보율).
- 성숙·안정배당 기업에 적합. r−g 민감도 큼(g가 r에 근접하면 발산).

## 2. 배당 안전성 핵심 지표

| 지표 | 안전 기준(대략) |
|---|---|
| EPS 배당성향 | 성숙 <60%, 성장 <40%, **>75% 경계, >100% 위험** |
| **FCF 배당성향** | <70% (이익보다 조작 어려워 더 중요) |
| Net Debt/EBITDA | ≤ 3x |
| 이자보상배율(EBIT/이자) | ≥ 3x |
| 연속 인상 연수 | 길수록 안전(컷 이력 = 감점) |

- **배당 컷 예측**: 위 지표 악화 + 2분기 연속 성향>100% = 적신호(차입·유보 소진으로 지급).

## 3. Chowder Rule (수익률 + 성장)

- **Chowder Number = 현재 배당수익률 + 5년 배당성장률(DGR)**.
- 기준: 고배당(>3%)은 **≥12**, 저배당(<3%)은 **≥15**, 유틸리티는 **≥8**.
- 의미: 수익률만 높고 성장 없는 **yield trap** 회피 + 총수익(배당+성장) 잠재 확보.

## 4. REIT/인컴 특수 지표

- REIT는 EPS 대신 **FFO**(순이익 + 부동산 감가상각) / **AFFO**(− 반복 CapEx·정액임대 조정)로 배당 능력 평가.
- REIT 배당성향은 **AFFO의 60~85%**가 통상. BDC/MLP도 별도 지표(NII 등).

## 5. 통합 사용

Weiss 수익률 밴드(저평가 신호)는 **배당이 안전할 때만 유효**([[weiss-dividend-yield]]). 밴드 진입 + FCF 성향·Net Debt·Chowder 통과 = 진짜 저평가 배당주.

## 6. KRX 적용

- 한국은 배당성향이 낮았으나 밸류업으로 상향 추세 → DGR 데이터 짧음(보수적 g).
- 금융지주(자본비율 규제)·통신·유틸(요금 규제) 배당 안전성은 규제 변수 점검.
- REIT(상장 리츠)는 FFO/AFFO·LTV·금리 민감도 점검.

## 7. 비판과 한계

DDM은 r−g 가정에 극민감(무배당 부적용). 배당성향 안전 기준은 산업별 상이(유틸·REIT는 높아도 정상). 과거 지표 기반이라 급격한 사업 악화·정책 변화는 선반영 못함. Chowder는 과거 DGR 외삽의 한계.
