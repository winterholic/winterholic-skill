# 레퍼런스(검증·거장 노하우) — 금융 ML 실증 & 마스터 플레이북 (Medallion)

> 목적: ML/데이터가 **사상 최고 수익(Medallion)** 을 만들 수 있음을 인정하되, 그것이 **재현 불가한 예외**임을 직시한다.
> 출처(웹 검증): Renaissance Technologies 위키·VisualCapitalist, López de Prado. 1차 출처 재확인 권장.

## 1. 실증 — 정점과 현실

| 사례 | 내용 |
|---|---|
| **Renaissance Medallion**(Jim Simons) | 1988–2018 **연 ~66% gross / ~39% net** — **역사상 최고 트랙레코드**(Buffett·Soros·Lynch·Dalio 능가) |
| Medallion 구조 | 외부자금 거의 안 받음·**용량 제한**·5%+44% 수수료·**물리학자/수학자 군단**·초단기 보유 |
| 공개 ML/퀀트 펀드 | 다수는 **실망스러운 성과**(과적합·alpha decay) |
| 대안데이터 | 비싸고($25k~$500k+/년) 널리 구독될수록 **alpha decay** |

**핵심 해석 — 균형 잡힌 시각**:
- ML/데이터는 **극단적 알파를 낼 수 있다(Medallion 증명)**. "기술적으로 불가능"이 아니다.
- 그러나 Medallion은 **예외**: 폐쇄·용량 제한·엘리트 팀·인프라·수십 년 축적의 산물. **대부분의 공개 ML 펀드는 재현 못 한다.** Medallion을 기대하지 말 것.

## 2. 거장 플레이북 (Jim Simons / Renaissance)

- **인간 재량 배제**: 신호가 약해도 모델을 따른다. 감정·스토리 개입 금지.
- **과학자를 고용**: 금융 전문가가 아니라 물리학자·수학자·통계학자. 데이터·방법론이 우위.
- **초단기·고빈도·소액 엣지를 대량 반복**: 승률 50.x%를 수백만 번. 분산·회전.
- **용량 한계 인정**: 알파가 자금 규모에 한계 → 외부자금 반환(욕심 절제).

## 3. 시니어 의사결정 체크 (López de Prado + Medallion 교훈)

1. **Medallion을 기대하지 않는가?** 공개 ML은 대부분 실패 — 겸손한 기대.
2. **가설 우선**인가? "많은 백테스트"가 아니라 이론적 가설 → CPCV·DSR 검증(→ [[lopez-de-prado-ml]]).
3. **피처가 알파, 모델은 그릇**(fractional diff·정보바)임을 아는가? 일간엔 GBM이 딥러닝 대체(→ [[ml-methods-models]]).
4. **alpha decay·비용**을 net으로 반영했는가? 대안데이터 ROI가 비용을 넘는가([[alt-data-nlp-sentiment]]).
5. **데이터·인프라·팀 해자**가 없는데 초과수익을 기대하는가? (Medallion의 진짜 엣지)

## 4. KRX 적용

- 한국 대안데이터 제한적 → 외국인/기관 순매수·공시(DART)·뉴스·커뮤니티 버즈 등 **국내 고유 신호**. 한국어 금융 NLP 필요.
- 샘플(종목·기간) 작아 과적합 위험↑ → 트리 모델 + CPCV·DSR 보수적. 레짐 단절(IMF·코로나·공매도 금지) 혼입 주의.

## 5. 비판·한계 (정직하게)

- Medallion은 **생존편향의 극단**(최고 1개만 회자) + 폐쇄·재현 불가. 공개 ML 펀드 다수는 시장 하회.
- 낮은 신호대잡음에서 ML 알파 보장 없음. 대안데이터 alpha decay 빠름·생존편향. 구현 난도·비용 높아 소규모엔 비효율.
