# 레퍼런스(심화) — 대안데이터 & NLP/센티먼트

> 목적: "다양한 정보를 효과적으로 사용" — 비전통 데이터의 종류·활용·비용·alpha decay.
> 웹 출처: similarweb·vertdata·extractalpha(alt-data taxonomy), EY survey(78% 채택), RavenPack(NLP).

## 1. 대안데이터 분류

| 종류 | 신호 | 예 |
|---|---|---|
| **신용카드 거래** | 기업 매출 선행(공시 수주 전) | 리테일·소비재 매출 추정 |
| **위성 이미지** | 물리적 활동 | 주차장 점유·유조탱크·작황 |
| **웹 데이터** | 수요·가격·평판 | 채용공고·웹트래픽·리뷰·가격 |
| **앱 사용/지오로케이션** | 트래픽·방문 | MAU·매장 방문 |
| **ESG** | 비재무 리스크 | 탄소·지배구조 데이터 |

## 2. NLP / 센티먼트

- 뉴스·실적 콜·공시·소셜의 **톤·이벤트**를 자동 추출. RavenPack 등은 1,200만+ 엔티티의 뉴스·전사·필링을 센티먼트 점수·이벤트 신호로 변환.
- 활용: 실적 콜 어조 변화, 가이던스 NLP, 뉴스 센티먼트 모멘텀, 소셜 버즈.
- 모델: 사전기반→금융 특화 트랜스포머(FinBERT 등).

## 3. 채택·비용

- EY 조사: 펀드의 **78%**가 대안데이터 사용/예정(2016년 52%→).
- 비용: 기초 센티먼트·ESG <$25k ~ 프리미엄 거래·지오 데이터 >$500k/년.

## 4. Alpha Decay & 함정

- 데이터가 비싸고 널리 구독될수록 **edge가 시간이 지나며 압축**(alpha decay).
- 생존편향·라이선스·개인정보·커버리지 변화·백필(backfill) 편향 주의 → point-in-time 검증.
- 신호 결합: 단일 데이터보다 **여러 신호의 약한 상관 결합**(→ [[ml-methods-models.md]] 피처).

## 5. 신호 → 전략 파이프라인

대안 피처 → triple-barrier 라벨 → 메타라벨링 → CPCV/DSR 검증 → 비용 차감 net → 사이징([[markowitz-kelly-risk]])·실행([[harris-kissell-execution]]).

## 6. KRX 적용

- 한국 대안데이터 시장은 미국 대비 제한적(카드사 데이터·통신·앱·물류 일부). 커버리지·라이선스 확인.
- **국내 고유 신호**: 외국인/기관·프로그램 순매수, 공매도 잔고, 공시(DART) 텍스트, 네이버/커뮤니티 버즈.
- 한국어 NLP는 금융 도메인 모델·형태소 처리 필요.

## 7. 비판과 한계

대안데이터는 비싸고 alpha decay 빠름·생존편향. 인과 아닌 상관일 수 있음(우연 상관 다수). 한국어·소규모 시장은 데이터 품질·양 부족. 규제·개인정보 리스크. ROI가 비용을 넘는지 항상 점검.
