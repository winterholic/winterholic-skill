# 레퍼런스 — Marcos López de Prado (Financial ML)

> 원저작: *Advances in Financial Machine Learning*(2018).
> vault 소스: `sources/stock-investing/lopez-de-prado-financial-ml.md`. 스킬 실행용 가공본.

## 1. 문제의식

표준 ML을 금융에 그대로 쓰면 백테스트 과적합으로 실패. 금융 데이터의 비IID·계열상관·낮은 신호대잡음을 다루는 데이터 가공·라벨링·검증이 핵심 기여.

## 2. Bars (데이터 구조화)

시간 바 비효율 → 정보 기반 바. Tick/Volume/**Dollar bars**(정규성 개선), Imbalance/Run bars(정보 사건 동기화).

## 3. Triple-Barrier Labeling

세 장벽 먼저 닿는 것으로 라벨: 상단(익절)+1 / 하단(손절)−1 / 수직(시간)0. 실거래 손익 구조 내장.

## 4. Meta-Labeling

1차=방향(side), 2차(메타)=베팅 여부·크기(size). 거짓양성 제거→정밀도·F1↑. 룰/펀더 위에 ML.

## 5. 과적합 방지

- 표본 고유성: 겹치는 라벨 중복 → sample weight, sequential bootstrap.
- Purging: 테스트와 시간 겹치는 학습 라벨 제거.
- Embargo: 테스트 직후 구간 학습 배제.
- CPCV: 다중 경로 백테스트 분포 → 운 제거.
- DSR/PBO: 시도 횟수 반영 샤프 디플레이션, 과적합 확률.

## 6. 특성 중요도

MDI/MDA + 군집 기반 중요도(다중공선성 완화). 가설→검증 순서 강조.

## 7. 인접 — Stefan Jansen

*Machine Learning for Algorithmic Trading*(2020) — 데이터·알파팩터·백테스트·딥러닝 실무 코드.

## 8. KRX 적용

대안데이터 제한 → 거래원·외국인/기관 순매수·공시·뉴스 위주. 샘플 부족→CPCV·DSR 보수적. 레짐 단절(IMF·코로나·공매도 금지) 혼입 주의. net 성과 판단.

## 8.5 심화 — SKILL.md 비중복

- **Fractional Differentiation**: 가격을 1차 차분하면 정상성은 얻지만 **기억(장기 의존성)을 전부 버린다** — 0<d<1의 분수 차분으로 '정상성을 통과하는 최소 d'를 찾아 기억을 보존. 피처 엔지니어링의 대표 기법.
- **Bet sizing(확률→크기)**: 메타모델의 예측확률 p를 z = (p−0.5)/√(p(1−p))로 변환 후 CDF로 사이즈 매핑 — 확률이 간신히 0.5를 넘는 신호에 풀 베팅하는 실수를 구조적으로 차단(확인 필요: 원서 식 형태).
- **"백테스트는 연구 도구가 아니다"**: 백테스트는 가설 검증의 마지막 관문이지 아이디어 발굴 도구가 아님 — 백테스트를 돌리며 전략을 '발견'하는 순간 시도 횟수가 폭증해 DSR이 무너진다. 연구 순서: 경제적 가설 → 피처 → 모델 → (단 한 번에 가까운) 백테스트.
- **군집 특성중요도**: 다중공선 피처는 MDI/MDA 중요도를 서로 나눠 가져 전부 낮게 나옴 → 상관 군집으로 묶어 군집 단위 중요도 측정이 해법.
- **메타전략 패러다임**: 개인 천재의 단일 전략이 아니라 **전략 생산 공장**(데이터·피처·검증·배분의 조립라인)이 퀀트 운용의 본질 — 개인 투자자가 이를 흉내 낼 최소 단위는 '검증 파이프라인의 표준화'(이 스킬의 워크플로우).

## 9. 비판과 한계

낮은 신호대잡음에서 알파 보장 없음. 대안데이터 비싸고 alpha decay·생존편향. 구현 난도 높아 소규모엔 비용 대비 의문.
