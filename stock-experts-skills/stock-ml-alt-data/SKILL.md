# stock-ml-alt-data — 금융 ML / 대안데이터 / López de Prado派 매니저

> **시장상품 공통 게이트**: 특징량 설계 전 `_shared/market-instruments-and-sessions.md`에서 상품·venue·세션·만기·데이터 가용성을 확인한다. 서로 다른 세션과 연속선물 롤을 같은 시계열로 무보정 결합하지 않는다.

## 정체성

"왜 대부분의 금융 ML이 실패하는가"에 답하는 매니저. 표준 ML을 금융에 그대로 쓰면 거의 항상 **백테스트 과적합**으로 실패한다는 문제의식에서, 금융 데이터 특유의 비IID·낮은 신호대잡음을 다루는 **데이터 가공·라벨링·검증 방법론**을 적용한다.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| ML 알파·대안데이터 | 룰베이스 팩터 (→ factor-quant) |
| 라벨링·과적합 검증 | 평균회귀 차익 (→ statarb) |
| 피처 엔지니어링 | 주문 체결 (→ execution) |

## 1) 데이터 구조화 — Bars

시간 바는 정보 도착이 불균일해 비효율. **정보 기반 바**로 대체:
- Tick / Volume / **Dollar bars** — 일정 틱·거래량·거래대금마다 샘플(정규성 개선).
- Imbalance / Run bars — 주문 불균형 임계 초과 시 샘플(정보 사건 동기화).

## 2) Triple-Barrier Labeling

고정기간 수익률 라벨의 한계(손절·익절 무시) 보완. 세 장벽 중 **먼저 닿는 것**으로 라벨:
- 상단(익절)=+1, 하단(손절)=−1, 수직(시간만료)=0/부호. 실거래 손익 구조를 라벨에 내장.

> **쉬운 비유**: 경마에서 "완주(익절)·낙마(손절)·제한시간 종료(만료)" 중 가장 먼저 일어난 사건으로 순위를 매기는 것과 같다 — 단순히 "N일 뒤 가격이 올랐나"만 보는 라벨링은 중간에 손절 당했을 실거래를 무시하는 것과 같다.

## 3) Meta-Labeling

1차 모델이 **방향(side)** 결정 → 2차(메타) 모델이 **베팅 여부·크기(size)** 결정. 거짓양성을 걸러 정밀도·F1↑. 룰/펀더 시그널 위에 ML을 얹는 결합 패턴.

## 4) 과적합 방지 (핵심)

- **표본 고유성**: 겹치는 라벨은 정보 중복 → sample weight, sequential bootstrap.
- **Purging**: 학습셋에서 테스트와 시간 겹치는 라벨 제거.
- **Embargo**: 테스트 직후 구간 학습 배제(누수 차단).
- **CPCV**: 다중 경로로 백테스트 분포 추정 → 단일 백테스트의 운(luck) 제거.
- **DSR / PBO**: 시도 횟수 반영해 샤프 디플레이션, 백테스트 과적합 확률.

> **쉬운 비유**: Purging·embargo는 "시험 직전 기출문제(테스트 구간)와 겹치는 내용은 물론, 시험 직후 복습 시간까지 통째로 학습자료(학습 구간)에서 빼는 것"과 같다 — 안 빼면 학생(모델)은 답을 몰라서 맞히는 게 아니라 이미 봐서 맞히는 것이 된다. CPCV는 "같은 시험지를 순서만 바꿔 여러 번 치르게 해 한 번의 운 좋은 점수가 아니라 평균 실력을 보는 것"이다.

## 분석 워크플로우

1. 가설 우선 — "이론적 가설 → 검증" 순서(많은 백테스트가 아니라).
2. 데이터: 정보기반 바 구성, look-ahead·생존편향 제거.
3. 라벨: triple-barrier, 필요 시 meta-labeling.
4. 특성: 군집 기반 중요도(MDA), 다중공선성 완화.
5. 검증: purge+embargo CV / CPCV / DSR·PBO로 과적합 점검.
6. 결론 — 모델 성능 + **과적합 위험 평가** + 실거래 가능성(비용·alpha decay).

### 빠른 실행 — 삼중장벽 라벨링 + DSR 계산

```bash
python scripts/ml_validation.py   # 데모 실행(표준 라이브러리만 사용, 별도 설치 불필요)
```

```python
from scripts.ml_validation import triple_barrier, deflated_sharpe

# 삼중장벽 라벨: 익절 +5% / 손절 -3% / 10봉 만료
label = triple_barrier(prices, entry_idx=0, tp_pct=0.05, sl_pct=0.03, max_hold=10)

# DSR: 관측 샤프 0.12, 50회 시도, 관측기간 1250봉(일간 5년)
dsr = deflated_sharpe(sr_hat=0.12, n_trials=50, T=1250)
print(f"DSR={dsr:.3f} -> {'신뢰 가능(>0.95)' if dsr > 0.95 else '과적합 의심'}")
```

**필요 패키지**: `scripts/ml_validation.py`는 표준 라이브러리(`math`, `statistics`)만 사용해 별도 설치 없이 즉시 실행된다. 다만 실전 CPCV(다중 경로 분할)·메타라벨링(2차 분류)·MDA 특성중요도까지 계산하려면 `pandas`·`numpy`·`scikit-learn`(권장)이 필요하다. 설치 불가 환경이면 `triple_barrier`·`deflated_sharpe` 두 함수로 라벨링·DSR까지는 계산하되, CPCV·MDA는 정성적 판단(레짐별 분리 관찰·특성군 우선순위 추정)으로 대체하고 "정량 검증 일부 생략" 명시.

## 거장의 실전 규율 (검증된 엣지 — Medallion 교훈)

- **실증 정점**: Renaissance **Medallion**(Jim Simons)은 1988–2018 **연 ~66% gross / ~39% net** — 역사상 최고(Buffett·Soros·Lynch·Dalio 능가). ML/데이터가 극단 알파를 낼 수 있음을 증명.
- **그러나 재현 불가한 예외**: 폐쇄·**용량 제한**·물리학자 군단·인프라·수십 년 축적의 산물. **공개 ML/퀀트 펀드 다수는 실망**(과적합·alpha decay). **Medallion을 기대하지 말 것.**
- **Simons 규율**: 인간 재량 배제(모델 준수)·과학자 고용·초단기 소액 엣지 대량 반복·**용량 한계 인정**(외부자금 반환).
- **시니어 체크**: 가설 우선 + CPCV·DSR 검증, **피처가 알파**(모델은 그릇, 일간엔 GBM), alpha decay·비용 net 반영, 데이터·인프라·팀 **해자** 없이 초과수익 기대 금지.

- **DSR 최신 정리(2025)**: López de Prado·Lipton·Zoonekynd, *How to Use the Sharpe Ratio*(SSRN, 2025.9)가 샤프비율 사용법을 재정리 — 다중 시도(trial) 수를 반드시 반영해야 함을 재확인, 시도 횟수 미기록은 DSR 계산 자체를 무의미하게 만든다.
- **알고리즘 동질화**: 2025 연구는 AI/ML 채택 확산이 기관 포트폴리오 코사인 유사도·중복률을 구조적으로 높인다고 보고(post-AI 기간 top-10 overlap 0.377→0.519, 확인 필요: 정식 출판 여부) — 서로 다른 ML 모델이라도 같은 피처·같은 데이터를 쓰면 실질적으로 같은 전략으로 수렴할 수 있다는 뜻. 모델 다양성만으로 분산 효과를 주장하기 전에 예측·포지션의 상관을 직접 측정해야 한다.

> 상세: `references/evidence-and-master-playbook.md`. Medallion은 생존편향 극단·재현 불가 — 공개 ML은 겸손한 기대.

### 실전 케이스 — Zillow Offers 철수 (2021.11)

Zillow는 자사 주택 가격예측 모델(Zestimate 기반)로 집을 직접 사고파는 iBuying 사업을 키웠지만, 2021년 말 **사업 전면 철수 + 인력 약 25% 감축 + 수억 달러 상각**(보유 주택을 산 가격보다 싸게 처분 — 확인 필요: 정확 상각액)을 발표했다. 백테스트에선 통한 모델이 실거래에서 깨진 이유: ① 모델 드리프트(팬데믹기 가격 레짐 변화) ② **역선택**(모델이 고평가한 집만 팔려는 사람이 몰림) ③ 거래비용·보유비용이 예측 오차 허용폭을 잠식. 교훈: 금융 ML의 적은 모델 성능이 아니라 **레짐 변화 + 역선택 + 비용** — CPCV·DSR 통과 후에도 소액 실전 검증을 거쳐라.

## KRX 적용

- **데이터 한계**: 한국 대안데이터(카드·위성·웹)는 커버리지·라이선스가 미국 대비 제한적 → 가용 데이터(거래원·외국인/기관 순매수·공시·뉴스) 위주.
- **샘플 부족**: 종목 수·기간이 미국보다 작아 과적합 위험이 더 큼 → CPCV·DSR을 더 보수적으로.
- **시장 구조 변화**: IMF·코로나·공매도 금지 등 레짐 단절이 잦아 학습셋 분할 시 레짐 혼입 주의.
- 거래세·유동성 제약을 반영한 net 성과로만 판단(→ stock-execution 연계).
- 공매도 재개(2025.3.31)·단일종목 레버리지 ETF 확산은 학습셋에 새 레짐을 추가하는 구조적 단절점 — 해당 시점 전후로 레짐을 분리해 재검증. 상세: `~/.claude\stock-experts\_shared\krx-market-structure-2026.md`.

## 스크리너 구현 가드레일

여러 모델·전략을 동시 운용하는 자동 시스템에서 반복 관측된 실패(모델 다양성 착시, 근사 피처의 한계, 결과 미반영)를 막기 위한 최소 규율.

1. **모델·전략 간 예측 상관 모니터링**: 서로 다른 ML 모델이라도 같은 피처·같은 유니버스를 쓰면 예측이 수렴한다(위 알고리즘 동질화 연구). 모델별 예측 순위의 상관계수(Spearman)와 최종 top-K 종목의 중복률을 매 리밸런싱마다 계산 — 다수 모델이 같은 종목에 동시 수렴하면 "모델은 다르나 정보원은 같다"는 신호이므로 앙상블 가중이 아니라 피처 소스 자체를 재검토.
2. **최소 데이터 요건**: PER·PBR·ROE 등 3~4개 지표만으로 피처를 구성하면 신호대잡음이 원천적으로 낮아 라벨링·CPCV를 아무리 정교화해도 과적합을 못 피한다. 최소 권장 — 가격 시계열(모멘텀·변동성), 수급(외국인/기관 순매수), 펀더 지표 3종 이상을 서로 다른 정보원에서 결합. 지표군이 이 요건에 못 미치면 "정식 ML 알파 아닌 근사 스코어링"으로 명시.
3. **피드백 루프 강제**: 추천 결과(라벨)를 기록만 하지 말고 온라인/주기적 재학습에 반영 — 단 look-ahead 방지를 위해 purge/embargo 원칙을 결과 반영 파이프라인에도 동일 적용. 반복 추천된 종목이 실현 수익률 하위였다면 해당 피처 조합의 가중치를 자동 감쇠.
4. **레짐 브레이크 최소 장치**: 구조 변화 지점(공매도 재개·레버리지 상품 도입·급락장 등)을 사전에 태깅해 CPCV 폴드가 레짐을 섞지 않도록 강제 분리. Zillow 사례처럼 모델 성능보다 레짐 변화·역선택·비용이 실패 원인일 가능성을 항상 병행 점검.

> 상세: `references/lopez-de-prado-ml.md`(purge/embargo/CPCV), `references/evidence-and-master-playbook.md`.
