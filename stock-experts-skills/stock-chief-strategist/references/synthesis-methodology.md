# 레퍼런스(심화) — 다중 관점 종합 방법론 (CIO 의사결정)

> 목적: 여러 전문가의 상충 의견을 **편향 없이 결합**하는 방법론. 라우터의 핵심 역량.
> 웹 출처: Black-Litterman(view 결합), 앙상블·다중전략 통념, Tetlock 예측 종설 통념.

## 1. 시간축 분리 (충돌 ≠ 모순)

- 같은 종목에 "장기 저평가(deepvalue) + 중기 추세 약세(trend)"는 둘 다 참일 수 있음.
- **결론을 시간축별로 분리** 제시(장기/중기/단기). 단일 결론 강요 금지.

## 2. 전제(가정) 노출

- 각 전문가 결론이 의존하는 가정(성장 지속·평균회귀·국면 판정·해자 유지)을 명시.
- 가정이 깨지는 조건(무효화 레벨·트리거)을 함께 — 그래야 모니터링 가능.

## 3. 확신도 가중 & 베이지안 갱신

- 각 view에 **확신도**를 부여해 가중(Black-Litterman 정신, → [[black-litterman-allocation]]).
- 신호 정합(여러 전문가 동방향) = 확신↑. 새 데이터로 사후 갱신.
- 단순 다수결 금지 — 근거의 질·독립성으로 가중(상관된 의견은 한 표).

## 4. 리스크/심리 Veto

- portfolio-risk·tail-risk·behavioral의 경고는 **거부권급 가중**. 시그널이 좋아도 사이징·꼬리·과열이 경고하면 보수적.
- "기대수익"보다 "생존(파산 회피)"을 우선.

## 5. 전문가 선정 규율

- 질문의 시간축·목적·스타일로 **1~3명만** 호출(과다 호출 = 노이즈). routing-matrix 참조.
- 방법이 특정된 질문은 해당 전문가 직접(라우터 우회).

## 6. 불확실성 정직성

- 합의 없으면 **억지 결론 금지** → "이견 + 무엇을 더 확인하면 갈릴지(확인 필요 데이터)"로 제시.
- 과신은 가장 흔한 실패(→ [[bias-catalog-munger]]). 예측은 확률·범위로.

## 7. 앙상블/다중전략 관점

- 독립적이고 약상관인 시그널·전략의 결합이 단일보다 강건(분산). 단 같은 데이터·같은 편향이면 분산 효과 없음.

## 8. 자동매매 파이프라인 조립

시그널(factor·statarb) → 거시/섹터 게이트(macro·sector) → 심리 필터(behavioral) → 사이징(portfolio-risk) → 헤지(tail-risk) → 실행(execution). 각 단계가 veto/조정 권한.

## 8.5 심화 — SKILL.md 비중복

- **Tetlock 슈퍼포캐스터 규율**: ① **base rate에서 시작**(내부 관점 아닌 외부 관점: "이런 류의 상황은 역사적으로 몇 %나 그렇게 됐나") ② 새 증거마다 **작게 갱신**(한 번에 뒤집지 않음) ③ 확률을 5%p 단위로 캘리브레이션. CIO 종합의 사전확률 = 각 스킬의 실증 base rate(evidence 파일들).
- **전문가 독립성 확보**: 전문가를 순차로 호출하면 앞 결론이 뒤를 오염(앵커링) — 가능하면 **각 전문가를 독립적으로 분석시킨 뒤** 종합 단계에서 처음 교차. 같은 데이터에서 출발한 의견 일치는 독립 확인이 아니다(한 표 처리).
- **Premortem(사전부검)**: 결론 확정 전 "1년 뒤 이 판단이 완전히 틀렸다고 가정하고, 무엇 때문이었는지"를 먼저 작성 — 각 전문가의 '한계' 섹션이 그 재료. 무효화 조건을 결론에 박는 절차적 장치.
- **의견 스프레드 = 불확실성 측정치**: 전문가 결론의 분산 자체가 정보 — 일치(낮은 스프레드)면 사이징 상향 여지, 큰 스프레드면 그 자체로 '확인 필요 데이터가 많다'는 신호라 사이징 하향. 스프레드를 보고서에 명시.
- **종합 결론의 형식 규율**: [방향 + 시간축 + 확률(또는 확신도) + 무효화 조건 + 사이징 게이트] 5요소를 모두 채워야 완결 — 하나라도 빠지면 모니터링 불가능한 '감상'이 된다.

## 9. 비판과 한계

종합은 **구성 전문가 품질의 합 이상을 못 만든다**(쓰레기 입력 시 쓰레기 종합). 확신도·가중은 주관적. 다중 view가 같은 편향을 공유하면 거짓 합의. 결론은 항상 실데이터 검증·사용자 판단을 거친다 — 투자 자문 아님.
