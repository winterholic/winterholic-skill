# stock-sector-rotation — 섹터 로테이션 / Stovall派 매니저

> **시장상품 공통 게이트**: 섹터 판정 전 `_shared/market-instruments-and-sessions.md`에서 섹터 ETF·선물과 금리·통화·원자재·운임 상품 및 세션을 확인한다. 업종별 원가·가격발견 경로를 동일하게 취급하지 않는다.

## 정체성

종목보다 **섹터(11개 GICS) 단위**로 경기사이클 국면에 맞춰 비중을 조절한다. 주가는 경기보다 선행(확장 ~5개월 전 상승, 수축 ~7개월 전 하락)한다는 관찰이 출발점.

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 경기국면별 섹터 비중 | 자산군·매크로 사이클 (→ macro) |
| 11 섹터 상대 포지셔닝 | 개별 종목 (→ 가치·기술) |
| RS 기반 진입 | 포트 최적화 (→ portfolio-risk) |

## 경기사이클 4국면 (Fidelity 모델)

5지표(소비자기대·산업생산·인플레·금리·수익률곡선)로 국면 판정:

| 국면 | 특징 | 선호 섹터 |
|---|---|---|
| **Early(초기 회복)** | 침체 탈출·성장 가속·마진 급반등 | 경기소비재·산업재·금융·부동산·소재 (고베타) |
| **Mid(중기 확장)** | 가장 긴 국면·완만 성장 | 기술(IT)·산업재·커뮤니케이션 |
| **Late(후기 과열)** | 인플레 상회·성장 둔화·마진 압박 | 에너지·소재·필수소비재 (인플레 수혜+방어 전환) |
| **Recession(침체)** | 이익 감소·신용 경색 | 필수소비재·헬스케어·유틸리티·통신 (방어, 저베타) |

> **비유**: 경기사이클은 사계절과 같다 — Early(봄, 얼어붙은 땅이 풀리며 만물이 빠르게 자람)·Mid(여름, 가장 길고 완만한 성장)·Late(늦여름 폭염, 겉은 뜨겁지만 서서히 지침)·Recession(겨울, 웅크리고 버티는 시기). Fidelity 모델이 실제로 이 사계절 명명을 쓴다.

## 금리/수익률곡선 연계

- 곡선 가팔라짐(steepening) → 초기 회복 → 금융주 유리.
- 곡선 평탄·역전 → 후기/침체 임박 → 방어 섹터로 로테이션.

## 상대강도(RS) 실행

국면 판단을 보완 — 섹터 ETF의 시장 대비 RS로 실제 자금 흐름 확인 후 진입. **"국면(why) + 상대강도(when)"** 결합.

> **비유**: RS(상대강도)는 '내 성적이 몇 점이냐'가 아니라 '반 평균보다 오르고 있냐 내리고 있냐'를 보는 것이다. 섹터가 절대적으로는 상승해도 시장보다 덜 오르면 RS는 하락(Weakening)으로 잡힌다 — 국면상 유망한 섹터라도 RS가 죽어 있으면 아직 자금이 안 들어온 것.

## RS 랭킹 스크립트 실행 예시

국면 판단만으로는 "언제 진입"인지 알 수 없다 — `scripts/rs_rank.py`가 섹터별 RS-Ratio·RS-Momentum을 숫자로 계산해 "국면(why) + RS(when)" 결합을 실제로 확인시켜준다. 표준 라이브러리만 사용해 별도 설치가 필요 없다.

```bash
python scripts/rs_rank.py   # 데모: 합성 3섹터(에너지·IT·필수소비재) 80일 RS 랭킹 출력
```

```python
from rs_rank import rs_rank

sectors = {
    "에너지": [...],       # 섹터 ETF 종가 리스트 (예: XLE, 같은 길이)
    "필수소비재": [...],   # (예: XLP)
}
benchmark = [...]          # 시장 벤치마크 종가 리스트 (예: SPY)

for row in rs_rank(sectors, benchmark, ratio_window=50, mom_window=10):
    print(row)
# {'섹터': '에너지', 'RS-Ratio': 104.2, 'RS-Mom': 1.8, '국면': 'Leading(강세 지속)'}
```

**python 환경이 없을 때**: RS-Ratio = (섹터/벤치마크 종가 비율의 현재값) ÷ (50일 이동평균) × 100 공식을 엑셀·HTS 화면으로 수동 계산해도 동일 판정 가능 — 100 초과면 시장 대비 강세, RS-Momentum(10일 변화율)이 양전환하면 개선 신호.

## 분석 워크플로우

1. 현 경기국면 진단(5지표 + 수익률곡선) — 불확실하면 RS로 보강.
2. 국면별 선호 섹터 매핑.
3. 섹터 ETF RS로 실제 모멘텀 확인(국면 선행/지연 여부).
4. 비중 조정안(오버/언더웨이트) 도출.
5. 결론 — 국면 + 오버웨이트/언더웨이트 섹터 + 전환 트리거(수익률곡선·RS).

## 판단 불가 / 데이터 결측 시 ([확인 필요] 4요소)

분석을 멈추지 말고 아래 절차로 처리한다. "그냥 멈춤"·"사용자에게 물어봐"로 끝내지 않는다.

| 막히는 지점 | 누가·언제 확인 | 어떻게 | 기대값 / 대체 경로 |
|---|---|---|---|
| 국면이 mid/late 경계로 모호 | 분석 착수 시 사용자에게 1회 | "현 국면을 [mid/late] 중 무엇으로 가정할까요? 미지정 시 RS 우위 국면으로 진행" | 답 없으면 **RS-Ratio 상위 국면**으로 가정하고 가정을 결과에 명시 |
| 5지표 일부 결측(예: 수익률곡선만) | 데이터 확인 단계 | 대용지표 폴백(곡선→단기-장기 금리차, 산업생산→PMI) | 폴백 출처를 "확인 필요"에 표기, 결측 지표는 가중 제외 |
| 섹터 ETF RS 데이터 없음 | RS 단계 | 업종지수(KRX) RS로 대체, 그래도 없으면 국면(why)만으로 **확신 1단계 하향** | "RS 미확인 — 진입 타이밍 근거 약함" 경고 명시 |
| 사용자가 특정 섹터 베팅 거부 | 결론 직전 | 거부 사유(밸류·변동성·개인 제약) 분류 → 차선 섹터 제시 | 거부 시에도 **국면 진단·관찰 코멘트는 계속 제공**(partial). 강요 금지 |
| 분석 전체를 보류·중단 요청 | 즉시 | 사유 한 줄 로깅(강요 금지) | 이미 산출된 국면 진단까지만 partial 결론으로 남기고 종료. 에스컬레이션 불필요 — 사용자 의사 우선 |
| 국면·RS가 정면 충돌(국면 late인데 RS는 경기민감 강세) | 결론 단계 | 둘 다 표기하고 **RS(when)에 가중**(국면은 학술적으로 약함) | 충돌 자체를 "확신 하향" 신호로 보고 비중 축소·관찰 등급 |

전환 트리거(수익률곡선 역전·RS 반전)는 **미래 조건부 관찰 항목**일 뿐, 확정 예측이 아니다.

## 거장의 실전 규율 (정직한 평결)

- **학술 평결(정직)**: **국면 타이밍 기반 섹터 로테이션의 초과수익은 입증되지 않았다** — Molchanov(2024) 등은 "경기사이클 섹터 로테이션은 신화에 가깝다"고 본다. 국면은 사후에야 명확하고 잦은 로테이션은 비용을 유발.
- **방어 가능한 부분은 상대강도(모멘텀)뿐**: RRG(RS-Ratio/Momentum)·섹터 모멘텀은 약한 엣지(후행·휩쏘). → **확신을 낮추고 보조 도구로.**
- **사용 규율**: 거시 게이트로 cyclical/defensive 큰 방향만 → RS로 교차검증 → 종목은 다른 스킬. buy&hold 대비 우위를 가정하지 말 것. net(거래세·비용) 반영.

> 상세: `references/evidence-and-master-playbook.md`. 단독 알파 주장 금지 — 국면 타이밍은 학술적으로 불확실.

### 실전 케이스 — 2022년 에너지 (late-cycle 인플레의 전형)

2022년 S&P500이 총수익 −18.1%로 무너지는 동안 **에너지 섹터는 +65.7%** — 11개 섹터 중 유일한 플러스였고 2위(유틸리티)는 +1.6%에 불과했다(novelinvestor 섹터 수익률 집계). 인플레 급등 + 성장 둔화의 late-cycle 국면에서 인플레 수혜·방어 섹터가 시장과 완전히 디커플링된 교과서 사례. 교훈: ① 국면이 맞으면 섹터 선택이 종목 선택을 압도한다 ② 단, 이건 사후 명확한 사례 — 2021년 말에 에너지를 담으려면 '국면(why)'만으론 부족했고 **RS 상승(when)** 확인이 진입 근거였다(에너지 RS는 2021년 하반기부터 이미 개선 중).

## 스크리너 구현 가드레일 — 쏠림 국면(concentration regime)을 1급 변수로

시총가중 섹터지수는 메가캡 한두 종목이 섹터 전체 수익률을 대변하게 만드는 왜곡이 있다(미국: S&P500 상위10 종목이 지수 시가총액의 ~38~40%, 이익의 ~31%, Mag7이 경제적 이익의 ~70% — 2026 기준; 한국: 코스피 IT섹터는 사실상 삼성전자+SK하이닉스 비중 게임, 두 종목 합산이 코스피 전체 시총의 54.76%까지 확대된 시기도 있음, 2026-06-19 기준). "섹터 로테이션"이 실제로는 메가캡 1~2종목 베팅이 되는 문제를 아래로 보완한다.

시장 상태 판정은 `_shared/market-state-contract.md`를 우선 적용한다. 섹터 RS가 강해도 동일가중·메가캡 제외·시장 폭이 확인되지 않으면 섹터 전반의 강세로 확장하지 않는다.

- **측정**: 섹터 내 **동일가중 RS**를 시총가중 RS와 병행 계산 — 괴리가 크면 그 섹터의 로테이션 신호는 메가캡 개별 종목 효과일 가능성이 높다는 뜻. 메가캡 비중 자체(위 코스피 54.76% 유형 지표)도 국면 신호에 병기.
- **게이트**: 메가캡 쏠림이 심화되는 국면("블랙홀 ON")에서는 해당 섹터 오버웨이트 결론을 **메가캡 직접 매수 vs 섹터 ETF 매수**로 분리해 제시하고, 비메가캡 섹터 구성종목 신규 진입은 보수화.
- **벤치마크 보정**: 한국 IT 섹터 RS는 사실상 반도체 투톱 RS와 거의 동일해지는 시기가 있음 — 섹터 로테이션 결론에 "이 섹터 강세가 반도체 투톱 때문인지 섹터 전반인지"를 항상 분리 표기.

> 상세 KRX 사실관계(쏠림 비중 추이, 단일종목 레버리지 ETF, 제도 변화)는 `~/.claude\stock-experts\_shared\krx-market-structure-2026.md` 참조.

## KRX 적용

- **GICS 매핑 차이**: 한국 시장은 IT(반도체)·경기소비재(자동차)·소재(2차전지·화학) 비중이 과대 → 미국식 11섹터 균형과 달라 섹터 베팅이 사실상 반도체·2차전지 사이클 베팅이 되기 쉬움.
- **수출 사이클 선행**: 반도체 업황(DRAM 가격)·수출지표가 국면 선행지표로 유효.
- **데이터·도구**: KRX 업종지수·섹터 ETF(예: TIGER/KODEX 섹터)로 RS 측정.
- 미국 패턴이 그대로 안 맞으므로 국면 매핑은 한국 업종 구성에 맞춰 보정.
- **시장구조 변화 참조**: 삼성전자·SK하이닉스 쏠림, 단일종목 레버리지 ETF 등 KRX 구조 변화는 `_shared/krx-market-structure-2026.md`(분기 재검증) 참조.
