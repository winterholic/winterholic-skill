# 레퍼런스(심화) — 실행 알고리즘 상세 (Almgren-Chriss·SOR·다크풀·RL)

> 목적: 실행 알고리즘의 수학적 구조와 현대 venue·AI 실행까지.
> 웹 출처: Medium(Almgren-Chriss framework), quantitativebrokers(IS history), arxiv(RL execution), hal.science(optimal execution).

## 1. Almgren-Chriss (최적 실행의 표준, 2000)

- 거래를 **시장충격 vs 가격 리스크 trade-off** 최적화로 정식화.
- 임시충격(temporary, 체결 속도에 비례)과 영구충격(permanent) 분리 모델링.
- **위험회피 λ**: λ↑(긴급) → 빠르게 체결(충격↑), λ→0 → 선형 스케줄 = **TWAP**.
- 출력: 매끄러운 청산 궤적(execution trajectory).

## 2. 알고리즘 계열

| 알고 | 스케줄 | 특징 |
|---|---|---|
| TWAP | 시간 균등(사전) | 단순·예측 가능 |
| VWAP | 거래량 프로파일(사전) | 충격 최소 표준 벤치마크 |
| POV | 실시간 거래량 비율(동적) | 유동성 추종 |
| IS/Adaptive | 충격↔타이밍 동적 | urgency로 조절 |
| Iceberg | 호가 일부만 노출 | 정보 누출 억제 |

## 3. Smart Order Routing (SOR) & 다크풀

- 다수 거래소·ECN·다크풀로 주문 분할 라우팅 → 최良 체결가·유동성.
- **다크풀**: 호가 비공개로 대량주문 정보 누출 억제(단 역선택·정보비대칭 위험).

## 4. RL 실행 (현대)

- 강화학습(DQN·PPO)이 시장 상호작용에서 적응적 스케줄 학습 → TWAP/VWAP 대비 우월 보고.
- 모델 가정 없이 학습하나 과적합·레짐 변화 위험(→ [[lopez-de-prado-ml]] 검증 필요).

## 5. Implementation Shortfall 재확인

- IS = 결정가 대비 실제 체결 결과 손실(충격+타이밍+미체결). 모든 알고리즘 평가의 단일 벤치마크.
- 알고리즘 선택: 소량·긴급→공격적/IS, 대량·비긴급→VWAP/분산.

## 6. 정보 활용

- 실시간 호가 잔량·체결 속도·거래량 프로파일, venue별 체결 통계.

## 7. KRX 적용

- 다크풀·복수거래소 구조가 미국 대비 단순(주로 KRX 단일) → SOR 효용 제한, 시간 분할(VWAP/TWAP) 중심.
- 동시호가·VI로 연속 스케줄 단절 → 단일가 구간 제외 설계. 거래세(매도)로 분할 비용 고려.

## 8. 비판과 한계

VWAP는 대량주문 자기참조(스스로 벤치마크 견인). 충격 모델은 추정 — 변동성 급변·유동성 증발 시 빗나감. RL은 블랙박스·과적합 위험. 정보 누출(다크풀도)로 실제 비용 > 모델.
