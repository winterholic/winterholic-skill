# 레퍼런스 — Harris & Kissell (Execution / Microstructure)

> 원저작: Larry Harris *Trading and Exchanges*(2003); Robert Kissell *The Science of Algorithmic Trading*(2013).
> vault 소스: `sources/stock-investing/harris-kissell-execution-microstructure.md`. 스킬 실행용 가공본.

## 1. 정체성

"어떻게 체결할까". 체결 품질이 나쁘면 알파 소멸. Harris=시장구조 교과서, Kissell=실행 알고·비용 수식화.

## 2. 참가자 (Harris)

이익동기(정보·가치·차익·추세) vs 유동성 공급자(딜러/마켓메이커, 역선택 위험). 스프레드·시장충격이 비용 원천.

## 3. 거래비용 분해

명시(수수료·세금) + 암묵(스프레드, 시장충격 임시/영구, 슬리피지, 타이밍/기회비용).

## 4. Implementation Shortfall

IS = paper 수익 − 실제 수익. 결정가 대비 총손실(충격+타이밍+미체결). 최적화 목적 = IS 기대·분산 최소화.

## 5. 실행 알고리즘

TWAP(시간균등) / VWAP(거래량 프로파일, 충격 최소 표준) / POV(거래량 비율) / IS·Adaptive(충격↔타이밍 동적, urgency).

## 6. Almgren-Chriss

시장충격(빠를수록↑) vs 변동성 리스크(느릴수록↑) trade-off를 효용함수로 → 최적 청산 스케줄. λ로 속도 조절.

## 7. KRX 적용

거래세(매도) 고정비용 → 저회전 유리, TCA 포함. ±30%·VI·동시호가가 VWAP 왜곡. 소형주 유동성 절벽→분할 확대·POV 보수. 외국인·프로그램 호가 모니터링.

## 7.5 심화 — SKILL.md 비중복

- **지정가의 숨은 비용 = 역선택**: 지정가는 스프레드를 아끼지만, 체결되는 순간은 대개 **정보 보유자가 반대편일 때**(가격이 불리하게 움직이기 직전). '공짜 스프레드'가 아니라 역선택 위험과의 교환 — 알파가 빠른 전략일수록 시장가/공격적 지정가가 정당.
- **긴급도-알파 감쇠 매칭**: 실행 속도의 제1 결정변수는 주문 크기가 아니라 **알파의 반감기** — 시그널이 며칠 안에 죽으면 충격을 감수하고 빠르게, 가치형처럼 느리면 며칠 분할. "충격 최소화"가 항상 정답이 아닌 이유.
- **정보 누출**: 일정한 슬라이싱 패턴(매 5분 같은 수량)은 탐지 알고리즘의 먹잇감 — 수량·시점 랜덤화, 아이스버그 주문 활용. 단 아이스버그도 잔량 탐지 기법이 존재.
- **Kissell류 비용 모델 구조**: 충격 ≈ a₁·(Q/ADV)^a₂·σ^a₃ 형태의 멱함수 + 일중 거래량 프로파일(U자형) 보정 — 계수는 시장별 실측. 제곱근 법칙(a₂≈0.5)은 그 특수형.
- **TCA 리포트 최소 항목**: arrival price 대비 / VWAP 대비 / close 대비 슬리피지를 **분리 보고** + 주문 크기·변동성·urgency별 분해 — 단일 평균은 개선점을 숨긴다. 측정 없는 실행 개선은 없다.

## 8. 비판과 한계

VWAP 자기참조. 시장충격 모델 추정치(레짐 변화 빗나감). HFT·다크풀·정보 누출로 실제 비용 과소추정.
