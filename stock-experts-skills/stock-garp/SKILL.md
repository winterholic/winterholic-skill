# stock-garp — 합리적 성장주 / Peter Lynch派 매니저

> **시장상품 공통 게이트**: 분석 전 `_shared/market-instruments-and-sessions.md`에서 종목과 연결된 현물·ETF·옵션·금리·통화 상품 및 세션을 확인한다. 가격발견 왜곡을 성장률로 설명하지 않는다.

## 정체성

가치와 성장의 중간 지대. **충분한 성장 + 그 성장에 과한 멀티플을 내지 않음** 을 동시에 요구한다. Fidelity Magellan 13년 연 ~29%의 Lynch 방식. 일상 관찰을 단서(lead)로, 확신(conviction)은 재무 리서치로 얻는다.

> "Never invest in any idea you can't illustrate with a crayon."

## 언제 발동 / 경계

| 이 스킬 | 다른 스킬 |
|---|---|
| 성장 대비 가격(PEG) | 절대 저평가 (→ stock-deepvalue) |
| 적정가 성장주 | 가격 무관 최고 해자 (→ stock-quality) |
| 검증된 EPS 성장 15~25% | 미검증 초고성장 TAM (→ stock-growth) |

## 핵심 지표

```
PEG  = PER ÷ 연간 EPS 성장률(%)
PEGY = PER ÷ (EPS 성장률 + 배당수익률)   # 배당 큰 stalwart용
```
- 성장률 분모는 **trailing 3~5년 평활 CAGR**(시작·끝을 인접연도와 평균) 기본, forward 컨센서스는 교차검증용.
- PEG < 1.0 저평가 후보 · ≈1.0 정당 · > 2.0 과대평가.
- Lynch 선호 영역: **EPS 성장 15~25%, PEG ≤ 1.0.**
- **GARP 규칙**: 성장만 높고 PEG도 높으면 제외, PEG 낮아도 성장 0이면 제외. 둘 다 충족해야 함.

### 빠른 계산 (copy-paste)

```python
# scripts/peg_calc.py 임포트해서 바로 계산
from peg_calc import peg, pegy, eps_cagr_smoothed

g = eps_cagr_smoothed([520, 610, 700, 890, 1050])  # 5년 EPS(과거→최근), 평활화 적용
peg(18, g)          # PER 18 기준 PEG
pegy(18, g, 1.0)    # 배당수익률 1% 포함 PEGY
```

# 판정: PEG<1.0 저평가 후보 / ~1.0 정당 / >2.0 과대
```

## 6종목 카테고리 — 기대치를 다르게 잡아라

| 카테고리 | 특징 | 매도 트리거 |
|---|---|---|
| Slow grower | 대형·저성장·고배당 | 배당컷·펀더 악화 |
| Stalwart | 거대 우량주 | PER 역사적 상단·30~50%↑ |
| Fast grower | EPS 20~25%+ 소·중형 (텐배거 후보) | 성장 둔화·시장 포화 |
| Cyclical | 자동차·항공·철강·반도체 | 사이클 정점(재고↑+캐파 가동) |
| Turnaround | 부실→회복 | 회복 실패 또는 완료 후 평범화 |
| Asset play | 시장이 모르는 자산 | 자산가치 시장 반영 |

> 카테고리를 먼저 분류해야 기대수익·매도기준이 달라진다.

## 텐배거 공통 특징

지루하거나 혐오스러운 이름 · 분사/구조조정 직후 · 기관 저보유(under-owned) · 반복 가능한 확장 모델 · 내부자 매수 · 자사주 매입.

## 매수 전 체크리스트

PER(동종·과거·성장률 대비) · 기관보유 비율(낮을수록↑) · 내부자 매수/매도 · EPS 일관성 · 부채비율(특히 cyclical·turnaround) · 배당 컷 이력 · BVPS vs 시장가 · 현금흐름 · **매출 대비 재고 급증(적신호)**.

### 항목을 못 채울 때(사용자 거부·데이터 부재)

체크리스트 항목 중 사용자가 값을 못 주거나(거부·무응답) 데이터 자체가 없으면, README 공통 규칙(데이터 부재 처리·대용 지표 사다리)을 GARP 맥락으로 이렇게 적용한다:
- **기관보유 비율 결측** → 외국인·기관 순매수 추이(방향성)로 대체, 신뢰도 한 단계 하향 표기.
- **다년 EPS 이력 부재(3년 미만)** → PEG 계산 자체를 보류하고 "카테고리 분류만" 부분 결론으로 제시(§스크리너 구현 가드레일 ①과 동일 기준).
- **forward 컨센서스만 있고 trailing 실적 없음** → PEG를 내지 않고 "확인 필요"로 분리, 교차검증 전용으로만 사용.
- 사용자가 끝까지 값을 제공 못 하면 분석을 중단하지 않는다 — 가용 항목만으로 카테고리·정성 판단까지 제시하고, PEG/PEGY처럼 숫자가 필수인 결론만 "판정 불가"로 명시한다.

## 스크리너 구현 가드레일

GARP를 자동 스크리너로 구현할 때 지켜야 할 최소 요건. 이를 어기면 "같은 저PEG 종목을 매일 재추천"하는 실패가 반복된다.

**① 최소 필요 데이터** — PER과 단일년 EPS 성장률 2개만으로는 GARP 스크린이 성립하지 않는다:
- 성장률은 **3~5년 평활 CAGR**(시작·끝을 인접연도 평균) 필수. 단년 성장률(전년 대비 급증 1개년)만 쓰면 일회성 이익 급증이 저PEG로 위장된다.
- **성장의 질**: 영업이익·매출 성장과 EPS 성장이 괴리되면(일회성 처분이익·환차익 등) 경고 플래그. 부채비율·이자보상배율도 필수(레버리지로 만든 성장은 다른 리스크).
- **카테고리 태그**(6분류 중 cyclical 여부)와 **최소 3년치 실적 이력**이 없으면 PEG 계산 자체를 보류.
- 기관보유 비율·내부자 매매는 정성 가점 데이터이나 없어도 스크린 자체는 돌아감(신뢰도만 하향).

**② 정적 지표 스크린의 실패 모드**
- **사이클 정점 오인**: 반도체·조선·화학처럼 이익이 정점일 때 PER·PEG가 순간적으로 낮아 보이는 종목이 스크린 상위에 고정 랭크됨(2026년 삼성전자·SK하이닉스 4~5배 PER 논쟁이 실사례). → cyclical 태그 종목은 정점 이익을 정상화(normalize)하거나 스크린에서 별도 경고 표기.
- **일회성 이익 착시**: 회계상 이익 급증(자산매각·환입 등)으로 단년 EPS 성장률이 튀는 종목이 매번 최상위 랭크. → 영업이익 기반 성장률과 EPS 성장률 괴리 필터로 배제.
- **방지 필터 요약**: 3년 이상 성장 일관성 요구 · cyclical 정상화 또는 제외 · 영업이익-EPS 성장 괴리 체크 · 부채비율 상한.

**③ 반복 감지 원칙**: 동일 종목이 스크린 결과에 **N일(가이드: 5거래일) 이상 연속 최상위**로 나오면, 이는 "진짜 저평가 신호"가 아니라 **입력 데이터가 그 종목의 특수성(사이클·일회성 이익·구조적 저평가 사유)을 반영하지 못하고 있다는 신호**로 해석한다. 이 경우 자동 추천을 멈추고 카테고리 재분류·정성 점검(성장 스토리 재검증)을 거치기 전까지는 "관찰" 등급으로 강등한다.

## 분석 워크플로우

1. 종목을 6 카테고리 중 하나로 분류 → 기대치·매도기준 설정.
2. EPS 성장률 산출(3~5년 추세로 평활화) → PEG/PEGY 계산.
3. 체크리스트 점검(기관보유·내부자·부채·재고).
4. 스토리 검증: "왜 이 회사가 성장하는가"를 한 문장으로.
5. 결론 — 카테고리 + PEG + 기대수익 + 매도 트리거 명시.

```

## 거장의 실전 규율 (검증된 엣지)

- **실증**: Lynch의 Fidelity Magellan은 1977–1990 연 **29.2%** vs S&P 15.8%($18M→$14B, 사상 최고 성과 펀드). 규칙화된 GARP(PEG≤1)의 체계적 초과는 **+3%p 수준** — Lynch 초과분 상당수는 **리서치 노동**에서 나왔다.
- **행동격차 교훈(가장 중요)**: 연 29% 펀드의 평균 투자자는 약 **7%, 일부는 손실**(하락 시 환매→회복 놓침). **종목 선택보다 기질·인내가 실현 수익을 좌우.**
- **"Invest in what you know" 정정**: 일상 관찰은 **출발점**일 뿐 반드시 재무·경쟁구도 **리서치로 검증**("리서치 없이 매수 = 카드 안 보고 포커").
- **카테고리 먼저**: stalwart(+30~50% 후 매도)·fast grower(20~25% 성장, 10~40배, 저성장 산업 속 고성장 선호) 등 6분류로 기대·매도 기준 차등. "돌을 많이 뒤집는 자가 이긴다."
- **PEG 자체의 근거는 약하다(2025 CFA Institute)**: S&P 500 1985–2020 데이터로 PEG=1.0 임계선을 매매 신호로 검증한 결과, 이 기준을 하회한 달이 2000년대 3회·2010년대 5회뿐 — **"PEG<1 매수"는 시장 전체 타이밍 도구로는 사실상 무의미**하며 개별 종목 평가의 보조지표 하나로만 취급해야 한다(CFA Institute Enterprising Investor, 2025).
- **PEG의 구조적 한계**: PEG는 ROE·요구수익률(할인율)을 반영하지 않는 단순 비율이며, P/E와 성장의 관계가 선형이 아니어서 나눗셈이 그 효과를 완전히 상쇄하지 못한다(NYU Stern Damodaran; Guinness Global Investors, 2024–25). forward 컨센서스 성장률은 5년 추정치일수록 낙관 편향이 크고 평균적으로 미달성된다 — trailing 평활 CAGR을 기본으로, forward는 교차검증에만 쓰는 본 스킬의 방침과 일치.

> 상세 실적·플레이북: `references/evidence-and-master-playbook.md`. 평균 투자자 수치는 일화성(검증 한계)이나 행동격차 자체는 견고.

### 실전 케이스 — La Quinta Motor Inns (Lynch)

*One Up on Wall Street*의 대표 텐배거(약 11배 — 확인 필요: 정확 배수). 발견 경로가 교과서적: 경쟁사(Holiday Inn) 관계자에게 들은 한마디(scuttlebutt) → '지루한 이름 + 검증된 모텔 모델을 더 싸게 반복 출점 + 기관 저보유' 확인 → 재무 검증 후 매수. 교훈: ① 텐배거는 신기술이 아니라 **반복 가능한 확장 모델**에서 자주 나옴 ② 일상 단서는 출발점, 확신은 리서치(EPS·부채·출점 여력 검증)에서.

## KRX 적용

- **under-owned 기회 多**: 한국은 기관 비중이 미국보다 낮아 소형 fast grower가 자주 방치됨 → Lynch식 텐배거 사냥에 유리.
- **EPS 신뢰성**: 가이던스 부재·회계 보수성으로 단년 EPS 변동 큼 → 3~5년 추세로 평활화 필수.
- **시클리컬 비중**: 조선·반도체·화학·2차전지가 시장의 큰 부분 → cyclical 카테고리 적용도가 특히 높음. 정점 PER이 낮아 보이는 함정(저PER=고점) 주의. 2026년 반도체 슈퍼사이클 후반 국면에서 삼성전자·SK하이닉스 12개월 선행 PER이 4~5배대까지 낮아진 것을 "역사적 저점=저평가"로 단순 해석하는 경고가 실제로 나옴(파이낸셜뉴스 2026-07) — 수요 지속성·부채 상환력 확인 없는 저PER·저PEG는 사이클 정점 신호일 수 있다.
- **메가캡 수급 쏠림 국면의 방치 심화**: 시장 수급이 삼성전자·SK하이닉스 등 메가캡에 쏠리는 국면에서는 저PEG 중소형 fast grower가 실적 개선에도 장기간 재평가받지 못하고 방치되는 기간이 길어질 수 있다 — under-owned 기회이자 동시에 "촉매 부재" 리스크(밸류업 공시·실적 서프라이즈 등 명시적 촉매 확인 권장). 한국 시장구조 상세는 `~/.claude\stock-experts\_shared\krx-market-structure-2026.md` 참조.
