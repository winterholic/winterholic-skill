# 가치 실현 게이트

저PBR·저PER·큰 장부자산을 발견했을 때 정량 스크린보다 먼저 “주주가 그 가치를 실제로 회수할 수 있는가”를 검사한다.

## 1. 자산을 회수 형태로 재분류

| 자산 유형 | 판단 원칙 |
|---|---|
| 현금·단기금융자산 | 담보·사용제한·자회사 귀속을 차감한 뒤 인정 |
| 상장 유가증권 | 세금·시장충격·지배권 할인과 매각 권한을 반영 |
| 매출채권·재고 | 연령·회전율·불량률·담보를 근거로 회수율을 산정 |
| 비핵심 토지·건물 | 독립 감정가, 처분 권한, 세금, 실제 매각 촉매가 있을 때만 인정 |
| 영업필수 전용자산 | 송배전망·전선·변전소·전용 공장처럼 사업을 멈추지 않고 팔 수 없는 자산. 단순 청산가치로 전액 인정하지 않는다 |
| 무형자산·이연자산 | 독립 매각 증거가 없으면 청산가치에서 제외 |

고정 할인율을 모든 기업에 적용하지 않는다. 회수율은 자산별 근거와 범위로 제시한다.

## 2. 주주의 청구권 확인

- 연결 자회사 부채·우선주·연금·충당부채·우발채무·담보권을 먼저 차감한다.
- 자산이 모회사 일반주주에게 귀속되는지 확인한다. 자회사 현금은 배당 제한과 소수주주 지분을 반영한다.
- 지배주주가 자산을 보유만 하고 배분하지 않은 이력이 있는지 본다.

## 3. 규제 가격결정권과 정치 위험

전력·가스·통신·보험 등은 규제 가격결정권을 별도 축으로 평가한다.

- 판매가격·요금·보험료를 회사가 독립적으로 조정할 수 있는가
- 원가 상승을 가격에 전가하는 공식 규칙과 시차가 있는가
- 정부 정책이 배당·투자·차입·자산매각을 제한하는가
- 정책 변화가 공표된 사실인지 기대나 선거 공약인지 구분했는가

규제 가격결정권이 약하고 영업필수 전용자산 비중이 높으면 낮은 PBR은 안전마진이 아니라 구조적 할인일 수 있다.

## 4. 가치 실현 촉매

다음처럼 주주가치로 전환되는 경로가 확인돼야 `candidate`로 승격할 수 있다.

- 계약된 자산매각과 세후 대금의 사용계획
- 자사주 매입이 아닌 소각, 특별배당, 공개된 자본배분 정책
- 확정된 요금·규제 변경
- 행동주의·지배구조 변화·분할·청산처럼 통제권에 영향을 주는 사건
- 현금소진 중단과 반복 가능한 잉여현금흐름 전환

소문·검토·예고는 촉매 후보일 뿐 확정 촉매가 아니다. 통과·부결 시나리오와 무효화 조건을 나눈다.

## 5. 판정

| 상태 | 판정 |
|---|---|
| 회수가능 자산이 시총을 충분히 상회하고 청구권·촉매가 확인됨 | `candidate` |
| 자산 할인은 있으나 촉매 또는 주주 귀속이 약함 | `watch` |
| 영업필수 전용자산·규제·현금소진이 할인을 설명함 | `avoid` 또는 장기 관찰 |
| 자산 세부·담보·연결부채·현금흐름이 없음 | 가치 실현 축 `abstain`·판정 보류 |

판정 보류 상태에서 PBR만으로 저평가를 확정하거나 적정가격을 만들지 않는다.
