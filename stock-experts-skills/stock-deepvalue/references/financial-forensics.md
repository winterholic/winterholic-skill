# 레퍼런스(심화) — 재무 포렌식 (Piotroski F·Altman Z·Beneish M·발생액)

> 목적: 딥밸류의 최대 적인 **value trap·분식**을 정량 스코어로 사전 차단. "싼 데는 이유가 있다"를 검증.
> 웹 출처: GuruFocus·Wikipedia(F-score), Wikipedia(Altman Z·Beneish M), drwealth.

## 1. Piotroski F-Score (재무 건전성, 0~9)

가치주 중 **재무가 개선되는 진짜 저평가**를 가려냄. 9개 신호 합산:
- **수익성(4)**: ROA>0 / 영업현금흐름>0 / ROA 개선 / 영업CF>순이익(발생액 양호).
- **레버리지·유동성(3)**: 장기부채 감소 / 유동비율 개선 / 신주발행 없음.
- **운영효율(2)**: 매출총이익률 개선 / 자산회전율 개선.
- 해석: **8~9 강함 / 0~2 약함**. 저PBR + 고 F-score 조합이 초과수익(연구상 시장 대비 +α).

## 2. Altman Z-Score (부도 위험)

- 5개 재무비율 가중합. **Z < 1.8 부도 위험 높음 / Z > 3.0 안전**.
- 딥밸류 net-net 후보의 청산·부도 리스크 1차 필터.
- 변형: Z'(비제조), Z''(이머징·비상장).

## 3. Beneish M-Score (분식 탐지)

- 8개 변수로 이익 조작 가능성 추정(발생액 가중 4.679로 큼).
- **M > −1.78 → 조작 의심**. (코넬대 학생들이 1998년 Enron을 M-score로 사전 식별한 사례.)

## 4. 발생액(Accruals) & 현금전환

- 순이익 ≫ 영업현금흐름(높은 발생액) = 이익의 질 의심(미래 수익률 낮음 — accruals anomaly).
- 현금전환주기·재고/매출 급증·매출채권 급증을 적신호로.

## 5. 통합 사용 (value trap 게이트)

1. Beneish M로 분식 의심 배제 → 2. Altman Z로 부도 위험 배제 → 3. Piotroski F로 재무 개선 확인 → 4. 그 다음 NCAV·DCF 밸류에이션.
- 단일 스코어 맹신 금지 — **사업 질·경쟁구도 정성 분석과 병행**.

## 6. KRX 적용

- 한국 회계는 보수적이나 한계기업·관리종목 분식 사례 존재 → Beneish·Z로 1차 스크린.
- 자산재평가·계열거래로 비율 왜곡 가능 → 연결·별도 재무 모두 확인.
- 감사의견(한정·거절)·계속기업 불확실성 주석을 정량 스코어 전에 우선 점검.

## 7. 비판과 한계

스코어는 과거 재무 기반 — 산업 특성(은행·보험은 Z 부적합)·일회성 항목에 취약. M-score는 위양성·위음성 모두 발생. **확인 필요**: 가중치·임계는 원논문 재확인 권장. 스코어는 배제용 필터이지 매수 신호가 아님.

## 8. 밸류트랩 판별 — 2024~2026 최신 흐름 (스크리너 구현용)

자동 스크리너에서 "싸다"와 "밸류트랩"을 가르는 최신 실증적 접근을 정리. 상세는 SKILL.md `## 스크리너 구현 가드레일` 참조.

- **F-Score + 주주환원 + 모멘텀 3요소 결합**: 단일 저PBR·저FCF yield 스크린보다 F-Score(재무 개선)·shareholder yield(배당+자사주)·모멘텀(가격·이익 개선 방향)을 함께 요구하는 스크린이 밸류트랩을 유의하게 더 잘 걸러낸다는 결과가 반복 확인됨 (Quant-Investing "How To Master Deep Value Investing"; Alpha Architect F-Score 개선 연구 — 확인 필요: 정확 초과수익 수치·표본기간).
- **부정적 품질 스크린이 유리**: "좋은 회사를 골라 담기"(긍정 스크린)보다 "나쁜 회사를 제외하기"(저품질·센티먼트 모멘텀 배제, 부정적 스크린)가 가치 팩터의 초과수익 노출을 덜 훼손하면서 밸류트랩 회피 효과가 크다 — 32년(미국) 데이터 기준 (Research Affiliates, "Active Value Investing: Avoiding Value Traps", PDF, 확인 필요: 정확 발행연도).
- **원논문(Piotroski 2000) 핵심 수치**: 1976~1996 미국 표본에서 저F-Score 가치주 대비 고F-Score 가치주가 연 **+7.5%p** 초과 성과 — 이 수치가 "F-Score를 반드시 게이트로 써야 하는" 근거로 가장 자주 인용됨.
- **스크리너 구현 시사점**: (1) 정적 저PBR/저PER만 통과 기준으로 쓰지 말 것 (2) F-Score 최소 임계(예 ≥5) + 주주환원 지표(배당성향 또는 자사주 매입률 하한) + 3년 이익 추세(적자 지속 배제)를 동시 게이트로 결합 (3) 그래도 동일 종목이 장기간(예 20영업일+) 반복 통과하면 "저평가 신호"가 아니라 "게이트가 그 저평가의 구조적 원인(규제산업·정책주·지주 디스카운트)을 못 잡아낸다"는 신호로 보고 정성 재검토로 넘길 것.
