# 레퍼런스(심화) — 추세 분석 도구 모음 (지표·시장폭·다중시간대)

> 목적: Weinstein 스테이지 분석을 보완하는 **추세 판별 지표·시장 내부지표(breadth)·다중시간대** 도구. 차트 데이터를 다각도로 교차검증하기 위함.
> 웹 출처: investopedia/Dow theory(bookmap·fidelity·ebc), tradeciety(지표 조합), forex.com(지표).

## 1. Dow Theory (추세 분석의 뿌리)

6대 원칙: ①평균은 모든 것을 반영 ②시장은 3추세(주·중·소) ③주추세 3국면(축적→대중참여→분배) ④**두 평균(산업·운송)의 상호 확인** ⑤**거래량이 추세를 확인** ⑥반전 신호 전까지 추세 지속.
- 핵심 실전: 고점·저점 구조(higher high/higher low = 상승추세) + **지수 간 다이버전스**(한 지수만 신고가 = 반전 경고).
- Weinstein Stage 2 = Dow의 "대중 참여 국면", Stage 3 = "분배 국면"에 대응.

## 2. 추세 지표 (Stage 판별 보강)

| 지표 | 용도 | 실전 기준 |
|---|---|---|
| 이동평균 정렬(MA stack) | 추세 방향·강도 | 주가>50일>150일>200일 + 200일 상승 = 정상 상승추세 |
| **ADX / DMI** | 추세의 *강도*(방향 아님) | ADX>25 추세장, <20 횡보. +DI>−DI 상승 |
| MACD | 추세 전환·모멘텀 | 시그널선 상향 교차=매수, 0선 위=상승국면 |
| 이동평균 기울기 | Stage 1↔2 전환 포착 | 30주선 평탄→상향 = Stage 2 진입(Weinstein) |

> **조합 원칙**: 같은 범주 지표를 겹쳐 쓰지 말 것(RSI+스토캐스틱=중복). **추세지표(MA·ADX) + 모멘텀 확인 + 거래량** 으로 서로 다른 차원을 본다.

## 3. Relative Strength & Point & Figure

- **RS 라인**(Mansfield): 종목/지수 비율. 신고가 추세 + RS 0선 위가 주도주 조건.
- **Point & Figure**: 시간·노이즈 제거, 횡보 폭(원인)으로 목표가(결과) 측정 — Wyckoff 원인-결과 법칙과 연결.

## 4. 시장 내부지표 (Breadth) — "시장 전체 Stage" 판정

개별 종목보다 시장이 Stage 2인지가 승률을 좌우(Weinstein). breadth로 교차검증:
- **A/D Line**(등락주선): 상승–하락 종목 누적. 지수 신고가인데 A/D 하락 = 내부 약화.
- **신고가/신저가**(New Highs vs Lows): 신저가 급증 = 추세 약화.
- **200일선 위 종목 비율**: 50% 상회 = 광범위 상승.
- **McClellan Oscillator/Summation**: A/D의 단기 모멘텀.

## 5. 다중 시간대(Multi-Timeframe) 분석

상위 시간대로 추세 방향 결정 → 하위 시간대로 진입 타이밍. 예: 월봉·주봉으로 Stage 판정 → 일봉 base breakout에서 진입. 상위 추세를 거스르는 하위 신호는 신뢰도↓.

## 6. 정보 활용 (추세 + 외부 데이터)

- 거래대금·외국인/기관 순매수 추세를 거래량 확인의 보조 증거로.
- 섹터 RS 순위로 "강한 섹터의 강한 종목"만 선별(top-down 결합 → [[stock-sector-rotation]]).

## 7. KRX 적용

- 한국은 운송지수 대신 코스피/코스닥·대형/소형 간 확인, 외국인 수급으로 Dow의 "참여" 판정.
- breadth는 KRX 등락주선·신고가 종목 수로 산출. ±30% 제한·테마 쏠림으로 신고가/신저가 노이즈 큼.

## 8. 비판과 한계

지표는 모두 후행(lagging) — 추세 확인엔 좋으나 전환 선행은 약함. breadth 다이버전스는 수개월 지속 가능(타이밍 도구 아님). 지표 과다는 분석마비·곡선맞춤 위험 → 2~3개 서로 다른 차원만.
