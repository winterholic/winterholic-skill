# 레퍼런스(검증·거장 노하우) — 팩터 투자 실증 실적 & 마스터 플레이북

> 목적: 팩터 프리미엄의 **장기 실재성**과, 그것을 누리려면 **다년 드로다운(value winter)을 견뎌야** 한다는 거장의 규율을 흡수한다.
> 출처(웹 검증): AQR(Asness) value drawdown 자료·Institutional Investor, Fama-French·Carhart, "Quality Minus Junk". 1차 출처 재확인 권장.

## 1. 실증 — 프리미엄과 그 대가

| 사실 | 내용 |
|---|---|
| 팩터 프리미엄 장기 실재 | Value·Momentum·Quality·Low-Vol 등 60년+·수십 시장에서 양의 위험조정수익(Fama-French·AQR) |
| **Value Winter (2018–2020)** | AQR 대표전략 고점 대비 **−38.7%**(2018.1–2020.11). 성장-가치 격차가 **1991년 이후 3퍼센타일 미만**의 극단 |
| 회복 | 2021~ 가치 반등·추세추종 호조로 강한 회복 |
| 팩터 타이밍 | Arnott 등: **타이밍은 상시 배분보다 나빴다** |

**핵심 해석**:
- 팩터는 **공짜 점심이 아니다** — 엣지의 대가로 **수년의 고통(−38.7% value winter)** 을 치른다.
- Asness: "**endurance, not elegance**(우아함이 아니라 인내)가 실행 가능한 전략과 학술적 호기심을 가른다." 드로다운을 못 견디면 바닥에서 항복한다.

## 2. 거장 플레이북 (Cliff Asness / AQR)

- **3번의 퀀트 위기**(1998 LTCM 여파, 2007 quant quake, 2018–20 value winter)를 견디고 살아남음.
- **규율을 지키되 과신 안 함**: value winter 중 오히려 가치 비중을 늘림(역발상), 단 "venial sin"(가벼운 죄)이라며 소량 팩터 타이밍의 한계 인정.
- **다중 팩터 분산**: 단일 팩터(가치)의 긴 겨울을 모멘텀·퀄리티·추세가 상쇄.

## 3. 시니어 의사결정 체크 (이 스킬의 핵심)

1. **−30%+ 다년 드로다운을 견딜 인내·자본**이 있는가? (없으면 바닥 항복 → 엣지 실현 실패)
2. **다중 팩터로 분산**했는가? 단일 팩터 겨울을 다른 팩터가 메운다.
3. **팩터 타이밍을 자제**하는가? (상시 배분 > 타이밍, 단 극단 밸류에이션은 약한 신호)
4. **net으로 검증**했는가? 거래비용·세금·용량 차감(→ [[backtesting-methodology]]·[[harris-kissell-execution]]).
5. **α의 t-stat**으로 진짜 알파와 팩터 노출(스마트베타)을 구분했는가?

## 4. KRX 적용

- 한국 Value·Momentum 유효(IMF 전후 구조변화). 소형주 거래비용·공매도 제약 → long-only tilt. 가치+퀄리티 결합 비교적 안정(강환국 PER+GP/A).
- 한국도 value winter 동조(글로벌 성장주 랠리기) → 인내·분산 동일 적용.

## 5. 비판·한계 (정직하게)

- 팩터 프리미엄은 **수년 부진 가능**(value 2010–2020). 크라우딩·공개로 감소(decay). in-sample·생존편향.
- AQR도 value winter에 큰 손실 — "교과서 프리미엄"과 "실현 수익"의 격차는 인내·실행에서 갈린다. 과거 실증, 미래 보장 아님.
